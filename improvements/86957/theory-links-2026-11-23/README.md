## Как принята связность

[LINKS.md](LINKS.md) объясняет результат проверки шести линий:

1. Программа → компиляция → линковка → библиотека.
2. Значение → объект → диапазон → время жизни.
3. Контракт функции → инвариант типа → операции класса.
4. Время жизни → владение → RAII.
5. Категория выражения → привязка ссылки → копирование/перемещение.
6. Алгоритм → стоимость → структура данных → стандартный контейнер.

Четыре отчёта `review_foundations.json`, `review_types.json`, `review_ownership.json`, `review_algorithms.json` фиксируют исходные ID и SHA-256, фактическую глубину чтения, выводы и источники. Все 50 изменений дополнительно прочитаны другим участником; отчёты `review_*_independent.json` привязаны к окончательным файлам. Независимая проверка нашла один неверный новый адрес конструктора; он исправлен и повторно принят.

[review_links.json](review_links.json) фиксирует окончательные file/text SHA-256 **всех 283 эффективных текстов** и хеши редакторских заключений. Автоматический контроль проверяет эти привязки, но не выдаёт наличие ссылки за доказательство правильности её смысла.

**SCOPE:** [review_scope.json](review_scope.json) повторно подтверждает 37 исходных текстов: 12 functions и 25 quality. Задания в них ранее превращены в законченные разборы либо исключены; простого переименования заголовков не осталось. Новых адаптаций в этой сессии — **0**. Девять из этих ID получили адресные уточнения LINKS, без повторного зачёта прежней работы.

Запускать из корня репозитория. Для новых проверок нужны Python 3.10+, GCC с C++17/C++20 и UBSan. README и `verify.py` каждого набора описывают его точные границы.

```bash
python3 tools/build_theory_upgrade.py --check
python3 improvements/86957/theory-links-2026-11-23/examples/types/verify.py
python3 improvements/86957/theory-links-2026-11-23/examples/ownership/verify.py

python3 tools/verify_theory_links.py
python3 tools/render_course_tree.py
python3 tools/render_course_tree.py --check
```

Для отдельного протокола контроль поддерживает `python3 tools/verify_theory_links.py --report ПУТЬ`. Пакет зарегистрирован в `PACKAGES` генератора дерева. Дерево после пересборки совпадает с опубликованным снимком: подготовленные правки не помечаются опубликованными.

Исторические `validation.json` не заменялись. Полные старые наборы T1/T3/T6 и продолжения, CMake/GoogleTest, Windows/MSVC, macOS и существующие оценочные программы в этой сессии не запускались. `cmake` отсутствовал в PATH; новый пакет не меняет CMake-примеры и не требует их повторного запуска. Содержательное чтение всех 283 текстов не означает новую компиляцию каждой старой программы или построчную формальную сертификацию курса.
