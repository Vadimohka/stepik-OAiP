## Авторская проверка

`python3 tools/build_theory_upgrade.py --check` сверяет неизменяемые исходные копии с деревом закреплённого коммита, разрешённые поля и ссылки между шагами. Проверки кода находятся в `examples/t1`, `examples/t3` и `examples/t6`: исходник объяснения должен совпадать с проверяемым файлом.

Нужны Python 3.10+, GCC с C++17/C++20 и CMake 3.22+. CMake можно указать переменной окружения `CMAKE`. Проверка GoogleTest в T3 использует закреплённую версию из официального репозитория; первый запуск требует сети. Windows/MSVC и macOS в текущей среде не запускались.

Эти проверки служат качеству теории. Они не создают учебные задания и не обращаются к прогрессу или решениям учащихся. Локальная проверка сама по себе не означает публикации: для неё требуется отдельная сверка через API Stepik и обновление снимка.
