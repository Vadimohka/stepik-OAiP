# Согласование с параллельными изменениями main

Перед первой отправкой этих пакетов в GitHub ветка `main` получила два новых коммита. Подготовленные пакеты перенесены с `d936c0ee8d9f720ba26fec1b109a1153ae3b5930` на [7a7db0a](https://github.com/Vadimohka/stepik-OAiP/commit/7a7db0a3061f9316cc6ae19c1b6c1d7f28888ee4), который содержит снимок после публикации 24 точечных исправлений.

Из 29 выбранных исходников изменился только шаг **3215206**: в примере дозаписи неразрывные пробелы заменены обычными, а поле `time` отражает новую выгрузку. Остальные 28 исходников совпадают с первоначально прочитанными GitHub blob SHA.

До первой публикации пакета baseline этого шага заменён точными байтами нового исходника, поле `time` нового варианта сохранено из него. Изменение учебного содержимого по-прежнему ограничено `block.text`. Новые примеры дозаписи используют корректный `std::ios::app`; ранее опубликованное исправление не возвращается.

Изменения README и регистрация пакета `corrections/86957` сохранены. Дерево курса пересобрано и проверено с учётом всех ранее опубликованных пакетов; новые пакеты не отмечаются как опубликованные на Stepik.

Этот перенос относится только к ещё не отправленным пакетам текущей работы. Проверки неизменности baseline и защиты ранее опубликованных пакетов в инструментах не ослаблялись.
