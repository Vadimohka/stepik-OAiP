Это позволяет проверить не только техническую правильность, но и то, что
задание проверяет объяснённое ранее понятие.

## Какие данные сохранены

ID шага, время исходного снимка, тип блока, настройки одиночного/множественного
выбора, порядок/перемешивание, размер выборки и число вариантов сохранены.
Изменены только текст задания, тексты/правильность/обратная связь вариантов,
общая обратная связь и включение обратной связи по вариантам.

`baseline/` содержит исходные `.step` для воспроизводимого сравнения. Проверяющий
скрипт удаляет из обеих структур только разрешённые к редактированию поля и
сравнивает всё остальное, поэтому случайное изменение настройки задания
приведёт к ошибке проверки.

## Локальная проверка

Из корня репозитория:

```bash
python3 improvements/86957/assessment-2026-11-23/verify.py \
  --report improvements/86957/assessment-2026-11-23/validation.json
```

Нужны Python 3 и компилятор `g++`; другой совместимый компилятор можно передать
через `--cxx`. Для явного сравнения с другим исходным снимком предусмотрен
`--baseline PATH`, а для соседних текстовых уроков — `--context PATH`.

Проверка включает:

- сохранение всех полей вне разрешённого набора и прежнего количества вариантов;
- соответствие ключей независимо заданным редакторским ожиданиям;
- 3088 подмножеств выбора в исходном порядке и ещё 6176 после двух перестановок;
- наличие обратной связи, обоснований и 34 фрагментов контекста в текстах уроков;
- точное совпадение встроенной программы вопроса 4718246 с файлом
  `examples/move_const_vector.cpp`;
- сборку этой программы в C++17 и C++20 с
  `-Wall -Wextra -Wpedantic -Werror` и проверку вывода `4 1`.

Проверки подмножеств подтверждают согласованность локальных авторских ключей.
Проверки контекста подтверждают наличие указанных объяснений, а не заменяют
методическую вычитку. Скрипт не проверяет реальный интерфейс, начисление баллов
или поведение оценивания Stepik. После переноса задания на платформу эти
свойства нужно сверить отдельно, а затем обновить снимок и статус публикации
по правилам `AGENTS.md`.
