### Значение приоритетов

- **P1** — неверное оценивание, недоопределённая задача, существенная ошибка работающего алгоритма или пример с опасным обращением к памяти/данным. Исправлять первым пакетом.
- **P2** — неверное или неоднозначное объяснение, непереносимый пример, ошибка компиляции в отдельном листинге, несогласованные ограничения. Исправлять при обновлении соответствующего урока.
- **P3** — редакторская и оформительская правка без изменения основного алгоритма.

Приоритет отражает влияние на учебный процесс, а не количество опечаток. Одна запись может охватывать несколько неверных флажков одного теста или повтор одного тезиса в нескольких шагах.

## Порядок обновления

1. Исправить P1 в ключах и численных проверках. Добавить пары «корректный ответ / заведомо некорректный ответ» для повторной проверки в редакторе Stepik.
2. Согласовать платформу курса: разумная базовая цель — ISO C++20; в отдельных заданиях C обозначить явно. Для sizeof, char, упаковки и адресов дополнительно назвать ABI и настройки. Это предложение для обновления, а не уже принятое автором решение.
3. Пересобрать исправленные учебные листинги. Для указателей и владения заменить примеры с неопределённым поведением, уточнить std::vector/std::string и RAII там, где это соответствует программе.
4. Согласовать условия задач с входными данными, границами, округлением и пробелами. Числа проверять с объявленной точностью; для матриц сравнивать числовые токены.
5. После содержательных исправлений провести сплошную литературную редактуру и отдельный проход по видео. Обновить отсутствующую иллюстрацию и повторно выгрузить курс для сравнения.

## Что проверка не утверждает

Это завершённый первый проход по тексту и авторским источникам, а не сертификат корректности курса. Видеозаписи не просмотрены полностью; не каждый листинг компилировался, и решения не отправлялись на живой Stepik. Код с заведомым неопределённым поведением проверялся по правилам языка, а не по случайному результату запуска. Подробные ограничения и не подтвердившиеся подозрения описаны в coverage.md и checks/README.md.
