# Применение исправлений к существующим шагам

Пакет опубликован. После применения всех 24 правок сверены авторские блоки и представление для учащихся.

## Перед применением

1. Откройте [журнал изменений](CHANGES.md) и [превью](preview.html).
2. Для каждого шага используйте его постоянный `step_id`, `lesson_id` и `position`
   из манифеста. Сохраните актуальный авторский блок перед заменой.
3. Сравните актуальный блок с `before_block_sha256`. Если он отличается,
   сначала сопоставьте изменения с новым содержимым: нельзя затирать внесённые
   после снимка правки. Контрольная сумма вычисляется по UTF-8 JSON блока с
   `ensure_ascii=False`, `sort_keys=True`, `separators=(',', ':')`.

## Что переносить

Обновляйте существующий шаг на месте. Импорт файла как нового шага создаст
другой ID и не заменит существующее задание.

В манифесте у каждого шага перечислены точные `changed_fields`:

- Для теоретических примеров и уточнений условия переносится `block.text`.
- Для задач с ошибкой проверки переносится `block.source.code` из расширенного
  редактора. У задачи «Реформа» также добавлены три набора в `block.source.test_cases`.
- Для вопроса о буквальном выводе программы меняется настройка учёта регистра.

Сверяйте список полей с манифестом, сохраняя ID, урок, позицию и остальные
настройки шага. Для восстановления исходной версии есть каталог `baseline/`.
Авторские `.step` содержат полные блоки, включая закрытые тесты, поэтому
это пакет для преподавателя.

## После применения

1. Повторно получите авторские `step-sources` и ученическое представление
   изменённых шагов. Сверьте авторский блок с `after_block_sha256` и проверьте
   отображение текста, кода, формул и пробелов.
2. Для изменённых проверяющих функций выполните правильные решения и
   отрицательные примеры из `evidence/` уже на Stepik. Это отдельная проверка
   от локального вызова Python-функции `check`.
3. После подтверждения обновите снимок `courses/86957/`, экспортный манифест и
   читаемые материалы. В манифесте этого пакета запишите
   `publication.status: verified_on_stepik`, `applied: true`, время и результат
   сверки. До такой сверки статус публикации не меняется.
4. Выполните команды из `AGENTS.md` и включите дерево в тот же коммит, что
   снимок и статус публикации:

```bash
python3 tools/render_course_tree.py
python3 tools/render_course_tree.py --check
```
