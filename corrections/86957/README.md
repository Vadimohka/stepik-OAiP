## Проверка результата

Общий запуск проверяет точные ID, уроки, позиции, контрольные суммы и заявленные
изменяемые поля. Пока пакет не опубликован, весь каталог `courses/86957/`
сравнивается с исходным Git-коммитом. Множество исправленных файлов должно точно
совпадать с манифестом; архив создаётся только из проверенного набора файлов.

Тесты воспроизводят ошибки исходных примеров и проверяют исправленные варианты.
Они включают GCC в C++17/C++20 и C11/C17 для двух примеров на C, ASan/UBSan
для выбранных случаев, инъекции отказа выделения памяти, правильные и неправильные
ответы для grader. Для AVL и RBT выполнено по 20 000 операций с проверкой
структурных инвариантов и сравнением со `std::map`.

В существующих 48 задачах было 433 сохранённых набора. Структурно проверены все;
независимо пересчитаны 398 наборов в 46 задачах. Сохранённые ответы в этой части
согласованы с условиями. В «Реформу» добавлены три проверки значимых пробелов,
поэтому после применения пакета сохранённых наборов будет 436. Прежние наборы
сохранены без изменений. Подробные границы проверки приведены в [COVERAGE.md](COVERAGE.md).

Для воспроизведения нужен полный Git-checkout этой ветки, Python 3.10+, Git,
GCC/G++ с поддержкой используемых режимов и санитайзеров. Команда из корня:

```bash
python3 tools/verify_corrections.py
```

Режим `--structural-only` проверяет структуру и не создаёт отчёт об успешном
полном прогоне. Для пересборки пакета после редактирования:

```bash
python3 tools/build_corrections_package.py
python3 tools/render_course_tree.py
python3 tools/verify_corrections.py
python3 tools/build_corrections_package.py --archive
```

ZIP — пакет для переноса изменений, а не полный репозиторий. Повторение всего
аудита требует исходного снимка, ресурсов и прежних регрессионных проверок из
репозитория. Бинарные исполняемые файлы в пакет не входят.

## Практические границы

Основное окружение — Linux, GCC 14.2.0. Windows/MSVC и проверяющая среда Stepik
не запускались. LeakSanitizer в текущей среде несовместим с ptrace; для выбранных
путей отказа память учитывается отдельными счётчиками. Протоколы не утверждают,
что просмотр и тестирование доказывают отсутствие всех возможных ошибок курса.

Перед применением нужно обновлять существующие ID, а после него — сверить
авторские блоки и отображение на Stepik. Инструкция учитывает `AGENTS.md` и
последующее обновление дерева опубликованного курса.
