# Выгрузка курса 86957

Авторизованная выгрузка получила карточку курса, 20 модулей, 62 размещения уроков, 62 урока, 485 шагов и 485 авторских файлов `.step`. Генератор вычитки не обнаружил пропусков. [Манифест выгрузки](courses/86957/manifest.json) показывает `content_status: complete`.

Из 200 медиассылок скачано 189 файлов. Четыре ссылки внешние, шесть указывают на альтернативные варианты медиа, один ресурс вернул HTTP 404. Поэтому общий статус — `partial`. Подробности в [манифесте медиа](courses/86957/assets/manifest.json).

Тексты комментариев и ответов, профили и решения учащихся, записи их прогресса и отдельные отчёты статистики не выгружались. В исходных объектах остались поля API со счётчиками и идентификаторами обсуждений и ссылками на записи прогресса.

## Что остановило работу

| Запрос | Наблюдавшийся результат |
|---|---|
| `POST https://stepik.org/oauth2/token/` | HTTP 403, HTML `Access Blocked`; токен не получен |
| `GET https://stepik.org/api/courses/86957` | HTTP 200, JSON карточки курса |
| `GET https://stepik.org/api/sections/256603` | HTTP 403, HTML `Access Blocked` |
| Пакетный запрос 20 модулей через `GET /api/sections?ids[]=…` | HTTP 403; дальнейшие API-запросы экспортёра прекращены |
| Страница курса в браузере | Осталась на состоянии «загрузка…», редактор не открылся |

Это не JSON-ответ OAuth `invalid_client`. По полученной странице нельзя сделать вывод, что Client ID или Client Secret неверны, и нельзя проверить преподавательские права. Повторные попытки обхода блокировки не выполнялись.

## Отсутствующие материалы

Все 62 урока, их шаги, тексты и примеры кода, авторские `step-sources`, ответы, тесты и файлы `.step` пока не выгружены. Изображения, вложения и видео уроков также не получены: ссылки на них нельзя собрать без содержимого уроков.

В `manifest.json` это отражено как `status: partial`, `content_status: partial` и `author_sources_unavailable: true`. Неизвестное число шагов не приравнивается к нулю. Текущую папку нельзя считать полной резервной копией или материалом для полноценной вычитки курса.

## Подготовлено для продолжения

Для повторного запуска в репозиторий включены экспортёр без сторонних зависимостей и отдельный генератор документов для чтения. Для продолжения выполните команды из [README](README.md) на своём компьютере. Если там API разрешит доступ, экспортёр заполнит ту же структуру каталогов; ключи вводятся локально со скрытым вводом и в выгрузку не сохраняются.
