# Применение подготовленного пакета

## Текущий статус

Пакет из 32 текстовых шагов применён и проверен через API Stepik. [Снимок курса](../../courses/86957/)

В репозиторий не включены ключи и токены. Инструмент выгрузки запрашивает их скрытым вводом либо получает из переменных окружения процесса.

## Перед обновлением существующих шагов

1. Восстановить авторизованный доступ аккаунта преподавателя к курсу. Настройки приложения и допустимый OAuth flow проверяются по [официальной справке Stepik](https://help.stepik.org/article/64188).
2. Получить новый авторский снимок в отдельный каталог, например:

   ```bash
   python3 tools/export_stepik.py --course 86957 --output exports/86957-before-modernization --fresh --skip-assets
   ```

   Эта команда читает материалы и не публикует изменения. `--skip-assets` означает, что новая проверка медиа не выполняется. Команда относится к полному репозиторию, где находится экспортёр.

3. Для каждого ID из `manifest.json` сверить курс, урок, позицию и авторский `block` свежего снимка с `baseline/`. Манифест содержит `before_block_sha256`; хеш считается по UTF-8 представлению `json.dumps(block, ensure_ascii=False, sort_keys=True, separators=(',', ':'))`. Любое расхождение нужно сначала разобрать: после подготовки пакета преподаватель мог внести новые изменения.
4. Пройти локальную проверку по `README.md`, просмотреть `preview.html` и соответствие соседним оценочным шагам. Сохранить свежие исходники для восстановления.

## Что именно применять

Обновляются **тексты существующих шагов**, перечисленных в манифесте. `.step` хранит авторский блок и исходный ID. Не нужно создавать новые уроки, менять порядок, переносить учащихся или заново создавать шаги: это другой тип операции с иными последствиями.

При использовании авторского редактора следует открыть конкретный существующий шаг по ссылке из `CHANGES.md`, заменить его HTML-текст и сохранить остальные параметры. Если используется API, обновление должно выполняться через авторский ресурс `step-sources` с сохранением исходного полного блока и метаданных; сначала необходимо сверить актуальную документацию и права записи. В этом пакете нет проверенного на живом сервисе автоматического загрузчика, поэтому наличие `.step` не означает, что его можно импортировать любым способом с сохранением прежнего ID.

## Подтверждение результата

После сохранения заново прочитать авторский источник и представление для учащегося. Проверить ID, урок, позицию, состояние шага и новый текст. Stepik может нормализовать HTML; сравнение нужно дополнить осмотром кода, таблиц, ссылок и самопроверок. Остальные поля блока должны остаться прежними.

После применения всего пакета получить свежий экспорт и обновить `courses/86957/`, читаемые представления и `EXPORT_STATUS.md`. До этой сверки статус пакета остаётся подготовленным, а опубликованный снимок в репозитории не подменяется проектом изменений. При частичном применении фиксируются конкретные успешно обновлённые ID и остаток; общий статус не объявляется завершённым.

Для восстановления выбранного текста использовать соответствующую сохранённую версию `baseline/`, предварительно проверив, что с момента применения не было других авторских изменений. История Git сохраняет полный исходный снимок.
