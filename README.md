## Полная выгрузка на своём компьютере

Нужен Python 3.10 или новее. Оба инструмента используют только стандартную библиотеку; устанавливать пакеты через `pip` не требуется.

Откройте терминал в корне скачанного или клонированного репозитория и выполните:

```bash
python tools/export_stepik.py --course 86957 --output exports/86957-new --fresh
```

Если команда `python` не найдена, на Windows обычно используется `py`, а на macOS/Linux — `python3`.

Скрипт запросит **Client ID** и **Client Secret** без отображения ввода. Они хранятся в памяти процесса и не записываются в выгрузку. Используйте приложение Stepik типа `Confidential` с `Authorization grant type = Client credentials` в аккаунте с правами преподавателя этого курса.

Для автоматического запуска поддерживаются переменные окружения процесса:

- `STEPIK_ACCESS_TOKEN`; либо
- `STEPIK_CLIENT_ID` и `STEPIK_CLIENT_SECRET`.

Значения этих переменных в репозитории отсутствуют. Ключи и токены не нужно добавлять в файлы проекта.

Новый каталог `exports/86957-new` позволяет сохранить подготовленные исправления в `courses/86957/steps/`. Сначала проверьте итоговый `exports/86957-new/manifest.json`. Поле `status: complete` означает завершение предусмотренной инструментом выгрузки; при `partial` необходимо смотреть `errors`, `missing_ids` и статусы медиа. Нулевой код завершения с `--skip-assets` подтверждает только получение содержимого, а не файлов медиа.

После получения уроков создайте документы для вычитки:

```bash
python tools/review_renderer.py exports/86957-new/course.json
```

В `exports/86957-new/review/` будут созданы `index.md`, `course.md`, `course.html` и отдельные файлы `lessons/<ID>.md`. Исходные блоки API остаются в `raw/`; читаемая версия их не заменяет.

Чтобы передать выгрузку одним архивом:

```bash
python -m zipfile -c stepik_86957.zip exports/86957-new
```

В архив попадает только каталог материалов курса. Полученный ZIP можно передать на вычитку.

## Что экспортирует инструмент

Экспортёр проходит структуру курса по ID: курс → модули → размещения уроков → уроки → шаги. Полученные ID сверяются с запрошенными. Сохраняются полные JSON-объекты, их объединённая версия и файлы `.step` из авторского `step-sources.block`. Публичное представление шага не подставляется вместо отсутствующего авторского исходника.

Медиассылки извлекаются из блоков и HTML. Доступные HTTPS-файлы сохраняются с SHA-256, размером и MIME-типом. Для видео выбирается максимальное доступное качество; все исходные варианты ссылок остаются в raw. Внешние веб-плееры и страницы фиксируются как ссылки. Файлы больше 95 MiB отмечаются как `oversized` и требуют отдельного решения для хранения.

Учебное содержимое Stepik инструмент не меняет. Единственный POST нужен для получения OAuth-токена, затем выполняются GET-запросы. Тексты комментариев, ответы в обсуждениях, профили и решения учащихся, их прогресс и отдельная статистика не запрашиваются. Исходные объекты API могут содержать счётчики, идентификаторы обсуждений и ссылки на записи прогресса.

## Повторный запуск и проверка полноты

Без `--fresh` используются уже сохранённые raw-объекты. С `--fresh` перечисленные в новом снимке объекты запрашиваются заново. Старые файлы, которых больше нет в структуре курса, автоматически не удаляются: текущий состав определяется `course.json` и манифестом. Для независимого снимка можно указать новый каталог через `--output`.

`expected_counts: null` означает, что из-за недоступного родительского объекта невозможно установить общее число дочерних объектов. `observed_expected_counts` содержит только известную нижнюю границу, а `declared_counts` — количества, заявленные в карточке курса.

Режим `--public` работает без OAuth и всегда отмечается как частичная выгрузка. Он не заменяет преподавательский экспорт. При HTTP 401/403 дальнейшие API-запросы прекращаются. Повторная блокировка при локальном запуске также не означает успешную выгрузку или доказанную ошибку ключа.
