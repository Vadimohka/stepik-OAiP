## Как повторить

Требуются Python 3 и `g++` с поддержкой C++17/C++20. Запускайте из корня клонированного репозитория:

```sh
python3 imports/86957/validation/round2/advanced/advanced_round2_validate.py --structural-only
python3 imports/86957/validation/round2/advanced/advanced_round2_validate.py
```

Первый запуск проверяет покрытие, JSON, неизменность ID/`time`/типа, полноту журнала, число правильных вариантов, HTML-экранирование и неизменность ранее проверенных алгоритмов. Второй дополнительно выполняет 32 проверки компиляции/запуска. Отдельную группу можно выбрать регулярным выражением:

```sh
python3 imports/86957/validation/round2/advanced/advanced_round2_validate.py --case 'question_'
```

Корень проекта находится по родительским каталогам `__file__`; при необходимости можно передать `--root /path/to/repository`. Ни сеть, ни Git-история для повторения не нужны. `advanced_baseline.json` содержит контрольные суммы и метаданные версии `8bf4639ce2799a13146e22ed13cf103dd1916ad5`, с которой сравнивался второй проход. Валидатор не импортирует скрипты редактирования и не изменяет `.step`.

Проверки читают текущие фрагменты непосредственно из курса. В `advanced_checks/` сохранены **16 минимальных исходников** — по одному на логический случай; каждый проверяется в двух стандартах. При запуске там создаются исполняемые файлы и диагностические `.log`, а соответствующий JSON-протокол обновляется рядом со скриптом. Успешно скомпилированный `question_cast_after_printer_fix.cpp` намеренно **не запускается**: в нём остаётся UB, которое учащийся должен распознать.

## Что проверено и где остаются границы

Проверены позиционирование `fseek` и запись в режиме append; размеры структур при указанном ABI; формат вывода битовых полей; начало времени жизни члена `union`; два читающих примера `const_cast`; отдельные правила конструкторов, копирования, `inline static`, абстрактных классов, ссылок, постфиксного `operator++`, присваивания через ссылку и `enum`; все четыре случая AVL-вращений и удаления с проверкой ключей, значений, высот и баланса. Дополнительно проверена допустимость агрегатной инициализации со снятыми вложенными скобками.

Сборки выполнены локальным GCC 14.2.0 в C++17/20. MSVC не запускался; численные размеры относятся к явно оговорённому ABI. Ошибочные примеры проверялись только компиляцией, без исполнения UB. Полная матрица алгоритмических регрессий первого прохода заново не запускалась; соответствующие фрагменты shared/weak, RBT и hash автоматически сверены на неизменность. Текстовые утверждения также проверялись по ссылкам на первичные материалы, указанным в журнале.

Видео и звук в этом проходе не просматривались и не расшифровывались; пиксели ранее проверенных изображений повторно не анализировались. Проверки не подтверждают поведение живого сервера Stepik и не выполняют импорт.
