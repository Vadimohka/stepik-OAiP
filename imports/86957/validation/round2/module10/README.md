# Проверка второго прохода: модуль 10

Из корня репозитория:

```bash
python imports/86957/validation/round2/module10/verify_module10.py
```

Нужны Python 3.10+ и `g++` с поддержкой C++17/20 и UBSan. Проверка не обращается к сети или Stepik.

Проверяются формула и граничные случаи интерполяционного поиска сравнением с линейной проверкой принадлежности, порог в примере скрытых констант, число итераций и диапазон произведений в `factmod`. Встроенные примеры `std::size` и heapsort извлекаются из актуальных `.step`, компилируются в C++17 и C++20 и запускаются. Для heapsort проверяются также пустой массив, повторяющиеся ключи и разные порядки входа.

`module10_validation.json` содержит результаты и SHA-256 всех 29 непрограммных шагов модуля. Минимальные C++ исходники лежат в `checks/`; исполняемые файлы создаются во временном каталоге и удаляются после проверки. Ошибки UBSan завершают проверку неуспешно.

Тесты не заменяют математическое доказательство асимптотики. Формулировки вопросов и их ключи проверены отдельно по определениям O/Θ/Ω и документации стандартных алгоритмов; источники указаны в общем журнале второго прохода. Изображения модуля сохранены; новая проверка видеоматериалов не выполнялась.
