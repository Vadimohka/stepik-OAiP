<h2>Выбор контейнера начинается с нужных операций</h2>
<p><strong>Цель:</strong> отличать позицию от ключа, множество от словаря и осознанно решать, сохранять ли повторения. Во всех примерах этого урока достаточно C++17; указанные возможности C++20 отмечены отдельно.</p>
<table><thead><tr><th>Задача</th><th>Один из подходящих контейнеров</th><th>Что он даёт</th></tr></thead><tbody>
<tr><td>Хранить значения в порядке добавления и обращаться по индексу</td><td><code>std::vector</code></td><td>Последовательность; повторения допустимы</td></tr>
<tr><td>Хранить разные числа и обходить их по возрастанию</td><td><code>std::set</code></td><td>Упорядоченное множество уникальных ключей</td></tr>
<tr><td>По имени находить связанное значение</td><td><code>std::map</code></td><td>Упорядоченный словарь «ключ → значение»</td></tr>
<tr><td>Искать по ключу без требования сортированного обхода</td><td><code>std::unordered_set</code> / <code>std::unordered_map</code></td><td>Хеширование; другие гарантии стоимости операций</td></tr></tbody></table>
<p>В <code>set</code> элемент сам является ключом. В <code>map</code> ключ связан со значением: например, слово связано с количеством его появлений. У разных ключей значения могут совпадать. Контейнеры <code>multiset</code> и <code>multimap</code> позволяют хранить несколько элементов с эквивалентными ключами. Это нужно, когда отдельные повторные записи имеют значение, а не когда достаточно одного счётчика.</p>
<h3>Разобранный пример: разные числа по порядку</h3>
<p>Ввод: <code>0 ≤ n ≤ 1000</code>, затем <code>n</code> целых чисел, представимых типом <code>int</code>. Вывод: количество разных чисел и строка с этими числами по возрастанию. Для пустого набора вторая строка пустая. Программа проверяет чтение обязательных данных.</p>
<p><strong>Полная программа C++17/20:</strong></p>
<pre><code class="language-cpp">#include &lt;iostream&gt;
#include &lt;set&gt;

int main() {
    int n = 0;
    if (!(std::cin &gt;&gt; n) || n &lt; 0 || n &gt; 1000) {
        return 1;
    }
    std::set&lt;int&gt; values;
    for (int i = 0; i &lt; n; ++i) {
        int value = 0;
        if (!(std::cin &gt;&gt; value)) {
            return 1;
        }
        values.insert(value);
    }

    std::cout &lt;&lt; values.size() &lt;&lt; '\n';
    bool first = true;
    for (int value : values) {
        if (!first) {
            std::cout &lt;&lt; ' ';
        }
        std::cout &lt;&lt; value;
        first = false;
    }
    std::cout &lt;&lt; '\n';
}
</code></pre><p>Для ввода:</p><pre>6
4 1 4 2 1 4
</pre><p>Получим:</p><pre>3
1 2 4
</pre>
<p>Повторная вставка 4 не создаёт новый элемент. При необходимости результат <code>insert</code> позволяет узнать, произошла ли вставка: его поле <code>second</code> равно <code>true</code> только для нового ключа; поле <code>first</code> указывает на вставленный или уже существующий элемент.</p>
<p>При стандартном сравнении целые числа обходятся по возрастанию. В общем случае порядок и эквивалентность определяет компаратор: ключи <code>a</code> и <code>b</code> эквивалентны, если оба сравнения <code>comp(a, b)</code> и <code>comp(b, a)</code> ложны. Это не обязательно то же самое, что <code>a == b</code>. Компаратор обязан задавать строгий слабый порядок; например, <code>&lt;=</code> для целых для этой роли не подходит, поскольку значение нельзя считать строго меньшим самого себя.</p>
<p>Поиск: <code>values.find(key) != values.end()</code>. Начиная с C++20 ту же проверку наличия можно записать <code>values.contains(key)</code>. В <code>set</code> нет доступа «элемент номер i» и оператора <code>[]</code>. Менять ключ через итератор нельзя: это могло бы нарушить порядок. Для смены значения в простом варианте удаляют старый ключ и вставляют новый.</p>
<h3>Разбор повторов и выбора модели</h3><p>Для пяти одинаковых чисел 4 множество содержит один ключ: программа печатает <code>1</code>, затем <code>4</code>. У <code>multiset</code> пять эквивалентных ключей могли бы храниться одновременно. У <code>vector</code> сохранялись бы все пять исходных элементов и их последовательность. Поэтому замена контейнера меняет смысл данных, если не согласовать требование к повторам и порядку.</p><p>Стандарт задаёт упорядоченный интерфейс и оценки операций; он не требует конкретной разновидности дерева. <a href="https://stepik.org/lesson/853541/step/2" rel="noopener noreferrer nofollow">Красно-чёрное дерево</a> помогает понять типичную реализацию, но свойства учебного дерева и гарантии <code>std::set</code> проверяются отдельно. Для поиска границы в дереве используется <code>values.lower_bound(key)</code>: свободный <code>std::lower_bound</code> на двунаправленных итераторах может делать линейное число продвижений.</p>
<p><strong>Справка:</strong> <a href="https://timsong-cpp.github.io/cppwp/n4861/associative.reqmts" rel="noopener noreferrer nofollow">Требования к ассоциативным контейнерам</a>; <a href="https://timsong-cpp.github.io/cppwp/n4861/set" rel="noopener noreferrer nofollow">std::set</a>.</p>

### Шаг 2 — text (ID 4035427)

[Открыть на Stepik](https://stepik.org/lesson/973825/step/2?unit=980684) · [Исходник step-source](../../raw/step-sources/4035427.json) · [Объект step](../../raw/steps/4035427.json)

<h2>std::map: счётчик слов и поиск без случайной вставки</h2>
<p><strong>После шага вы сможете</strong> подсчитать повторения, получить значение по ключу и объяснить, когда операция меняет словарь. Заголовок для <code>std::map</code> — <code>&lt;map&gt;</code>, для <code>std::string</code> — <code>&lt;string&gt;</code>.</p>
<p>Элемент <code>std::map&lt;Key, T&gt;</code> — пара <code>std::pair&lt;const Key, T&gt;</code>. Поле <code>first</code> содержит ключ, поле <code>second</code> — связанное значение. Ключ нельзя присвоить заново через эту пару, а значение можно изменять. Уникальны ключи, но не значения. <code>map</code> и <code>set</code> — самостоятельные контейнеры; один не является наследником другого.</p>
<h3>Одна запись — один счётчик</h3>
<p>Ввод: <code>0 ≤ n ≤ 1000</code>, затем <code>n</code> слов и одно слово-запрос. Слово по условию содержит от 1 до 20 строчных латинских букв; пробелы разделяют слова. Вывод: разные слова с частотами по лексикографическому порядку, ответ на запрос и количество ключей. Регистр и пунктуацию программа не нормализует; этот пример не является обработчиком произвольного текста на естественном языке.</p>
<p><strong>Полная программа C++17/20:</strong></p>
<p>Алфавит и длина слов здесь являются предусловием примера. Код проверяет количество и наличие обязательных слов, но не проверяет их алфавит или длину; полноценная проверка текстового формата — отдельная операция. Число вхождений не превосходит 1000 и помещается в <code>int</code>.</p>
<pre><code class="language-cpp">#include &lt;iostream&gt;
#include &lt;map&gt;
#include &lt;string&gt;

int main() {
    int n = 0;
    if (!(std::cin &gt;&gt; n) || n &lt; 0 || n &gt; 1000) {
        return 1;
    }
    std::map&lt;std::string, int&gt; counts;
    for (int i = 0; i &lt; n; ++i) {
        std::string word;
        if (!(std::cin &gt;&gt; word)) {
            return 1;
        }
        ++counts[word];
    }
    std::string query;
    if (!(std::cin &gt;&gt; query)) {
        return 1;
    }

    for (const auto&amp; entry : counts) {
        std::cout &lt;&lt; entry.first &lt;&lt; ' ' &lt;&lt; entry.second &lt;&lt; '\n';
    }
    const auto it = counts.find(query);
    if (it == counts.end()) {
        std::cout &lt;&lt; "not found\n";
    } else {
        std::cout &lt;&lt; "count " &lt;&lt; it-&gt;second &lt;&lt; '\n';
    }
    std::cout &lt;&lt; "keys " &lt;&lt; counts.size() &lt;&lt; '\n';
}
</code></pre><p>Ввод:</p><pre>5
pear apple pear plum apple
peach
</pre><p>Вывод:</p><pre>apple 2
pear 2
plum 1
not found
keys 3
</pre>
<p>В <code>++counts[word]</code> оператор <code>[]</code> намеренно используется для накопления. Если ключа ещё нет, создаётся значение типа <code>int</code>, инициализированное нулём; затем оно увеличивается. Если ключ есть, увеличивается его текущий счётчик. Это поведение зависит от типа значения: оператор <code>[]</code> не является универсальным способом получить «ноль» для любого класса.</p>
<h3>Как читать и обновлять словарь</h3>
<table><thead><tr><th>Операция</th><th>Если ключ отсутствует</th><th>Когда использовать</th></tr></thead><tbody>
<tr><td><code>find(key)</code></td><td>Возвращает <code>end()</code>; не вставляет</td><td>Обычный поиск с обработкой отсутствия</td></tr>
<tr><td><code>at(key)</code></td><td>Бросает <code>std::out_of_range</code>; не вставляет</td><td>Доступ с проверкой существования ключа</td></tr>
<tr><td><code>operator[](key)</code></td><td>Вставляет ключ со значением, инициализированным без аргументов</td><td>Намеренное накопление или создание записи</td></tr>
<tr><td><code>try_emplace(key, value)</code> (C++17)</td><td>Вставляет запись; существующее значение сохраняет</td><td>Добавление только нового ключа</td></tr>
<tr><td><code>insert_or_assign(key, value)</code> (C++17)</td><td>Вставляет запись; существующее значение заменяет</td><td>Явное обновление или создание</td></tr></tbody></table>
<p>В программе запрос <code>peach</code> не добавляет запись: поиск выполняется через <code>find</code>. Если заменить его на <code>counts[query]</code>, размер словаря для этого примера станет 4. У константного <code>map</code> оператора <code>[]</code> нет; для чтения доступны <code>find</code> и <code>at</code>. Если нужно только наличие, в C++20 есть <code>contains</code>.</p>
<p>Итератор <code>it</code> можно разыменовать только после проверки <code>it != counts.end()</code>. Запись <code>it-&gt;second</code> обращается к значению найденной пары. Ссылка <code>const auto&amp;</code> в цикле читает существующие пары без их копирования. Удаление элемента делает его итератор недействительным, поэтому нельзя использовать прежний итератор после <code>erase</code>.</p>
<h3>Разбор отсутствующего и существующего слова</h3><p>Для <code>0 apple</code> словарь пуст, поэтому две строки ответа равны <code>not found</code> и <code>keys 0</code>. В основном наборе запрос <code>pear</code> даёт <code>count 2</code>, а число разных ключей остаётся 3. Чтение через <code>find</code> не вставляет отсутствующий ключ.</p><p>Если интерфейс должен возвращать частоту 0 для отсутствующего слова, в ветке <code>it == counts.end()</code> результатом выбирается 0. Запись <code>counts[query]</code> для этой цели изменила бы словарь: отсутствие ключа и сохранённый нулевой счётчик — разные состояния. Это пример инварианта структуры: каждой сохранённой записи соответствует намеренно добавленный ключ.</p>
