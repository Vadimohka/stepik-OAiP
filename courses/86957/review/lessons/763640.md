<h3>Типы условных операторов</h3>

<p>Условные конструкции направляют ход программы по одному из возможных путей в зависимости от условия.</p>

<h3>Конструкция if</h3>

<p>Конструкция if проверяет истинность условия, и если оно истинно, выполняет блок инструкций. Этот оператор имеет следующую сокращенную форму:</p>

<pre><code class="language-cpp">if (условие) {
    инструкции;
}</code></pre>

<p>В качестве условия использоваться условное выражение, которое возвращает true или false. Если условие возвращает true, то выполняются последующие инструкции, которые входят в блок if. Если условие возвращает false, то последующие инструкции не выполняются. Блок инструкций заключается в фигурные скобки.</p>

<p>Например:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {
    int x = 60;      
    if(x &gt; 50) {
        std::cout &lt;&lt; "x is greater than 50 \n";
    }      
    if(x &lt; 30) {
        std::cout &lt;&lt; "x is less than 30 \n";
    }
    std::cout &lt;&lt; "End of Program" &lt;&lt; "\n";
    return 0;
}</code></pre>

<p>Здесь определены две условных конструкции if. Они проверят больше или меньше значение переменной x, чем определенное значение. В качестве инструкции в обоих случаях выполняется вывод некоторой строки на консоль.</p>

<p>В первом случае <code>x &gt; 50</code> условие истинно, так как значение переменной x действительно больше 50, поэтому это условие возвратит true, и, следовательно, будут выполнятся инструкции, которые входят в блок if.</p>

<p>Во втором случае операция отношения <code>x &lt; 30</code> возвратит false, так как условие ложно, поэтому последующий блок инструкций выполняться не будет. В итоге при запуске программы вывод консоли будет выглядеть следующим образом:</p>

<pre><em>x greater than 50</em>
</pre>

<p>Также мы можем использовать полную форму конструкции if, которая включает оператор else:</p>

<pre><code class="language-cpp">if (выражение_условия) {
    инструкция_1
} else {
    инструкция_2
}</code></pre>

<p>После оператора else мы можем определить набор инструкций, которые выполняются, если условие в операторе if возвращает false. То есть если условие истинно, выполняются инструкции после оператора if, а если это выражение ложно, то выполняются инструкции после оператора else.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {
    int x = 50;

    if(x &gt; 60) {
        std::cout &lt;&lt; "x is greater than 60 \n";
    }
    else {
        std::cout &lt;&lt; "x is less or equal 60 \n";
    }
    return 0;
}</code></pre>

<p>В данном случае условие <code>x &gt; 60</code> ложно, то есть возвращает false, поэтому будет выполняться блок else. И в итоге на консоль будет выведена строка "x is less or equal 60 \n".</p>

<p>Однако нередко надо обработать не два возможных альтернативных варианта, а гораздо больше. Например, в случае выше можно насчитать три условия: переменная x может быть больше 60, меньше 60 и равна 60. Для проверки альтернативных условий мы можем вводить выражения else if:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {
    int x = 60;
    
    if(x &gt; 60) {
        std::cout &lt;&lt; "x is greater than 60 \n";
    }
    else if (x &lt; 60) {
        std::cout &lt;&lt; "x is less than 60 \n";
    }
    else {
        std::cout &lt;&lt; "x is equal 60 \n";
    }
    return 0;
}</code></pre>

<p>То есть в данном случае мы получаем три ветки развития событий в программе.</p>

<p>Если в блоке if или else или else-if необходимо выполнить только одну инструкцию, то фигурные скобки можно опустить:</p>

<pre><code>int d = b * b - 4 * a * c ;
if (d &gt; 0) roots = 2;
else if (d == 0) roots = 1;
else roots = 0;</code></pre>

<p>Но не нужно, это моветон.  </p>

<h3>Тернарный оператор</h3>

<p>Тернарный оператор ?: позволяет сократить определение простейших условных конструкций if и имеет следующую форму:</p>

<pre><code>[первый операнд - условие] ? [второй операнд] : [третий операнд]</code></pre>

<p>Оператор использует сразу три операнда. В зависимости от условия тернарный оператор возвращает второй или третий операнд: если условие равно true (то есть истинно), то возвращается второй операнд; если условие равно false (то есть ложно), то третий. Например:</p>

<pre><code>#include &lt;iostream&gt;

int main() {
    setlocale(LC_ALL, "russian");

    int x = 5;
    int y = 3;
    char sign;

    std::cout &lt;&lt; "Введите знак операции: ";
    std::cin &gt;&gt; sign;

    int result = sign=='+'?x + y:x - y;

    std::cout &lt;&lt; "Результат: " &lt;&lt; result &lt;&lt; "\n";
    return 0;
}</code></pre>

<p>В данном случае производится ввод знака операции. Здесь результатом тернарной операции является переменная result. И если переменная sign содержит знак "+", то result будет равно второму операнду - (x+y). Иначе result будет равно третьему операнду.</p>

<p>Также тернарные операторы могут быть вложены друг в друга.</p>

<pre><code class="language-cpp">int b = a &gt; 0 ? a &lt; 100 ? 1 : 0 : -1;</code></pre>

<p>Очевидно, что так писать не стоит.</p>

<h3>Конструкция switch</h3>

<p>Другую форму организации ветвления программ представляет конструкция switch...case. Она имеет следующую форму:</p>

<pre><code class="language-cpp">switch (выражение) {
    case константа_1: инструкции_1;
    case константа_2: инструкции_2;
    default: инструкции;
}</code></pre>

<p>Количество блоков case обычно не ограничено, однако стандарт С гарантирует лишь 257 таких блоков. Стандарт С++ рекомендует поддержку 16 384 блоков. </p>

<p>После ключевого слова switch в скобках идет сравниваемое выражение. Значение этого выражения последовательно сравнивается со значениями после оператора сase. И если совпадение будет найдено, то будет выполняться определенный блок сase.</p>

<p>В конце конструкции switch может стоять блок default. Выполняется в том случае, если значение после switch не соответствует ни одному из операторов case. Он необязателен, но его рекомендуют использовать всегда. Например:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {
    int x = 2;
    switch(x) {
        case 1:
            std::cout &lt;&lt; "x = 1" &lt;&lt; "\n";
            break;
        case 2:
            std::cout &lt;&lt; "x = 2" &lt;&lt; "\n";
            break;
        case 3:
            std::cout &lt;&lt; "x = 3" &lt;&lt; "\n";
            break;
        default:
            std::cout &lt;&lt; "x is undefined" &lt;&lt; "\n";
            break;
    }
    return 0;
}</code></pre>

<p>Чтобы избежать выполнения последующих блоков case/default, в конце каждого блока ставится оператор break. То есть в данном случае будет выполняться оператор</p>

<pre><code class="language-cpp">case 2:
    std::cout &lt;&lt; "x = 2" &lt;&lt; "\n";
    break;</code></pre>

<p>После выполнения оператора break произойдет выход из конструкции switch..case, и остальные операторы case будут проигнорированы. Поэтому на консоль будет выведена следующая строка</p>

<pre><em>x = 2</em></pre>

<p>Стоит отметить важность использования оператора break. Если мы его не укажем в блоке case, то после этого блока выполнение перейдет к следующему блоку case. Например, уберем из предыдущего примера все операторы break:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {
    int x = 2;
    switch(x) {
        case 1:
            std::cout &lt;&lt; "x = 1" &lt;&lt; "\n";
        case 2:
            std::cout &lt;&lt; "x = 2" &lt;&lt; "\n";
        case 3:
            std::cout &lt;&lt; "x = 3" &lt;&lt; "\n";
        default:
            std::cout &lt;&lt; "x is undefined" &lt;&lt; "\n";
    }
    return 0;
}</code></pre>

<p>В этом случае опять же будет выполняться оператор <code>case 2:</code>, так как переменная x=2. Однако так как этот блок case не завершается оператором break, то после его завершения будет выполняться набор инструкций после <code>case 3:</code> даже несмотря на то, что переменная x по прежнему равна 2. В итоге мы получим следующий консольный вывод:</p>

<pre><em>x = 2
x = 3
x is undefined</em>
</pre>

<p>*Конструкция Switch-case во всех языках программирования имеет дурную славу и не просто так. Программируя сложные конструкции (чуть сложнее, чем меню в консоли :)) внимательность разработчика должна быть на предельному уровне. О <a href="https://ru.stackoverflow.com/questions/214914/Чем-конструкция-switch-плоха" rel="noopener noreferrer nofollow">минусах</a> и <a href="https://habr.com/ru/post/166201/" rel="noopener noreferrer nofollow">плюсах</a> данного оператора можете почитать в прикреплённых статьях.</p>

<p><strong>switch vs if-else</strong></p>

<p>А что же лучше?<br>
Начнём с того, что switch ограничен использованием констант, потому для реализации сложных условий придётся использовать if-else.<br>
О читаемости говорить не будем, многое зависит от ситуации и личных предпочтений.<br>
switch быстрее if-else, но не всегда, сейчас поясню. В зависимости от компилятора и блоков case (разряженные - не разряженные значения), switch case может работать по-разному:</p>

<ul>
	<li>Раскрыться в if-else. Раньше так происходило всегда, но и сейчас подобное поведение можно встретить.  Сложность $\mathcal{O}(n)$.</li>
	<li>Может использовать binary search по условиям, но это не точно. Сложность $\mathcal{O}(\log{n})$.</li>
	<li>Branch table - что-то вроде hash table. Сложность $\mathcal{O}(1)$.</li>
</ul>

<p>Switch и if-else обычно применяются для малых n, потому прирост в производительности не существенен. Нет однозначного ответа, что лучше.</p>
