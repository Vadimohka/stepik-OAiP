<h2>Условие выбирает путь выполнения</h2>
<p>Условие — выражение, результат которого используется как <code>bool</code>. В <code>if (number &gt; 0)</code> сравнение даёт <code>true</code> или <code>false</code>. Для числового условия ноль означает ложь, ненулевое значение — истину, но явное сравнение обычно лучше показывает смысл.</p>
<p><strong>Схема синтаксиса, не компилируемый код. Слова по-русски обозначают заменяемые части.</strong></p>
<pre><code class="language-text">if (условие) {
    действия_при_истине;
} else {
    действия_при_лжи;
}
</code></pre>
<p><strong>Полная программа C++17/C++20.</strong></p>
<pre><code class="language-cpp">#include &lt;iostream&gt;
int main() {
    int number{};
    if (!(std::cin &gt;&gt; number)) {
        std::cout &lt;&lt; "INVALID\n";
        return 1;
    }
    if (number &gt; 0) {
        std::cout &lt;&lt; "positive\n";
    } else if (number &lt; 0) {
        std::cout &lt;&lt; "negative\n";
    } else {
        std::cout &lt;&lt; "zero\n";
    }
    const int nonnegative = number &gt;= 0 ? 1 : 0;
    std::cout &lt;&lt; nonnegative &lt;&lt; '\n';
}
</code></pre>
<p>Для положительного, отрицательного числа и нуля выполняется ровно одна ветвь цепочки. При вводе <code>-2</code> вывод равен <code>negative</code>, затем <code>0</code> на новой строке. Если прочитать первое целое не удалось — например, получены <code>abc</code>, конец ввода без числа или число вне диапазона <code>int</code>, — программа печатает <code>INVALID</code>. Оператор <code>&gt;&gt;</code> читает числовой префикс: ввод <code>12x</code> даёт число 12, поэтому здесь будут напечатаны <code>positive</code> и <code>1</code> на разных строках. Оставшиеся символы программа не использует; проверку всей строки этот пример не выполняет. Несколько самостоятельных <code>if</code>, напротив, проверялись бы независимо: истинными могут оказаться несколько условий.</p>
<p>Конструкция <code>else if</code> означает ещё один <code>if</code> после <code>else</code>. Условия идут по порядку; после первой выбранной ветви остальные пропускаются. Фигурные скобки связывают инструкции в блок и делают принадлежность <code>else</code> очевидной. Без скобок <code>else</code> относится к ближайшему подходящему <code>if</code>.</p>
<h3>Условное выражение ?:</h3>
<p><code>условие ? значение_при_истине : значение_при_лжи</code> выбирает одно из двух выражений. В программе <code>number &gt;= 0 ? 1 : 0</code> даёт значение для инициализации <code>nonnegative</code>. Вычисляется только выбранная часть. Для длинных действий удобнее <code>if</code>; для выбора простого значения — <code>?:</code>. Вложенные условные выражения быстро затрудняют чтение.</p>
<p>Чтобы проверить принадлежность отрезку, пишут <code>0 &lt;= number &amp;&amp; number &lt;= 100</code>. Запись <code>0 &lt;= number &lt;= 100</code> сначала сравнивает ноль с числом, а затем результат <code>bool</code> со ста; математической двойной проверки она не выполняет. Для выбора по нескольким отдельным значениям предназначен <a href="https://stepik.org/lesson/763640/step/2" rel="noopener noreferrer nofollow">switch</a>.</p>

<h2>switch: выбор по отдельным значениям</h2>
<p><code>switch</code> удобен, когда одно целое значение выбирает вариант: номер команды, день недели или символ операции. Выражение условия вычисляется один раз. Управление переходит к совпавшей метке <code>case</code>, а при отсутствии совпадения — к <code>default</code>, если она есть. Без <code>default</code> несовпадение просто пропускает тело.</p>
<p><strong>Полная программа C++17/C++20.</strong></p>
<pre><code class="language-cpp">#include &lt;iostream&gt;
int main() {
    int command{};
    if (!(std::cin &gt;&gt; command)) {
        std::cout &lt;&lt; "INVALID\n";
        return 1;
    }
    switch (command) {
        case 1:
            std::cout &lt;&lt; "open\n";
            break;
        case 2:
        case 3:
            std::cout &lt;&lt; "save\n";
            break;
        default:
            std::cout &lt;&lt; "unknown\n";
            break;
    }
}
</code></pre>
<p>Команды 2 и 3 ведут к одному действию. <code>break</code> завершает весь <code>switch</code>. Метка сама не создаёт отдельную ветвь с автоматическим выходом: если после выполняемых инструкций нет перехода, выполнение продолжается через следующие метки.</p>
<p><strong>Фрагмент внутри main с подключённым &lt;iostream&gt;.</strong></p>
<pre><code class="language-cpp">int command{2};
switch (command) {
    case 2:
        std::cout &lt;&lt; "two\n";
        [[fallthrough]];
    case 3:
        std::cout &lt;&lt; "three\n";
        break;
}
</code></pre>
<p>Этот фрагмент выводит <code>two</code> и <code>three</code> на разных строках. Значение команды остаётся равным 2: повторного сравнения с 3 не происходит. Атрибут <code>[[fallthrough]];</code> доступен с C++17 и отмечает намеренный переход к следующей метке; он не меняет этот порядок выполнения.</p>
<p>В начальных примерах условие имеет целочисленный тип. Язык также допускает перечисления и некоторые классовые типы с преобразованием; <code>std::string</code> и <code>double</code> напрямую не подходят. Значения <code>case</code> должны быть константными выражениями и различаться после преобразования к типу условия. Для интервала вроде «от 10 до 20» нужен <code>if</code>. Если внутри ветви объявляется переменная с инициализатором, отдельный блок <code>{ ... }</code> ограничивает её область и предотвращает переход через её инициализацию из другой метки.</p>
<p>Стандарт не обещает, что <code>switch</code> быстрее цепочки <code>if</code>: реализация может использовать сравнения или таблицу переходов. Выбор формы здесь определяется устройством условия и ясностью программы.</p>
