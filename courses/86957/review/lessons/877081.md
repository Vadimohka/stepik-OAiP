<p>Определим простейший класс</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

// определение класса
class SomeClass {
private:
    int somedata; // поле класса

public:
    // метод класса, изменяющий значение поля
    void setdata(int d) { 
        somedata = d; 
    }

    // метод класса, отображающий значение поля
    void showdata() {
        std::cout &lt;&lt; "Значение поля равно " &lt;&lt; somedata &lt;&lt; std::endl;
    }
};</code></pre>

<p><strong>Методы класса</strong> — это функции, входящие в состав класса. Класс SomeClass содержит два метода: setdata() и showdata(). Тела обоих методов состоят из одного оператора, который записан на одной строке с фигурными скобками, ограничивающими тело функции. Разумеется, можно использовать и более традиционный способ оформления функций:</p>

<pre><code class="language-cpp">void setdata(int d) {
    somedata = d;
}</code></pre>

<p>И</p>

<pre><code class="language-cpp">void showdata() {
    std::cout &lt;&lt; "Значение поля равно " &lt;&lt; somedata;
}</code></pre>

<p>В тех случаях, когда тела методов невелики по размеру, имеет смысл использовать более сжатую форму их записи.</p>

<p>Методы класса SomeClass выполняют действия, типичные для методов классов вообще: они считывают и присваивают значения полям класса. Метод setdata() принимает аргумент и присваивает полю somedata значение, равное значению аргумента. Метод showdata() отображает на экране значение поля somedata. Обратите внимание на то, что функции setdata() и showdata() определены внутри класса, то есть код функции содержится непосредственно в определении класса (здесь определение функции не означает, что код функции помещается в память. Это происходит лишь при создании объекта класса). Методы класса, определенные подобным образом, по умолчанию являются встраиваемыми. Позже мы увидим, что функции внутри класса можно не только определять, но и объявлять, а определение функции производить в другом месте. Функция, определенная <em>вне класса,</em> по умолчанию уже <em>не является встраиваемой</em>.</p>

<h2><strong>Сообщения</strong></h2>

<p>В некоторых объектно-ориентированных языках программирования вызовы методов объектов называют сообщениями. Так, например, вызов s1.showdata(); можно рассматривать как посылку сообщения объекту s1 с указанием вывести на экран свои данные. Термин сообщение не входит в число формальных терминов языка C++, однако его полезно держать в голове в процессе дальнейшего обсуждения. Представление вызова методов в виде сообщений подчеркивает независимость объектов как самостоятельных единиц, взаимодействие с которыми осуществляется путем обращения к их методам.</p>

<h2><strong>Класс как тип данных</strong></h2>

<p>Здесь мы рассмотрим пример, демонстрирующий применение объектов C++ в качестве переменных типа, определенного пользователем. Объекты будут представлять расстояния, выраженные в английской системе мер. Ниже приведен листинг программы:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

// длина в английской системе
class Distance {
private:
    int feet;
    float inches;

public:
    // установка значений полей
    void setdist(int ft, float in) {
        feet = ft;
        inches = in;
    }

    // ввод полей с клавиатуры
    void getdist() {
        std::cout &lt;&lt; "Введите число футов: ";
        std::cin &gt;&gt; feet;
        std::cout &lt;&lt; "Введите число дюймов: ";
        std::cin &gt;&gt; inches;
    }

    // вывод полей на экран
    void showdist() {
        std::cout &lt;&lt; feet &lt;&lt; " футов " &lt;&lt; inches &lt;&lt; " дюймов";
    }
};

int main() {
    setlocale(LC_ALL, "Russian");
    Distance dist1, dist2; // две длины
    dist1.setdist(11, 6.25); // установка значений для d1
    dist2.getdist(); // ввод значений для dist2

    // вывод длин на экран
    std::cout &lt;&lt; "\ndist1 - "; 
    dist1.showdist();
    std::cout &lt;&lt; "\ndist2 - "; 
    dist2.showdist();
    std::cout &lt;&lt; std::endl;
    return 0;
}</code></pre>

<p>В этой программе класс Distance содержит два поля: feet и inches. Класс Distance имеет три метода:</p>

<ol>
	<li>setdist(), предназначенный для задания значений полей объекта через передаваемые ему аргументы;</li>
	<li>getdist(), получающий эти же значения с клавиатуры;</li>
	<li>showdist(), отображающий на экране расстояние в футах и дюймах</li>
</ol>

<p>Таким образом, значения полей объекта класса Distance могут быть заданы двумя способами. В функции main() мы определили две переменные типа Distance: dist1 и dist2. Значения полей для первой из них задаются с помощью функции setdist(), вызванной с аргументами 11 и 6.25, а значения полей переменной dist2 вводятся пользователем.</p>

<p>Данный пример демонстрирует два способа использования методов класса для инициализации полей объекта класса. Но как правило, удобнее инициализировать поля объекта автоматически в момент его создания, а не явно вызывать в программе соответствующий метод. Такой способ инициализации реализуется с помощью особого метода класса, называемого <strong>конструктором</strong>. Что же это такое?</p>

<h2><strong>Понятие конструктора класса в языке С++</strong></h2>

<p><strong>Конструктор</strong> — это метод класса, выполняющийся автоматически в момент создания объекта.</p>

<p>Рассмотрим следующий пример:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

// длина в английской системе
class Distance { 
private:
    int feet;
    float inches;

public: 
    // конструктор без аргументов
    Distance() {
        feet = 0;
        inches = 0;
    }

    // конструктор с двумя аргументами
    Distance(int ft, float in) {
        feet = ft;
        inches = in;   
    }

    // ввод длины пользователем
    void getdist() {
        std::cout &lt;&lt; "Введите число футов: ";
        std::cin &gt;&gt; feet;
        std::cout &lt;&lt; "Введите число дюймов: "; 
        std::cin &gt;&gt; inches;
    }

    // вывод полей на экран
    void showdist() {
        std::cout &lt;&lt; feet &lt;&lt; " футов " &lt;&lt; inches &lt;&lt; " дюймов";
    }
};</code></pre>

<p>Также допустима такая форма записи конструкторов:</p>

<pre><code class="language-cpp">// Данные конструкторы аналогичны тем, которые использованы в примере выше
Distance() : feet(O), inches(O.O) { }
Distance(int ft, float in) : feet(ft), inches(in) { }</code></pre>

<p>У конструкторов есть несколько особенностей, отличающих их от других методов класса.</p>

<p>Во-первых, имя конструктора в точности совпадает с именем класса. Таким образом, компилятор отличает конструкторы от других методов класса.</p>

<p>Во-вторых, у конструкторов не существует возвращаемого значения. Это объясняется тем, что конструктор автоматически вызывается системой, и, следовательно, не существует вызывающей программы или функции, которой конструктор мог бы возвратить значение. Следовательно, указание возвращаемого значения для конструктора не имеет смысла. Отсутствие типа возвращаемого значения у конструкторов является вторым признаком, по которому компилятор может отличить их от других методов класса.</p>

<p>Теперь мы можем инициализировать объект класса с помощью передачи аргументов в конструктор:</p>

<pre><code class="language-cpp">int main() {
    setlocale(LC_ALL, "Russian");
    Distance dist1; // первая длина
    Distance dist2(11, 6.25); // определение и инициализация
    dist1.getdist(); // ввод dist1

    // вывод всех длин
    std::cout &lt;&lt; "\ndist1 = ";
    dist1.showdist();
    std::cout &lt;&lt; "\ndist2 = ";
    dist2.showdist();
    std::cout &lt;&lt; std::endl;
    return 0;
} </code></pre>

<h2><strong>Перегруженные конструкторы</strong></h2>

<p>Было бы удобно производить инициализацию переменных класса Distance в момент их создания, то есть использовать объявления типа Distance width(5, 6.25); где определяется объект width, сразу же инициализируемый значениями 5 и 6.25 для футов и дюймов соответственно. Чтобы сделать это, вызовем конструктор следующим образом:</p>

<p><code>Distance(int ft, float in) : feet(ft), inches(in) { }</code></p>

<p>Мы инициализируем поля feet и inches теми значениями, которые передаются конструктору в качестве аргументов. Тем не менее, мы хотим сохранить возможность определять переменные класса Distance без инициализации т.е.</p>

<p><code>Distance dist1, dist2;</code></p>

<p>Ранее в нашей программе не было конструктора, но определения работали без ошибок. Почему же они работали без конструктора?</p>

<p>Это объясняется тем, что компилятор <strong>автоматически</strong> встраивает в программу конструктор без параметров, который и создает переменные класса, несмотря на то, что явного определения конструктора мы не делали. Такой конструктор без параметров называется <em>конструктором по умолчанию</em>. Если бы конструктор по умолчанию не создавался автоматически, то мы <em>не смогли</em> бы определять переменные классов, в которых отсутствует конструктор. Зачастую нам хотелось бы, чтобы начальные значения полям объекта присваивались также и в конструкторе без параметров. Если возложить эту функцию на конструктор по умолчанию, то мы не сможем узнать, какими значениями были инициализированы поля. Если же для нас важно, какими значениями будут инициализироваться поля объекта класса, то нам следует явно определить конструктор и поступить следующим образом:</p>

<p><code>Distance() : feet(O), inches(O.O) // конструктор по умолчанию { } // тело функции пусто, никаких действий не производится</code></p>

<p>Члены класса инициализируются константными значениями, в данном случае целым значением 0 для переменной feet и вещественным значением 0.0 для переменной inches. Значит, мы можем использовать объекты, инициализируемые с помощью конструктора без параметров, будучи уверенными в том, что поля объекта имеют нулевые, а не другие, случайные, значения. Теперь у нас имеется два явно определенных конструктора с одним и тем же именем <code>Distance()</code>, и поэтому говорят, что конструктор является перегруженным. Какой из этих двух конструкторов исполняется во время создания нового объекта, зависит от того, сколько аргументов используется при вызове:</p>

<p><code>Distance length; // вызывает первый конструктор</code></p>

<p><code>Distance width(11, 6.0); // вызывает второй конструктор</code></p>

<h2><strong>Конструкторы и собственные типы данных</strong></h2>

<p>Разработчики компиляторов для языков C, C++ или C# должны позаботиться о том, чтобы для любой переменной стандартного типа, которую программист определяет в своей программе, вызывался необходимый конструктор. Например, если в программе встречается определение переменной типа int, где-то должен существовать конструктор, который выделит для этой переменной четыре байта памяти. Таким образом, научившись создавать свои собственные конструкторы, мы можем выполнять задачи, с которыми сталкиваются разработчики компиляторов.</p>

<h2><strong>Деструкторы</strong></h2>

<p>Как мы уже видели, особый метод класса — конструктор — вызывается при создании объекта. Как вы, возможно, догадались, существует другая функция, автоматически вызываемая при уничтожении объекта и называемая деструктором. Более подробно мы рассмотрим эти действия в разделе "Умные указатели", а пока использование деструкторов не будет иметь для нас большого смысла.</p>

<h2><strong>Определение методов класса вне класса</strong></h2>

<p>До сих пор мы всегда определяли методы класса внутри самого класса. На самом деле это не является обязательным. В следующем примере метод add_dist() определен вне класса Distance(). Внутри определения класса содержится лишь прототип функции add_dist();</p>

<p><code>void add_dist(Distance, Distance);</code></p>

<p>Такая форма означает, что функция является методом класса, однако ее определение следует искать не внутри определения класса, а где-то в другом месте листинга. В примере ниже функция add_dist() определена позже, чем класс Distance().</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

// длина в английской системе
class Distance { 
private:
    int feet;
    float inches;

public: 
    // конструктор без аргументов
    Distance() {
        feet = 0;
        inches = 0;
    }

    // конструктор с двумя аргументами
    Distance(int ft, float in) {
        feet = ft;
        inches = in;   
    }

    // ввод длины пользователем
    void getdist() {
        std::cout &lt;&lt; "Введите число футов: ";
        std::cin &gt;&gt; feet;
        std::cout &lt;&lt; "Введите число дюймов: "; 
        std::cin &gt;&gt; inches;
    }

    // вывод полей на экран
    void showdist() {
        std::cout &lt;&lt; feet &lt;&lt; " футов " &lt;&lt; inches &lt;&lt; " дюймов";
    }

    // прототип
    void add_dist(Distance, Distance); 

    // деструктор класса Distance
    ~Distance() { }
};

// сложение длин d1 и d2 в методе объявленном за пределами класса
void Distance::add_dist(Distance dd1, Distance dd2) {
    // сложение дюймов с возможным заемом
    inches = dd1.inches + dd2.inches;
    feet = 0;
    // если число дюймов больше 12.0 то уменьшаем число дюймов на 12.0
    // и увеличиваем число футов на 1
    if(inches &gt;= 12.0) {
        inches -= 12.0;
        feet++;
    }
    feet += dd1.feet + dd2.feet;
}

int main() {
    setlocale(LC_ALL, "Russian");
    Distance dist1, dist3; // две длины
    Distance dist2(11, 6.25); // определение и инициализация
    dist1.getdist(); // ввод dist1
    dist3.add_dist(dist1, dist2); //dist3 = dist1 + dist2
    // вывод всех длин
    std::cout &lt;&lt; "\ndist1 = ";
    dist1.showdist();
    std::cout &lt;&lt; "\ndist2 = ";
    dist2.showdist();
    std::cout &lt;&lt; "\ndist3 = ";
    dist3.showdist();
    std::cout &lt;&lt; std::endl;
    return 0;
} </code></pre>

<p>Основной блок этой программы начинается с присвоения начальных значений полям объекта dist2 класса Distance, после чего производится его сложение с экземпляром dist1, инициализируемым пользователем.</p>

<p>Перед именем функции add_dist() стоит имя класса Distance и новый символ <code>::</code>. Этот символ является знаком операции глобального разрешения. Такая форма записи устанавливает взаимосвязь функции и класса, к которой относится эта функция. В данном случае запись <code>Distance::add_dist()</code> означает, что функция add_dist() является методом класса Distance.</p>

<h2><strong>Объекты в качестве аргументов функций</strong></h2>

<p>Рассмотрим, каким образом исполняется программа выше. Объекты dist1 и dist3 создаются при помощи конструктора по умолчанию (конструктора без аргументов), а объект dist2 — при помощи конструктора, принимающего два аргумента, значения которых инициализируют поля объекта dist2. Значения для инициализации объекта dist1 вводятся пользователем при помощи метода getdist(). Теперь мы хотим сложить значения dist1 и dist2 и присвоить результат объекту dist3. Это делается с помощью вызова функции: <code>dist3.add_dist(dist1, dist2);</code>.</p>

<p>Величины, которые мы хотим сложить, передаются в качестве аргументов методу add_dist(). Синтаксис передачи объектов в функцию такой же, как и для переменных стандартных типов: на месте аргумента указывается имя объекта. Поскольку add_dist() является методом класса Distance, он имеет доступ к любым полям любого объекта класса Distance, используя операцию точки (.), например <code>dist1.inches и dist2.feet</code>.</p>

<p>Если внимательно изучить функцию add_dist(), то мы увидим несколько важных деталей, касающихся методов класса. Методу класса всегда предоставлен доступ к полям объекта, для которого он вызван: объект связан с методом операцией точки (.). Однако на самом деле методу класса доступны и другие объекты. Если задаться вопросом, к каким объектам имеет доступ метод add_dist(), то, взглянув на вызов <code>dist3.add_dist(dist1, dist2);</code> можно заметить, что, кроме объекта dist3, из которого был вызван метод add_ dist(), он имеет доступ также и к объектам dist1 и dist2, поскольку они выступают в качестве его аргументов. Можно рассматривать объект dist3 как псевдоаргумент функции add_dist(); формально он не является аргументом, но функция имеет доступ к его полям. Смысл приведенного вызова можно сформулировать так: «выполнить метод add_dist() объекта dist3». Когда внутри функции происходит обращение к полям inches и feet, это означает, что на самом деле обращение происходит к полям dist3.inches и dist3.feet. Обратите внимание на то, что функция не возвращает значения. Типом возвращаемого значения для функции add_dist() является void. Результат автоматически присваивается объекту dist3.</p>

<p>Подводя итог вышесказанному, мы можем утверждать, что каждый вызов метода класса обязательно связан с конкретным объектом этого класса (исключением является вызов статической функции, как мы увидим позже). Метод может прямо обращаться по имени (feet и inches в данном примере) к любым, открытым и закрытым, членам этого объекта. Кроме того, метод имеет непрямой (через операцию точки, например dist1.inches и dist2.feet) доступ к членам других объектов своего класса; последние выступают в качестве аргументов метода.</p>

<h2><strong>Дружественная функция в языке С++</strong></h2>

<p><strong>Дружественная функция</strong> – это функция, которая может получить доступ к закрытым членам класса, как если бы она была членом этого класса. Во всем остальном дружественная функция похожа на обычную функцию. Дружественная функция может быть либо обычной функцией, либо функцией-членом другого класса. Чтобы объявить дружественную функцию, просто используйте ключевое слово <code>friend</code> перед прототипом функции, которую вы хотите сделать другом класса. Не имеет значения, объявляете ли вы дружественную функцию в закрытом или открытом разделе класса.</p>

<p>Вот пример использования дружественной функции:</p>

<pre><code class="language-cpp">class Accumulator {
private:
    int m_value;
public:
    Accumulator() { 
        m_value = 0;
    }
 
    void add(int value) {
        m_value += value;
    }
 
    // Сделаем функцию reset() другом этого класса
    friend void reset(Accumulator &amp;accumulator);
};
 
// reset() теперь является другом класса Accumulator
void reset(Accumulator &amp;accumulator) {
    // и может получить доступ к закрытым данным объектов Accumulator
    accumulator.m_value = 0;
}
 
int main() {
    Accumulator acc;
    acc.add(5); // добавляем 5 в накапливающий сумматор
    reset(acc); // сбрасываем накапливающий сумматор в 0
 
    return 0;
}</code></pre>

<p>В этом примере мы объявили функцию с именем <code>reset()</code>, которая принимает объект класса <code>Accumulator</code> и устанавливает значение <code>m_value</code> равным 0. Поскольку <code>reset()</code> не является членом класса <code>Accumulator</code>, обычно <code>reset()</code> не будет иметь доступ к закрытым членам <code>Accumulator</code>. Однако, поскольку <code>Accumulator</code> специально объявил эту функцию <code>reset()</code> как друга класса, то ей предоставляется доступ к закрытым членам <code>Accumulator</code>.</p>

<p>Обратите внимание, что мы должны передать в <code>reset()</code> объект <code>Accumulator</code>. Это потому, что <code>reset()</code> не является функцией-членом. У нее нет указателя <code>*this</code> и нет объекта <code>Accumulator</code> для работы, если он не указан.</p>

<p>Вот еще один пример:</p>

<pre><code class="language-cpp">class Value {
private:
    int m_value;
public:
    Value(int value) {
        m_value = value;
    }
    friend bool isEqual(const Value &amp;value1, const Value &amp;value2);
};
 
bool isEqual(const Value &amp;value1, const Value &amp;value2) {
    return (value1.m_value == value2.m_value);
}</code></pre>

<p>В этом примере мы объявляем функцию <code>isEqual()</code> другом класса <code>Value</code>. <code>isEqual()</code> принимает в качестве параметров два объекта <code>Value</code>. Поскольку <code>isEqual()</code> является другом класса <code>Value</code>, она может получить доступ к закрытым членам всех объектов <code>Value</code>. В этом случае она использует этот доступ для сравнения двух объектов и возвращает <code>true</code>, если они равны.</p>

<h2>Несколько друзей</h2>

<p>Функция может быть другом для более чем одного класса одновременно. Например, рассмотрим следующий пример:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
class Humidity;
 
class Temperature {
private:
    int m_temp;
public:
    Temperature(int temp=0) {
        m_temp = temp;
    }
 
    friend void printWeather(const Temperature &amp;temperature,
                             const Humidity &amp;humidity);
};
 
class Humidity {
private:
    int m_humidity;
public:
    Humidity(int humidity = 0) {
        m_humidity = humidity;
    }
 
    friend void printWeather(const Temperature &amp;temperature,
                             const Humidity &amp;humidity);
};
 
void printWeather(const Temperature &amp;temperature, const Humidity &amp;humidity) {
    std::cout &lt;&lt; "The temperature is " &lt;&lt; temperature.m_temp &lt;&lt;
       " and the humidity is " &lt;&lt; humidity.m_humidity &lt;&lt; '\n';
}
 
int main() {
    Humidity hum(10);
    Temperature temp(12);
 
    printWeather(temp, hum);
 
    return 0;
}</code></pre>

<p>В этом примере стоит отметить две вещи. Во-первых, поскольку <code>printWeather</code> является другом обоих классов, она может получить доступ к закрытым данным из объектов обоих классов. Во-вторых, обратите внимание на следующую строку в верхней части примера:</p>

<pre><code>class Humidity;</code></pre>

<p>Это прототип класса, который сообщает компилятору, что в будущем мы собираемся определить класс под названием <code>Humidity</code>. Без этой строки компилятор при синтаксическом анализе прототипа для <code>printWeather()</code> внутри класса <code>Temperature</code> сообщил бы нам, что не знает, что такое <code>Humidity</code>. Прототипы классов выполняют ту же роль, что и прототипы функций – они сообщают компилятору, как что-то выглядит, чтобы его можно было использовать сейчас и определить позже. Однако, в отличие от функций, классы не имеют возвращаемых типов или параметров, поэтому прототипы классов всегда представляют собой просто <code>class ClassName</code>, где <code>ClassName</code> – это имя класса. </p>

<p>Обращаю особое внимание на то, что дружеские функции<strong> не являются членами класса</strong>, однако <strong>получают</strong> <strong>доступ к полям с модификатором доступа private</strong>. Особое внимание данному моменту будет уделено в следующем уроке, где будут разобраны дружественные классы в языке С++.</p>
