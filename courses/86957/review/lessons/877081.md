<h3>Метод и текущий объект this</h3>

<p>Метод — функция-член класса. У обычного нестатического метода есть текущий объект: тот, который указан слева от точки или стрелки. Внутри метода указатель <code>this</code> обозначает этот объект.</p><p>Фрагмент; определения и контекст указаны в объяснении:</p><pre><code class="language-cpp">void SomeClass::setdata(int data) {
    this-&gt;data_ = data;
}

int SomeClass::data() const {
    return this-&gt;data_;
}</code></pre><p>Это альтернативные определения методов класса из <a href="https://stepik.org/lesson/877082/step/5" rel="noopener noreferrer nofollow">предыдущего примера</a>. Чтобы использовать их, внутри класса оставляют объявления <code>void setdata(int data);</code> и <code>int data() const;</code>, а прежние тела удаляют. Одновременно определять один метод двумя способами нельзя. Префикс <code>SomeClass::</code> связывает определение с классом.</p><p>При вызове <code>first.setdata(7)</code> указатель <code>this</code> обозначает <code>first</code>; при вызове для <code>second</code> — второй объект. Записи <code>data_</code> и <code>this-&gt;data_</code> в этом контексте обозначают одно поле. Если параметр назван так же, как поле, явное <code>this-&gt;</code> помогает различить их.</p><p>Доступ разрешён по классу, а не только к одному экземпляру. Метод может обращаться к закрытым полям другого объекта своего класса, если получил ссылку на него. Это понадобится для сравнения и сложения. Статическая функция-член отличается: у неё нет <code>this</code>, потому что она не привязана к одному экземпляру.</p><p>Определение метода непосредственно внутри класса в обычном заголовочном файле неявно является <code>inline</code>. Здесь это правило об определениях в разных единицах трансляции, а не обещание подстановки команд вместо вызова. Раздельные объявления, определения и компоновка работают так же, как в <a href="https://stepik.org/lesson/770592/step/2" rel="noopener noreferrer nofollow">многофайловом примере</a>.</p>

<h3>Distance: смысл типа и допустимое состояние</h3>

<p>Построим учебный тип длины <code>Distance</code>. В одном футе 12 дюймов. Чтобы сосредоточиться на устройстве класса, будем хранить только <strong>целые неотрицательные дюймы</strong>. Дробные дюймы и отрицательные перемещения в этот пример не входят.</p><p>Инвариант: число футов находится в диапазоне 0–1 000 000, число оставшихся дюймов — 0–11. Предел футов — явное учебное ограничение, позволяющее обсуждать отказ операции и выполнять арифметику в <code>long long</code> без переполнения. Это не ограничение единиц измерения или C++.</p><p>Полная программа, C++17 и C++20:</p><pre><code class="language-cpp">#include &lt;iostream&gt;

class Distance {
    long long feet_{};
    long long inches_{};
public:
    bool set(long long feet, long long inches) {
        if (feet &lt; 0 || feet &gt; 1'000'000 || inches &lt; 0 || inches &gt;= 12) {
            return false;
        }
        feet_ = feet;
        inches_ = inches;
        return true;
    }
    long long feet() const { return feet_; }
    long long inches() const { return inches_; }
};

int main() {
    Distance distance;
    long long feet{}, inches{};
    if (!(std::cin &gt;&gt; feet &gt;&gt; inches)) {
        std::cout &lt;&lt; "input error\n";
        return 1;
    }
    if (!distance.set(feet, inches)) {
        std::cout &lt;&lt; "invalid distance\n";
        return 1;
    }
    std::cout &lt;&lt; distance.feet() &lt;&lt; ' ' &lt;&lt; distance.inches() &lt;&lt; '\n';
    return 0;
}</code></pre><p>Для входа <code>11 6</code> программа выводит <code>11 6</code>. Вход <code>1 12</code> отклоняется: интерфейс принимает уже нормализованные части, а не произвольное число дюймов. Можно было бы выбрать автоматическую нормализацию, но это был бы другой контракт.</p><p>Ввод выполняется во временные числа. Лишь после проверки формы и диапазона <code>set</code> записывает оба поля. При отказе прежний объект остаётся допустимым. Начальные нули тоже допустимы, поэтому объект никогда не требует обязательного «первого setter-а» перед чтением.</p><p>Класс управляет смысловым состоянием, а <code>main</code> — диалогом и сообщениями об ошибке. Поэтому те же операции можно использовать без клавиатуры. В <a href="https://stepik.org/lesson/877081/step/3" rel="noopener noreferrer nofollow">следующем шаге</a> значения будут проверяться непосредственно при создании объекта конструктором.</p>

<h3>Конструктор устанавливает инвариант</h3>

<p>Конструктор участвует в инициализации нового объекта. В его объявлении используется имя класса, а тип возвращаемого значения не записывается. Конструктор не заменяет выделение памяти: для локального объекта хранение обеспечивает объявление, а конструктор инициализирует его части.</p><p>Полная программа, C++17 и C++20:</p><pre><code class="language-cpp">#include &lt;iostream&gt;
#include &lt;stdexcept&gt;

class Distance {
    long long feet_{};
    long long inches_{};
public:
    static constexpr long long max_feet = 1'000'000;

    Distance() = default;
    Distance(long long feet, long long inches)
        : feet_(feet), inches_(inches) {
        if (feet &lt; 0 || feet &gt; max_feet || inches &lt; 0 || inches &gt;= 12) {
            throw std::invalid_argument("distance");
        }
    }

    long long feet() const { return feet_; }
    long long inches() const { return inches_; }
    long long total_inches() const { return feet_ * 12 + inches_; }
};

int main() {
    Distance zero;
    const Distance length{11, 6};
    std::cout &lt;&lt; zero.feet() &lt;&lt; ' ' &lt;&lt; zero.inches() &lt;&lt; '\n';
    std::cout &lt;&lt; length.total_inches() &lt;&lt; '\n';
    try {
        Distance invalid{1, 12};
        std::cout &lt;&lt; invalid.total_inches() &lt;&lt; '\n';
    } catch (const std::invalid_argument&amp;) {
        std::cout &lt;&lt; "invalid distance\n";
    }
    return 0;
}</code></pre><p>Результат:</p><pre><code class="language-no-highlight">0 0
138
invalid distance</code></pre><p>Список после двоеточия инициализирует поля: <code>feet_(feet), inches_(inches)</code>. Поля инициализируются в порядке их объявления в классе, а не в произвольном порядке списка. Тело конструктора затем проверяет сочетание значений. При неверном диапазоне оно бросает исключение: полностью созданного <code>invalid</code> не появляется, а уже созданные подобъекты освобождаются по правилам языка.</p><p><code>Distance() = default;</code> явно оставляет конструктор без аргументов. Поля с <code>{}</code> получают нули, то есть допустимую длину. После объявления конструктора с параметрами конструктор по умолчанию не добавляется автоматически; здесь он нужен и указан явно. В общем случае defaulted-конструктор может оказаться удалённым, если один из подобъектов нельзя инициализировать.</p><p><code>max_feet</code> — именованная константа типа, общая для всех объектов; её <code>static constexpr</code> объявление подробнее связано с <a href="https://stepik.org/lesson/877083/step/1" rel="noopener noreferrer nofollow">членами класса static</a>. Арифметика выполняется в <code>long long</code>, а выбранный предел намного меньше его гарантированного максимума.</p><p>В учебном типе из <a href="https://stepik.org/lesson/877081/step/2" rel="noopener noreferrer nofollow">предыдущего шага</a> ошибку изменения сообщал <code>bool</code>. У конструктора нет такого возвращаемого значения: при невозможности создать допустимый объект здесь используется исключение. Другой проект может предоставлять отдельную функцию создания с явным результатом ошибки. Главное — не выдавать завершённый объект с нарушенным инвариантом.</p>

<h3>Деструктор и владение ресурсом</h3>

<p>Деструктор — специальная функция-член, которая участвует в уничтожении объекта. Его запись начинается с <code>~</code> перед именем класса. Он не принимает аргументов и не имеет записываемого возвращаемого типа. Для локальных объектов с автоматической длительностью хранения уничтожение происходит при выходе из их блока, в обратном порядке завершения их создания. Локальный <code>static</code> сохраняется между вызовами, как разобрано в <a href="https://stepik.org/lesson/770592/step/1" rel="noopener noreferrer nofollow">теме времени жизни и static</a>.</p><p>Полная программа, C++17 и C++20:</p><pre><code class="language-cpp">#include &lt;iostream&gt;
#include &lt;stdexcept&gt;
#include &lt;string&gt;

class Trace {
    std::string name_;
public:
    explicit Trace(const std::string&amp; name) : name_(name) {
        std::cout &lt;&lt; "begin " &lt;&lt; name_ &lt;&lt; '\n';
    }
    ~Trace() {
        std::cout &lt;&lt; "end " &lt;&lt; name_ &lt;&lt; '\n';
    }
};

int main() {
    try {
        Trace first{"first"};
        Trace second{"second"};
        throw std::runtime_error("stop");
    } catch (const std::runtime_error&amp;) {
        std::cout &lt;&lt; "caught\n";
    }
    return 0;
}</code></pre><p>Результат:</p><pre><code class="language-no-highlight">begin first
begin second
end second
end first
caught</code></pre><p>Сначала созданы <code>first</code> и <code>second</code>. Исключение переводит управление к подходящему обработчику; при выходе из блока сначала уничтожается <code>second</code>, затем <code>first</code>. Уничтожение не требует вручную вставленных вызовов очистки на каждом таком пути. После тела деструктора автоматически уничтожаются члены и базы в предписанном обратном порядке.</p><p>Идея RAII связывает ресурс с временем жизни владеющего объекта: объект получает ресурс при создании и освобождает его при уничтожении. Ресурсом может быть память, открытый файл или блокировка. Это уже встречалось у <a href="https://stepik.org/lesson/771131/step/1" rel="noopener noreferrer nofollow">файлового потока</a> и <code>std::string</code>; оно не ограничено операциями <code>new</code>/<code>delete</code>.</p><p>Деструктор <code>Trace</code> нужен только для наблюдения за порядком. Строка <code>name_</code> освобождает свои ресурсы сама. Для <code>Distance</code>, содержащего только числа, собственный пустой деструктор не нужен. Когда поля уже правильно владеют своими ресурсами, обычно достаточно не определять специальные операции вручную — это рекомендация «правило нуля». Она будет продолжена в <a href="https://stepik.org/lesson/853536/step/1" rel="noopener noreferrer nofollow">уроке об умных указателях</a>.</p><p>Пример показывает выход из блока и раскрутку стека к обработчику. Аварийное завершение процесса и вызов <code>std::exit</code> не гарантируют уничтожение всех локальных объектов активных функций. В деструкторах избегают выхода исключения наружу: при раскрутке другого исключения это может завершить программу.</p>

<h3>Определение метода вне класса и контракт сложения</h3>

<p>В классе можно оставить объявление метода, а его тело определить отдельно. Имя <code>Distance::add_dist</code> связывает функцию с классом. Это остаётся методом и имеет те же права доступа, что при записи тела внутри класса.</p><p>Полная программа, C++17 и C++20:</p><pre><code class="language-cpp">#include &lt;iostream&gt;
#include &lt;stdexcept&gt;

class Distance {
    long long feet_{};
    long long inches_{};
public:
    static constexpr long long max_feet = 1'000'000;
    Distance() = default;
    Distance(long long feet, long long inches);
    long long feet() const { return feet_; }
    long long inches() const { return inches_; }
    long long total_inches() const { return feet_ * 12 + inches_; }
    Distance add_dist(const Distance&amp; other) const;
};

Distance::Distance(long long feet, long long inches)
    : feet_(feet), inches_(inches) {
    if (feet &lt; 0 || feet &gt; max_feet || inches &lt; 0 || inches &gt;= 12) {
        throw std::invalid_argument("distance");
    }
}

Distance Distance::add_dist(const Distance&amp; other) const {
    const long long total = total_inches() + other.total_inches();
    if (total &gt; max_feet * 12 + 11) {
        throw std::overflow_error("distance sum");
    }
    return Distance{total / 12, total % 12};
}

int main() {
    const Distance first{3, 5};
    const Distance second{11, 7};
    Distance result = first.add_dist(second);
    std::cout &lt;&lt; result.feet() &lt;&lt; ' ' &lt;&lt; result.inches() &lt;&lt; '\n';
    std::cout &lt;&lt; first.feet() &lt;&lt; ' ' &lt;&lt; first.inches() &lt;&lt; '\n';
    return 0;
}</code></pre><p>Результат:</p><pre><code class="language-no-highlight">15 0
3 5</code></pre><p>Сумма 3 футов 5 дюймов и 11 футов 7 дюймов равна 15 футам: 12 дюймов дают ещё один фут. Метод переводит обе длины в целые дюймы, складывает их и возвращает нормализованный результат через деление и остаток. Каждый операнд ограничен инвариантом, поэтому промежуточная сумма безопасна для <code>long long</code>. Результат выше допустимого предела вызывает <code>std::overflow_error</code>.</p><p>Метод возвращает новый объект; левый и правый операнды остаются прежними даже при отказе. Это контракт сложения, а не метод «записать сумму двух чужих объектов в текущий». <code>const</code> после списка параметров относится к текущему объекту, а <code>const Distance&amp;</code> — к параметру. Обе части записи сохранены в объявлении и определении.</p><p>В отдельном проекте определение класса помещают в заголовок, а определения обычных методов — в <code>.cpp</code>, который участвует в сборке. Полный <a href="https://stepik.org/lesson/770592/step/2" rel="noopener noreferrer nofollow">многофайловый пример</a> уже показывает, как объявления доступны другим единицам трансляции. Здесь всё записано в одном файле, чтобы наблюдать синтаксис и поведение без смены инструмента.</p>

<h3>Друг класса: точное право доступа</h3>

<p>Иногда операция естественно записывается свободной функцией, но ей нужен доступ к внутреннему представлению. Класс может явно объявить такую функцию другом с помощью <code>friend</code>. Это право доступа, а не членство в классе.</p><p>Полная программа, C++17 и C++20:</p><pre><code class="language-cpp">#include &lt;iostream&gt;

class Value {
    int number_;
public:
    explicit Value(int number) : number_(number) {}
    friend bool equal(const Value&amp; left, const Value&amp; right);
};

bool equal(const Value&amp; left, const Value&amp; right) {
    return left.number_ == right.number_;
}

int main() {
    const Value first{7}, second{7}, third{8};
    std::cout &lt;&lt; std::boolalpha &lt;&lt; equal(first, second) &lt;&lt; ' '
              &lt;&lt; equal(first, third) &lt;&lt; '\n';
    return 0;
}</code></pre><p>Результат:</p><pre><code class="language-no-highlight">true false</code></pre><p>У <code>equal</code> нет <code>this</code>, поэтому она получает оба объекта как параметры. Доступ к <code>number_</code> разрешён объявлением внутри <code>Value</code>. Помещение <code>friend</code> в секцию <code>public</code> или <code>private</code> не меняет смысл предоставленного доступа. В данном примере любое значение <code>int</code> допустимо, а сравнение не меняет состояния.</p><p>Дружба не наследуется, не является взаимной и не передаётся по цепочке. Если <code>A</code> разрешил доступ <code>B</code>, это не даёт <code>A</code> доступ к <code>B</code> и не делает друзей <code>B</code> друзьями <code>A</code>. Друг обязан сохранять тот же инвариант, что и методы класса.</p><p>Если публичного интерфейса достаточно, свободной функции не нужна дружба. Например, функция вывода может пользоваться методами чтения. Рекомендация — предоставлять ровно тот доступ, который нужен реализации; это решение проектирования, а не обязательное правило языка. В <a href="https://stepik.org/lesson/877083/step/3" rel="noopener noreferrer nofollow">следующем уроке о доступе</a> показан друг, являющийся одной функцией-членом другого класса; перегрузки операторов тоже могут быть свободными функциями.</p>
