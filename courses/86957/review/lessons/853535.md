<p><strong>Конструктор копирования</strong></p>

<p><strong>Конструктор копирования</strong> в C++ используется для создания копии объекта класса при инициализации. <strong>Оператор присваивания копированием</strong> (или <em><strong>«копирующее присваивание»</strong></em>) используется для копирования одного объекта класса в другой существующий объект. По умолчанию компилятор автоматически предоставляет конструктор копирования и оператор присваивания копированием, если они не определены пользователем. Однако, эти автоматически сгенерированные функции выполняют только поверхностное копирование, что может приводить к проблемам у классов, работающих с динамической памятью. Для решения этих проблем необходимо переопределить конструктор копирования и оператор присваивания копированием, чтобы они выполняли <strong>глубокое копирование данных</strong>.</p>

<h3><strong>Семантика перемещения</strong></h3>

<p> </p>

<p>В C++11 были добавлены две новые функции - конструктор перемещения и оператор присваивания перемещением - для работы с семантикой перемещения.В отличие от семантики копирования, которая заключается в создании копии объекта, целью семантики перемещения является перенос владения ресурсами из одного объекта в другой. Это более эффективный процесс, чем копирование, так как он не требует создания новых ресурсов и копирования данных. Особенно полезно использовать семантику перемещения для объектов, которые управляют большими блоками памяти или ресурсами, например, файловыми дескрипторами.</p>

<p><strong>Конструктор перемещения</strong> и <strong>оператор присваивания перемещением</strong> определяются так же, как и конструктор и оператор присваивания копированием. Однако, вместо константной ссылки l-value, функции с перемещением принимают неконстантную ссылку r-value в качестве параметра.</p>

<h3>Когда вызываются конструктор перемещения и оператор присваивания перемещением?</h3>

<p>Конструктор перемещения и оператор присваивания перемещением вызываются, когда аргументом для создания или присваивания является r-value. Чаще всего это будет литерал или временное значение, то есть временный объект.</p>

<p>В большинстве случаев конструктор перемещения и оператор присваивания перемещением не предоставляются по умолчанию. Однако, если это возможно, эти функции могут быть предоставлены по умолчанию, и в этом случае они будут выполнять то же самое, что и конструктор копирования и оператор присваивания копированием, то есть копирование, а не перемещение.</p>

<p>Если мы создаем объект или выполняем присваивание, где аргументом является l-value, то единственное разумное, что мы можем сделать - это скопировать l-value. Мы не можем изменять l-value безопасно, так как он может использоваться в программе позже. Если у нас есть выражение <code>a = b</code>, то мы не хотим, чтобы <code>b</code> был изменен.</p>

<p>Однако, если мы создаем объект или выполняем присваивание, где аргументом является r-value, то мы знаем, что это временный объект. Вместо копирования его ресурсов, что может быть затратно, мы можем просто переместить их в другой объект, который мы создаем или которому присваиваем текущий. Это безопасно, потому что временный объект будет уничтожен в конце выражения, поэтому мы можем быть уверены, что он <strong>никогда</strong> не будет повторно использован.</p>

<p>В C++11 через ссылки r-value мы можем изменять поведение функций в зависимости от того, чем является аргумент: r-value или l-value. Это позволяет нам принимать более разумные и эффективные решения о том, как должен работать наш код.</p>

<p style="text-align: center;"><strong>std::move и std::forward</strong></p>

<p>Функция <strong>std::move</strong> позволяет явно привести объект к r-value, тем самым сообщая компилятору, что можно использовать семантику перемещения для данного объекта. Она принимает в качестве параметра ссылку на объект и возвращает r-value ссылку на этот объект. Функция не перемещает объект, а лишь приводит его к r-value, поэтому ее можно использовать безопасно для любого объекта, который может быть перемещен. Вот простейший пример использования:</p>

<pre><code>int main() {
    std::vector&lt;int&gt; v1{1, 2, 3};
    std::vector&lt;int&gt; v2 = std::move(v1); // перемещение v1 в v2

    std::cout &lt;&lt; v1.size() &lt;&lt; std::endl; // 0
    std::cout &lt;&lt; v2.size() &lt;&lt; std::endl; // 3

    return 0;
}</code></pre>

<p>Функция <strong>std::forward</strong> используется для передачи параметров в шаблонных функциях, чтобы сохранить r-value или l-value семантику параметров. Она принимает два параметра: ссылку на объект и тип этого объекта. Внутри функции тип объекта приводится к r-value или l-value, в зависимости от того, является ли переданный параметр r-value или l-value. Если переданный параметр является r-value, то std::forward вернет r-value ссылку на объект, если же параметр является l-value, то вернется l-value ссылка. Функция std::forward позволяет сохранить правильную семантику переданных параметров, что особенно важно для шаблонных функций.</p>

<pre><code>template&lt;typename T&gt;
void foo(T&amp;&amp; arg) {
    bar(std::forward&lt;T&gt;(arg));
}

void bar(std::vector&lt;int&gt;&amp;&amp; v) {
    std::cout &lt;&lt; "r-value reference" &lt;&lt; std::endl;
}

void bar(std::vector&lt;int&gt;&amp; v) {
    std::cout &lt;&lt; "l-value reference" &lt;&lt; std::endl;
}

int main() {
    std::vector&lt;int&gt; v1{1, 2, 3};
    foo(v1); // передача l-value
    foo(std::vector&lt;int&gt;{1, 2, 3}); // передача r-value

    return 0;
}</code></pre>

<p>В этом примере мы создаем шаблонную функцию <code>foo</code>, которая принимает параметр <code>arg</code> с помощью ссылки на универсальную ссылку <code>T&amp;&amp;</code>. Внутри функции <code>foo</code> мы вызываем функцию <code>bar</code> и передаем в нее <code>arg</code>, используя функцию std::forward, чтобы сохранить правильную семантику параметра.</p>

<p>Функция <code>bar</code> имеет две перегрузки: для l-value ссылок и для r-value ссылок. В зависимости от типа параметра, который был передан в <code>foo</code>, будет вызвана соответствующая перегрузка функции <code>bar</code>.</p>

<p>В функции <code>main</code> мы вызываем функцию <code>foo</code> дважды: первый раз с передачей l-value (вектора <code>v1</code>), а второй раз с передачей r-value (вектора, созданного прямо в вызове функции). В результате, при вызове <code>bar</code> будет выведено соответствующее сообщение о типе переданного параметра.</p>

<p>Использование std::move и std::forward позволяет сократить затраты на копирование объектов и повысить производительность программы за счет использования семантики перемещения. Однако, следует быть внимательным при использовании этих функций, чтобы не произошло нежелательного перемещения ресурсов или повреждения объектов.</p>
