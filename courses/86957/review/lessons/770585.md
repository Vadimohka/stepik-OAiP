<h3><strong>Указатель в С++</strong></h3>

<p>Указатель – переменная, значением которой является адрес ячейки памяти.</p>

<p><img alt="" height="1140" name="Frame 10.png" src="https://ucarecdn.stepik.net/231618f6-930c-4d8b-9689-5956a618e3da/-/crop/4609x1140/0,564/-/preview/" width="4609"></p>

<p>То есть указатель ссылается на блок данных  из области памяти, причём на самое его начало. Указатель может ссылаться на переменную или функцию. Для этого нужно знать адрес переменной или функции. Так вот, чтобы узнать адрес конкретной переменной в С++ существует унарная операция взятия адреса <code>&amp;</code>. Такая операция извлекает адрес объявленных переменных, для того, чтобы его присвоить указателю.</p>

<p>Указатели используются для передачи по ссылке данных, что намного ускоряет процесс обработки этих данных (в том случае, если объём данных большой), так как их не надо копировать, как при передаче по значению, то есть, используя имя переменной. В основном указатели используются для организации динамического распределения памяти, например при объявлении массива, не надо будет его ограничивать в размере. Ведь программист заранее не может знать, какого размера нужен массив тому или иному пользователю, в таком случае используется динамическое выделение памяти под массив. Любой указатель необходимо объявить перед использованием, как и любую переменную.</p>

<p>Для определения указателя надо указать тип объекта, на который указывает указатель, и символ звездочки *. Например, определим указатель на объект типа int:</p>

<pre><code class="language-cpp">int *p;</code></pre>

<p>Указатель - это такой же тип данных, как и int, double или сhar, которые вы изучали до этого.</p>

<pre><code class="language-cpp">int *a;  // тип переменной a - указатель на int
int b;   // тип переменной b - int
char c;  // тип переменной c - char
long *d; // тип переменной d - указатель на long
</code></pre>

<p>Пока указатель не ссылается ни на какой объект. При этом в отличие от ссылки указатель необязательно инициализировать каким-либо значением. Теперь присвоим указателю адрес переменной:</p>

<pre><code class="language-cpp">int x = 10;     // определяем переменную
int *p;         // определяем указатель
p = &amp;x;         // указатель получает адрес переменной</code></pre>

<p>Для получения адреса переменной применяется операция &amp;. Что важно, переменная x имеет тип int, и указатель, который указывает на ее адрес, тоже имеет тип int. То есть должно быть соответствие по типу.</p>

<p>Если мы попробуем вывести адрес переменной на консоль, то увидим, что он представляет шестнадцатеричное значение:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int x = 10;     // определяем переменную
    int *p;         // определяем указатель
    p = &amp;x;         // указатель получает адрес переменной
    std::cout &lt;&lt; "p = " &lt;&lt; p &lt;&lt; std::endl;
    return 0;
}</code></pre>

<p>В каждом отдельном случае адрес может отличаться, но к примеру, в моем случае машинный адрес переменной x - 0x9FE860. То есть в памяти компьютера есть адрес 0x9FE860, по которому располагается переменная x. Так как переменная x представляет тип int, то на большинстве архитектур она будет занимать следующие 4 байта (на конкретных архитектурах размер памяти для типа int может отличаться). Таким образом, переменная типа int последовательно займет ячейки памяти с адресами 0x9FE860, 0x9FE861, 0x9FE862, 0x9FE863.</p>

<p>И указатель p будет ссылаться на адрес, по которому располагается переменная x, то есть на адрес 0x9FE860.</p>

<p><img alt="" height="2859" name="Frame 12.png" src="https://ucarecdn.stepik.net/e64b797c-7720-4a6d-836f-bd96bb790e50/-/crop/4342x2859/0,174/-/preview/" width="4342"></p>

<p>Но так как указатель хранит адрес, то мы можем по этому адресу получить хранящееся там значение, то есть значение переменной x. Для этого применяется операция * или операция разыменования, то есть та операция, которая применяется при определении указателя. Результатом этой операции всегда является объект, на который указывает указатель. Применим данную операцию и получим значение переменной x:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int x = 10;
    int *p;
    p = &amp;x;
    std::cout &lt;&lt; "Address = " &lt;&lt; p &lt;&lt; std::endl;
    std::cout &lt;&lt; "Value = " &lt;&lt; *p &lt;&lt; std::endl;
    return 0;
}</code></pre>

<h3>Возможности работы с указателями</h3>

<p>Значение, которое получено в результате операции разыменования, можно присвоить другой переменной:</p>

<pre><code class="language-cpp">int x = 10;
int *p  = &amp;x;
int y = *p;
std::cout &lt;&lt; "Value = " &lt;&lt; y &lt;&lt; std::endl;    // 10</code></pre>

<p>И также используя указатель, мы можем менять значение по адресу, который хранится в указателе:</p>

<pre><code class="language-cpp">int x = 10;
int *p = &amp;x;
*p = 45;
std::cout &lt;&lt; "x = " &lt;&lt; x &lt;&lt; std::endl;     // 45</code></pre>

<p>Так как по адресу, на который указывает указатель, располагается переменная x, то соответственно ее значение изменится.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

[Открыть на Stepik](https://stepik.org/lesson/770585/step/4?unit=773026) · [Исходник step-source](../../raw/step-sources/3212970.json) · [Объект step](../../raw/steps/3212970.json)

<h3>Подробнее об операциях с указателями</h3>

<p>Указатели поддерживают ряд операций: присваивание, получение адреса указателя, получение значения по указателю, некоторые арифметические операции и операции сравнения.</p>

<h3>Присваивание</h3>

<p>Указателю можно присвоить либо адрес объекта того же типа, либо значение другого указателя.</p>

<p>Присвоение указателю адреса уже рассматривалось в прошлой теме. Для получения адреса объекта используется операция &amp;:</p>

<pre><code class="language-cpp">int a = 10;
int *pa = &amp;a;   // указатель pa хранит адрес переменной a</code></pre>

<p>При этом указатель и переменная должны иметь один и тот же тип, в данном случае это тип int.</p>

<p>Присвоение указателю другого указателя:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int a = 10;
    int b = 2;
      
    int *pa = &amp;a;
    int *pb = &amp;b;
      
    std::cout &lt;&lt; "Variable a: address=" &lt;&lt; pa &lt;&lt; "\t value=" &lt;&lt; *pa &lt;&lt; std::endl;
    std::cout &lt;&lt; "Variable b: address=" &lt;&lt; pb &lt;&lt; "\t value=" &lt;&lt; *pb &lt;&lt; std::endl;
      
    pa = pb;    // теперь указатель pa хранит адрес переменной b
    std::cout &lt;&lt; "Variable b: address=" &lt;&lt; pa &lt;&lt; "\t value=" &lt;&lt; *pa &lt;&lt; std::endl;
     
    return 0;
}</code></pre>

<p>Когда указателю присваивается другой указатель, то фактически первый указатель начинает также указывать на тот же адрес, на который указывает второй указатель.</p>

<h3>Нулевые указатели</h3>

<p>Нулевой указатель (null pointer) - это указатель, который не указывает ни на какой объект. Если мы не хотим, чтобы указатель указывал на какой-то конкретный адрес, то можно присвоить ему условное нулевое значение. Для создания нулевого указателя можно применять различные способы:</p>

<pre><code class="language-cpp">int *p1 = nullptr;
int *p2 = NULL;
int *p3 = 0;</code></pre>

<p>В этом примере указателям присваивается нулевое значение, однако предпочтительным является использование именно nullptr. Т.к. это значение имеет тип именно указателя, тогда как 0 и NULL являются int и в связи с этим иногда поведение может оказаться неожидаемым.</p>

<h3>Ссылки на указатели</h3>

<p>Так как ссылка не является объектом, то нельзя определить указатель на ссылку, однако можно определить ссылку на указатель. Через подобную ссылку можно изменять значение, на которое указывает указатель или изменять адрес самого указателя:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int a = 10;
    int b = 6;
     
    int *p = 0;     // указатель
    int *&amp;pRef = p;     // ссылка на указатель
    
    pRef = &amp;a;          // через ссылку указателю p присваивается адрес переменной a
    std::cout &lt;&lt; "p value=" &lt;&lt; *p &lt;&lt; std::endl;   // 10
    *pRef = 70;         // изменяем значение по адресу, на который указывает указатель
    std::cout &lt;&lt; "a value=" &lt;&lt; a &lt;&lt; std::endl;    // 70
    pRef = &amp;b;          // изменяем адрес, на который указывает указатель
    std::cout &lt;&lt; "p value=" &lt;&lt; *p &lt;&lt; std::endl;   // 6
     
    return 0;
}</code></pre>

<h3>Разыменование указателя</h3>

<p>Операция разыменования указателя представляет выражение в виде <code>*имя_указателя</code>. Эта операция позволяет получить объект по адресу, который хранится в указателе.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int a = 10;
      
    int *pa = &amp;a;
    int *pb = pa;
      
    *pa = 25;
      
    std::cout &lt;&lt; "Value on pointer pa: " &lt;&lt; *pa &lt;&lt; std::endl;  // 25
    std::cout &lt;&lt; "Value on pointer pb: " &lt;&lt; *pb &lt;&lt; std::endl;  // 25
    std::cout &lt;&lt; "Value of variable a: " &lt;&lt; a &lt;&lt; std::endl;    // 25
     
    return 0;
}</code></pre>

<p>Через выражение <code>*pa</code> мы можем получить значение по адресу, который хранится в указателе <code>pa</code>, а через выражение типа <code>*pa = значение</code> вложить по этому адресу новое значение.</p>

<p>И так как в данном случае указатель <code>pa</code> указывает на переменную <code>a</code>, то при изменении значения по адресу, на который указывает указатель, также изменится и значение переменной <code>a</code>.</p>

<h3>Адрес указателя</h3>

<p>Указатель хранит адрес переменной, и по этому адресу мы можем получить значение этой переменной. Но кроме того, указатель, как и любая переменная, сам имеет адрес, по которому он располагается в памяти. Этот адрес можно получить также через операцию &amp;:</p>

<pre><code class="language-cpp">int a = 10;
int *pa = &amp;a;
std::cout &lt;&lt; "address of pointer=" &lt;&lt; &amp;pa &lt;&lt; std::endl;        // адрес указателя
std::cout &lt;&lt; "address stored in pointer=" &lt;&lt; pa &lt;&lt; std::endl;  // адрес, который хранится в указателе - адрес переменной a         
std::cout &lt;&lt; "value on pointer=" &lt;&lt; *pa &lt;&lt; std::endl;          // значение по адресу в указателе - значение переменной a</code></pre>

<h3>Операции сравнения</h3>

<p>К указателям могут применяться операции сравнения &gt;, &gt;=, &lt;, &lt;=,==, !=. Операции сравнения применяются только к указателям одного типа и к значениям NULL и nullptr. Для сравнения используются номера адресов:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int a = 10;
    int b = 20;
    int *pa = &amp;a;
    int *pb = &amp;b;
     
    if (pa &gt; pb) {
        std::cout &lt;&lt; "pa (" &lt;&lt; pa &lt;&lt; ") is greater than pb ("&lt;&lt; pb &lt;&lt; ")" &lt;&lt; std::endl;
    } else {
        std::cout &lt;&lt; "pa (" &lt;&lt; pa &lt;&lt; ") is less or equal pb ("&lt;&lt; pb &lt;&lt; ")" &lt;&lt; std::endl;
    }
     
    return 0;
}</code></pre>

<h3>Приведение типов</h3>

<p>Иногда требуется присвоить указателю одного типа значение указателя другого типа. В этом случае следует выполнить операцию приведения типов с помощью операции <code>(тип_указателя *)</code>:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    char c = 'N';
    char *pc = &amp;c;
    int *pd = (int*)pc;
    void *pv = (void*)pc;
    std::cout &lt;&lt; "pv=" &lt;&lt; pv &lt;&lt; std::endl;
    std::cout &lt;&lt; "pd=" &lt;&lt; pd &lt;&lt; std::endl;
 
    return 0;
}</code></pre>

<p>Для преобразования указателя к другому типу в скобках перед указателем ставится тип, к которому надо преобразовать. Причем если мы не можем просто создать объект, например, переменную типа void, то для указателя это вполне будет работать. То есть можно создать указатель типа void.</p>

<p>Кроме того, следует отметить, что указатель на тип char (<code>char *pc = &amp;c</code>) при выводе на консоль система интерпретирует как строку:</p>

<pre><code class="language-cpp">std::cout &lt;&lt; "pc=" &lt;&lt; pc &lt;&lt; std::endl;</code></pre>

<p>Поэтому если мы все-таки хотим вывести на консоль адрес, который хранится в указателе типа char, то это указатель надо преобразовать к другому типу, например, к void* или к int*.</p>

<h3>Арифметика указателей</h3>

<p>Указатели могут участвовать в арифметических операциях (сложение, вычитание, инкремент, декремент). Однако сами операции производятся немного иначе, чем с числами. И многое здесь зависит от типа указателя.</p>

<p>К указателю можно прибавлять целое число, и также можно вычитать из указателя целое число. Кроме того, можно вычитать из одного указателя другой указатель.</p>

<p>Рассмотрим вначале операции инкремента и декремента и для этого возьмем указатель на объект типа int:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int n = 10;
      
    int *ptr = &amp;n;
    std::cout &lt;&lt; "address=" &lt;&lt; ptr &lt;&lt; "\tvalue=" &lt;&lt; *ptr &lt;&lt; std::endl;
      
    ptr++;
    std::cout &lt;&lt; "address=" &lt;&lt; ptr &lt;&lt; "\tvalue=" &lt;&lt; *ptr &lt;&lt; std::endl;
      
    ptr--;
    std::cout &lt;&lt; "address=" &lt;&lt; ptr &lt;&lt; "\tvalue=" &lt;&lt; *ptr &lt;&lt; std::endl;
 
    return 0;
}</code></pre>

<p>Операция инкремента ++ увеличивает значение на единицу. В случае с указателем увеличение на единицу будет означать увеличение адреса, который хранится в указателе, на размер типа указателя. То есть в данном случае указатель на тип int, а размер объектов int в большинстве архитектур равен 4 байтам. Поэтому увеличение указателя типа int на единицу означает увеличение значение указателя на 4.</p>

<p><img alt="" height="2739" name="Frame 13.png" src="https://ucarecdn.stepik.net/268c8ae4-5247-45a9-afb3-ebd68d92c438/-/preview/" width="5372"></p>

<p>Фактически увеличение на единицу означает, что мы хотим перейти к следующему объекту в памяти, который находится за текущим и на который указывает указатель. А уменьшение на единицу означает переход назад к предыдущему объекту в памяти.</p>

<p>После изменения адреса мы можем получить значение, которое находится по новому адресу, однако это значение может быть неопределенным, как показано в случае выше.</p>

<p>В случае с указателем типа int увеличение/уменьшение на единицу означает изменение адреса на 4. Аналогично, для указателя типа short эти операции изменяли бы адрес на 2, а для указателя типа char на 1.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    double d = 10.6;
    double *pd = &amp;d;
    std::cout &lt;&lt; "Pointer pd: address:" &lt;&lt; pd &lt;&lt; std::endl;
    pd++;
    std::cout &lt;&lt; "Pointer pd: address:" &lt;&lt; pd &lt;&lt; std::endl;
          
    char c = 'N';
    char *pc = &amp;c;
    std::cout &lt;&lt; "Pointer pc: address:" &lt;&lt; (void*)pc &lt;&lt; std::endl;
    pc++;
    std::cout &lt;&lt; "Pointer pc: address:" &lt;&lt; (void*)pc &lt;&lt; std::endl;
 
    return 0;
}</code></pre>

<p>Увеличение на единицу указателя типа double дало увеличения хранимого в нем адреса на 8 единиц (размер объекта double - 8 байт), а увеличение на единицу указателя типа char дало увеличение хранимого в нем адреса на 1 (размер типа char - 1 байт).</p>

<p>Аналогично указатель будет изменяться при прибавлении/вычитании не единицы, а какого-то другого числа.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    double d = 10.6;
    double *pd = &amp;d;
    std::cout &lt;&lt; "Pointer pd: address:" &lt;&lt; pd &lt;&lt; std::endl;
    pd = pd + 2;
    std::cout &lt;&lt; "Pointer pd: address:" &lt;&lt; pd &lt;&lt; std::endl;
      
    char c = 'N';
    char *pc = &amp;c;
    std::cout &lt;&lt; "Pointer pc: address:" &lt;&lt; (void*)pc &lt;&lt; std::endl;
    pc = pc - 3;
    std::cout &lt;&lt; "Pointer pc: address:" &lt;&lt; (void*)pc &lt;&lt; std::endl;
 
    return 0;
}</code></pre>

<p>В отличие от сложения операция вычитания может применять не только к указателю и целому числу, но и к двум указателям одного типа:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int a = 10;
    int b = 23;
    int *pa = &amp;a;
    int *pb = &amp;b;
    int c = pa - pb;
      
    std::cout &lt;&lt; "pa: " &lt;&lt; pa &lt;&lt; std::endl;
    std::cout &lt;&lt; "pb: " &lt;&lt; pb &lt;&lt; std::endl;
    std::cout &lt;&lt; "c: " &lt;&lt; c &lt;&lt; std::endl;
 
    return 0;
}</code></pre>

<p>Результатом разности двух указателей является "расстояние" между ними. Например, в случае выше адрес из первого указателя на 4 больше, чем адрес из второго указателя (0x60fe8c + 4 = 0x60fe90). Так как размер одного объекта int равен 4 байтам, то расстояние между указателями будет равно (0x60fe90 - 0x60fe8c)/4 = 1.</p>

<h3>Некоторые особенности операций</h3>

<p>При работе с указателями надо отличать операции с самим указателем и операции со значением по адресу, на который указывает указатель.</p>

<pre><code class="language-cpp">int a = 10;
int *pa = &amp;a;
int b = *pa + 20;   // операция со значением, на который указывает указатель
pa++;               // операция с самим указателем
     
std::cout &lt;&lt; "b: " &lt;&lt; b &lt;&lt; std::endl;  ;  // 30</code></pre>

<p>То есть в данном случае через операцию разыменования <code>*pa</code> получаем значение, на которое указывает указатель pa, то есть число 10, и выполняем операцию сложения. То есть в данном случае обычная операция сложения между двумя числами, так как выражение <code>*pa</code> представляет число.</p>

<p>Но в то же время есть особенности, в частности, с операциями инкремента и декремента. Дело в том, что операции *, ++ и -- имеют одинаковый приоритет и при размещении рядом выполняются справа налево.</p>

<p>Например, выполним постфиксный инкремент:</p>

<pre><code class="language-cpp">int a = 10;
int *pa = &amp;a;
std::cout &lt;&lt; "pa: address=" &lt;&lt; pa &lt;&lt; "\tvalue=" &lt;&lt; *pa &lt;&lt; std::endl;
int b = *pa++;      // инкремент адреса указателя
          
std::cout &lt;&lt; "b: value=" &lt;&lt; b &lt;&lt; std::endl;
std::cout &lt;&lt; "pa: address=" &lt;&lt; pa &lt;&lt; "\tvalue=" &lt;&lt; *pa &lt;&lt; std::endl;</code></pre>

<p>В выражении <code>b = *pa++;</code> сначала к указателю присваивается единица (то есть к адресу добавляется 4, так как указатель типа int). Затем так как инкремент постфиксный, с помощью операции разыменования возвращается значение, которое было до инкремента - то есть число 10. И это число 10 присваивается переменной b.</p>

<p>Изменим выражение:</p>

<pre><code class="language-cpp">b = ++*pa;</code></pre>

<p>В данном случае сначала с помощью операции разыменования получаем значение по адресу из указателя pa, к этому значению прибавляется единица. То есть теперь значение по адресу, который хранится в указателе, равно 11. Затем результат операции присваивается переменной b.</p>

<p>Изменим выражение:</p>

<pre><code class="language-cpp">b = *++pa;</code></pre>

<p>Теперь сначала изменяет адрес в указателе, затем мы получаем по этому адресу значение и присваиваем его переменной b. Полученное значение в этом случае может быть неопределенным.</p>

<h3>Указатели на константы</h3>

<p>Указатели могут указывать как на переменные, так и на константы. Чтобы определить указатель на константу, он тоже должен объявляться с ключевым словом const:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    const int a = 10;
    const int *pa = &amp;a;
    std::cout &lt;&lt; "address=" &lt;&lt; pa &lt;&lt; "\tvalue=" &lt;&lt; *pa &lt;&lt; std::endl;
     
    return 0;
}</code></pre>

<p>Здесь указатель <code>pa</code> указывает на константу <code>a</code>. Поэтому даже если мы захотим изменить значение по адресу, который хранится в указателе, мы не сможем это сделать, например так:</p>

<pre><code class="language-cpp">*pa = 34;</code></pre>

<p>В этом случае мы просто получим ошибку во время компиляции.</p>

<p>Возможна также ситуация, когда указатель на константу на самом деле указывает на переменную:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int a = 10;
    const int *pa = &amp;a;
    std::cout &lt;&lt;"value=" &lt;&lt; *pa &lt;&lt; std::endl;     // 10
    a = 22;
    std::cout &lt;&lt;"value=" &lt;&lt; *pa &lt;&lt; std::endl;     // 22
    //*pa = 34;     // так делать нельзя
     
    return 0;
}</code></pre>

<p>В этом случае переменную отдельно мы сможем изменять, однако по прежнему изменить ее значение через указатель мы не сможем.</p>

<p>Через указатель на константу мы не можем изменять значение переменной/константы. Но мы можем присвоить указателю адрес любой другой переменной или константы:</p>

<pre><code class="language-cpp">const int a = 10;
const int *pa = &amp;a;     // указатель указывает на константу a
const int b = 45;
pa = &amp;b;                // указатель указывает на константу b
std::cout &lt;&lt;"value=" &lt;&lt; *pa &lt;&lt; std::endl;     // 45
std::cout &lt;&lt;"value=" &lt;&lt; a &lt;&lt; std::endl;     // 10 - константа a не изменяется</code></pre>

<h3>Константный указатель</h3>

<p>От указателей на константы надо отличать константные указатели. Они не могут изменять адрес, который в них хранится, но могут изменять значение по этому адресу.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int a = 10;
    int *const pa = &amp;a;
    std::cout &lt;&lt; "value=" &lt;&lt; *pa &lt;&lt; std::endl;      // 10
    *pa = 22;                                       // меняем значение
    std::cout &lt;&lt; "value=" &lt;&lt; *pa &lt;&lt; std::endl;      // 22
  
    int b = 45;
    // pa = &amp;b;         так нельзя сделать
     
    return 0;
}</code></pre>

<h3>Константный указатель на константу</h3>

<p>И объединение обоих предыдущих случаев - константный указатель на константу, который не позволяет менять ни хранимый в нем адрес, ни значение по этому адресу:</p>

<pre><code class="language-cpp">int a = 10;
const int *const pa = &amp;a;
 
//*pa = 22;  так сделать нельзя
 
int b = 45;
// pa = &amp;b;  так сделать нельзя </code></pre>

<p>Для лучшего понимания очередности написания типа данных, звездочки и слова const в объявлении указателя, можно прибегнуть к простому приему — прочитать полученную конструкцию справа налево:<br>
const int *ptr1 — значит ptr1 — указатель на int константный<br>
int *const ptr2 — значит ptr2 — константный указатель на int<br>
const int* const ptr3 — значит ptr3 — константный указатель на int константный</p>

<h2>Указатели на указатели</h2>

<p>Указатели могут ссылаться на другие указатели. При этом в ячейках памяти, на которые будут ссылаться первые указатели, будут содержаться не значения, а адреса вторых указателей. Число символов <strong><code>*</code></strong> при объявлении указателя показывает порядок указателя. Чтобы получить доступ к значению, на которое ссылается указатель его необходимо разыменовывать соответствующее количество раз. Разработаем программу, которая будет выполнять некоторые операции с указателями порядка выше первого.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {
    int var = 123; // инициализация переменной var числом 123
    int* ptrvar = &amp;var; // указатель на переменную var
    int** ptr_ptrvar = &amp;ptrvar; // указатель на указатель на переменную var
    int*** ptr_ptr_ptrvar = &amp;ptr_ptrvar;
    std::cout &lt;&lt; " var\t\t= " &lt;&lt; var &lt;&lt; std::endl;
    std::cout &lt;&lt; " *ptrvar\t= " &lt;&lt; *ptrvar &lt;&lt; std::endl;
    std::cout &lt;&lt; " **ptr_ptrvar   = " &lt;&lt; **ptr_ptrvar &lt;&lt; std::endl; // два раза разименовываем указатель, так как он второго порядка
    std::cout &lt;&lt; " ***ptr_ptrvar  = " &lt;&lt; ***ptr_ptr_ptrvar &lt;&lt; std::endl; // указатель третьего порядка
    std::cout &lt;&lt; "\n ***ptr_ptr_ptrvar -&gt; **ptr_ptrvar -&gt; *ptrvar -&gt;      var -&gt; " &lt;&lt; var &lt;&lt; std::endl;
    std::cout &lt;&lt; "\t  " &lt;&lt; &amp;ptr_ptr_ptrvar &lt;&lt; " -&gt; " &lt;&lt; "    " &lt;&lt; &amp;ptr_ptrvar &lt;&lt; " -&gt;" &lt;&lt; &amp;ptrvar &lt;&lt; " -&gt; " &lt;&lt; &amp;var &lt;&lt; " -&gt; " &lt;&lt; var &lt;&lt; std::endl;
    return 0;
}</code></pre>

<p>Я как обычно напишу, что лучше вставить код себе и посмотреть что будет, но дополнительно оставлю скрин с результатом работы программы:</p>

<p><img alt="" height="196" name="image.png" src="https://ucarecdn.stepik.net/ec792ba0-8226-4e1a-9d91-0c01220f8672/" width="657"></p>

<p>Данная программа доказывает тот факт, что для получения значения количество разыменований указателя должно совпадать с его порядком. Логика n-кратного разыменования заключается в том, что программа последовательно перебирает адреса всех указателей вплоть до переменной, в которой содержится значение. В программе показана реализация указателя третьего порядка. И если, используя такой  указатель (третьего порядка) необходимо получить значение, на которое он ссылается, делается 4 шага:</p>

<ol>
	<li>по значению указателя третьего порядка получить адрес указателя второго порядка;</li>
	<li>по значению указателя второго порядка получить адрес указателя первого порядка;</li>
	<li>по значению указателя первого порядка получить адрес переменной;</li>
	<li>по адресу переменной получить доступ к её значению.</li>
</ol>

<p>Данные четыре действия показаны на скриншоте с результатом работы (две предпоследние строки). Верхняя строка показывает имена указателей, а нижняя строка их адреса.</p>

<p>На рисунке ниже показана схема разыменовывания указателя третьего порядка из верхней программы. Суть в том, что указатели связаны друг с другом через свои адреса. Причём, например, для указателя <code>ptr_ptrvar</code> данное число <code>0x63FEB4</code> является адресом, а для указателя <code>ptr_ptr_ptrvar</code> это же число является значением.</p>

<p><img alt="" height="4997" name="Frame 14.png" src="https://ucarecdn.stepik.net/719ea24b-78b2-4cb3-a9db-98b9d8ff3b4a/-/crop/11212x4997/0,155/-/preview/" width="11212"></p>

<p>Именно таким образом выполняется связка указателей. Вообще говоря, указатели порядка выше второго используются редко, но данный материал поможет понять механизм работы указателей.</p>
