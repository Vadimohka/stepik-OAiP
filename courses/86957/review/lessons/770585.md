<h2>Зачем нужен указатель</h2>
<p>Переменная позволяет обращаться к объекту по имени, а индекс — к элементу массива. Указатель хранит способ обращения к объекту, который можно передать или заменить во время работы. Например, две части программы могут обращаться к одному элементу без копирования самого элемента.</p>
<p>Для этого модуля достаточно уже известных переменных, типов, массивов и условий. Мы будем последовательно различать объект, значение указателя, доступ через него, границы массива и время жизни. Сам факт хранения адреса не продлевает жизнь объекта и не делает указатель владельцем.</p>

<p>Сначала используются только адреса существующих локальных объектов. Затем <a href="https://stepik.org/lesson/770586/step/2" rel="noopener noreferrer nofollow">свяжем указатели с массивами</a> и <a href="https://stepik.org/lesson/770587/step/1" rel="noopener noreferrer nofollow">динамической памятью</a>. Для обычных коллекций контейнеры <code>std::array</code> и <code>std::vector</code> остаются удобным основным средством; указатели помогают понять их интерфейсы и ограничения.</p>

<h2>Объект-указатель и объект, на который он указывает</h2>
<p>Тип <code>int*</code> означает «указатель на <code>int</code>». Переменная такого типа сама является объектом и хранит значение указателя. В простейшем случае это значение указывает на другой живой объект. Указатель также может быть нулевым или обозначать позицию сразу за массивом; эти значения нельзя разыменовывать.</p>
<p><strong>Полная программа C++17/C++20.</strong></p>
<pre><code class="language-cpp">#include &lt;iostream&gt;
int main() {
    int value{10};
    int* pointer = &amp;value;
    std::cout &lt;&lt; *pointer &lt;&lt; '\n';
    *pointer = 25;
    std::cout &lt;&lt; value &lt;&lt; '\n';
    pointer = nullptr;
    std::cout &lt;&lt; std::boolalpha &lt;&lt; (pointer == nullptr) &lt;&lt; '\n';
}
</code></pre>
<p>Вывод: <code>10</code>, <code>25</code>, <code>true</code>. Операция <code>&amp;value</code> получает указатель на <code>value</code>. Выражение <code>*pointer</code> обращается к этому объекту. Поэтому присваивание через него меняет именно <code>value</code>, а не отдельную копию.</p>
<table><thead><tr><th>Запись</th><th>Что обозначает</th></tr></thead><tbody><tr><td><code>int* pointer</code></td><td>Объявление объекта-указателя; звёздочка участвует в записи типа.</td></tr><tr><td><code>&amp;value</code></td><td>Получение адреса объекта <code>value</code>; тип выражения <code>int*</code>.</td></tr><tr><td><code>*pointer</code></td><td>Разыменование: доступ к объекту <code>int</code>, когда указатель действителен для такого доступа.</td></tr><tr><td><code>nullptr</code></td><td>Нулевое значение указателя, обозначающее отсутствие объекта.</td></tr></tbody></table>
<p>После <code>pointer = nullptr;</code> объект <code>value</code> продолжает существовать и содержит 25. Изменение указателя не уничтожает прежний объект. В примере владелец хранения — блок <code>main</code>, а указатель лишь даёт доступ.</p>
<p>Локальное <code>int* p;</code> без инициализатора не задаёт допустимого значения. Используйте сразу адрес либо <code>nullptr</code>. Проверка на <code>nullptr</code> полезна, но не доказывает, что любой другой указатель действителен: он мог пережить объект. Числа адресов, которые показывает отладчик, зависят от реализации и запуска; их нельзя автоматически считать физическими адресами оперативной памяти.</p>

<h2>Копия значения и общий доступ</h2>
<p>При копировании числа получается отдельное значение в отдельном объекте. При копировании указателя получаются два указателя на тот же исходный объект. Новый объект <code>int</code> от копирования адреса не создаётся.</p>
<p><strong>Полная программа C++17/C++20.</strong></p>
<pre><code class="language-cpp">#include &lt;iostream&gt;
int main() {
    int value{10};
    int copy = value;
    int* first = &amp;value;
    int* second = first;
    *second = 45;
    std::cout &lt;&lt; value &lt;&lt; ' ' &lt;&lt; copy &lt;&lt; ' ' &lt;&lt; *first &lt;&lt; '\n';
    int other{7};
    second = &amp;other;
    *second = 8;
    std::cout &lt;&lt; value &lt;&lt; ' ' &lt;&lt; other &lt;&lt; ' ' &lt;&lt; *first &lt;&lt; '\n';
}
</code></pre>
<p>Первая строка вывода — <code>45 10 45</code>. Указатели <code>first</code> и <code>second</code> дают общий доступ к <code>value</code>; независимая копия <code>copy</code> сохраняет 10. Затем присваивание <code>second = &amp;other</code> меняет лишь значение второго указателя. <code>first</code> по-прежнему указывает на <code>value</code>. Поэтому вторая строка — <code>45 8 45</code>.</p>
<p>Общий доступ не означает совместного владения: ни один указатель в этой программе ничего не выделял и не должен освобождать. Оба исходных объекта существуют до выхода из <code>main</code>. Если бы объект перестал существовать, все указатели на него потеряли бы право доступа, независимо от числа копий.</p>
<p>Типы тоже проверяются: <code>int*</code> нельзя неявно инициализировать адресом <code>double</code>. Принудительное приведение указателя не превращает лежащий там объект в другой тип. Операции с самими указателями уточняются в <a href="https://stepik.org/lesson/770585/step/4" rel="noopener noreferrer nofollow">следующем шаге</a>.</p>

<h2>Что можно делать с указателем</h2>
<p>Указатель можно копировать, присваивать ему другой допустимый адрес, сравнивать с нулём и разыменовывать при выполнении контракта. Для доступа необходимы одновременно подходящий тип, живой объект и допустимые границы. Ненулевое значение само по себе этого не доказывает.</p>
<p><strong>Фрагмент внутри функции; это не отдельная программа.</strong></p>
<pre><code class="language-cpp">int first{10}, second{20};
int* current = &amp;first;
current = &amp;second; // меняем адрес в current
*current = 21;     // меняем second
int* absent = nullptr;
if (absent != nullptr) {
    *absent = 5;   // эта ветвь не выполняется
}
</code></pre>
<p>Присваивание <code>current</code> и присваивание <code>*current</code> меняют разные объекты. Нулевой указатель используют как явное обозначение отсутствия. В современном C++ для него выбирают <code>nullptr</code>; литерал 0 и исторический макрос <code>NULL</code> также встречаются, но хуже выражают типовой смысл.</p>
<h3>Адрес самого указателя</h3>
<p>У <code>int* current</code> есть собственный адрес <code>&amp;current</code> типа <code>int**</code>. Это адрес объекта-указателя, а не адрес <code>second</code>. Подробная двухуровневая цепочка разобрана в <a href="https://stepik.org/lesson/770585/step/7" rel="noopener noreferrer nofollow">отдельном шаге</a>. Ссылка <code>int*&amp; alias = current;</code> — другое имя для уже существующего указателя; через неё можно менять сам <code>current</code>. Ссылки вводятся систематически в <a href="https://stepik.org/lesson/770590/step/1" rel="noopener noreferrer nofollow">модуле 7</a>.</p>
<h3>Сравнение</h3>
<p><strong>Полная программа C++17/C++20.</strong></p>
<pre><code class="language-cpp">#include &lt;iostream&gt;
int main() {
    int values[]{10, 20};
    int* first = &amp;values[0];
    int* same = first;
    int* second = &amp;values[1];
    std::cout &lt;&lt; std::boolalpha &lt;&lt; (first == same) &lt;&lt; ' '
              &lt;&lt; (first &lt; second) &lt;&lt; '\n';
}
</code></pre>
<p>Равенство подтверждает общий объект; отношение порядка здесь относится к элементам одного массива. Не используйте числовой порядок адресов независимых объектов как переносимый способ установить их «расположение в памяти».</p>
<h3>char*: адрес или строка при выводе</h3>
<p><strong>Фрагмент внутри функции; требуется &lt;iostream&gt;.</strong></p>
<pre><code class="language-cpp">char letter{'N'};
char* position = &amp;letter;
std::cout &lt;&lt; *position &lt;&lt; '\n';
std::cout &lt;&lt; static_cast&lt;const void*&gt;(position) &lt;&lt; '\n';
</code></pre>
<p>Первая строка печатает символ N, вторая — представление адреса, зависящее от реализации. Прямое <code>std::cout &lt;&lt; position</code> выбрало бы вывод C-строки до нулевого терминатора. Один отдельный <code>char</code> не является такой строкой; чтение за его границами недопустимо. Контракт строкового указателя раскрывается в <a href="https://stepik.org/lesson/770586/step/4" rel="noopener noreferrer nofollow">уроке о массивах символов</a>.</p>

<h3>Арифметика указателей</h3>

<p>К указателю на элемент массива можно прибавлять и из него вычитать целое число. Смещение на 1 означает переход на один элемент соответствующего типа, то есть на <code>sizeof(T)</code> байт для <code>T*</code>. Размеры <code>int</code>, <code>short</code> и <code>double</code> зависят от реализации; <code>sizeof(char)</code> всегда равен 1.</p>

<p>Результат должен указывать на элемент того же массива или на позицию сразу за последним элементом. Такой указатель за концом можно использовать как границу, но нельзя разыменовывать. Отдельный объект для этих правил рассматривается как массив из одного элемента.</p>

<h4>Инкремент и декремент</h4>

<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {
    int values[]{10, 20, 30};
    int* ptr = values;
    std::cout &lt;&lt; *ptr &lt;&lt; '\n'; // 10
    ++ptr;
    std::cout &lt;&lt; *ptr &lt;&lt; '\n'; // 20
    --ptr;
    std::cout &lt;&lt; *ptr &lt;&lt; '\n'; // 10
}</code></pre>

<p>В этом примере все обращения остаются внутри массива. Для <code>int n = 10; int* p = &amp;n;</code> выражение <code>p + 1</code> допустимо только как указатель за объектом; <code>*(p + 1)</code> недопустимо. Уже формирование <code>p + 2</code> выходит за допустимые границы.</p>

<h4>Прибавление и вычитание смещения</h4>

<pre><code class="language-cpp">double values[]{10.6, 20.6, 30.6, 40.6};
double* pd = values;
pd += 2;              // &amp;values[2]
std::cout &lt;&lt; *pd;     // 30.6
pd -= 1;              // &amp;values[1]

char letters[]{'A', 'B', 'C', 'D'};
char* pc = &amp;letters[3];
pc -= 3;              // &amp;letters[0]
std::cout &lt;&lt; *pc;     // A</code></pre>

<h4>Разность указателей</h4>

<p>Вычитать можно указатели на элементы одного массива, включая позицию за его концом. Результат — расстояние в элементах, имеющее тип <code>std::ptrdiff_t</code>. Оно должно помещаться в этот тип. Вычитание указателей на разные самостоятельные объекты не определено.</p>

<pre><code class="language-cpp">int values[]{10, 23, 42};
int* first = values;
int* last = values + 2;
auto distance = last - first; // 2
std::cout &lt;&lt; distance;</code></pre>

<h4>Операции с указателем и с объектом</h4>

<p>Выражение <code>*p + 20</code> прибавляет 20 к значению объекта; <code>p + 1</code> сдвигает указатель. Постфиксный <code>++</code> связывается сильнее унарного <code>*</code>: <code>*p++</code> означает <code>*(p++)</code>. Значение выражения <code>p++</code> — старый указатель. Префиксные <code>++</code> и <code>*</code> группируются справа налево: <code>++*p</code> означает <code>++(*p)</code>, а <code>*++p</code> — <code>*(++p)</code>. Приоритет определяет группировку выражения, а не универсальный порядок выполнения операций.</p>

<pre><code class="language-cpp">int values[]{10, 20, 30};
int* p = values;
int b = *p++; // b=10, p указывает на values[1]
b = ++*p;     // values[1]=21, b=21, p не изменился
b = *++p;     // p указывает на values[2], b=30</code></pre>

<p>Декремент применяется по тем же правилам. Перед любым смещением и разыменованием проверяйте границы массива. Выход за границы — неопределённое поведение всей программы, а не обещание получить какое-либо «случайное значение».</p>

<h3>Указатели на константы</h3>

<p>Указатели могут указывать как на изменяемые объекты, так и на константы. В объявлении указателя на константный объект <code>const</code> относится к типу объекта: например, <code>const int* pa</code>. Сам указатель в этом объявлении можно изменять.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    const int a = 10;
    const int *pa = &amp;a;
    std::cout &lt;&lt; "address=" &lt;&lt; pa &lt;&lt; "\tvalue=" &lt;&lt; *pa &lt;&lt; std::endl;
     
    return 0;
}</code></pre>

<p>Здесь указатель <code>pa</code> указывает на константу <code>a</code>. Поэтому даже если мы захотим изменить значение по адресу, который хранится в указателе, мы не сможем это сделать, например так:</p>

<pre><code class="language-cpp">*pa = 34;</code></pre>

<p>В этом случае мы просто получим ошибку во время компиляции.</p>

<p>Возможна также ситуация, когда указатель на константу на самом деле указывает на переменную:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int a = 10;
    const int *pa = &amp;a;
    std::cout &lt;&lt;"value=" &lt;&lt; *pa &lt;&lt; std::endl;     // 10
    a = 22;
    std::cout &lt;&lt;"value=" &lt;&lt; *pa &lt;&lt; std::endl;     // 22
    //*pa = 34;     // так делать нельзя
     
    return 0;
}</code></pre>

<p>В этом случае переменную отдельно мы сможем изменять, однако по-прежнему изменить ее значение через указатель мы не сможем.</p>

<p>Через указатель на константу мы не можем изменять значение переменной/константы. Но мы можем присвоить указателю адрес другой переменной или константы типа int:</p>

<pre><code class="language-cpp">const int a = 10;
const int *pa = &amp;a;     // указатель указывает на константу a
const int b = 45;
pa = &amp;b;                // указатель указывает на константу b
std::cout &lt;&lt;"value=" &lt;&lt; *pa &lt;&lt; std::endl;     // 45
std::cout &lt;&lt;"value=" &lt;&lt; a &lt;&lt; std::endl;     // 10 - константа a не изменяется</code></pre>

<h3>Константный указатель</h3>

<p>От указателей на константы надо отличать константные указатели. Они не могут изменять адрес, который в них хранится, но могут изменять значение по этому адресу.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int a = 10;
    int *const pa = &amp;a;
    std::cout &lt;&lt; "value=" &lt;&lt; *pa &lt;&lt; std::endl;      // 10
    *pa = 22;                                       // меняем значение
    std::cout &lt;&lt; "value=" &lt;&lt; *pa &lt;&lt; std::endl;      // 22
  
    int b = 45;
    // pa = &amp;b;         так нельзя сделать
     
    return 0;
}</code></pre>

<h3>Константный указатель на константу</h3>

<p>И объединение обоих предыдущих случаев - константный указатель на константу, который не позволяет менять ни хранимый в нем адрес, ни значение по этому адресу:</p>

<pre><code class="language-cpp">int a = 10;
const int *const pa = &amp;a;
 
//*pa = 22;  так сделать нельзя
 
int b = 45;
// pa = &amp;b;  так сделать нельзя </code></pre>

<p>Для лучшего понимания очередности написания типа данных, звездочки и слова const в объявлении указателя, можно прибегнуть к простому приему — прочитать полученную конструкцию справа налево:<br>
const int *ptr1 — значит ptr1 — указатель на константный int<br>
int *const ptr2 — значит ptr2 — константный указатель на int<br>

<h2>Указатель на указатель</h2>
<p>Указатель сам является объектом, поэтому можно получить его адрес. Если <code>current</code> имеет тип <code>int*</code>, то <code>&amp;current</code> имеет тип <code>int**</code>. Одно разыменование такого значения обращается к указателю, второе — к числу, на которое он сейчас указывает.</p>
<p><strong>Полная программа C++17/C++20.</strong></p>
<pre><code class="language-cpp">#include &lt;iostream&gt;
int main() {
    int first{10}, second{20};
    int* current = &amp;first;
    int** handle = &amp;current;
    **handle = 11;
    *handle = &amp;second;
    **handle = 22;
    std::cout &lt;&lt; first &lt;&lt; ' ' &lt;&lt; second &lt;&lt; ' ' &lt;&lt; *current &lt;&lt; '\n';
}
</code></pre>
<table><thead><tr><th>Выражение</th><th>Обозначаемый объект</th></tr></thead><tbody><tr><td><code>handle</code></td><td>Хранит адрес <code>current</code>.</td></tr><tr><td><code>*handle</code></td><td>Сам объект-указатель <code>current</code>; ему присваивается <code>&amp;second</code>.</td></tr><tr><td><code>**handle</code></td><td>Сначала <code>first</code>, после изменения <code>current</code> — <code>second</code>.</td></tr></tbody></table>
<p>Вывод: <code>11 22 22</code>. Все звенья цепочки — живые локальные объекты. Перед вторым разыменованием требуется, чтобы и промежуточный указатель обозначал допустимый объект. Наличие внешнего <code>handle</code> не гарантирует допустимость всей цепочки.</p>
<p><code>int**</code> не означает автоматически «двумерный массив». Он указывает на объект <code>int*</code>; этот объект может быть элементом массива указателей на отдельные строки. А встроенный <code>int[2][3]</code> содержит сами строки подряд и при преобразовании даёт указатель на строку, с другим типом. <a href="https://stepik.org/lesson/770586/step/3" rel="noopener noreferrer nofollow">Следующий урок</a> сопоставляет эти представления.</p>
