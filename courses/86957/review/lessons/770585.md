<h3><strong>Указатель в С++</strong></h3>

<p>Указатель – переменная, значением которой является адрес ячейки памяти.</p>

<p><img alt="" height="1140" name="Frame 10.png" src="https://ucarecdn.stepik.net/231618f6-930c-4d8b-9689-5956a618e3da/-/crop/4609x1140/0,564/-/preview/" width="4609"></p>

<p>То есть указатель ссылается на блок данных  из области памяти, причём на самое его начало. Указатель может ссылаться на переменную или функцию. Для этого нужно знать адрес переменной или функции. Так вот, чтобы узнать адрес конкретной переменной в С++ существует унарная операция взятия адреса <code>&amp;</code>. Такая операция извлекает адрес объявленных переменных, чтобы присвоить его указателю.</p>

<p>Передача указателя в функцию позволяет работать с исходным объектом без копирования самого объекта; значение указателя при этом может передаваться по значению. Указатели также применяются для работы с динамически выделенной памятью. Например, размер динамического массива можно выбрать во время выполнения, когда станет известно, сколько элементов нужно пользователю. Любой указатель необходимо объявить перед использованием, как и любую переменную.</p>

<p>Для определения указателя надо указать тип объекта, на который указывает указатель, и символ звездочки *. Например, определим указатель на объект типа int:</p>

<pre><code class="language-cpp">int *p;</code></pre>

<p>Указатель - это такой же тип данных, как и int, double или сhar, которые вы изучали до этого.</p>

<pre><code class="language-cpp">int *a;  // тип переменной a - указатель на int
int b;   // тип переменной b - int
char c;  // тип переменной c - char
long *d; // тип переменной d - указатель на long
</code></pre>

<p>Локальный указатель без инициализатора имеет неопределённое значение: его нельзя читать или разыменовывать до присваивания допустимого значения. Обычно удобно сразу инициализировать его адресом объекта либо <code>nullptr</code>. В следующем примере адрес присваивается до использования указателя.</p>

<pre><code class="language-cpp">int x = 10;     // определяем переменную
int *p;         // определяем указатель
p = &amp;x;         // указатель получает адрес переменной</code></pre>

<p>Для получения адреса переменной применяется <code>&amp;</code>. Если <code>x</code> имеет тип <code>int</code>, то выражение <code>&amp;x</code> имеет тип <code>int*</code>. Указатель объявляется <code>int* p = &amp;x;</code>: тип самого <code>p</code> — <code>int*</code>, а тип объекта, на который он указывает, — <code>int</code>.</p>

<p>Если мы попробуем вывести адрес переменной на консоль, то обычно увидим шестнадцатеричное представление адреса:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int x = 10;     // определяем переменную
    int *p;         // определяем указатель
    p = &amp;x;         // указатель получает адрес переменной
    std::cout &lt;&lt; "p = " &lt;&lt; p &lt;&lt; std::endl;
    return 0;
}</code></pre>

<p>В каждом отдельном случае адрес может отличаться, но к примеру, в моем случае машинный адрес переменной x - 0x9FE860. То есть в памяти компьютера есть адрес 0x9FE860, по которому располагается переменная x. Так как переменная x представляет тип int, то на большинстве архитектур она будет занимать следующие 4 байта (на конкретных архитектурах размер памяти для типа int может отличаться). Таким образом, переменная типа int последовательно займет ячейки памяти с адресами 0x9FE860, 0x9FE861, 0x9FE862, 0x9FE863.</p>

<p>И указатель p будет ссылаться на адрес, по которому располагается переменная x, то есть на адрес 0x9FE860.</p>

<p><img alt="" height="2859" name="Frame 12.png" src="https://ucarecdn.stepik.net/e64b797c-7720-4a6d-836f-bd96bb790e50/-/crop/4342x2859/0,174/-/preview/" width="4342"></p>

<p>Если указатель хранит адрес существующего объекта, через него можно обратиться к этому объекту. Для этого применяется унарный оператор <code>*</code> — разыменование. Тот же символ в объявлении, например <code>int* p;</code>, обозначает тип указателя и не выполняет разыменование. В следующем примере <code>*p</code> обозначает переменную <code>x</code>:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int x = 10;
    int *p;
    p = &amp;x;
    std::cout &lt;&lt; "Address = " &lt;&lt; p &lt;&lt; std::endl;
    std::cout &lt;&lt; "Value = " &lt;&lt; *p &lt;&lt; std::endl;
    return 0;
}</code></pre>

<h3>Возможности работы с указателями</h3>

<p>Значение, которое получено в результате операции разыменования, можно присвоить другой переменной:</p>

<pre><code class="language-cpp">int x = 10;
int *p  = &amp;x;
int y = *p;
std::cout &lt;&lt; "Value = " &lt;&lt; y &lt;&lt; std::endl;    // 10</code></pre>

<p>Также, используя указатель, мы можем менять значение по адресу, который хранится в указателе:</p>

<pre><code class="language-cpp">int x = 10;
int *p = &amp;x;
*p = 45;
std::cout &lt;&lt; "x = " &lt;&lt; x &lt;&lt; std::endl;     // 45</code></pre>

<p>Так как по адресу, на который указывает указатель, располагается переменная x, то соответственно ее значение изменится.</p>

<p>Иллюстрация, как это работает:</p>

<pre><code class="language-cpp">int var = 10;
int* ptr = &amp;var;
*ptr = 20;       // var теперь равен 20
int** pptr = &amp;ptr;
**pptr = 30;     // var теперь равен 30</code></pre>
<p><code>pptr</code> хранит адрес <code>ptr</code>, <code>*pptr</code> — указатель на <code>var</code>, а <code>**pptr</code> обращается к самой <code>var</code>.</p>

<p>Создадим еще несколько указателей:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    short c = 12;
    int d = 10;
    short s = 2;
      
    short *pc = &amp;c;          // получаем адрес переменной c типа short
    int *pd = &amp;d;           // получаем адрес переменной d типа int
    short *ps = &amp;s;         // получаем адрес переменной s типа short
      
    std::cout &lt;&lt; "Variable c: address=" &lt;&lt; pc &lt;&lt; "\t value=" &lt;&lt; *pc &lt;&lt; std::endl;
    std::cout &lt;&lt; "Variable d: address=" &lt;&lt; pd &lt;&lt; "\t value=" &lt;&lt; *pd &lt;&lt; std::endl;
    std::cout &lt;&lt; "Variable s: address=" &lt;&lt; ps &lt;&lt; "\t value=" &lt;&lt; *ps &lt;&lt; std::endl;
     
    return 0;
}</code></pre>

<p>Запустите несколько раз код у себя и посмотрите, что получится.</p>

### Шаг 4 — text (ID 3212970)

[Открыть на Stepik](https://stepik.org/lesson/770585/step/4?unit=773026) · [Исходник step-source](../../raw/step-sources/3212970.json) · [Объект step](../../raw/steps/3212970.json)

<h3>Подробнее об операциях с указателями</h3>

<p>Указатели поддерживают ряд операций: присваивание, получение адреса указателя, получение значения по указателю, некоторые арифметические операции и операции сравнения.</p>

<h3>Присваивание</h3>

<p>Указателю можно присвоить либо адрес объекта того же типа, либо значение другого указателя.</p>

<p>Присвоение указателю адреса уже рассматривалось в прошлой теме. Для получения адреса объекта используется операция &amp;:</p>

<pre><code class="language-cpp">int a = 10;
int *pa = &amp;a;   // указатель pa хранит адрес переменной a</code></pre>

<p>Здесь переменная <code>a</code> имеет тип <code>int</code>, а <code>pa</code> — <code>int*</code>, то есть указатель на <code>int</code>. Согласуются тип объекта и тип, на который указывает указатель.</p>

<p>Присвоение указателю другого указателя:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int a = 10;
    int b = 2;
      
    int *pa = &amp;a;
    int *pb = &amp;b;
      
    std::cout &lt;&lt; "Variable a: address=" &lt;&lt; pa &lt;&lt; "\t value=" &lt;&lt; *pa &lt;&lt; std::endl;
    std::cout &lt;&lt; "Variable b: address=" &lt;&lt; pb &lt;&lt; "\t value=" &lt;&lt; *pb &lt;&lt; std::endl;
      
    pa = pb;    // теперь указатель pa хранит адрес переменной b
    std::cout &lt;&lt; "Variable b: address=" &lt;&lt; pa &lt;&lt; "\t value=" &lt;&lt; *pa &lt;&lt; std::endl;
     
    return 0;
}</code></pre>

<p>Когда указателю присваивается другой указатель, то фактически первый указатель начинает также указывать на тот же адрес, на который указывает второй указатель.</p>

<h3>Нулевые указатели</h3>

<p>Нулевой указатель (null pointer) - это указатель, который не указывает ни на какой объект. Если мы не хотим, чтобы указатель указывал на какой-то конкретный адрес, то можно присвоить ему условное нулевое значение. Для создания нулевого указателя можно применять различные способы:</p>

<pre><code class="language-cpp">int *p1 = nullptr;
int *p2 = NULL;
int *p3 = 0;</code></pre>

<p>Во всех трёх объявлениях получается нулевой указатель. С C++11 предпочитайте <code>nullptr</code>: у этого литерала отдельный тип <code>std::nullptr_t</code>, который не является типом указателя, но преобразуется в нулевые указатели. <code>NULL</code> — макрос, конкретное определение которого зависит от реализации; оно не обязано иметь тип <code>int</code>. Нулевой указатель не указывает на доступный объект, разыменовывать его нельзя.</p>

<h3>Ссылки на указатели</h3>

<p>Так как ссылка не является объектом, то нельзя определить указатель на ссылку, однако можно определить ссылку на указатель. Через подобную ссылку можно изменять объект, на который указывает указатель, или адрес, хранящийся в указателе:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int a = 10;
    int b = 6;
     
    int *p = 0;     // указатель
    int *&amp;pRef = p;     // ссылка на указатель
    
    pRef = &amp;a;          // через ссылку указателю p присваивается адрес переменной a
    std::cout &lt;&lt; "p value=" &lt;&lt; *p &lt;&lt; std::endl;   // 10
    *pRef = 70;         // изменяем значение по адресу, на который указывает указатель
    std::cout &lt;&lt; "a value=" &lt;&lt; a &lt;&lt; std::endl;    // 70
    pRef = &amp;b;          // изменяем адрес, на который указывает указатель
    std::cout &lt;&lt; "p value=" &lt;&lt; *p &lt;&lt; std::endl;   // 6
     
    return 0;
}</code></pre>

<h3>Разыменование указателя</h3>

<p>Операция разыменования указателя представляет выражение в виде <code>*имя_указателя</code>. Эта операция позволяет получить объект по адресу, который хранится в указателе.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int a = 10;
      
    int *pa = &amp;a;
    int *pb = pa;
      
    *pa = 25;
      
    std::cout &lt;&lt; "Value on pointer pa: " &lt;&lt; *pa &lt;&lt; std::endl;  // 25
    std::cout &lt;&lt; "Value on pointer pb: " &lt;&lt; *pb &lt;&lt; std::endl;  // 25
    std::cout &lt;&lt; "Value of variable a: " &lt;&lt; a &lt;&lt; std::endl;    // 25
     
    return 0;
}</code></pre>

<p>Через выражение <code>*pa</code> мы можем получить значение по адресу, который хранится в указателе <code>pa</code>, а через выражение типа <code>*pa = значение</code> вложить по этому адресу новое значение.</p>

<p>И так как в данном случае указатель <code>pa</code> указывает на переменную <code>a</code>, то при изменении значения по адресу, на который указывает указатель, также изменится и значение переменной <code>a</code>.</p>

<h3>Адрес указателя</h3>

<p>Указатель хранит адрес переменной, и по этому адресу мы можем получить значение этой переменной. Но кроме того, указатель, как и любая переменная, сам имеет адрес, по которому он располагается в памяти. Этот адрес можно получить также через операцию &amp;:</p>

<pre><code class="language-cpp">int a = 10;
int *pa = &amp;a;
std::cout &lt;&lt; "address of pointer=" &lt;&lt; &amp;pa &lt;&lt; std::endl;        // адрес указателя
std::cout &lt;&lt; "address stored in pointer=" &lt;&lt; pa &lt;&lt; std::endl;  // адрес, который хранится в указателе - адрес переменной a         
std::cout &lt;&lt; "value on pointer=" &lt;&lt; *pa &lt;&lt; std::endl;          // значение по адресу в указателе - значение переменной a</code></pre>

<h3>Операции сравнения</h3>

<p>Указатели можно сравнивать на равенство: <code>==</code> и <code>!=</code>. Порядок элементов одного массива можно определять сравнениями <code>&lt;</code>, <code>&gt;</code>, <code>&lt;=</code>, <code>&gt;=</code>. В примере оба указателя относятся к одному массиву. Числовой порядок адресов несвязанных объектов не следует использовать как переносимое правило языка.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {
    int values[]{10, 20};
    int* pa = &amp;values[0];
    int* pb = &amp;values[1];
    std::cout &lt;&lt; std::boolalpha &lt;&lt; (pa &lt; pb) &lt;&lt; '\n'; // true
}</code></pre>

<h3>Вывод адреса и значения char</h3>

<p>Для вывода адреса объекта через указатель на <code>char</code> преобразуйте его к <code>const void*</code>. Преобразование к <code>int*</code> для этого не требуется и не разрешает обращаться к символу как к объекту <code>int</code>.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {
    char c = 'N';
    char* pc = &amp;c;
    std::cout &lt;&lt; "address=" &lt;&lt; static_cast&lt;const void*&gt;(pc) &lt;&lt; '\n';
    std::cout &lt;&lt; "character=" &lt;&lt; *pc &lt;&lt; '\n';
    const char text[] = "N";
    std::cout &lt;&lt; "string=" &lt;&lt; text &lt;&lt; '\n';
}</code></pre>

<p>Перегрузка <code>operator&lt;&lt;</code> для <code>char*</code> или <code>const char*</code> ожидает C-строку с завершающим нулевым символом. Один объект <code>char c = 'N';</code> такой строкой не является. Выражение <code>std::cout &lt;&lt; pc;</code> для этого <code>pc</code> может читать за границами объекта и имеет неопределённое поведение. Для одного символа выводите <code>*pc</code>, для строки используйте массив с терминатором, как <code>text</code> в примере.</p>

<h3>Арифметика указателей</h3>

<p>К указателю на элемент массива можно прибавлять и из него вычитать целое число. Смещение на 1 означает переход на один элемент соответствующего типа, то есть на <code>sizeof(T)</code> байт для <code>T*</code>. Размеры <code>int</code>, <code>short</code> и <code>double</code> зависят от реализации; <code>sizeof(char)</code> всегда равен 1.</p>

<p>Результат должен указывать на элемент того же массива или на позицию сразу за последним элементом. Такой указатель за концом можно использовать как границу, но нельзя разыменовывать. Отдельный объект для этих правил рассматривается как массив из одного элемента.</p>

<h4>Инкремент и декремент</h4>

<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {
    int values[]{10, 20, 30};
    int* ptr = values;
    std::cout &lt;&lt; *ptr &lt;&lt; '\n'; // 10
    ++ptr;
    std::cout &lt;&lt; *ptr &lt;&lt; '\n'; // 20
    --ptr;
    std::cout &lt;&lt; *ptr &lt;&lt; '\n'; // 10
}</code></pre>

<p>В этом примере все обращения остаются внутри массива. Для <code>int n = 10; int* p = &amp;n;</code> выражение <code>p + 1</code> допустимо только как указатель за объектом; <code>*(p + 1)</code> недопустимо. Уже формирование <code>p + 2</code> выходит за допустимые границы.</p>

<h4>Прибавление и вычитание смещения</h4>

<pre><code class="language-cpp">double values[]{10.6, 20.6, 30.6, 40.6};
double* pd = values;
pd += 2;              // &amp;values[2]
std::cout &lt;&lt; *pd;     // 30.6
pd -= 1;              // &amp;values[1]

char letters[]{'A', 'B', 'C', 'D'};
char* pc = &amp;letters[3];
pc -= 3;              // &amp;letters[0]
std::cout &lt;&lt; *pc;     // A</code></pre>

<h4>Разность указателей</h4>

<p>Вычитать можно указатели на элементы одного массива, включая позицию за его концом. Результат — расстояние в элементах, имеющее тип <code>std::ptrdiff_t</code>. Оно должно помещаться в этот тип. Вычитание указателей на разные самостоятельные объекты не определено.</p>

<pre><code class="language-cpp">int values[]{10, 23, 42};
int* first = values;
int* last = values + 2;
auto distance = last - first; // 2
std::cout &lt;&lt; distance;</code></pre>

<h4>Операции с указателем и с объектом</h4>

<p>Выражение <code>*p + 20</code> прибавляет 20 к значению объекта; <code>p + 1</code> сдвигает указатель. Постфиксный <code>++</code> связывается сильнее унарного <code>*</code>: <code>*p++</code> означает <code>*(p++)</code>. Значение выражения <code>p++</code> — старый указатель. Префиксные <code>++</code> и <code>*</code> группируются справа налево: <code>++*p</code> означает <code>++(*p)</code>, а <code>*++p</code> — <code>*(++p)</code>. Приоритет определяет группировку выражения, а не универсальный порядок выполнения операций.</p>

<pre><code class="language-cpp">int values[]{10, 20, 30};
int* p = values;
int b = *p++; // b=10, p указывает на values[1]
b = ++*p;     // values[1]=21, b=21, p не изменился
b = *++p;     // p указывает на values[2], b=30</code></pre>

<p>Декремент применяется по тем же правилам. Перед любым смещением и разыменованием проверяйте границы массива. Выход за границы — неопределённое поведение всей программы, а не обещание получить какое-либо «случайное значение».</p>

<h3>Указатели на константы</h3>

<p>Указатели могут указывать как на изменяемые объекты, так и на константы. В объявлении указателя на константный объект <code>const</code> относится к типу объекта: например, <code>const int* pa</code>. Сам указатель в этом объявлении можно изменять.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    const int a = 10;
    const int *pa = &amp;a;
    std::cout &lt;&lt; "address=" &lt;&lt; pa &lt;&lt; "\tvalue=" &lt;&lt; *pa &lt;&lt; std::endl;
     
    return 0;
}</code></pre>

<p>Здесь указатель <code>pa</code> указывает на константу <code>a</code>. Поэтому даже если мы захотим изменить значение по адресу, который хранится в указателе, мы не сможем это сделать, например так:</p>

<pre><code class="language-cpp">*pa = 34;</code></pre>

<p>В этом случае мы просто получим ошибку во время компиляции.</p>

<p>Возможна также ситуация, когда указатель на константу на самом деле указывает на переменную:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int a = 10;
    const int *pa = &amp;a;
    std::cout &lt;&lt;"value=" &lt;&lt; *pa &lt;&lt; std::endl;     // 10
    a = 22;
    std::cout &lt;&lt;"value=" &lt;&lt; *pa &lt;&lt; std::endl;     // 22
    //*pa = 34;     // так делать нельзя
     
    return 0;
}</code></pre>

<p>В этом случае переменную отдельно мы сможем изменять, однако по-прежнему изменить ее значение через указатель мы не сможем.</p>

<p>Через указатель на константу мы не можем изменять значение переменной/константы. Но мы можем присвоить указателю адрес другой переменной или константы типа int:</p>

<pre><code class="language-cpp">const int a = 10;
const int *pa = &amp;a;     // указатель указывает на константу a
const int b = 45;
pa = &amp;b;                // указатель указывает на константу b
std::cout &lt;&lt;"value=" &lt;&lt; *pa &lt;&lt; std::endl;     // 45
std::cout &lt;&lt;"value=" &lt;&lt; a &lt;&lt; std::endl;     // 10 - константа a не изменяется</code></pre>

<h3>Константный указатель</h3>

<p>От указателей на константы надо отличать константные указатели. Они не могут изменять адрес, который в них хранится, но могут изменять значение по этому адресу.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    int a = 10;
    int *const pa = &amp;a;
    std::cout &lt;&lt; "value=" &lt;&lt; *pa &lt;&lt; std::endl;      // 10
    *pa = 22;                                       // меняем значение
    std::cout &lt;&lt; "value=" &lt;&lt; *pa &lt;&lt; std::endl;      // 22
  
    int b = 45;
    // pa = &amp;b;         так нельзя сделать
     
    return 0;
}</code></pre>

<h3>Константный указатель на константу</h3>

<p>И объединение обоих предыдущих случаев - константный указатель на константу, который не позволяет менять ни хранимый в нем адрес, ни значение по этому адресу:</p>

<pre><code class="language-cpp">int a = 10;
const int *const pa = &amp;a;
 
//*pa = 22;  так сделать нельзя
 
int b = 45;
// pa = &amp;b;  так сделать нельзя </code></pre>

<p>Для лучшего понимания очередности написания типа данных, звездочки и слова const в объявлении указателя, можно прибегнуть к простому приему — прочитать полученную конструкцию справа налево:<br>
const int *ptr1 — значит ptr1 — указатель на константный int<br>
int *const ptr2 — значит ptr2 — константный указатель на int<br>
const int* const ptr3 — значит ptr3 — константный указатель на константный int</p>

<h2>Указатели на указатели</h2>

<p>Указатель на указатель хранит адрес другой переменной-указателя. Та, в свою очередь, хранит адрес следующего объекта. Число символов <code>*</code> в объявлении показывает число уровней косвенного обращения. Чтобы дойти до конечного объекта, такой указатель последовательно разыменовывают нужное число раз. Рассмотрим пример:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {
    int var = 123; // инициализация переменной var числом 123
    int* ptrvar = &amp;var; // указатель на переменную var
    int** ptr_ptrvar = &amp;ptrvar; // указатель на указатель на переменную var
    int*** ptr_ptr_ptrvar = &amp;ptr_ptrvar;
    std::cout &lt;&lt; " var\t\t= " &lt;&lt; var &lt;&lt; std::endl;
    std::cout &lt;&lt; " *ptrvar\t= " &lt;&lt; *ptrvar &lt;&lt; std::endl;
    std::cout &lt;&lt; " **ptr_ptrvar   = " &lt;&lt; **ptr_ptrvar &lt;&lt; std::endl; // два раза разыменовываем указатель, так как он второго порядка
    std::cout &lt;&lt; " ***ptr_ptr_ptrvar = " &lt;&lt; ***ptr_ptr_ptrvar &lt;&lt; std::endl; // указатель третьего порядка
    std::cout &lt;&lt; "\n ***ptr_ptr_ptrvar -&gt; **ptr_ptrvar -&gt; *ptrvar -&gt;      var -&gt; " &lt;&lt; var &lt;&lt; std::endl;
    std::cout &lt;&lt; "\t  " &lt;&lt; &amp;ptr_ptr_ptrvar &lt;&lt; " -&gt; " &lt;&lt; "    " &lt;&lt; &amp;ptr_ptrvar &lt;&lt; " -&gt;" &lt;&lt; &amp;ptrvar &lt;&lt; " -&gt; " &lt;&lt; &amp;var &lt;&lt; " -&gt; " &lt;&lt; var &lt;&lt; std::endl;
    return 0;
}</code></pre>

<p>Я как обычно напишу, что лучше вставить код себе и посмотреть, что будет, но дополнительно оставлю пример результата работы программы:</p>

<p></p><pre>var = 123
*ptrvar = 123
**ptr_ptrvar = 123
***ptr_ptr_ptrvar = 123

***ptr_ptr_ptrvar -&gt; **ptr_ptrvar -&gt; *ptrvar -&gt; var -&gt; 123
0x63FEB0 -&gt; 0x63FEB4 -&gt; 0x63FEB8 -&gt; 0x63FEBC -&gt; 123</pre><p></p>

<p>Данная программа показывает, что для получения значения количество разыменований указателя должно совпадать с его порядком. Логика n-кратного разыменования заключается в том, что программа последовательно перебирает адреса всех указателей вплоть до переменной, в которой содержится значение. В программе показана реализация указателя третьего порядка. И если, используя такой  указатель (третьего порядка) необходимо получить значение, на которое он ссылается, делается 4 шага:</p>

<ol>
	<li>по значению указателя третьего порядка получить адрес указателя второго порядка;</li>
	<li>по значению указателя второго порядка получить адрес указателя первого порядка;</li>
	<li>по значению указателя первого порядка получить адрес переменной;</li>
	<li>по адресу переменной получить доступ к её значению.</li>
</ol>

<p>Данные четыре действия показаны в примере результата работы (две последние непустые строки). Верхняя строка показывает имена указателей, а нижняя строка их адреса.</p>
