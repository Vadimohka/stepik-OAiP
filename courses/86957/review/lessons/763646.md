<h3>Двумерные массивы в С++</h3>

<p>До этого момента мы рассматривали одномерные массивы, которыми не всегда можно ограничиться. Допустим, необходимо обработать некоторые данные из таблицы. В таблице есть две характеристики: количество строк и количество столбцов. Также и в двумерном массиве, кроме количества элементов массива, есть такие характеристики, как количество строк и количество столбцов. Визуально двумерный массив — это обычная таблица со строками и столбцами. Фактически двумерный массив — это одномерный массив одномерных массивов. Структура двумерного массива с именем <code>a</code>, размером <code>m на n</code> показана ниже, где <code>m</code> — количество строк двумерного массива, <code>n</code> — количество столбцов двумерного массива, <code>m * n</code><strong> </strong>— количество элементов массива.</p>

<table><thead><tr><th>Индекс строки</th><th>Столбец 0</th><th>Столбец 1</th><th>…</th><th>Столбец n−1</th></tr></thead><tbody><tr><th>0</th><td>a[0][0]</td><td>a[0][1]</td><td>…</td><td>a[0][n−1]</td></tr><tr><th>1</th><td>a[1][0]</td><td>a[1][1]</td><td>…</td><td>a[1][n−1]</td></tr><tr><th>…</th><td>…</td><td>…</td><td>…</td><td>…</td></tr><tr><th>m−1</th><td>a[m−1][0]</td><td>a[m−1][1]</td><td>…</td><td>a[m−1][n−1]</td></tr></tbody></table>

<p> </p>

<p>В объявлении двумерного массива, так же как и одномерного, сначала нужно указать:</p>

<ul>
	<li>тип данных;</li>
	<li>имя массива.</li>
</ul>

<p>Затем в первых квадратных скобочках указывается количество строк двумерного массива, во вторых квадратных скобочках — количество столбцов двумерного массива. Двумерный массив визуально отличается от одномерного второй парой квадратных скобочек. Рассмотрим пример объявления двумерного массива. Допустим, нам необходимо объявить двумерный массив из 15 элементов. В таком случае двумерный массив может иметь три строки и пять столбцов или пять строк и три столбца.</p>

<pre><code class="language-cpp">// пример объявления двумерного массива:
int a[5][3];</code></pre>

<ul>
	<li><code>a</code><strong> </strong>— имя целочисленного массива</li>
	<li>число в первых квадратных скобках указывает количество строк двумерного массива, в данном случае их 5;</li>
	<li>число во вторых квадратных скобках указывает количество столбцов двумерного массива, в данном случае их 3.</li>
</ul>

<pre><code class="language-cpp">// инициализация двумерного массива:
int a[5][3] = { {9, 66, -1}, {3, -3, 30}, {1, 1, 1}, {4, 7, 8}, {5, -5, 0} };</code></pre>

<p>В данном массиве 5 строк, 3 столбца. После знака = записан список инициализации в фигурных скобках. В этом примере внутри него по одному списку на каждую строку; списки разделены запятыми. В каждой внутренней паре фигурных скобок через запятую записываются элементы строки. Во внутреннем списке можно указать меньше элементов, чем размер строки: незаданные <code>int</code> будут равны нулю. Например, <code>int a[2][3]{{1, 2}, {4}};</code> задаёт строки <code>{1, 2, 0}</code> и <code>{4, 0, 0}</code>. Указывать больше элементов, чем размер строки, нельзя. В показанной полной инициализации для пяти строк использованы пять внутренних пар скобок. Во внутренних скобочках записаны по три элемента, так как количество столбцов — три.</p>

<h3>Перебор двумерного массива</h3>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    const int rows = 3, columns = 2;
    int numbers[rows][columns] = { {1, 2}, {3, 4}, {5, 6} };
    for (int i=0; i &lt; rows; i++) {
        for (int j=0; j &lt; columns; j++) {
            std::cout &lt;&lt; numbers[i][j] &lt;&lt; "\t";
        }
        std::cout &lt;&lt; std::endl;
    }
    return 0;
}</code></pre>

<p>Также для перебора элементов многомерного массива можно использовать другую форму цикла for:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    const int rows = 3, columns = 2;
    int numbers[rows][columns] = { {1, 2}, {3, 4}, {5, 6} };
     
    for (auto &amp;subnumbers : numbers) {
        for (int number : subnumbers) {
            std::cout &lt;&lt; number &lt;&lt; "\t";
        }
        std::cout &lt;&lt; std::endl;
    }
         
    return 0;
}</code></pre>

<p><em><strong>*</strong></em>Для перебора массивов, которые входят в массив, применяются ссылки. То есть во внешнем цикле <code>for(auto &amp;subnumbers : numbers)</code> имя subnumbers обозначает ссылку на очередной подмассив. Во внутреннем цикле <code>for(int number : subnumbers)</code> из каждого подмассива в subnumbers получаем отдельные его элементы в переменную number и выводим ее значение на консоль.</p>

<h3>Хранение многомерных массивов</h3>

<p>В языке С++ вы можете создавать массивы с ещё большим количеством измерений: трёхмерные, четырёхмерные и так далее. Однако в них сложно ориентироваться, поэтому использовать их рекомендуется только в тех случаях, когда без них не обойтись. Например, в момент отрисовки трёхмерной графики.</p>

<p>Встроенный двумерный массив располагается в памяти по строкам. Для <code>int a[3][6];</code> непосредственно после <code>a[0][5]</code> расположен <code>a[1][0]</code>. Допустимые индексы определяются объявленными размерами. Непрерывность хранения не разрешает обращаться за границы отдельной строки через её индекс или указатель.</p>

<table><caption>Порядок элементов int a[3][6] по строкам</caption><tbody><tr><td><code>a[0][0]</code></td><td><code>a[0][1]</code></td><td><code>a[0][2]</code></td><td><code>a[0][3]</code></td><td><code>a[0][4]</code></td><td><code>a[0][5]</code></td></tr><tr><td><code>a[1][0]</code></td><td><code>a[1][1]</code></td><td><code>a[1][2]</code></td><td><code>a[1][3]</code></td><td><code>a[1][4]</code></td><td><code>a[1][5]</code></td></tr><tr><td><code>a[2][0]</code></td><td><code>a[2][1]</code></td><td><code>a[2][2]</code></td><td><code>a[2][3]</code></td><td><code>a[2][4]</code></td><td><code>a[2][5]</code></td></tr></tbody></table>

<p> Пример с трёхмерным массивом <code>float a[2][2][4]</code>:</p>

<table><caption>Слой i = 0 массива float a[2][2][4]</caption><tbody><tr><td><code>a[0][0][0]</code></td><td><code>a[0][0][1]</code></td><td><code>a[0][0][2]</code></td><td><code>a[0][0][3]</code></td></tr><tr><td><code>a[0][1][0]</code></td><td><code>a[0][1][1]</code></td><td><code>a[0][1][2]</code></td><td><code>a[0][1][3]</code></td></tr></tbody></table>

<p>Быстрее всего изменяется последний индекс <code>k</code>: после <code>a[0][1][1]</code> расположен <code>a[0][1][2]</code>, после <code>a[0][1][3]</code> — <code>a[1][0][0]</code>. У массива <code>a[2][2][4]</code> индексы <code>i</code> и <code>j</code> лежат в пределах 0…1, а <code>k</code> — 0…3.</p>

<h3>Где хранятся массивы</h3>

<p>Размер, известный при компиляции, и продолжительность хранения — разные свойства. Массив в пространстве имён, статический член класса и локальный массив с <code>static</code> имеют статическую продолжительность хранения. Локальный массив без <code>static</code> обычно имеет автоматическую продолжительность хранения и на распространённых реализациях размещается на стеке. Размер стека ограничен, поэтому большой автоматический массив может привести к переполнению стека. Массив, созданный через <code>new[]</code>, имеет динамическую продолжительность хранения; его освобождают через <code>delete[]</code>.</p>

<pre><code class="language-cpp">void example() {
    int automatic_array[100]{};        // автоматическая продолжительность хранения
    static int static_array[100]{};    // статическая продолжительность хранения
}</code></pre>
