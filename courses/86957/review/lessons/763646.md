<h3>Двумерные массивы в С++</h3>

<p>До этого момента мы рассматривали одномерные массивы, которыми не всегда можно ограничиться. Допустим, необходимо обработать некоторые данные из таблицы. В таблице есть две характеристики: количество строк и количество столбцов. Также и в двумерном массиве, кроме количества элементов массива, есть такие характеристики как, количество строк и количество столбцов двумерного массива. То есть, визуально, двумерный массив — это обычная таблица, со строками и столбцами. Фактически двумерный массив — это одномерный массив одномерных массивов. Структура двумерного массива, с именем <code>a</code>, размером <code>m на n</code> показана ниже, где, <code>m</code> — количество строк двумерного массива, <code>n</code> — количество столбцов двумерного массива, <code>m * n</code><strong> </strong>— количество элементов массива.</p>

<p><img alt="" height="309" name="Frame.png" src="https://ucarecdn.stepik.net/95aeb297-bbdd-4a25-95a7-19c2d3d5565f/-/preview/" width="598"></p>

<p> </p>

<p>В объявлении  двумерного массива, также как и в объявлении одномерного массива, первым делом, нужно указать:</p>

<ul>
	<li>тип данных;</li>
	<li>имя массива.</li>
</ul>

<p>После чего, в первых квадратных скобочках указывается количество строк двумерного массива, во вторых квадратных скобочках — количество столбцов двумерного массива. Двумерный массив визуально отличается от одномерного второй парой квадратных скобочек. Рассмотрим пример объявления двумерного массива. Допустим нам необходимо объявить двумерный массив, с количеством элементов, равным 15. В таком случае двумерный массив может иметь три строки и пять столбцов или пять строк и три столбца.</p>

<pre><code class="language-cpp">// пример объявление двумерного массива:
int a[5][3];</code></pre>

<ul>
	<li><code>a</code><strong> </strong>— имя целочисленного массива</li>
	<li>число в первых квадратных скобках указывает количество строк двумерного массива, в данном случае их 5;</li>
	<li>число во вторых квадратных скобках указывает количество столбцов двумерного массива, в данном случае их 3.</li>
</ul>

<pre><code class="language-cpp">// инициализация двумерного массива:
int a[5][3] = { {9, 66, -1}, {3, -3, 30}, {1, 1, 1}, {4, 7, 8}, {5, -5, 0} };</code></pre>

<p>В данном массиве 5 строк, 3 столбца. После знака присвоить ставятся общие фигурные скобочки, внутри которых ставится столько пар фигурных скобочек, сколько должно быть строк в двумерном массиве, причём эти скобочки разделяются запятыми. В каждой паре фигурных скобочек записывать через запятую элементы двумерного массива. Во всех фигурных скобочках количество элементов должно совпадать. Так как в массиве пять строк, то и внутренних пар скобочек тоже пять. Во внутренних скобочках записаны по три элемента, так как количество столбцов — три.</p>

<h3>Перебор двумерного массива</h3>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    const int rows = 3, columns = 2;
    int numbers[rows][columns] = { {1, 2}, {3, 4}, {5, 6} };
    for (int i=0; i &lt; rows; i++) {
        for (int j=0; j &lt; columns; j++) {
            std::cout &lt;&lt; numbers[i][j] &lt;&lt; "\t";
        }
        std::cout &lt;&lt; std::endl;
    }
    return 0;
}</code></pre>

<p>Также для перебора элементов многомерного массива можно использовать другую форму цикла for:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {
    const int rows = 3, columns = 2;
    int numbers[rows][columns] = { {1, 2}, {3, 4}, {5, 6} };
     
    for (auto &amp;subnumbers : numbers) {
        for (int number : subnumbers) {
            std::cout &lt;&lt; number &lt;&lt; "\t";
        }
        std::cout &lt;&lt; std::endl;
    }
         
    return 0;
}</code></pre>

<p><em><strong>*</strong></em>Для перебора массивов, которые входят в массив, применяются ссылки. То есть во внешнем цикле <code>for(auto &amp;subnumbers : numbers)</code> &amp;subnumbers представляет ссылку на подмассив в массиве. Во внутреннем цикле <code>for(int number : subnumbers)</code> из каждого подмассива в subnumbers получаем отдельные его элементы в переменную number и выводим ее значение на консоль.</p>

### Шаг 9 — code (ID 3381234)

[Открыть на Stepik](https://stepik.org/lesson/763646/step/9?unit=765813) · [Исходник step-source](../../raw/step-sources/3381234.json) · [Объект step](../../raw/steps/3381234.json)

<p>Для заданной матрицы А размером N*M построить матрицу В такого же размера, элементы которой обладают следующим свойством: элемент B[i][j] равен максимальному из элементов матрицы А, расположенных левее и выше позиции (i,j), включая позицию (i,j).
