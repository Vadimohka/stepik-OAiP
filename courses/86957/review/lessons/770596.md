<h3>Структуры</h3>

<p>C++ предоставляет несколько способов определения пользовательских типов. В этом модуле рассмотрим структуры — механизм, унаследованный языком C++ от C.</p>

<p>Структура в языке C++ представляет собой производный тип данных, который представляет какую-то определенную сущность, так же, как и класс. Нередко структуры применительно к С++ также называют классами. И в реальности различия между ними не такие большие.</p>

<p>Для определения структуры применяется ключевое слово struct, а сам формат определения выглядит следующим образом:</p>

<pre><code class="language-cpp">struct имя_структуры {
    компоненты_структуры
};</code></pre>

<p>Имя_структуры представляет произвольный идентификатор, к которому применяются те же правила, что и при наименовании переменных.</p>

<p>После имени структуры в фигурных скобках помещаются Компоненты_структуры, которые представляют набор описаний объектов и функций, которые составляют структуру.</p>

<p>Например, определим простейшую структуру:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
#include &lt;string&gt;
 
struct person {
    int age;
    std::string name;
};
 
int main() {
    person tom;
    tom.name = "Tom";
    tom.age = 34;
    std::cout &lt;&lt; "Name: " &lt;&lt; tom.name &lt;&lt; "\tAge: " &lt;&lt; tom.age &lt;&lt; std::endl;
    return 0;
}</code></pre>

<p>Здесь определена структура <code>person</code>, которая имеет два элемента: <code>age</code> (представляет тип int) и <code>name</code> (представляет тип string).</p>

<p>После определения структуры мы можем ее использовать. Для начала мы можем определить объект структуры - по сути обычную переменную, которая будет представлять выше созданный тип. Также после создания переменной структуры можно обращаться к ее элементам - получать их значения или, наоборот, присваивать им новые значения.</p>

<p>Члены структуры являются публичными по умолчанию. В C++ доступ можно изменить секциями private и protected; к закрытым членам нельзя обращаться извне произвольно.</p>

<p>Показанная структура person является агрегатом: её можно инициализировать списком в фигурных скобках, передавая значения полей по порядку. Первым объявлено поле age типа int, поэтому сначала указываем возраст, затем имя. У классов и структур с конструкторами правила инициализации могут отличаться.</p>

<pre><code class="language-cpp">person tom = { 34, "Tom" };</code></pre>

<p>Нестатическое поле может иметь полный объектный тип или тип ссылки. Структура не может непосредственно содержать поле своего же типа: в этот момент её тип ещё неполон. Но можно хранить указатель или ссылку на структуру этого типа:</p>

<pre><code class="language-cpp">struct node {
    void* value;
    struct node *next;
};</code></pre>

<p>Можно упростить пример: синтаксис языка позволяет создавать экземпляры структуры сразу же после определения:</p>

<pre><code class="language-cpp">struct point_t {
    int x;
    int y;
} A;</code></pre>

<p>Структура также может быть анонимной. Тогда мы не сможем использовать имя структуры в дальнейшем:</p>

<pre><code class="language-cpp">#include &lt;cmath&gt;
#include &lt;iostream&gt;

int main() {
    struct {
        int x;
        int y;
    } A;
    float distance;
    A.x = 10;
    A.y = 20;
    distance = sqrt((float) (A.x*A.x + A.y*A.y));
    std::cout &lt;&lt; distance;
}</code></pre>

<h3>Определение нового типа</h3>

<p>В C++ объявление <code>struct point_t</code> создаёт новый тип, и далее имя <code>point_t</code> можно использовать без слова <code>struct</code>. Объявление <code>typedef</code> создаёт дополнительное имя уже существующего типа, а не новый самостоятельный тип. В языке C имя-тег структуры используется вместе со словом <code>struct</code>, если для него не объявлен typedef-псевдоним.</p>

<pre><code class="language-cpp">struct point_t {
    int x;
    int y;
};

typedef point_t Point; // Point и point_t — один и тот же тип

int main() {
    point_t p = {10, 20}; // C++: слово struct не требуется
    Point px = {10, 20};
    return p.x == px.x ? 0 : 1;
}</code></pre>

<p>В C++ имя типа доступно и внутри его определения, поэтому самоссылочная структура записывается так:</p>

<pre><code class="language-cpp">struct Node {
    int value;
    Node* next;
};</code></pre>

<h3>Указатели на структуру</h3>

<p>Указатель на структуру создаётся как обычно. Отличие заключается в том, что можно обращаться к полям структуры через указатель с помощью операции "стрелка" (минус + больше). Пример – пользователь вводит число – размер массива пользователей. После этого вводит для каждого из них логин и пароль. Третье поле - идентификатор – задаётся автоматически. После этого все пользователи выводятся на экран.</p>

<p>Пример на ISO C11 (его также можно собрать как C++17/20). Используется интерфейс выделения памяти языка C:</p>

<pre><code class="language-cpp">#include &lt;stdio.h&gt;
#include &lt;stdlib.h&gt;
#include &lt;string.h&gt;
 
#define MAX_SIZE 20
 
typedef struct User {
    char *login;
    char *password;
    int id;
} User;
 
void jsonUser(User *user) {
    printf("{id: %d, login: \"%s\", password: \"%s\"}\n", 
            user-&gt;id, user-&gt;login, user-&gt;password);
}
 
void freeUsersArray(User** users, unsigned size) {
    unsigned i;
    for (i = 0; i &lt; size; i++) {
        free((*users)[i].login);
        free((*users)[i].password);
    }
    free(*users);
}
 
int main() {
    User *users = NULL;
    unsigned size;
    char buffer[128];
    unsigned i;
 
    printf("Enter number of users: ");
    if (scanf("%u", &amp;size) != 1) return 1;
 
    size = size &lt;= MAX_SIZE? size: MAX_SIZE;
    users = (User*) malloc(size * sizeof(User));
    if (size != 0 &amp;&amp; users == NULL) return 1;
    for (i = 0; i &lt; size; i++) {
        users[i].login = NULL;
        users[i].password = NULL;
    }
 
    for (i = 0; i &lt; size; i++) {
        printf("user #%u\nname: ", i);
        if (scanf("%127s", buffer) != 1) {
            freeUsersArray(&amp;users, size);
            return 1;
        }
        users[i].id = i;
        users[i].login = (char*) malloc(strlen(buffer) + 1);
        if (users[i].login == NULL) {
            freeUsersArray(&amp;users, size);
            return 1;
        }
        strcpy(users[i].login, buffer);
        printf("password: ");
        if (scanf("%127s", buffer) != 1) {
            freeUsersArray(&amp;users, size);
            return 1;
        }
        users[i].password = (char*) malloc(strlen(buffer) + 1);
        if (users[i].password == NULL) {
            freeUsersArray(&amp;users, size);
            return 1;
        }
        strcpy(users[i].password, buffer);
    }
 
    for (i = 0; i &lt; size; i++) {
        jsonUser(&amp;users[i]);
    }
 
    freeUsersArray(&amp;users, size);

}</code></pre>

<p>Обратите внимание на освобождение памяти: free(users) освобождает только сам массив. Память, на которую указывают поля login и password, автоматически не освобождается. Поэтому в этом примере сначала освобождаем строки каждого пользователя, затем сам массив. Перед вводом все указатели на строки получают NULL: так общая функция очистки безопасна и при частично заполненном массиве. Результаты scanf и malloc проверяются; при конце ввода или отказе выделения памяти программа освобождает уже полученную память и завершается с кодом 1.<br>При вызове jsonUser передаём указатель на экземпляр структуры, поэтому внутри функции доступ к полям осуществляется с помощью оператора -&gt;.</p>

<h3>Устройство структуры в памяти</h3>

<p>В показанных структурах поля располагаются в порядке объявления, но между ними и в конце объекта может находиться заполнение для выравнивания. Смещение поля от начала объекта зависит от размеров и требований к выравниванию предшествующих полей, а также от настроек упаковки. Поэтому размер структуры не всегда равен сумме размеров её полей.</p>

<p><img alt="" height="2118" name="Frame 32.png" src="https://ucarecdn.stepik.net/a48b3771-7662-413a-ad6a-9c0bcbb62bae/-/crop/5114x2118/0,188/-/preview/" width="5114"></p>

<p>Проверяем у себя в IDE:</p>

<pre><code class="language-cpp">#include &lt;stdio.h&gt;
 
struct Test1 {
    char a;
    char b;
    int c;
} A;
 
struct Test2 {
    int x;
    int y;
} B;
 
struct Test3 {
    char a;
    char b;
    char c;
    int d;
} C;
 
int main() {
    printf("sizeof(A) = %zu\n", sizeof(A));
    printf("sizeof(B) = %zu\n", sizeof(B));
    printf("sizeof(C) = %zu\n", sizeof(C));

}</code></pre>

<p>При sizeof(char) = 1 и sizeof(int) = 4 суммы размеров полей равны 6, 8 и 7 байтам. Это ещё не размеры самих структур. Например, в обычном ABI MSVC x64/GCC x86-64 при alignof(int) = 4 и без изменения упаковки sizeof каждой из трёх структур равен 8: заполнение обеспечивает выравнивание int. Стандарт C++ не фиксирует эти численные размеры.</p>

<p>Есть возможность изменить упаковку структур в памяти. Можно явно указать компилятору каким образом производить упаковку полей структуры, объединений или полей класса. Каким образом это делать, зависит от компилятора. Один из самых распространённых способов <code>#pragma pack(n)</code>.</p>

<p>У неё есть несколько разновидностей, рассмотрим только одну. pragma pack(n) указывает значение в байтах, используемое для упаковки. Значение по умолчанию зависит от компилятора, целевой архитектуры и параметров сборки. Для воспроизводимых примеров задавайте упаковку явно через #pragma pack(push, n), а затем восстанавливайте её через #pragma pack(pop). Допустимыми значениями являются 1, 2, 4, 8 и 16. При таком режиме выравнивание каждого поля ограничивается меньшим из n и его естественного требования к выравниванию. Размер структуры также учитывает необходимое конечное заполнение; pragma не меняет sizeof встроенных типов.</p>

<p>Использование #pragma pack не приветствуется: логика работы программы не должна зависеть от внутреннего представления структуры (если, конечно, вы не занимаетесь системным программированием или ломаете чужие программы и сети).</p>

<h3>Приведение типов</h3>

<p>Совпадение полей не делает два разных структурных типа взаимозаменяемыми. Для показанных ниже Point и Apex прямое присваивание apex = point или приведение (Apex)point не определено как допустимое преобразование и приводит к ошибке компиляции. В C++ преобразование можно отдельно описать конструктором или оператором преобразования, но здесь их нет.</p>

<p>Для таких похожих структур можно явно скопировать нужные поля:</p>

<pre><code>#include &lt;stdio.h&gt;
 
struct Point {
    int x;
    int y;
};
 
struct Apex {
    int a;
    int b;
};

int main() {
    struct Point point = {10, 20};
    struct Apex apex;
 
    apex.a = point.x;
    apex.b = point.y;
 
    printf("a = %d, b = %d", apex.a, apex.b);

}</code></pre>

<p>Приведение указателя само по себе не превращает массив int в объект Point. Следующий пример может компилироваться, но чтение массива через Point нарушает правила доступа к объекту и имеет неопределённое поведение в ISO C++17/20:</p>

<pre><code class="language-cpp">#include &lt;stdio.h&gt;
 
struct Point {
    int x;
    int y;
};
 
int main() {
    struct Point point = {10, 20};
    int x[3] = {300, 400, 500};
 
    point = (*(struct Point*)(x));
 
    printf("a = %d, b = %d", point.x, point.y);

}</code></pre>

<p>Однако стоит помнить, что поведение программы при таком приведении <strong>не определено</strong>.</p>

<h3>Вложенные структуры</h3>

<p>Структура сама может являться полем структуры. Пример: структура Model – модель автомобиля, имеет название, номер, год выпуска и поле Make, которое в свою очередь хранит номер марки и её название.</p>

<pre><code class="language-cpp">#include &lt;stdio.h&gt;
#include &lt;stdlib.h&gt;
#include &lt;string.h&gt;
 
#define YEAR_OFFSET 1890
 
typedef struct Model {
    int id;
    struct {
        int id;
        char *name;
    } make;
    char *name;
    unsigned char year; //year is an offset to 1890
} Model;
 
char* mallocByString(const char *str) { // функция, которая инициализирует поля типа char*
    char* p = (char*) malloc(strlen(str) + 1);
    if (p != NULL) strcpy(p, str);
    return p;
}
 
void freeModel(Model* model) { // очистка памяти
    free(model-&gt;make.name);
    free(model-&gt;name);
}
 
void xmlModel(Model *model) {
    printf("Some info");
}
 
int main() {
     
    Model cl;
    cl.id = 1;
    cl.make.id = 1;
    cl.make.name = mallocByString("Acura");
    cl.name = mallocByString("CL");
    if (cl.make.name == NULL || cl.name == NULL) {
        freeModel(&amp;cl);
        return 1;
    }
    cl.year = (2003 - YEAR_OFFSET);
 
    xmlModel(&amp;cl);
    freeModel(&amp;cl);

}</code></pre>

<p>Вложенные структуры можно инициализировать вложенными списками. В следующем отдельном примере строки — неизменяемые литералы, поэтому поля имеют тип const char*. Освобождать эти литералы через free не нужно:</p>

<pre><code class="language-cpp">#include &lt;stdio.h&gt;
 
typedef struct Model {
    int id;
    struct {
        int id;
        const char *name;
    } make;
    const char *name;
    unsigned char year; //year is an offset to 1890
} Model;
 
int main() {
    Model m = {10, {10, "Acura"}, "CL", 112};
    printf("Model name = %s\n", m.name);
    printf("Make name = %s\n", m.make.name);

}</code></pre>
<p>mallocByString возвращает NULL при отказе выделения памяти и не вызывает strcpy с нулевым указателем. После получения обеих строк main проверяет результат. При ошибке freeModel освобождает успешно выделенные строки; free(NULL) допустим.</p>

<h3>Указатели на поля структуры и на вложенные структуры</h3>

<p>Указатели на поля структуры определяются так же, как и обычные указатели. Указатели на вложенные структуры возможны только тогда, когда структура определена. Немного переделаем предыдущий пример: "деанонимизируем" вложенную безымянную структуру и возьмём указатели на поля структуры Model:</p>

<pre><code class="language-cpp">#include &lt;stdio.h&gt;
#include &lt;stdlib.h&gt;

    int id;
    Make make;
    char *name;

    char* p = (char*) malloc(strlen(str) + 1);
    if (p != NULL) strcpy(p, str);
    return p;

    free(model-&gt;make.name);
    free(model-&gt;name);

int main() {
    Make *make = NULL;
    Model cl;
    int *id;
 
    cl.id = 2;
    cl.make.id = 1;
    cl.make.name = mallocByString("Acura");
    cl.name = mallocByString("CL");

<p>В примере имя Make позволяет явно записать тип указателя на поле make. Одинаковый набор полей сам по себе не делает две отдельно объявленные структуры одним типом. В C++ указатель на объект безымянного типа можно получить и без имени типа, например auto* make = &amp;cl.make; поэтому именование вложенной структуры удобно, но не является обязательным условием взятия адреса.</p>
<p>mallocByString возвращает NULL при отказе выделения памяти и не вызывает strcpy с нулевым указателем. После получения обеих строк main проверяет результат. При ошибке freeModel освобождает успешно выделенные строки; free(NULL) допустим.</p>

### Шаг 8 — text (ID 3216509)

[Открыть на Stepik](https://stepik.org/lesson/770596/step/8?unit=773037) · [Исходник step-source](../../raw/step-sources/3216509.json) · [Объект step](../../raw/steps/3216509.json)

<h3>Битовые поля</h3>

<p>Битовые поля обеспечивают удобный доступ к отдельным битам данных. Они позволяют задавать ширину отдельных полей в битах; размер содержащего их объекта по-прежнему измеряется целым числом байтов. Это позволяет экономить память, более плотно размещая данные.</p>

<p>Битовое поле не может существовать само по себе. Оно может быть только нестатическим членом класса (в том числе struct или union). Например, в рамках структуры битовые поля имеют следующую форму определений:</p>

<pre><code class="language-cpp">struct имя_структуры {
    тип1 имя_поля1 : ширина_поля1;
    тип2 имя_поля2 : ширина_поля2;
    //..............
    типi имя_поляi : ширина_поляi;
};</code></pre>

<p>Тип битового поля в C++ должен быть целочисленным или перечислимым: допустимы, например, bool, unsigned int, char и enum. Ширина — неотрицательное целое константное выражение. Нулевая ширина допускается только у безымянного поля и задаёт границу размещения. Ширина может превышать число битов типа, но лишние биты служат заполнением и не расширяют диапазон значений. Адрес битового поля получить нельзя; детали его размещения определяет реализация.</p>

<p>Например, определим структуру с битовыми полями:</p>

<pre><code class="language-cpp">struct point {
    unsigned int x:5;   // 0-31
    unsigned int y:3;   // 0-7
};</code></pre>

<p>Структура point содержит два битовых поля. Первое поле x имеет ширину в 5 бит. То есть оно может принимать значения от 0 до 31. Второе поле - y - имеет ширину в 3 бита и может принимать значения от 0 до 7.</p>

<p>Затем мы сможем работать с этой структурой и ее элементами как и с любой структурой:</p>

<pre><code class="language-cpp">#include &lt;stdio.h&gt;
 
struct point {
    unsigned int x:5;   // 0-31
    unsigned int y:3;   // 0-7
};
 
int main(void) {
    struct point center = {0, 5};
    center.x = 2;
    printf("x = %u    y = %u\n", (unsigned)center.x, (unsigned)center.y);  // x = 2  y = 5
     
    return 0;
}</code></pre>

<p>Порядок размещения битовых полей зависит от реализации. Для обычного размещения unsigned int-битовых полей в MSVC на x86/x64 поле x занимает младшие пять битов первого байта, а y — следующие три. При x = 2 и y = 5 схема первого байта выглядит так:</p>

<p><img alt="" height="1042" name="Frame 29.png" src="https://ucarecdn.stepik.net/90a23d84-e3af-4b3f-8684-99f00c654b9a/-/crop/3105x1042/0,190/-/preview/" width="3105"></p>

<p>На схеме показаны восемь битов первого байта, занятые x и y при обычном размещении unsigned int-битовых полей в MSVC для x86/x64. Это не означает, что sizeof(point) равен одному байту: единица размещения и заполнение зависят от реализации. На трёх старших битах изображённого байта размещено поле point.y. Так как оно имеет значение 5, то в двоичной системе это будет 101. А на следующих 5 битах помещается поле point.x со значением 2 (то есть 10 в двоичной системе).</p>

<p>Представление первого байта можно скопировать в unsigned char и вывести его биты. Так мы исследуем конкретную реализацию, не читая неактивный член union:</p>

<pre><code class="language-cpp">#include &lt;cstdio&gt;
#include &lt;cstring&gt;

struct point {
    unsigned int x : 5;
    unsigned int y : 3;
};

int main() {
    point center = {2, 5};
    unsigned char first_byte{};
    std::memcpy(&amp;first_byte, &amp;center, sizeof first_byte);
    for (int bit = 7; bit &gt;= 0; --bit) {
        std::printf("%u ", (static_cast&lt;unsigned&gt;(first_byte) &gt;&gt; bit) &amp; 1u);
    }
    std::printf("\nsizeof(point) = %zu\n", sizeof(point));
}</code></pre>

<p>Чтение неактивного члена union не является переносимым способом анализа представления в ISO C++17/20. memcpy копирует байты представления; порядок битовых полей и итоговый размер структуры всё равно нужно устанавливать для выбранной реализации.</p>
