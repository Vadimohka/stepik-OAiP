<h3>Структуры</h3>

<p>C++ предоставляет множество способов для определения пользовательских типов, который заключается в использовании структур. В этом модуле будет рассмотрен способ, который был унаследован языком С++ еще от языка С.</p>

<p>Структура в языке C++ представляет собой производный тип данных, который представляет какую-то определенную сущность, также как и класс. Нередко структуры применительно к С++ также называют классами. И в реальности различия между ними не такие большие.</p>

<p>Для определения структуры применяется ключевое слово struct, а сам формат определения выглядит следующим образом:</p>

<pre><code class="language-cpp">struct имя_структуры {
    компоненты_структуры
};</code></pre>

<p>Имя_структуры представляет произвольный идентификатор, к которому применяются те же правила, что и при наименовании переменных.</p>

<p>После имени структуры в фигурных скобках помещаются Компоненты_структуры, которые представляют набор описаний объектов и функций, которые составляют структуру.</p>

<p>Например, определим простейшую структуру:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
#include &lt;string&gt;
 
struct person {
    int age;
    std::string name;
};
 
int main() {
    person tom;
    tom.name = "Tom";
    tom.age = 34;
    std::cout &lt;&lt; "Name: " &lt;&lt; tom.name &lt;&lt; "\tAge: " &lt;&lt; tom.age &lt;&lt; std::endl;
    return 0;
}</code></pre>

<p>Здесь определена структура <code>person</code>, которая имеет два элемента: <code>age</code> (представляет тип int) и <code>name</code> (представляет тип string).</p>

<p>После определения структуры мы можем ее использовать. Для начала мы можем определить объект структуры - по сути обычную переменную, которая будет представлять выше созданный тип. Также после создания переменной структуры можно обращаться к ее элементам - получать их значения или, наоборот, присваивать им новые значения.</p>

<p>Все поля структуры являются публичными, т.е. создав объект/экземпляр структуры, мы можем обратиться к любому полю.</p>

<p>Инициализация структур аналогична инициализации массивов: в фигурных скобках передаются значения для элементов структуры по порядку. Так как в структуре person первым определено свойство, которое представляет тип int - число, то в фигурных скобках вначале идет число. И так далее для всех элементов структуры по порядку.</p>

<pre><code class="language-cpp">person tom = { 34, "Tom" };</code></pre>

<p>Полями структуры могут быть любые объявленные типы, кроме самой структуры этого же типа, но можно хранить указатель на структуру этого типа:</p>

<pre><code class="language-cpp">struct node {
    void* value;
    struct node *next;
};</code></pre>

<p>Можно упростить пример: синтаксис языка позволяет создавать экземпляры структуры сразу же после определения:</p>

<pre><code class="language-cpp">struct point_t {
    int x;
    int y;
} A;</code></pre>

<p>Структура также может быть анонимной. Тогда мы не сможем использовать имя структуры в дальнейшем:</p>

<pre><code class="language-cpp">#include &lt;cmath&gt;
#include &lt;iostream&gt;

int main() {
    struct {
        int x;
        int y;
    } A;
    float distance;
    A.x = 10;
    A.y = 20;
    distance = sqrt((float) (A.x*A.x + A.y*A.y));
    std::cout &lt;&lt; distance;
}</code></pre>

<h3>Определение нового типа</h3>

<p>Когда мы определяем новую структуру с помощью служебного слова struct, в пространстве имён структур (оно не имеет ничего общего с пространствами имён С++) создаётся новый идентификатор. Для доступа к нему необходимо использовать служебное слово struct. Можно определить новый тип с помощью служебного слова typedef. Тогда будет создан псевдоним для нашей структуры, видимый в глобальном контексте:</p>

<pre><code class="language-cpp">#include &lt;conio.h&gt;
#include &lt;stdio.h&gt;
 
//Определяем новую структуру
struct point_t {
    int x;
    int y;
};
 
//Определяем новый тип
typedef struct point_t Point;
 
void main() {
    //Обращение через имя структуры
    struct point_t p = {10, 20};
    //Обращение через новый тип
    Point px = {10, 20};
 
    getch();
}</code></pre>

<p>Если мы создаём новый тип-структуру, полем которого является указатель на этот же тип, то его необходимо объявлять явно с использованием служебного слова struct:</p>

<pre><code class="language-cpp">typedef struct Node {
    int value;
    struct Node *next;
} Node;</code></pre>

<h3>Указатели на структуру</h3>

<p>Указатель на структуру создаётся как обычно. Отличие заключается в том, что можно обращаться к полям структуры через указатель с помощью операции "стрелка" (минус + больше). Пример – пользователь вводит число – размер массива пользователей. Поле этого вводит для каждого из них логин и пароль. Третье поле - идентификатор – задаётся автоматически. После этого все пользователи выводятся на экран.</p>

<p>Код на языке С который отлично демонстрирует тонкости работы со структурами:</p>

<pre><code class="language-cpp">#include &lt;conio.h&gt;
#include &lt;stdio.h&gt;
#include &lt;stdlib.h&gt;
#include &lt;string.h&gt;
 
#define MAX_SIZE 20
 
typedef struct User {
    char *login;
    char *password;
    int id;
} User;
 
void jsonUser(User *user) {
    printf("{id: %d, login: \"%s\", password: \"%s\"}\n", 
            user-&gt;id, user-&gt;login, user-&gt;password);
}
 
void freeUsersArray(User** users, unsigned size) {
    unsigned i;
    for (i = 0; i &lt; size; i++) {
        free((*users)[i].login);
        free((*users)[i].password);
    }
    free(*users);
}
 
void main() {
    User *users = NULL;
    unsigned size;
    char buffer[128];
    unsigned i;
 
    printf("Enter number of users: ");
    scanf("%d", &amp;size);
 
    size = size &lt;= MAX_SIZE? size: MAX_SIZE;
    users = (User*) malloc(size * sizeof(User));
 
    for (i = 0; i &lt; size; i++) {
        printf("user #%d\nname: ", i);
        scanf("%127s", buffer);
        users[i].id = i;
        users[i].login = (char*) malloc(strlen(buffer) + 1);
        strcpy(users[i].login, buffer);
        printf("password: ");
        scanf("%127s", buffer);
        users[i].password = (char*) malloc(strlen(buffer) + 1);
        strcpy(users[i].password, buffer);
    }
 
    for (i = 0; i &lt; size; i++) {
        jsonUser(&amp;users[i]);
    }
 
    freeUsersArray(&amp;users, size);
    getch();
}</code></pre>

<p>Обратите внимание на удаление массива структур: при удалении экземпляра структуры он не удаляет своих полей самостоятельно, поэтому необходимо сначала удалять поля, после этого удалять сам массив.<br>
При вызове функции jsonUser мы передаём указатель на экземпляр структуры, поэтому внутри функции доступ до полей осуществляется с помощью оператора стрелка.</p>

<h3>Устройство структуры в памяти</h3>

<p>Поля структуры расположены в памяти друг за другом. Тип поля определяет сдвиг относительно предыдущего поля. Имя поля - это сдвиг относительно адреса экземпляра. На самом деле размер структуры не всегда равен сумме размеров её полей: это связано с тем, что компилятор оптимизирует расположение структуры в памяти и может поля небольшого размера подгонять до чётных адресов.</p>

<p><img alt="" height="2118" name="Frame 32.png" src="https://ucarecdn.stepik.net/a48b3771-7662-413a-ad6a-9c0bcbb62bae/-/crop/5114x2118/0,188/-/preview/" width="5114"></p>

<p>Проверяем у себя в IDE:</p>

<pre><code class="language-cpp">#include &lt;conio.h&gt;
#include &lt;stdio.h&gt;
 
struct Test1 {
    char a;
    char b;
    int c;
} A;
 
struct Test2 {
    int x;
    int y;
} B;
 
struct Test3 {
    char a;
    char b;
    char c;
    int d;
} C;
 
void main() {
    printf("sizeof(A) = %d\n", sizeof(A));
    printf("sizeof(B) = %d\n", sizeof(B));
    printf("sizeof(C) = %d\n", sizeof(C));
 
    getch();
}</code></pre>

<p>Первая структура должна иметь размер 6 байт, вторая 8 байт, третья 7 байт, однако на 32-разрядной машине компилятор VC сделает их все три равными 8 байт. Стандарт гарантирует, что поля расположены друг за другом, но не гарантирует, что непрерывно.</p>

<p>Есть возможность изменить упаковку структур в памяти. Можно явно указать компилятору каким образом производить упаковку полей структуры, объединений или полей класса. Каким образом это делать, зависит от компилятора. Один из самых распространённых способов <code>#pragma pack(n)</code>.</p>

<p>У неё есть несколько разновидностей, рассмотрим только одну. pragma pack(n) указывает значение в байтах, используемое для упаковки. Если параметр компилятора не заданы для модуля значения по умолчанию n 8. Допустимыми значениями являются 1, 2, 4, 8 и 16. Выравнивание поля происходит по адресу, кратному n или сумме нескольких полей объекта, в зависимости от того, какая из этих величин меньше.</p>

<p>Использование #pragma pack не приветствуется: логика работы программы не должна зависеть от внутреннего представления структуры (если, конечно, вы не занимаетесь системным программированием или ломаете чужие программы и сети).</p>

<h3>Приведение типов</h3>

<p>Стандартом поведение при приведении одной структуры к другой не определено. Это значит, что даже если структуры имеют одинаковые поля, то нельзя явно кастовать одну структуру до другой.</p>

<p>Если у нас существуют две похожие друга на друга структуры, то правильное приведение типов выглядит так:</p>

<pre><code>#include &lt;stdio.h&gt;
 
struct Point {
    int x;
    int y;
};
 
struct Apex {
    int a;
    int b;
};

void main() {
    struct Point point = {10, 20};
    struct Apex apex;
 
    apex.a = point.x;
    apex.b = point.y;
 
    printf("a = %d, b = %d", apex.a, apex.b);
 
    getch();
}</code></pre>

<p>Привести массив к структуре (или любому другому типу) по стандарту также невозможно (хотя в различных компиляторах есть для этого инструменты), пример:</p>

<pre><code class="language-cpp">#include &lt;conio.h&gt;
#include &lt;stdio.h&gt;
 
struct Point {
    int x;
    int y;
};
 
void main() {
    struct Point point = {10, 20};
    int x[3] = {300, 400, 500};
 
    point = (*(struct Point*)(x));
 
    printf("a = %d, b = %d", point.x, point.y);
 
    getch();
}</code></pre>

<p>Однако стоит помнить, что поведение программы при таком приведении <strong>не определено</strong>.</p>

<h3>Вложенные структуры</h3>

<p>Структура сама может являться полем структуры. Пример: структура Model – модель автомобиля, имеет название, номер, год выпуска и поле Make, которое в свою очередь хранит номер марки и её название.</p>

<pre><code class="language-cpp">#include &lt;conio.h&gt;
#include &lt;stdio.h&gt;
#include &lt;stdlib.h&gt;
#include &lt;string.h&gt;
 
#define YEAR_OFFSET 1890
 
typedef struct Model {
    int id;
    struct {
        int id;
        char *name;
    } make;
    char *name;
    unsigned char year; //year is an offset to 1890
} Model;
 
char* mallocByString(const char *str) { // функция, которая инициализирует поля типа char*
    char* p = (char*) malloc(strlen(str) + 1);
    strcpy(p, str);
    return p;
}
 
void freeModel(Model* model) { // очистка памяти
    free(model-&gt;make.name);
    free(model-&gt;name);
}
 
void xmlModel(Model *model) {
    printf("Some info");
}
 
int main() {
     
    Model cl;
    cl.id = 1;
    cl.make.id = 1;
    cl.make.name = mallocByString("Acura");
    cl.name = mallocByString("CL");
    cl.year = (2003 - YEAR_OFFSET);
 
    xmlModel(&amp;cl);
    freeModel(&amp;cl);
 
    getch();
}</code></pre>

<p>Вложенные структуры инициализируются как многомерные массивы. В предыдущем примере можно произвести начальную инициализацию следующим образом:</p>

<pre><code class="language-cpp">#include &lt;stdio.h&gt;
#include &lt;conio.h&gt;
 
typedef struct Model {
    int id;
    struct {
        int id;
        char *name;
    } make;
    char *name;
    unsigned char year; //year is an offset to 1890
} Model;
 
void main() {
    Model m = {10, {10, "Acura"}, "CL", 112};
    printf("Model name = %s\n", m.name);
    printf("Make name = %s\n", m.make.name);
    getch();
}</code></pre>

<h3>Указатели на поля структуры и на вложенные структуры</h3>

<p>Указатели на поля структуры определяются также, как и обычные указатели. Указатели на вложенные структуры возможны только тогда, когда структура определена. Немного переделаем предыдущий пример: "деанонимизируем" вложенную безымянную структуру и возьмём указатели на поля структуры Model:</p>

<pre><code class="language-cpp">#include &lt;conio.h&gt;
#include &lt;stdio.h&gt;
#include &lt;stdlib.h&gt;
#include &lt;string.h&gt;
 
#define YEAR_OFFSET 1890
 
//Отдельно выделили структуру "Марка"
typedef struct Make {
    int id;
    char *name;
} Make;
 
//Теперь полем структуры "Модель" является структура "Марка"
typedef struct Model {
    int id;
    Make make;
    char *name;
    unsigned char year; //year is an offset to 1890
} Model;
 
char* mallocByString(const char *str) { // функция, которая инициализирует поля типа char*
    char* p = (char*) malloc(strlen(str) + 1);
    strcpy(p, str);
    return p;
}
  
void freeModel(Model* model) { // очистка памяти
    free(model-&gt;make.name);
    free(model-&gt;name);
}
 
void main() {
    Make *make = NULL;
    Model cl;
    int *id;
 
    cl.id = 2;
    cl.make.id = 1;
    cl.make.name = mallocByString("Acura");
    cl.name = mallocByString("CL");
    cl.year = (2003 - YEAR_OFFSET);
 
    //Получаем указатель на вложенную структуру
    make = &amp;cl.make;
    //Получаем указатель на поле структуры
    id = &amp;cl.id;
    printf("make.name = %s\n", make-&gt;name);
    printf("make.id = %d\n", make-&gt;id);
    printf("model.id = %d\n", *id);

### Шаг 8 — text (ID 3216509)

[Открыть на Stepik](https://stepik.org/lesson/770596/step/8?unit=773037) · [Исходник step-source](../../raw/step-sources/3216509.json) · [Объект step](../../raw/steps/3216509.json)

<h3>Битовые поля</h3>

<p>Битовые поля обеспечивают удобный доступ к отдельным битам данных. Они позволяют формировать объекты с длиной, не кратной байту. Что в свою очередь позволяет экономить память, более плотно размещая данные.</p>

<p>Битовое поле не может существовать само по себе. Оно может быть только элементом структуры или объединения. Например, в рамках структуры битовые поля имеют следующую форму определений:</p>

<pre><code class="language-cpp">struct имя_структуры {
    тип1 имя_поля1 : ширина_поля1;
    тип2 имя_поля2 : ширина_поля2;
    //..............
    типi имя_поляi : ширина_поляi;
}</code></pre>

<p>В данном случае типi представляет тип поля. В качестве типа поля может использоваться только int, допустимы модификаторы signed и unsigned. имя_поля_i - это произвольный идентификатор, а ширина_поля_i - положительное целое число, которое не должно превышать длину машинного слова для конкретной платформы (машинное слово измеряется в битах или байтах и равно разрядности регистров процессора, например, для архитектуры 64x - длина 64 бита).</p>

<p>Например, определим структуру с битовыми полями:</p>

<pre><code class="language-cpp">struct point {
    unsigned int x:5;   // 0-31
    unsigned int y:3;   // 0-7
};</code></pre>

<p>Структура point содержит два битовых поля. Первое поле x имеет ширину в 5 бит. То есть оно может принимать значения от 0 до 31. Второе поле - y - имеет ширину в 3 бита и может принимать значения от 0 до 7.</p>

<p>Затем мы сможем работать с этой структурой и ее элементами как и с любой структурой:</p>

<pre><code class="language-cpp">#include &lt;stdio.h&gt;
 
struct point {
    unsigned int x:5;   // 0-31
    unsigned int y:3;   // 0-7
};
 
int main(void) {
    struct point center = {0, 5};
    center.x = 2;
    printf("x =% d    y= % d \ n ", center.x, center.y);  // x = 2  y = 5
     
    return 0;
}</code></pre>

<p>В зависимости от платформы расположение полей структуры в памяти может отличаться. В частности, на Windows порядок расположения следующий: поля в начале структуры имеют младшие адреса, а поля в конце структуры имеют старшие адреса. То есть если мы возьмем из примера выше поля x и y структуры point с финальными значениями x=2 и y=5, то мы получим на Windows следующее размещение битов в памяти:</p>

<p><img alt="" height="1042" name="Frame 29.png" src="https://ucarecdn.stepik.net/90a23d84-e3af-4b3f-8684-99f00c654b9a/-/crop/3105x1042/0,190/-/preview/" width="3105"></p>

<p>Так как поля x и y вместо занимают 8 бит, то соответственно на картинке имеется 8 ячеек. На трех первых битах размещено поле point.y. Так как оно имеет значение 5, то в двоичной системе это будет 101. А на следующих 5 битах помещается поле point.x со значением 2 (то есть 10 в двоичной системе).</p>

<p>В принципе мы сами можем программным образом узнать размещение полей в памяти. Для этого воспользуемся объединениями:</p>

<pre><code class="language-cpp">#include &lt;stdio.h&gt;
 
struct point {
    unsigned int x:5;   // 0-31
    unsigned int y:3;   // 0-7
};
 
union code {
    struct point p;
    struct{
        unsigned a0:1;
        unsigned a1:1;
        unsigned a2:1;
        unsigned a3:1;
        unsigned a4:1;
        unsigned a5:1;
        unsigned a6:1;
        unsigned a7:1;
    } byte;
};
 
 
int main(void) {
    struct point center = {2, 5};
    union code c;
    c.p = center;
    printf("7 \t 6 \t 5 \t 4 \t 3 \t 2 \t 1 \t 0 \n");
    printf("%d \t %d \t %d \t %d \t %d \t %d \t %d \t %d \n", 
            c.byte.a7, c.byte.a6, c.byte.a5, c.byte.a4, 
            c.byte.a3, c.byte.a2, c.byte.a1, c.byte.a0);
    return 0;
}</code></pre>

<p>Объединение code содержит два элемента - структуры point и безымянную структуру byte. Как известно из прошлой темы, элементы структуры будут занимать одну и ту же область в памяти, точнее будут начинаться с одного и того же места в памяти. Поэтому для выяснения, какие биты заняты, безымянная структура byte имеет 8 полей, каждое из которых имеет ширину 1 бит.</p>
