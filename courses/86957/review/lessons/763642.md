<h2>Оператор return</h2>

<p>Оператор <kbd>return</kbd> используется для выхода из функции. Отнесение его к категории операторов перехода обусловлено тем, что он заставляет программу перейти в точку вызова функции. Оператор <kbd>return</kbd> может иметь ассоциированное с ним значение, тогда при выполнении данного оператора это значение возвращается в качестве значения функции. В функциях типа <kbd>void</kbd> используется оператор <kbd>return</kbd> без значения.</p>

<p>В обычной функции C++ с возвращаемым значением оператор <code>return</code> должен содержать выражение, результат которого используется для получения возвращаемого значения. Общая форма:</p>

<pre>return <em>выражение</em>;</pre>

<p>В показанной форме для функции с возвращаемым значением результат выражения используется для получения результата вызова функции. Особенность return с выражением типа void рассмотрена ниже.</p>

<p>В функции может быть несколько операторов <code>return</code>; выполняется тот из них, до которого дошло управление. Достижение конца функции с возвращаемым типом <code>void</code> эквивалентно <code>return;</code>. Для <code>main</code> достижение конца эквивалентно <code>return 0;</code>. В остальных обычных функциях с возвращаемым значением достижение конца без возврата значения приводит к неопределённому поведению.</p>

<pre><code class="language-cpp">int IMin(int a, int b) {
   if (a &lt; b) return(a);
   else return (b);
}
</code></pre>

<pre><code class="language-cpp">int IMin(int a, int b) {
   return ((a &lt; b) ? a : b);
}
</code></pre>

<p>В функции с возвращаемым типом <code>void</code> можно написать <code>return;</code> без выражения. Также допустимо вернуть выражение типа void, например вызов другой void-функции; возвращаемого значения при этом всё равно нет. В следующем фрагменте для досрочного выхода используется return без выражения (предполагается подключённый заголовок iostream):</p>

<pre><code class="language-cpp">void Print(char a) {
   if (a == 0) {
      std::cout &lt;&lt; "Это плохой аргумент \n"; 
      return;
   }
   std::cout &lt;&lt; "Введен аргумент" &lt;&lt; a;
}
</code></pre>

<h2>Оператор goto</h2>

<p>Кроме <kbd>goto</kbd>, в языке С++ есть другие операторы управления (например <kbd>break</kbd>, <kbd>continue</kbd>), поэтому необходимости в применении <kbd>goto</kbd> практически нет. В результате чрезмерного использования операторов <kbd>goto</kbd> программа плохо читается, она становится "похожей на спагетти". Чаще всего такими программами недовольна администрация фирм, производящих программный продукт. То есть оператор <kbd>goto</kbd> весьма непопулярен, более того, считается, что в программировании не существует ситуаций, в которых нельзя обойтись без оператора <kbd>goto</kbd>. Но в некоторых случаях его применение все же уместно. Иногда, при умелом использовании, этот оператор может оказаться весьма полезным, например, если нужно покинуть глубоко вложенные циклы. </p>

<p>Для оператора <kbd>goto</kbd> всегда необходима метка. <em>Метка</em> — это идентификатор с последующим двоеточием. Метка должна находиться в той же функции, что и <kbd>goto</kbd>, переход в другую функцию невозможен. Общая форма оператора <kbd>goto</kbd> следующая:</p>

<pre><code>goto метка;
.
.
.
метка:</code></pre>

<p>Метка может находиться как до, так и после оператора <kbd>goto</kbd>. Например, используя оператор <kbd>goto</kbd>, можно сто раз увеличить целочисленную переменную x: её значение изменится с 1 до 101:</p>

<pre><code>  x = 1;
loop1:
  x++;
  if (x &lt;= 100) goto loop1;</code></pre>

<h3>Оператор goto также не рекомендуется к использованию!</h3>

<p>Внимательный студент уже заметил, что метки используются и в switch. Это разные конструкции языка, но для переходов в обоих случаях важны область видимости и инициализация переменных. Например, нельзя перепрыгнуть через инициализацию автоматической переменной с инициализатором и попасть в область, где она уже должна быть активна: такую программу компилятор отвергнет. При выходе из блока через goto локальные автоматические объекты уничтожаются по обычным правилам. Это не связано с наличием сборщика мусора; объекты со статическим временем хранения не исчезают при выходе из блока. Подробности разобраны в прикреплённой статье.</p>

<h2>Оператор break</h2>

<p><code>break</code> завершает ближайший охватывающий цикл или <code>switch</code> и передаёт управление инструкции, следующей за ним. В switch это выход из всего оператора switch, а не только из текущей последовательности после case. Обычный блок в фигурных скобках, например тело if, сам по себе целью break не является.</p>

<p>Когда выполняется break, относящийся к данному циклу, цикл немедленно завершается без повторной проверки его условия. Например, программа:</p>

<pre><code>#include &lt;iostream&gt;

int main() {
  for (int t = 0; t &lt; 100; t++) {
    std::cout &lt;&lt; t;
    if (t == 10) {
      break;
    }
  }
  return 0;
}</code></pre>

<p>выводит на экран числа от 0 до 10. После этого выполнение цикла прекращается оператором <kbd>break</kbd>, условие <kbd>t &lt; 100</kbd> при этом игнорируется.</p>

<p>break часто используют, когда событие должно прекратить цикл. Следующий фрагмент — условный пример с внешней проверкой клавиатуры: name, found и kbhit должны быть предоставлены остальной программой. Нажатие клавиши завершает цикл поиска, после чего функция продолжает выполнение за циклом:</p>

<pre><code>void look_up(char *name) {
  do {
    /* поиск имени 'name' */
    if (kbhit()) break;
  } while (!found);
  /* process match */
}</code></pre>

<p>Функция kbhit не входит в стандарт C или C++. Наличие, имя и заголовок такой функции зависят от платформы; например, Microsoft CRT предоставляет <code>_kbhit</code>. Здесь эта проверка показана только как условие для демонстрации break.</p>

<p>Оператор <kbd>break</kbd> вызывает выход только из внутреннего цикла. Например, программа</p>

<pre><code>for (int t = 0; t &lt; 100; ++t) {
  count = 1;
  for (;;) {
    std::cout &lt;&lt; count;
    count++;
    if (count == 10) {
      break;
    }
  }
}</code></pre>

<p>100 раз выводит на экран числа от 1 до 9. Оператор <kbd>break</kbd> передает управление внешнему циклу <kbd>for</kbd>.</p>

<p>Если оператор <kbd>break</kbd> присутствует внутри оператора <kbd>switch</kbd>, который вложен в какие-либо циклы, то <kbd>break</kbd> относится только к <kbd>switch</kbd>, выход из цикла не происходит.</p>

<h2>Оператор continue</h2>

<p>Можно сказать, что оператор <kbd>continue</kbd> немного похож на <kbd>break</kbd>. Оператор <kbd>break</kbd> вызывает прерывание цикла, a <kbd>continue</kbd> — прерывание текущей итерации цикла и осуществляет переход к следующей итерации. При этом все операторы до конца тела цикла пропускаются. В цикле <kbd>for</kbd> оператор <kbd>continue</kbd> вызывает выполнение операторов приращения и проверки условия цикла. В циклах <kbd>while</kbd> и <kbd>do-while</kbd> оператор <kbd>continue</kbd> передает управление операторам проверки условий цикла. В следующем примере программа подсчитывает количество пробелов в строке, введенной пользователем:</p>

<pre><code class="language-cpp">#include &lt;cstddef&gt;
#include &lt;iostream&gt;
#include &lt;string&gt;

int main() {
    std::string text;
    std::cout &lt;&lt; "Введите строку: ";
    if (!std::getline(std::cin, text)) {
        return 0;
    }

    std::size_t spaces = 0;
    for (char ch : text) {
        if (ch != ' ') {
            continue;
        }
        ++spaces;
    }

    std::cout &lt;&lt; spaces &lt;&lt; " пробелов\n";
}</code></pre>

<p>Каждый символ строки сравнивается с пробелом. Если сравниваемый символ не является пробелом, оператор <kbd>continue</kbd> передает управление в конец цикла <kbd>for</kbd> и выполняется следующая итерация. Если символ является пробелом, значение переменной <code>spaces</code> увеличивается на 1.</p>

<p>В следующем примере оператор <kbd>continue</kbd> применяется для выхода из цикла <kbd>while</kbd> путем передачи управления на условие цикла:</p>

<pre><code class="language-cpp">#include &lt;cstdio&gt;

void code() {
    bool done = false;
    while (!done) {
        int ch = std::getchar();
        if (ch == EOF || ch == '$') {
            done = true;
            continue;
        }
        std::putchar(ch + 1);
    }
}</code></pre>

<p>Второй пример рассчитан на ASCII-текст: функция заменяет каждый считанный символ символом с кодом на единицу больше. Она прекращает работу при <code>$</code> или конце ввода. Результат getchar хранится в int, чтобы можно было отличить символ от EOF. После установки done оператор continue передаёт управление к проверке условия while, и цикл завершается. Это демонстрация управления циклом, а не способ кодировать произвольный Unicode-текст.</p>
