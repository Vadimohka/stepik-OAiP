<h2>Операторы перехода</h2>
<p>Обычно инструкции блока выполняются по порядку. Оператор перехода меняет место продолжения. Чтобы прочитать код, нужно понимать не только условие перехода, но и его точную цель.</p>
<table><thead><tr><th>Запись</th><th>Куда переходит управление</th></tr></thead><tbody><tr><td><code>return</code></td><td>Завершает текущий вызов функции; у функции с результатом передаёт его вызывающему коду.</td></tr><tr><td><code>break</code></td><td>Завершает ближайший охватывающий цикл или <code>switch</code>.</td></tr><tr><td><code>continue</code></td><td>Пропускает оставшуюся часть текущего прохода ближайшего цикла.</td></tr><tr><td><code>goto label;</code></td><td>Переходит к именованной метке в той же функции; переход ограничен правилами инициализации.</td></tr></tbody></table>
<p>Цикл повторяет тело, а один проход называется итерацией. В примерах следующих шагов <code>for (int i = 0; i &lt; 3; ++i)</code> перебирает 0, 1 и 2. Подробная последовательность проверки условия и изменения счётчика приведена в <a href="https://stepik.org/lesson/763719/step/4" rel="noopener noreferrer nofollow">уроке о for</a>.</p>
<p>Следующие четыре шага разбирают <a href="https://stepik.org/lesson/763642/step/2" rel="noopener noreferrer nofollow">return</a>, <a href="https://stepik.org/lesson/763642/step/3" rel="noopener noreferrer nofollow">goto</a>, <a href="https://stepik.org/lesson/763642/step/4" rel="noopener noreferrer nofollow">break</a> и <a href="https://stepik.org/lesson/763642/step/5" rel="noopener noreferrer nofollow">continue</a>. При обычном выходе из области локальные автоматические объекты уничтожаются, в том числе при таких переходах. Позже это станет основой автоматического освобождения ресурсов.</p>

<h2>return: завершение вызова функции</h2>
<p>Функция — именованная часть программы, которую можно вызвать. Пока достаточно знать, что значения аргументов поступают в параметры, а <code>return</code> завершает текущий вызов и может передать результат. Подробное устройство функции разобрано в <a href="https://stepik.org/lesson/770590/step/1" rel="noopener noreferrer nofollow">модуле 7</a>.</p>
<p><strong>Полная программа C++17/C++20.</strong></p>
<pre><code class="language-cpp">#include &lt;iostream&gt;
int minimum(int a, int b) {
    if (a &lt; b) {
        return a;
    }
    return b;
}
int main() {
    std::cout &lt;&lt; minimum(4, 7) &lt;&lt; ' ' &lt;&lt; minimum(7, 4)
              &lt;&lt; ' ' &lt;&lt; minimum(4, 4) &lt;&lt; '\n';
    return 0;
}
</code></pre>
<p>Вывод: <code>4 4 4</code>. При <code>a &lt; b</code> первая инструкция <code>return</code> завершает вызов: до второй управление не доходит. Иначе возвращается <code>b</code>. Равенство допустимо, потому что оба значения одинаковы.</p>
<p>У <code>minimum</code> результат имеет тип <code>int</code>. У функции с возвращаемым типом <code>void</code> результата нет и возможен <code>return;</code>. Также допустим <code>return</code> с выражением типа <code>void</code>: это всё равно не создаёт возвращаемого значения. Скобки после <code>return</code> не обязательны — это оператор языка, а не вызов функции.</p>
<p>Достижение конца обычной <code>void</code>-функции эквивалентно <code>return;</code>. У <code>main</code> достижение конца эквивалентно <code>return 0;</code>. В остальных обычных функциях, обещающих значение, выход через конец без результата приводит к неопределённому поведению. Поэтому каждая допустимая ветвь должна возвращать результат или завершаться другим определённым способом.</p>
<p>Ноль из <code>main</code> означает успешное завершение. В примерах курса код 1 обозначает обнаруженную ошибку ввода. Это соглашение программы о сообщении результата среде запуска; напечатанный текст и код завершения — разные каналы.</p>

<h2>goto: переход к метке</h2>
<p><code>goto label;</code> передаёт управление к <code>label:</code> в той же функции. Метка — имя с двоеточием перед инструкцией. Этот механизм полезно узнавать в существующем коде, хотя обычные ветвления и циклы обычно яснее выражают структуру алгоритма.</p>
<p><strong>Фрагмент внутри main с подключённым &lt;iostream&gt;.</strong></p>
<pre><code class="language-cpp">int number{-2};
if (number &lt; 0) {
    goto negative;
}
std::cout &lt;&lt; "nonnegative\n";
goto done;
negative:
std::cout &lt;&lt; "negative\n";
done:
;
</code></pre>
<p>Значение −2 выбирает метку <code>negative</code>, поэтому выводится одна строка <code>negative</code>. После <code>done:</code> стоит пустая инструкция <code>;</code>: в C++17/20 метка должна относиться к инструкции. Ту же логику проще записать так:</p>
<p><strong>Альтернативный фрагмент, не продолжение предыдущего; требуется &lt;iostream&gt;.</strong></p>
<pre><code class="language-cpp">int number{-2};
if (number &lt; 0) {
    std::cout &lt;&lt; "negative\n";
} else {
    std::cout &lt;&lt; "nonnegative\n";
}
</code></pre>
<p>Нельзя перейти в другую функцию. Нельзя перепрыгнуть через инициализацию локальной переменной и попасть в область, где она должна быть уже создана, например через <code>int x{5};</code> к использованию <code>x</code>. При выходе из блока через <code>goto</code> уже созданные автоматические объекты уничтожаются по обычным правилам.</p>
<p>Ветвления и циклы тоже могут компилироваться в машинные переходы, но стандарт не требует одинакового машинного кода или скорости для разных записей. Для начала удобно читать программу как последовательность блоков <code>if</code> и циклов. <a href="https://stepik.org/lesson/763642/step/4" rel="noopener noreferrer nofollow">break</a> и <a href="https://stepik.org/lesson/763642/step/5" rel="noopener noreferrer nofollow">continue</a> дают более узкие и явно заданные цели перехода.</p>

<h2>break: завершение ближайшего цикла или switch</h2>
<p><code>break</code> завершает ближайший охватывающий цикл или <code>switch</code>. Выполнение продолжается после этой конструкции. Блок <code>if</code> сам по себе целью <code>break</code> не является.</p>
<p><strong>Полная программа C++17/C++20.</strong></p>
<pre><code class="language-cpp">#include &lt;iostream&gt;
int main() {
    for (int i = 0; i &lt; 10; ++i) {
        if (i == 3) {
            break;
        }
        std::cout &lt;&lt; i &lt;&lt; '\n';
    }
    std::cout &lt;&lt; "done\n";
}
</code></pre>
<p>Цикл начинает с 0, проверяет <code>i &lt; 10</code> и увеличивает счётчик после обычного прохода тела. В вывод попадают 0, 1 и 2. При <code>i == 3</code> сначала выполняется <code>break</code>; число 3 не печатается. Приращение счётчика и следующая проверка условия уже не выполняются. Затем выводится <code>done</code>.</p>
<p>Если один цикл вложен в другой, <code>break</code> завершает только внутренний. Если внутри цикла расположен <code>switch</code>, а <code>break</code> находится в нём, он завершает только <code>switch</code>. Для окончания функции применяется <code>return</code>. Таким образом, цель перехода определяется вложенностью, а не ближайшими фигурными скобками.</p>
<p>Полный порядок исполнения <code>for</code> раскрыт в <a href="https://stepik.org/lesson/763719/step/4" rel="noopener noreferrer nofollow">следующем уроке о циклах</a>. В отличие от <code>break</code>, <code>continue</code> сохраняет цикл и пропускает только остаток одной итерации.</p>

<h2>continue: пропуск остатка итерации</h2>
<p><code>continue</code> относится к ближайшему охватывающему циклу. Он пропускает оставшиеся инструкции тела, но не завершает сам цикл. В <code>for</code> далее выполняется выражение приращения, затем проверка условия. В <code>while</code> и <code>do-while</code> управление переходит к проверке условия.</p>
<p><strong>Полная программа C++17/C++20.</strong></p>
<pre><code class="language-cpp">#include &lt;iostream&gt;
int main() {
    for (int i = 1; i &lt;= 5; ++i) {
        if (i % 2 == 0) {
            continue;
        }
        std::cout &lt;&lt; i &lt;&lt; '\n';
    }
}
</code></pre>
<p>Вывод: 1, 3 и 5 на отдельных строках. Для 2 и 4 остаток от деления на 2 равен нулю, поэтому вывод пропущен. Счётчик всё равно увеличивается: <code>++i</code> находится в заголовке <code>for</code>, а не в пропущенной части тела.</p>
<p>В цикле <code>while</code> нужно внимательно расположить изменение состояния. Если увеличение счётчика находится в конце тела, <code>continue</code> может пропустить его. Тогда условие следующей итерации останется тем же и цикл может не завершиться. Перенос <code>continue</code> из <code>for</code> в <code>while</code> требует повторного разбора порядка действий.</p>
<p><code>switch</code> сам по себе не даёт цели для <code>continue</code>. Если <code>switch</code> вложен в цикл, <code>continue</code> внутри него относится к этому циклу. Сопоставление всех трёх циклических форм начинается в <a href="https://stepik.org/lesson/763719/step/1" rel="noopener noreferrer nofollow">следующем уроке</a>.</p>
