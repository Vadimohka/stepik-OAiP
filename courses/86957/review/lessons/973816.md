<h2>Контейнер, алгоритм и итератор: как они работают вместе</h2>
<p><strong>После шага вы сможете</strong> передать диапазон элементов стандартному алгоритму и проверить результат поиска до обращения к нему. Предполагается, что вы уже знакомы с <code>std::vector</code>, циклами и функциями.</p>
<p>В разговоре о C++ словом <strong>STL</strong> обычно называют связанную систему стандартных контейнеров, итераторов и алгоритмов. Стандартная библиотека шире: в неё также входят строки, потоки, умные указатели и другие средства. Дополнительную «библиотеку STL» для этих примеров устанавливать не требуется.</p>
<ul><li><strong>Контейнер</strong> хранит данные и управляет временем жизни своих элементов. Например, <code>std::vector&lt;int&gt;</code> хранит последовательность чисел.</li>
<li><strong>Итератор</strong> обозначает позицию в последовательности. Он похож на указатель по способу использования, но не обязан быть указателем.</li>
<li><strong>Алгоритм</strong> выполняет действие над подходящим диапазоном: ищет, сортирует, копирует. Например, <code>std::find</code> работает с разными контейнерами через их итераторы.</li></ul>
<h3>Диапазон [begin, end)</h3>
<p><code>begin()</code> обозначает начало, а <code>end()</code> — позицию <em>после</em> последнего элемента. Левая граница включена, правая исключена. У пустого контейнера они равны. <strong>Разыменовывать <code>end()</code> нельзя.</strong> Поэтому результат <code>std::find</code> сначала сравнивают с концом диапазона: совпадение означает, что элемент не найден.</p>
<h3>Полная программа: сортировка и поиск</h3>
<p>Пример работает в C++17 и C++20. Ввод: <code>n</code> от 0 до 1000, затем <code>n</code> целых чисел и искомое число. Все числа должны быть представимы типом <code>int</code>; повторения разрешены. Программа выводит отсортированную последовательность и результат поиска. Для <code>n = 0</code> первая строка вывода пустая. При невозможности прочитать обязательное число программа завершается с кодом 1.</p>
<pre><code class="language-cpp">#include &lt;cstddef&gt;
#include &lt;algorithm&gt;
#include &lt;iostream&gt;
#include &lt;vector&gt;

int main() {
    int n = 0;
    if (!(std::cin &gt;&gt; n) || n &lt; 0 || n &gt; 1000) {
        return 1;
    }
    std::vector&lt;int&gt; values;
    for (int i = 0; i &lt; n; ++i) {
        int value = 0;
        if (!(std::cin &gt;&gt; value)) {
            return 1;
        }
        values.push_back(value);
    }
    int key = 0;
    if (!(std::cin &gt;&gt; key)) {
        return 1;
    }

    std::sort(values.begin(), values.end());
    for (std::size_t i = 0; i &lt; values.size(); ++i) {
        if (i != 0) {
            std::cout &lt;&lt; ' ';
        }
        std::cout &lt;&lt; values[i];
    }
    std::cout &lt;&lt; '\n';

    const auto it = std::find(values.begin(), values.end(), key);
    std::cout &lt;&lt; (it != values.end() ? "found" : "missing") &lt;&lt; '\n';
}
</code></pre><p>Ввод:</p><pre>5
5 2 5 1 4
5
</pre><p>Вывод:</p><pre>1 2 4 5 5
found
</pre>
<p><code>std::find</code> выполняет линейный поиск и не использует отсортированность данных. Здесь сортировка нужна для вывода. Для поиска в отсортированном векторе можно использовать <code>std::lower_bound</code>, разобранный в модуле поиска. Наличие общих итераторов не означает, что любой алгоритм подходит любому контейнеру: <code>std::sort</code> требует изменяемых элементов и итераторов произвольного доступа. Его можно применять к вектору, но не к <code>std::set</code>; множество само поддерживает порядок.</p>
<h3>Разбор пустого диапазона и цены подготовки</h3><p>Ввод <code>0 7</code> задаёт пустой вектор и ключ 7. Диапазон <code>[begin(), end())</code> пуст, <code>find</code> возвращает <code>end()</code>, а проверка перед разыменованием приводит к сообщению <code>missing</code>. Для ключа 3 в основном примере результат также <code>missing</code>; сам поиск вектор не меняет.</p><p>Сортировка в программе нужна для демонстрации упорядоченного вывода. Если требуется только один раз узнать, есть ли число в исходных данных, линейный <code>find</code> можно выполнить без сортировки. Стоимость подготовки учитывается в <a href="https://stepik.org/lesson/771129/step/1" rel="noopener noreferrer nofollow">контракте поиска</a>, а выбор хранения связан с <a href="https://stepik.org/lesson/973837/step/2" rel="noopener noreferrer nofollow">интерфейсами структур данных</a>.</p>
