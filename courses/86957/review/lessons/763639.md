<h3>Операции преобразования типов:</h3>

<p>Пример явного преобразования int в double. Фрагмент предполагает подключённый &lt;iostream&gt; и размещение внутри main:</p>

<pre><code class="language-cpp">int m{};
if (!(std::cin &gt;&gt; m)) {
    return 1;
}
double x = (double)m / 2 + (double)7 / 3;</code></pre>

<h3>Опасные и безопасные преобразования</h3>

<p>Преобразование сохраняет значение без потерь, если целевой тип способен представить его точно. Одного сравнения размеров типов в байтах недостаточно: важны диапазон значений и точность. Для стандартных целых типов и конечных значений стандартных типов с плавающей точкой можно использовать следующие цепочки без потери значения:</p>

<p>signed char → short → int → long → long long</p>

<p>unsigned char → unsigned short → unsigned int → unsigned long → unsigned long long</p>

<p>Значения bool преобразуются в числа 0 и 1. Для char нужно учитывать, является ли он знаковым или беззнаковым в выбранной реализации; например, не всякое значение беззнакового char обязательно помещается в short.</p>

<p>float → double → long double. При этом преобразование целого числа в double не всегда точно: например, double формата IEEE 754 binary64 не может представить целое 9007199254740993 без округления.</p>

<p>*Подробнее можно почитать <a href="https://metanit.com/cpp/tutorial/2.4.php" rel="noopener noreferrer nofollow">здесь</a>.</p>

<h3>Побитовые операции в языке С++</h3>

<p>Побитовые операции выполняются над отдельными разрядами или битами чисел. Данные операции производятся только над целыми числами.</p>

<h3>Операции сдвига</h3>

<p>Каждое целое число в памяти представлено в виде определенного количества разрядов. И операции сдвига позволяют сдвинуть битовое представление числа на несколько разрядов вправо или влево. Операции сдвига применяются только к целочисленным операндам. Есть две операции:</p>

<ul>
	<li>
	<p>&lt;&lt;</p>

	<p>Сдвигает битовое представление числа, представленного первым операндом, влево на определенное количество разрядов, которое задается вторым операндом.</p>
	</li>
	<li>
	<p>&gt;&gt;</p>

	<p>Сдвигает битовое представление числа вправо на определенное количество разрядов.</p>
	</li>
</ul>

<p>Количество сдвигаемых разрядов должно быть неотрицательным и меньше ширины типа левого операнда после целочисленного продвижения. Нарушение этого условия приводит к неопределённому поведению.</p>

<p>Применение операций</p>

<pre><code class="language-cpp">int a = 2 &lt;&lt; 2;           // 10  на два разряда влево = 1000 - 8

int b = 16 &gt;&gt; 3;          // 10000 на три разряда вправо = 10 - 2</code></pre>

<p> </p>

<p>Число 2 в двоичном представлении 10. Если сдвинуть число 10 на два разряда влево, то получится 1000, что в десятичной системе равно числу 8.</p>

<p> </p>

<p>Число 16 в двоичном представлении 10000. Если сдвинуть двоичное число 10000 на три разряда вправо (три последних разряда отбрасываются), то получится 10, что в десятичной системе представляет число 2.</p>

<h3>Поразрядные операции</h3>

<p>Поразрядные операции также проводятся только над соответствующими разрядами целочисленных операндов:</p>

<ul>
	<li>
	<p>&amp;: поразрядная конъюнкция (операция И или поразрядное умножение). Возвращает 1, если оба из соответствующих разрядов обоих чисел равны 1</p>
	</li>
	<li>
	<p>|: поразрядная дизъюнкция (операция ИЛИ или поразрядное сложение). Возвращает 1, если хотя бы один из соответствующих разрядов обоих чисел равен 1</p>
	</li>
	<li>
	<p>^: поразрядное исключающее ИЛИ. Возвращает 1, если только один из соответствующих разрядов обоих чисел равен 1</p>
	</li>
	<li>
	<p>~: поразрядное отрицание или инверсия. Инвертирует все разряды операнда. Если разряд равен 1, то он становится равен 0, а если он равен 0, то он получает значение 1.</p>
	</li>
</ul>

<p>Следующие примеры рассматриваются в C++20, где знаковые целые используют дополнительный код. В частности, ~9 равно -10:</p>

<pre><code class="language-cpp">int a = 5 | 2;          // 101 | 010 = 111  - 7

int b = 6 &amp; 2;          // 110 &amp; 010 = 10  - 2

int c = 5 ^ 2;          // 101 ^ 010 = 111 - 7

int d = ~9;             // -10</code></pre>

<p> </p>

<p>Например, выражение <code>5 | 2</code> равно 7. Число 5 в двоичной записи равно 101, а число 2 - 10 или 010. Сложим соответствующие разряды обоих чисел. При сложении если хотя бы один разряд равен 1, то сумма обоих разрядов равна 1. Поэтому получаем:</p>

<p> </p>

<table>
	<tbody>
		<tr>
			<td>1</td>
			<td>0</td>
			<td>1</td>
		</tr>
		<tr>
			<td>0</td>
			<td>1</td>
			<td>0</td>
		</tr>
		<tr>
			<td>1</td>
			<td>1</td>
			<td>1</td>
		</tr>
	</tbody>
</table>

<p>В итоге получаем число 111, что в десятичной записи представляет число 7.</p>

<p>Возьмем другое выражение <code>6 &amp; 2</code>. Число 6 в двоичной записи равно 110, а число 2 - 10 или 010. Умножим соответствующие разряды обоих чисел. Произведение обоих разрядов равно 1, если оба этих разряда равны 1. Иначе произведение равно 0. Поэтому получаем:</p>

<table>
	<tbody>
		<tr>
			<td>1</td>
			<td>1</td>
			<td>0</td>
		</tr>
		<tr>
			<td>0</td>
			<td>1</td>
			<td>0</td>
		</tr>
		<tr>
			<td>0</td>
			<td>1</td>
			<td>0</td>
		</tr>
	</tbody>
</table>

<p>Получаем число 010, что в десятичной системе равно 2.</p>
