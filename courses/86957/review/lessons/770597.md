<h3>Что такое объединение в языке C++?</h3>

<p><em>Объединение</em> – это группирование переменных, которые разделяют одну и ту же область памяти. В зависимости от интерпретации осуществляется обращение к той или другой переменной объединения. Все нестатические поля объединения начинаются по одному адресу.</p>

<p>Объединение позволяет представить в компактном виде данные, которые могут изменяться. Одни и те же данные могут быть представлены разными способами с помощью объединений.</p>

<p>Точно так же, как и <strong>структуры</strong>, объединения требуют объявления типа (шаблона) и объявления переменной этого типа.</p>

<p>Объявление объединения (типа объединения или шаблона объединения) начинается с ключевого слова union.</p>

<pre><code class="language-cpp">union имя_типа_объединения {
    тип переменная1;
    тип переменная2;
    ...
    тип переменнаяN;
};</code></pre>

<p> Где:</p>

<ul>
	<li><em>имя_типа_объединения</em> – непосредственно имя вновь созданного типа;</li>
	<li><em>переменная1</em>, <em>переменная2</em>, <em>переменная</em><em>N</em> – переменные, которые являются полями объединения. Эти переменные могут быть разных типов;</li>
	<li><em>тип</em> – тип переменной, который является полем объединения.</li>
</ul>

<p>Тип переменной может быть:</p>

<ul>
	<li><strong><u>базовым типом</u></strong>, принятым в языке C++;</li>
	<li>тип <strong><u>структура</u></strong>;</li>
	<li>тип объединения;</li>
	<li>тип класс.</li>
</ul>

<h4>Размер объединения</h4>

<p><em>Длина объединения</em> – это размер памяти в байтах, которая выделяется для одной переменной этого типа объединения.</p>

<p>Размер объединения не меньше размера любого его нестатического поля. Он может превышать максимум размеров полей из-за требований выравнивания и конечного заполнения. Точный размер даёт sizeof. В каждый момент обычно активен только один член union; запись в другой член меняет активный член. Чтение неактивного члена в общем случае имеет неопределённое поведение в ISO C++17/20.</p>

<h3>Устройство union</h3>

<p>Пусть задан тип объединения, которое содержит переменные типов с плавающей точкой</p>

<pre><code class="language-cpp">union Floats {
    float f; // рассматривается 4 байта
    double d; // рассматривается 8 байт
};</code></pre>

<p>Тип объединения Floats содержит 2 переменные с именами <em>f</em> и <em>d</em>. Переменная <em>f</em> есть типа float, переменная <em>d</em> есть типа double. Для переменной <em>f</em> типа float рассматривается (принимается во внимание) 4 байта. Для переменной <em>d</em> типа double принимается во внимание 8 байт, так как компилятор выделяет для этого типа именно 8 байт.</p>

<p>Чтобы использовать объединение Floats в другом программном коде (методе, обработчике события и т.п.) нужно объявить переменную типа Floats как показано ниже</p>

<pre><code class="language-cpp">Floats Fl;
int d;
Fl.f = 20.5; // Fl.d не определено
Fl.d = -100.35; // теперь Fl.f не определено

d = sizeof(Fl); // d = 8</code></pre>

<p>В этом примере предполагаются обычные для MSVC x64/GCC x86-64 размеры и выравнивания float (4/4) и double (8/8); тогда sizeof(Floats) равен 8. В общем случае размер union не меньше наибольшего поля и может включать заполнение для выравнивания.</p>

<p>Ниже отображено размещение (интерпретация) переменных <em>f</em>, <em>d</em> из объединения Floats.</p>

<p><img alt="" height="991" name="Frame 30.png" src="https://ucarecdn.stepik.net/4628fa87-6e5a-49c8-9493-d956b341f023/-/crop/2286x991/0,20/-/preview/" width="2286"></p>

<p>Доступ к полям объединения осуществляется так же, как и для структуры:</p>

<ul>
	<li>с помощью символа <strong>‘ . ‘</strong>;</li>
	<li>с помощью последовательности символов <strong>‘-&gt;’</strong> в случае, когда объявлена переменная-указатель на объединение. </li>
</ul>

<p>В программах на C++ для определения размера переменной типа «struct» или «union» <strong>обязательно нужно использовать операцию sizeof()</strong>. Определение размера «вручную» есть ошибочным поскольку:</p>

<ul>
	<li>размеры некоторых встроенных типов (например тип int) могут быть разными для разных компьютеров. Например, на одних платформах для типа int будет выделено 2 байта, на других 4 байта;</li>
	<li>размер объекта может включать заполнение, необходимое для выравнивания его полей и элементов массива таких объектов. Например:</li>
</ul>

<p> </p>

<pre><code class="language-cpp">struct alignas(16) ArrayOfChars {
    char A[10];
    char B[8];
};</code></pre>

<p>при обычном размещении полей занимает 32 байта: полезные данные занимают 18 байт, а конечное заполнение доводит размер до кратного 16. Сам массив A по-прежнему занимает ровно 10 байт. Без alignas(16) при обычном размещении такая структура занимает 18 байт. Точный результат для реализации проверяют через sizeof.</p>

<p>Таким образом, использование операции sizeof() для определения размера структуры или объединения позволяет не зашивать этот размер в программу. Само по себе это ещё не гарантирует переносимость всего программного кода.</p>

<h3>Объявление вложенных объединений в шаблоне объединения</h3>

<p>Определение объединения может включать поля, типами которых являются структуры, объединения и классы.</p>

<p>В примере ниже объявляется шаблон объединения с именем Types, содержащий два вложенных объединения Floats и Ints, структуру ArrayOfChars и класс MyPoint.</p>

<p>Объявление структур и объединений имеет следующий вид:</p>

<pre><code class="language-cpp">// объединение целочисленных типов
union Ints {
    unsigned short int a;
    unsigned int b;
    unsigned long int c;
};

// структура, содержащая 2 строки
struct ArrayOfChars {
    char A[10];
    char B[8];
};

// объявление типа "объединение Floats"
union Floats {
    float f; // рассматривается 4 байта
    double d; // рассматривается 8 байт
};</code></pre>

<pre><code class="language-cpp">class MyPoint {
    public:
        int x;
        int y;

        // методы класса
        int GetX(void) { return x; }
        int GetY(void) { return y; }
        void SetXY(int nx, int ny) { x = nx; y = ny; }
};</code></pre>

<pre><code class="language-cpp">union Types {
    Floats Fl; // объединение
    Ints I;   // объединение
    ArrayOfChars A; // структура
    MyPoint MP;   // класс
};</code></pre>

<p>Использование объединения Types в некотором программном коде:</p>

<pre><code>// объявить переменную типа "объединение Types"
Types T;

// изменить значения полей переменной T
T.Fl.f = (float)20.35; // объединение Floats
T.I.b = 230; // объединение Ints
T.A.A[2] = 'A'; // структура ArrayOfChars
T.MP = MyPoint{}; // тривиальное присваивание начинает время жизни поля MP
T.MP.SetXY(3,8); // теперь метод вызывается у активного члена union
int d;
d = T.MP.GetX(); // d = 3</code></pre>

<p>Пример объявления и использования массива объединений: </p>

<pre><code class="language-cpp">Floats F[5]; // объявляется массив из 5 объединений типа Floats

// заполнение значений полей
for (int i = 0; i &lt; 5; i++) {
    F[i].d = i * 0.2 + i * i;
}</code></pre>
