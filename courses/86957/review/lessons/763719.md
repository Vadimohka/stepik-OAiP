<h2>Цикл: повторение с контролем состояния</h2>
<p>Цикл повторяет тело — группу инструкций. Один проход тела называется <strong>итерацией</strong>. Для понимания цикла полезно последовательно назвать начальное состояние, условие продолжения, действие тела и изменение, которое приближает остановку.</p>
<table><thead><tr><th>Форма</th><th>Когда проверяется условие</th><th>Обычный смысл</th></tr></thead><tbody><tr><td><code>while</code></td><td>До каждого прохода</td><td>Повторять, пока выполняется условие; тело может не выполниться ни разу.</td></tr><tr><td><code>do-while</code></td><td>После прохода</td><td>Выполнить тело, затем решить, нужен ли следующий проход.</td></tr><tr><td><code>for</code></td><td>До каждого прохода</td><td>Собрать инициализацию, проверку и изменение счётчика в одном заголовке.</td></tr><tr><td><code>for (элемент : диапазон)</code></td><td>Обход существующего диапазона</td><td>По очереди обработать элементы массива или контейнера; применяется в модуле 5.</td></tr></tbody></table>
<p>Например, для чисел от 1 до 9 состояние — текущий номер. Начальное значение 1, условие <code>i &lt; 10</code>, изменение <code>++i</code>. Без изменения номера истинное условие само по себе не станет ложным. Отдельно надо учитывать диапазон типа: переполнение счётчика не является допустимым способом остановки.</p>
<p>Разборы <a href="https://stepik.org/lesson/763719/step/2" rel="noopener noreferrer nofollow">while</a>, <a href="https://stepik.org/lesson/763719/step/4" rel="noopener noreferrer nofollow">for</a> и <a href="https://stepik.org/lesson/763719/step/6" rel="noopener noreferrer nofollow">do-while</a> используют эту модель. <code>break</code>, <code>continue</code> и <code>return</code> могут изменить обычный порядок, поэтому они учитываются при разборе каждой ветви.</p>

<h2>while: сначала условие, затем тело</h2>
<p>Конструкция <code>while (условие) { тело }</code> проверяет условие перед каждой итерацией. При ложном условии выполнение сразу продолжается за циклом; тело может не выполниться ни разу.</p>
<p><strong>Полная программа C++17/C++20.</strong></p>
<pre><code class="language-cpp">#include &lt;iostream&gt;
int main() {
    int i{1};
    while (i &lt; 10) {
        std::cout &lt;&lt; i &lt;&lt; " * " &lt;&lt; i &lt;&lt; " = " &lt;&lt; i * i &lt;&lt; '\n';
        ++i;
    }
    std::cout &lt;&lt; "next = " &lt;&lt; i &lt;&lt; '\n';
}
</code></pre>
<p>Программа выводит квадраты от <code>1 * 1 = 1</code> до <code>9 * 9 = 81</code>, затем <code>next = 10</code>. Перед каждым выполненным проходом <code>i</code> лежит от 1 до 9. После вывода <code>++i</code> прибавляет единицу. Когда получится 10, условие станет ложным. Всего тело выполнится девять раз, а условие будет проверено десять раз.</p>
<p>Если начальное значение равно 10, квадрат не выводится вообще: первая проверка уже ложна. Если убрать <code>++i</code>, в этой программе повторялось бы одно и то же значение. Если использовать <code>i &lt;= 10</code>, добавится квадрат 10; граница должна соответствовать назначению алгоритма.</p>
<p>Фигурные скобки объединяют вывод и изменение счётчика в одно тело. Случайная точка с запятой после <code>while (i &lt; 10)</code> образовала бы пустое тело, а следующий блок уже не принадлежал бы циклу. <a href="https://stepik.org/lesson/763719/step/4" rel="noopener noreferrer nofollow">for</a> позволяет перенести изменение счётчика в заголовок.</p>

<h2>for: счётчик и порядок выполнения</h2>
<p>В обычном <code>for</code> три части заголовка разделены точками с запятой: инициализация; условие; выражение после итерации. Сначала один раз выполняется инициализация. Затем чередуются проверка условия, тело и выражение после итерации. Последнее часто увеличивает счётчик, но может выполнять другое обновление.</p>
<p><strong>Полная программа C++17/C++20.</strong></p>
<pre><code class="language-cpp">#include &lt;iostream&gt;
int main() {
    for (int i = 1; i &lt; 10; ++i) {
        std::cout &lt;&lt; i &lt;&lt; " * " &lt;&lt; i &lt;&lt; " = " &lt;&lt; i * i &lt;&lt; '\n';
    }
}
</code></pre>
<p>Это те же девять квадратов, что в примере <code>while</code>. Разница в организации кода: имя <code>i</code>, объявленное в заголовке, доступно внутри цикла и его заголовка, а после цикла недоступно. Первое значение 1; последним напечатано 9; после увеличения до 10 проверка прекращает цикл.</p>
<p><code>continue</code> в этом цикле ведёт к <code>++i</code>, затем к проверке. Поэтому механическая замена на <code>while</code> с увеличением в конце тела может изменить поведение. <code>break</code> завершает цикл, не выполняя приращение.</p>
<p><strong>Фрагмент внутри функции; это не отдельная программа.</strong></p>
<pre><code class="language-cpp">int i{1};
for (; i &lt; 10; ) {
    ++i;
}
// После цикла i == 10.
</code></pre>
<p>Части заголовка можно пропускать, сохраняя обе точки с запятой. Пропущенное условие считается истинным: <code>for (;;)</code> не имеет проверки остановки в заголовке. Это не означает, что тело обязательно бесконечно: внутри может выполняться <code>break</code> или <code>return</code>.</p>
<p>Для подсчёта шагов выбирайте целочисленный счётчик с подходящим диапазоном. Счётчик <code>double</code>, к которому многократно прибавляют десятичную дробь, может накапливать округление и неожиданно пересекать границу. Когда нужны только все элементы коллекции, <a href="https://stepik.org/lesson/763644/step/2" rel="noopener noreferrer nofollow">цикл по диапазону</a> избавляет от ручного индекса.</p>

[Открыть на Stepik](https://stepik.org/lesson/763719/step/6?unit=765887) · [Исходник step-source](../../raw/step-sources/3177786.json) · [Объект step](../../raw/steps/3177786.json)

<h2>do-while: сначала тело, затем условие</h2>
<p>У <code>do-while</code> проверка стоит после тела. Если управление дошло до самого цикла, тело начинает выполняться хотя бы один раз; досрочный выход из тела, например через <code>break</code>, может пропустить проверку. После <code>while (условие)</code> нужна точка с запятой.</p>
<p><strong>Полная программа C++17/C++20.</strong></p>
<pre><code class="language-cpp">#include &lt;iostream&gt;
int main() {
    int before{};
    while (before &lt; 0) {
        ++before;
    }
    int after{};
    do {
        ++after;
    } while (after &lt; 0);
    std::cout &lt;&lt; before &lt;&lt; ' ' &lt;&lt; after &lt;&lt; '\n';
}
</code></pre>
<p>Вывод <code>0 1</code>. У первого цикла условие <code>0 &lt; 0</code> сразу ложно. У второго сначала выполняется <code>++after</code>, поэтому проверяется уже <code>1 &lt; 0</code>. Затем второй цикл завершается.</p>
<p>Форма полезна, когда первое действие требуется независимо от предварительного условия. Она не гарантирует успешность ввода или вычисления: результаты операций в теле всё равно нужно проверять. Выбор между <code>while</code> и <code>do-while</code> определяется тем, допускает ли алгоритм ноль проходов.</p>

<h2>Разбор цикла с отбором значений</h2>
<p>Рассмотрим сумму целых от 1 до 100 включительно, которые не делятся ни на 2, ни на 3. Здесь <code>continue</code> отделяет причину пропуска от основного действия — прибавления.</p>
<p><strong>Полная программа C++17/C++20.</strong></p>
<pre><code class="language-cpp">#include &lt;iostream&gt;
int main() {
    int sum{};
    int count{};
    for (int i = 1; i &lt;= 100; ++i) {
        if (i % 2 == 0 || i % 3 == 0) {
            continue;
        }
        sum += i;
        ++count;
    }
    std::cout &lt;&lt; count &lt;&lt; ' ' &lt;&lt; sum &lt;&lt; '\n';
}
</code></pre>
<p>Программа печатает <code>33 1633</code>. Первые выбранные числа — 1, 5, 7, 11; последнее — 97. Значения 2 и 3 отклоняются по отдельным условиям, 6 — по обоим. Логическое ИЛИ достаточно: для исключения числа нужна хотя бы одна причина.</p>
