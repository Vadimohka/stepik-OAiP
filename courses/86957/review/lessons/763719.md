<h3>Цикл while</h3>

<p>Цикл <code>while</code> выполняет некоторый код, пока его условие истинно, то есть возвращает true. Он имеет следующее формальное определение:</p>

<pre><code>while (условие) {
    // выполняемые действия
}</code></pre>

<p>После ключевого слова while в скобках записывается условие, значение которого приводится к bool. Затем следует тело цикла. Перед каждой итерацией условие проверяется снова: при true выполняется тело, при false цикл завершается.</p>

<p>Например, выведем квадраты чисел от 1 до 9:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {  
    int i = 1;
    while (i &lt; 10) {
        std::cout &lt;&lt; i &lt;&lt; " * " &lt;&lt; i &lt;&lt; " = " &lt;&lt; i * i &lt;&lt; std::endl;
        i++;
    }
    return 0;
}</code></pre>

<p> </p>

<p>Здесь пока условие <code>i &lt; 10</code> истинно, будет выполняться цикл while, в котором выводится на консоль квадрат числа и инкрементируется переменная i. В какой-то момент переменная i увеличится до 10, условие <code>i &lt; 10</code> возвратит false, и цикл завершится.</p>

<p> </p>

<p>Консольный вывод программы:</p>

<pre><em>1 * 1 = 1
2 * 2 = 4
3 * 3 = 9
4 * 4 = 16
5 * 5 = 25
6 * 6 = 36
7 * 7 = 49
8 * 8 = 64
9 * 9 = 81</em>
</pre>

<p>Каждый отдельный проход цикла называется итерацией. То есть в примере выше было 9 итераций.</p>

<p>Если цикл содержит одну инструкцию, то фигурные скобки можно опустить:</p>

<pre><code class="language-cpp">int i = 0;
while (++i &lt; 10) std::cout &lt;&lt; i &lt;&lt; " * " &lt;&lt; i &lt;&lt; " = " &lt;&lt; i * i &lt;&lt; std::endl;</code></pre>

<h3>Цикл for</h3>

<p>Цикл for имеет следующее формальное определение:</p>

<pre><code class="language-cpp">for (инициализация; условие; выражение_приращения) {
    // тело цикла
}</code></pre>

<p> </p>

<p>инициализация выполняется один раз в начале цикла и задаёт начальные условия; как правило, это инициализация счетчиков - специальных переменных, которые используются для контроля за циклом.</p>

<p> </p>

<p>условие проверяется перед каждой итерацией. Как правило, в качестве условия используется операция сравнения, и если она возвращает ненулевое значение (то есть условие истинно), то выполняется тело цикла, а затем вычисляется выражение_приращения.</p>

<p>выражение_приращения задаёт изменение параметров цикла, нередко здесь происходит увеличение счетчиков цикла на единицу.</p>

<p>Например, перепишем программу по выводу квадратов чисел с помощью цикла for:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {  
    for (int i = 1; i &lt; 10; i++) {
        std::cout &lt;&lt; i &lt;&lt; " * " &lt;&lt; i &lt;&lt; " = " &lt;&lt; i * i &lt;&lt; std::endl;
    }
    return 0;
}</code></pre>

<p> </p>

<p>Первая часть объявления цикла - <code>int i = 1</code> - создает и инициализирует счетчик i. Фактически это то же самое, что и объявление и инициализация переменной. Счетчик необязательно должен представлять тип int. Это может быть и другой числовой тип, например, float. И перед выполнением цикла его значение будет равно 1.</p>

<p> </p>

<p>Вторая часть - условие, при котором будет выполняться цикл. В данном случае цикл будет выполняться, пока переменная i не станет равна 10.</p>

<p>И третья часть - приращение счетчика на единицу. Опять же нам необязательно увеличивать на единицу. Можно уменьшать: i--. Можно изменять на другое значение: i+=2.</p>

<p>В итоге блок цикла сработает 9 раз, пока переменная i не станет равна 10. И каждый раз это значение будет увеличиваться на 1. И по сути мы получим тот же самый результат, что и в случае с циклом while в предыдущем шаге.</p>

<p>Необязательно заполнять все три части заголовка: можно опустить любую из них или все сразу, сохранив обе точки с запятой. Отсутствующее условие считается истинным:</p>

<pre><code class="language-cpp">int i = 1;
for (; i &lt; 10;) {
    std::cout &lt;&lt; i &lt;&lt; " * " &lt;&lt; i &lt;&lt; " = " &lt;&lt; i * i &lt;&lt; std::endl;
    i++;
}</code></pre>

<p> </p>

<p>Формально определение цикла осталось тем же, только теперь инициализация и выражение приращения в заголовке отсутствуют: <code>for (; i &lt; 10;)</code>. Переменная-счетчик определена и инициализирована вне цикла, а ее приращение происходит в самом цикле.</p>

<p><strong>Цикл do-while</strong></p>

<p>В С++ существует вариация цикла while, которая называется do-while. В отличие от обычного while в do-while условие проверяется не до, а <em>после</em> итерации. Т.е. такой цикл всегда имеет хотя бы одну итерацию.</p>

<p>Давайте сравним обычный while:</p>

<pre><code>int i = 10;
int mult = 1;
while (i &lt; 10) {
    mult *= i;
}
// mult = 1</code></pre>

<p>И <strong>do-while</strong>: </p>

<pre><code>int i = 10;
int mult = 1;
do {
    mult *= i;
} while (i &lt; 10);
// mult = 10</code></pre>

<p>Как видите, в случае с do-while мы умножили на 10 переменную mult, а в обычном while — нет.</p>

<p><strong>Ещё немного про break в циклах</strong></p>

<p>В предыдущем уроке упомянут оператор <strong>break</strong>, который также используется для выхода из цикла. Рассмотрим его действие на следующем примере.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {
    for (int i = 1; i &lt; 10; ++i) {
        if (i == 4) {
            break;
        }
        std::cout &lt;&lt; i &lt;&lt; '\n';
    }
}</code></pre>

<p>Цикл выводит числа 1, 2 и 3, каждое на отдельной строке. Когда i становится равно 4, оператор <code>break</code> завершает цикл до вывода этого значения.</p>

<p>Ещё один оператор, который можно использовать с циклами — это оператор<strong> continue. </strong>Оператор <strong>continue</strong> прерывает текущую итерацию цикла и переходит к следующей. Например, можно посчитать сумму всех чисел от 1 до 100, которые <strong><em>не</em></strong> делятся ни на 2, ни на 3, следующим образом.</p>

<pre><code>int sum = 0;
for (int i = 1; i &lt;= 100; ++i) {
    if ((i % 2 == 0) || (i % 3 == 0)) {
        continue; // перейти к следующей итерации
    }
    sum += i;
}</code></pre>

### Шаг 8 — code (ID 3299645)
