<h1>Перегрузка операций</h1>

<p>Перегрузка операций — это одна из самых захватывающих возможностей ООП. Она может превратить сложный и малопонятный листинг программы в интуитивно понятный. Например, строки</p>

<p><code>d3.addobjects(d1, d2);</code></p>

<p>похожие, но одинаково непонятные</p>

<p><code>d3 = d1.addobjects(d2);</code></p>

<p>можно заменить на более читаемую</p>

<p><code>d3 = d1 + d2;</code></p>

<p>Довольно непривлекательный термин «перегрузка операций» дается обычным операциям C++, таким, как +, *, &lt;= или +=, в случае их применения с определенными пользователем типами данных.</p>

<p>Обычно <code>а = b + с;</code><span style="font-size: inherit; font-weight: inherit;"> </span><span style="font-size: inherit; font-weight: inherit;">работает только с основными типами данных, такими, как int или float, и попытка использования обычных операторов, когда a, b и с являются объектами определенного пользователем класса, приведет к протестам компилятора. Однако, используя перегрузку, вы можете сделать эту строку правильной даже в том случае, если a, b и с являются объектами определенного пользователем класса.</span></p>

<p><span style="font-size: inherit; font-weight: inherit;">На самом деле перегрузка операций дает вам возможность переопределить язык C++. Если вы считаете, что ограничены стандартными возможностями операций, то вы можете назначить их выполнять нужные вам действия. Используя классы для создания новых видов переменных и перегрузку для определения новых операций, вы можете, расширив C++, создать новый, свой собственный язык.</span></p>

<p><span style="font-size: inherit; font-weight: inherit;">Другой вид действий, преобразование типов, тесно связан с перегрузкой операций. C++ совершает преобразование простых типов, таких, как int или float, автоматически; но преобразование, включающее в себя созданные пользователем типы, требует немного работы со стороны программиста.</span></p>

<p><span style="font-size: inherit; font-weight: inherit;">Перегрузка операций — непростая тема. Мы обсудим некоторые нюансы ее использования в конце главы.</span></p>

<h1>Перегрузка унарных операций</h1>

<p>Давайте начнем с перегрузки унарных операций. Как нам известно, унарные операции имеют только один операнд (операнд — это выражение, к которому применяется операция). Примером унарной операции могут служить операции уменьшения и увеличения ++ и -- и унарный минус, например -33.</p>

<p>В примере COUNTER ранее мы создали класс Counter для хранения значения счетчика. Объект этого класса мы увеличивали вызовом метода: c1.inc_count(); Он выполнял свою работу, но листинг программы станет более понятным, если мы применим вместо этой записи операцию увеличения ++. ++c1; Все опытные программисты C++ сразу догадаются, что это выражение увеличивает переменную c1. Давайте перепишем программу COUNTER, чтобы сделать это действие возможным.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

class Counter {
private:
    unsigned int count; // значение счетчика

public:
    // конструктор
    Counter() {
        count = 0;
    }

    // получить значение
    unsigned int get_count() {
        return count; 
    }

    // увеличить значение
    void operator++() { 
        ++count;
    }
};

int main() {
    Counter c1, c2; // определяем переменные
    std::cout &lt;&lt; "c1 = " &lt;&lt; c1.get_count(); // выводим на экран
    std::cout &lt;&lt; "\nc2 = " &lt;&lt; c2.get_count();
    ++c1; // увеличиваем c1
    ++c2; // увеличиваем c2
    ++c2; // увеличиваем c2
    std::cout &lt;&lt; "\nc1 = " &lt;&lt; c1.get_count(); // снова показываем значения
    std::cout &lt;&lt; "\nc2 = " &lt;&lt; c2.get_count() &lt;&lt; std::endl;
    return 0;
}</code></pre>

<p>В этой программе мы создали два объекта класса Counter: c1 и c2. Значения счетчиков выведены на дисплей, сначала они равны 0. Затем, используя перегрузку операции ++, мы увеличиваем c1 на единицу, а c2 на два и выводим полученные значения. Результат работы программы:</p>

<pre><code class="language-cpp">c1 = 0 - изначально обе переменные равны нулю
c2 = 0
c1 = 1 - после однократного увеличения
c2 = 2 - после двукратного увеличения</code></pre>

<p> Выражения, соответствующие этим действиям: ++c1; ++c2; ++c2;</p>

<p>Операция ++ применена к c1 и дважды применена к c2. В этом примере мы использовали префиксную версию операции ++, постфиксную мы объясним позднее.</p>

<h1>Ключевое слово operator</h1>

<p>Как использовать обычные операции с определенными пользователями типами? В этом объявлении использовано ключевое слово operator для перегрузки операции ++:</p>

<p><code>void operator++()</code></p>

<p>Сначала пишут возвращаемый тип (в нашем случае void), затем ключевое слово operator, затем саму операцию (++) и наконец список аргументов, заключенный в скобки (здесь он пуст). Такой синтаксис говорит компилятору о том, что если операнд принадлежит классу Counter, то нужно вызывать функцию с таким именем, встретив в тексте программы операцию ++. Работая с различными библиотеками мы уже видели, что только компилятор может различать перегружаемые функции по типу данных и количеству их аргументов. Перегружаемые операции компилятор отличает по типу данных их операндов. Если операнд имеет базовый тип, такой, как int в <code>++intvar;</code> то компилятор будет использовать свою встроенную процедуру для увеличения переменной типа int. Но если операнд является объектом класса Counter, то компилятор будет использовать написанную программистом функцию operator++().</p>

<h1>Аргументы операции и значения, возвращаемые операцией</h1>

<p>В функции main() операция ++ применена к объекту, как в выражении ++c1. До сих пор функция operator++() не имела аргументов. Что же увеличивает эта операция? Она увеличивает переменную count объекта, к которому применяется. Так как методы класса всегда имеют доступ к объектам класса, для которых они были вызваны, то для этой операции не требуются аргументы.</p>

<p><img alt="" height="429" name="Frame 36.png" src="https://ucarecdn.stepik.net/d7f65d59-feaa-4d6a-aa79-b89449c7096f/-/crop/5019x4468/0,173/-/preview/" width="482"></p>

<p> Функция operator++() имеет небольшой дефект. Вы можете его выявить, если используете в функции main() строку, похожую на эту: c1 = ++c2; Компилятор будет протестовать. Почему? Просто потому, что мы определили тип void для возвращаемого значения функции operator++(). А в нашем выражении присваивания будет запрошена переменная типа Counter. То есть компилятор запросит значение переменной c2, после того как она будет обработана операцией ++, и присвоит ее значение переменной c1. Но, при данном нами определении, мы не можем использовать ++ для увеличения объекта Counter в выражении присваивания: с таким операндом может быть использована только операция ++. Конечно, обыкновенная операция ++, примененная к данным таких типов, как int, не столкнется с этими проблемами. Для того чтобы иметь возможность использовать написанный нами operator++() в выражениях присваивания, нам необходимо правильно определить тип его возвращаемого значения.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

class Counter {
private:
    unsigned int count; // значение счетчика

public:
    // конструктор
    Counter() {
        count = 0;
    }

    // получить значение
    unsigned int get_count() {
        return count;
    }

    Counter operator++() {
        ++count;
        Counter temp;
        temp.count = count;
        return temp;
    }
};

int main() {
    Counter c1, c2; // определяем переменные
    std::cout &lt;&lt; "\nc1 = " &lt;&lt; c1.get_count(); // выводим на экран
    std::cout &lt;&lt; "\nc2 = " &lt;&lt; c2.get_count();
    ++c1; // увеличиваем c1
    c2 = ++c1; // c1 = 2, c2 = 2
    std::cout &lt;&lt; "\nc1 = " &lt;&lt; c1.get_count(); // снова показываем значения
    std::cout &lt;&lt; "\nc2 = " &lt;&lt; c2.get_count() &lt;&lt; std::endl;
    return 0;
} </code></pre>

<p>Здесь функция operator++() создает новый объект класса Counter, названный temp, для использования его в качестве возвращаемого значения. Она сначала увеличивает переменную count в своем объекте, а затем создает объект temp и присваивает ему значение count, то же значение, что и в собственном объекте. В конце функция возвращает объект temp. Получаем ожидаемый эффект. Выражение типа <code>++c1</code> теперь возвращает значение, которое можно использовать в других выражениях, таких, как: <code>c2 = ++c1;</code> как показано в функции main(), где значение, возвращаемое ++c1, присваивается c2. Результат работы этой программы будет следующим:</p>

<pre><code class="language-cpp">c1 = 0
c2 = 0
c1 = 2
c2 = 2</code></pre>

<h1>Временные безымянные объекты</h1>

<p>В примере ранее мы создали временный объект temp типа Counter, чьей единственной целью было хранение возвращаемого значения для операции ++. Реализация этого объекта потребовала трех строк программы:</p>

<p><code>Counter temp; // временный Объект Counter</code></p>

<p><code>temp.count = count; // присваиваем ему значение count</code></p>

<p><code>return temp; // возвращаем Объект</code></p>

<p>Существует много путей возвращения временного объекта из функции или перегруженной операции. Давайте рассмотрим еще один из способов:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

class Counter {
private:
    unsigned int count;

public:
    Counter() {
        count = 0;
    }

    Counter(int c) {
        count = c;
    }

    unsigned int get_count() {
        return count;
    }

    Counter operator++() {
        ++count;
        return Counter(count);
    }
};

int main() {
    Counter c1, c2; // определяем переменные
    std::cout &lt;&lt; "\nc1 = " &lt;&lt; c1.get_count(); // выводим на экран
    std::cout &lt;&lt; "\nc2 = " &lt;&lt; c2.get_count();
    ++c1; // увеличиваем c1
    c2 = ++c1; // c1 = 2, c2 = 2
    std::cout &lt;&lt; "\nc1 = " &lt;&lt; c1.get_count(); // снова показываем значения
    std::cout &lt;&lt; "\nc2 = " &lt;&lt; c2.get_count() &lt;&lt; std::endl;
    return 0;
} </code></pre>

<p>В строке этой программы <code>return Counter(count);</code> возвращается объект с тем же значением счётчика, для чего в предыдущей версии требовались три строки. Здесь создается объект типа Counter. Он не имеет имени, так как оно нигде не будет использоваться. Этот объект инициализируется значением, полученным в виде параметра count. Но постойте: требуется ли здесь конструктор с одним аргументом? Да, требуется. Поэтому мы вставили этот конструктор в список методов класса в новой версии программы.</p>

<p> <code>Counter(int c) : count(c) { }</code></p>

<p>Объект, инициализированный значением count, может быть возвращен функцией. Результат работы этой программы тот же, что и предыдущей версии программы. В обеих программах возвращается объект с текущим значением count. Во второй версии Counter(count) непосредственно вызывает конструктор с параметром int; это не вызов конструктора копирования.</p>

<h1>Постфиксные операции</h1>

<p>До сих пор мы применяли операцию увеличения, используя только префиксную запись:</p>

<p> <code>++c1</code> </p>

<p>А как можно использовать постфиксную запись, где переменная увеличивается после того, как ее значение было использовано в выражении?</p>

<p><code>c1++</code></p>

<p>Чтобы иметь возможность работать с двумя версиями операции, мы определим два варианта перегрузки операции ++.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

class Counter {
private:
    unsigned int count;

public:
    Counter() {
        count = 0;
    }

    Counter(int c) {
        count = c;
    }

    unsigned int get_count() {
        return count;
    }

    Counter operator++() {
        return Counter(++count);
    }

    Counter operator++(int) {
        return Counter(count++);
    }
};

int main() {
    Counter c1, c2; // определяем переменные
    std::cout &lt;&lt; "\nc1 = " &lt;&lt; c1.get_count(); // выводим на экран
    std::cout &lt;&lt; "\nc2 = " &lt;&lt; c2.get_count();
    ++c1; // увеличиваем c1
    c2 = ++c1; // c1 = 2, c2 = 2
    std::cout &lt;&lt; "\nc1 = " &lt;&lt; c1.get_count(); // снова показываем значения
    std::cout &lt;&lt; "\nc2 = " &lt;&lt; c2.get_count();
    c2 = c1++;
    std::cout &lt;&lt; "\nc1 = " &lt;&lt; c1.get_count(); // и снова
    std::cout &lt;&lt; "\nc2 = " &lt;&lt; c2.get_count() &lt;&lt; std::endl;
    return 0;
} </code></pre>

<p>Теперь у нас есть два типа объявления функции operator++. С одной из них, для префиксной операции, мы уже были знакомы ранее:</p>

<p><code>Counter operator++();</code></p>

<p>Для реализации постфиксной записи операции ++ используем новую функцию:</p>

<p><code>Counter operator++(int);</code></p>

<p>Различие сигнатур — дополнительный параметр int у постфиксной версии. Это настоящий параметр, который обычно оставляют без имени и не используют: при записи c1++ компилятор передаёт в него 0. При явном вызове c1.operator++(2) можно передать другое значение, но такая запись уже является обычным вызовом функции. Дополнительный int позволяет различить префиксную и постфиксную перегрузки. Результат работы программы будет таким:</p>

<pre><code class="language-cpp">c1 = 0
c2 = 0
c1 = 2
c2 = 2
c1 = 3
c2 = 2</code></pre>

<p>Первые четыре строки мы уже видели в предыдущих программах. А в последних двух строках мы видим результаты, полученные после обработки выражения <code>c2 = c1++;</code></p>

<p>Здесь c1 увеличивается до 3, но переменной c2 значение переменной c1 было присвоено до ее увеличения. Поэтому переменная c2 имеет значение 2. Конечно же, мы можем использовать различные варианты записи операции и для <code>operator--</code>.</p>

<h2>Арифметические операции</h2>

<p>Ранее мы рассматривали два объекта класса Distance, которые складывались с помощью метода add_dist(); dist3.add_dist(dist1, dist2); Используя перегрузку операции +, мы можем отказаться от этого неприглядного выражения и воспользоваться таким: dist3 = dist1 + dist2; </p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

// длина в английской системе
class Distance {
private:
    int feet;
    float inches;

public:
    // конструктор без аргументов
    Distance() {
        feet = 0;
        inches = 0;
    }

    // конструктор с двумя аргументами
    Distance(int ft, float in) {
        feet = ft;
        inches = in;
    }
     

    // получение информации от пользователя
    void getdist() {
        std::cout &lt;&lt; "\nВведите футы: ";
        std::cin &gt;&gt; feet;
        std::cout &lt;&lt; "Введите дюймы: ";
        std::cin &gt;&gt; inches;
    }

    // показ информации
    void showdist() {
        std::cout &lt;&lt; feet &lt;&lt; " футов " &lt;&lt; inches &lt;&lt; " дюймов";
    }

    // сложение двух длин
    Distance operator+(Distance) const;
};

// сложение двух длин
Distance Distance::operator+(Distance d2) const {
    int f = feet + d2.feet; // складываем футы
    float i = inches + d2.inches; // складываем дюймы
    // если число дюймов больше 12.0 то уменьшаем число дюймов на 12.0
    // и увеличиваем число футов на 1
    if (i &gt;= 12.0)
    {
        i -= 12.0;
        f++;
    }
    return Distance(f, i); // создаем и возвращаем временную переменную
}

<p>Объявление метода operator+() в классе Distance выглядит следующим образом:</p>

<p><code>Distance operator+(Distance);</code></p>

<p>Эта операция возвращает значение типа Distance и принимает один аргумент типа Distance. В выражении: <code>dist3 = dist1 + dist2;</code>важно понимать, к каким объектам будут относиться аргументы и возвращаемые значения. Когда компилятор встречает это выражение, то он просматривает типы аргументов. Обнаружив только аргументы типа Distance, он выполняет операции выражения, используя метод класса Distance operator+(). Но какой из объектов используется в качестве аргумента этой операции — dist1 или dist2? И не нужно ли нам использовать два аргумента, так как мы складываем два объекта?</p>

<p>Для показанной перегрузки бинарной операции нестатическим методом действует правило: объект, стоящий с левой стороны операции (в нашем случае dist1), вызывает функцию оператора. Объект, стоящий справа от знака операции, должен быть передан в функцию в качестве аргумента. Операция возвращает значение, которое мы затем используем для своих нужд. В нашем случае мы присваиваем его объекту dist3.</p>

<p><img alt="" height="5529" name="Frame 37.png" src="https://ucarecdn.stepik.net/222f1bd8-dba9-42f7-bd08-a033058822d9/-/crop/12728x5529/0,332/-/preview/" width="12728"></p>

<p> В функции operator+() к левому операнду мы имеем прямой доступ, используя feet и inches, так как это объект, вызывающий функцию. К правому операнду мы имеем доступ как к аргументу функции, то есть как d2.feet и d2.inches. Мы можем обобщить изложенное выше и сказать, что обычной бинарной операции, перегруженной нестатическим методом, требуется один явный параметр для правого операнда, так как один из операндов является объектом, вызывающим функцию. Обычный унарный оператор-член не требует явного параметра; у постфиксных ++ и -- есть дополнительный int. Операторы, определённые вне класса, получают оба операнда бинарной операции как параметры независимо от наличия friend. Для вычисления значения функции operator+() мы сначала складываем значения feet и inches обоих операндов (корректируя результат, если это необходимо). <h1>Операция индексации массива ([])</h1>

<p>Операция индексации, которая обычно используется для доступа к элементам массива, может быть перегружена. Это полезно в том случае, если вы хотите изменить способ работы C++ с массивами. <p>Для демонстрации перегрузки операции индексации массива мы должны вернуться к другой теме, с которой мы уже встречались ранее, — возвращению значений из функции по ссылке. В показанном изменяемом массиве int оператор индексации возвращает int&amp;, чтобы присваивание через результат меняло сам элемент. В общем случае перегруженный operator[] может возвращать и значение или иной подходящий тип. Чтобы показать, почему это так, мы рассмотрим три программы, которые реализуют «безопасный» массив, каждая при этом использует свой подход для вставки и считывания элементов массива:</p>

<ul>

	<li>метод access(), использующий возвращение по ссылке;</li>
	<li>перегруженная операция [], использующая возвращение по ссылке.</li>
</ul>

<p>Все три программы используют класс safearray, в котором определен массив, состоящий из 100 элементов типа int.     return 0;
} </code></pre>

<p>Данные помещаются в массив с помощью метода putel() и выводятся на дисплей с помощью метода getel(). Безопасность массива реализована с помощью вывода сообщения об ошибке при попытке использования индекса, не входящего в границы массива. Однако этот формат несколько груб.</p>

<h2>Метод access(), использующий возвращение по ссылке</h2>

<p>Как оказывается, мы можем использовать один метод для вставки и вывода элементов массива. Секрет этого метода в использовании возвращения значения по ссылке. Это означает, что мы можем записать функцию с левой стороны знака равно, при этом значение справа будет присвоено объекту, на который ссылается результат вызова слева.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
#include &lt;cstdlib&gt; // для std::exit
#include &lt;clocale&gt;

const int LIMIT = 100; // размер массива

class safearray {
private:
    int arr[LIMIT];
public:
    // обратите внимание, что функция возвращает ссылку!
    int &amp;access(int n) {
        if (n &lt; 0 || n &gt;= LIMIT) {
            std::cout &lt;&lt; "\nОшибочный индекс!";
            std::exit(1);
        }
        return arr[n];
    }
};


int main() {
    setlocale(LC_ALL, "Russian");
    safearray sa1;
    // задаем значения элементов
    for (int j = 0; j &lt; LIMIT; j++) {
        sa1.access(j) = j * 10; // используем функцию слева от знака =
    }
    // показываем элементы
    for (int j = 0; j &lt; LIMIT; j++) {
        int temp = sa1.access(j); // используем функцию справа от знака =
        std::cout &lt;&lt; "Элемент " &lt;&lt; j &lt;&lt; " равен " &lt;&lt; temp &lt;&lt; std::endl;
    }
    return 0;
} </code></pre>

<p>Строка:  <code>sa1.access(j) = j * 10;</code> означает, что значение j*10 будет помещено в элемент массива arr[j], ссылка на который возвращается методом. Это использование одного метода для ввода и вывода элементов массива в общем случае немного более удобно, чем использование отдельных методов, на одно имя меньше. Но существует еще лучший способ, вовсе без имен.</p>

<h2>Перегруженная операция [], использующая возвращение по ссылке</h2>

<p>Мы перегрузим операцию индексации [] в классе safearray для использования стандартной записи C++ для доступа к элементам массива. Однако, так как эта операция обычно используется слева от знака равно, наша перегруженная функция должна возвращать свое значение по ссылке, как показано в предыдущей программе.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
#include &lt;cstdlib&gt; // для std::exit
#include &lt;clocale&gt;

const int LIMIT = 100; // размер массива

class safearray {
private:
    int arr[LIMIT];
public:
    // обратите внимание, что функция возвращает ссылку!
    int &amp;operator[](int n) {
        if (n &lt; 0 || n &gt;= LIMIT) {
            std::cout &lt;&lt; "\nОшибочный индекс!";
            std::exit(1);
        }
        return arr[n];
    }
};

int main() {
    setlocale(LC_ALL, "Russian");
    safearray sa1;
    // задаем значения элементов
    for (int j = 0; j &lt; LIMIT; j++) {
        sa1[j] = j * 10; // используем функцию слева от знака =
    }
    // показываем элементы
    for (int j = 0; j &lt; LIMIT; j++) {
        int temp = sa1[j]; // используем функцию справа от знака =
        std::cout &lt;&lt; "Элемент " &lt;&lt; j &lt;&lt; " равен " &lt;&lt; temp &lt;&lt; std::endl;
    }
    return 0;
} </code></pre>

<p>В этой программе мы можем использовать обычную запись операции индексации массива <code>sa1[j] = j * 10;</code> и <code>int temp = sa1[j];</code> для ввода и вывода элементов массива.</p>
