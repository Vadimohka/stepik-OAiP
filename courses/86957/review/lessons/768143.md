<h3>Основы организации ввода-вывода</h3>

<p>По умолчанию язык C++ не содержит встроенных средств для ввода с консоли и вывода на консоль, эти средства предоставляются библиотекой iostream. В ней определены два типа: istream и ostream. istream представляет поток ввода, а ostream - поток вывода.</p>

<p>Термин "поток" в данном случае представляет последовательность символов, которая записывается на устройство ввода-вывода или считывается с него. И в данном случае под устройством ввода-вывода рассматривается консоль.</p>

<p>Для записи или вывода символов на консоль применяется объект cout, который представляет тип ostream. А для чтения с консоли используется объект cin</p>

<p>Для использования этих объектов в начало исходного файла необходимо подключить библиотеку iostream:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;</code></pre>

<p>Библиотека iostream определяет три стандартных потока:</p>

<ul>
	<li>cin  стандартный входной поток (stdin в С)</li>
	<li>cout  стандартный выходной поток (stdout в С)</li>
	<li>cerr  стандартный поток вывода сообщений об ошибках (stderr в С)</li>
</ul>

<h3>Вывод на консоль</h3>

<p>Для вывода на консоль применяется оператор &lt;&lt;. Этот оператор получает два операнда. Левый операнд представляет объект типа ostream, в данном случае объект cout. А правый операнд - значение, которое надо вывести на консоль.</p>

<p>Так как оператор &lt;&lt; возвращает левый операнд - cout, то с помощью цепочки операторов мы можем передать на консоль несколько значений. Например, определим простейшую программу вывода на консоль:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {   
    int age = 33;
    double weight = 81.23;
    std::cout &lt;&lt; "Name: " &lt;&lt; "Tom" &lt;&lt; "\n";
    std::cout &lt;&lt; "Age: " &lt;&lt; age &lt;&lt; std::endl;
    std::cout &lt;&lt; "Weight: " &lt;&lt; weight &lt;&lt; std::endl;
    return 0;
}</code></pre>

<p>Оператору &lt;&lt; передаются различные значения - строки, значения переменных, которые выводятся на консоль.</p>

<p>Строки могут содержать управляющие последовательности, которые интерпретируются определенным образом. Например, последовательность "\n" интерпретируется как перевод на новую строку. Из других управляющих последовательностей также нередко употребляется "\t", которая интерпретируется как табуляция.</p>

<p>Также цепочку операторов &lt;&lt; можно завершать значением std::endl, которое вызывает перевод на новую строку и сброс буфера. При выводе в поток данные вначале помещаются в буфер. И сброс буфера гарантирует, что все переданные для вывода на консоль данные немедленно будут выведены на консоль.</p>

<h3>Ввод с консоли</h3>

<p>Для считывания с консоли данных применяется оператор ввода &gt;&gt;, который принимает два операнда. Левый операнд представляет объект типа istream (в данном случае объект cin), с которого производится считывание, а правый операнд - объект, в который считываются данные.</p>

<p>Например, считаем данные с консоли:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {   
    int age;
    double weight;
    std::cout &lt;&lt; "Input age: ";
    std::cin &gt;&gt; age;
    std::cout &lt;&lt; "Input weight: ";
    std::cin &gt;&gt; weight;
    std::cout &lt;&lt; "Your age: " &lt;&lt; age &lt;&lt; "\t your weight: " &lt;&lt; weight &lt;&lt; std::endl;
    return 0;
}</code></pre>

<p>Здесь после приглашений к вводу программа ожидает ввода значений для переменных age и weight.</p>

<p>Стоит отметить, что так оператор ввода в первом случае будет добавлять данные в целочисленную переменную age, то он ожидает ввода числа. В случае с переменной weight оператор ввода ожидает дробное число, причем разделителем целой и дробной части должна быть точка. Поэтому мы не можем ввести любые значения, например, строки. В этом случае программа может выдать некорректный результат.</p>

<p>Оператор ввода &gt;&gt; возвращает левый операнд - объект cin, поэтому мы можем по цепочке считывать данные в различные переменные:</p>

<pre><code class="language-cpp">include &lt;iostream&gt;
 
int main() {   
    int age;
    double weight;
    std::cout &lt;&lt; "Input age: ";
    std::cin &gt;&gt; age &gt;&gt; weight;
    std::cout &lt;&lt; "Your age: " &lt;&lt; age &lt;&lt; "\t your weight: " &lt;&lt; weight &lt;&lt; std::endl;
    return 0;
}</code></pre>

<p>После ввода одного из значений надо будет ввести пробел и затем вводить следующее значение.</p>

<p>По умолчанию <code>cin</code> <em>привязан</em> к <code>cout</code>, что означает, что перед каждой операцией над <code>cin</code> сначала сбрасывается буфер <code>cout</code>, отключить привязку можно следующей строчкой кода:</p>

<pre><code class="language-cpp">cin.tie(NULL);</code></pre>

<p>Отключение этой функции позволяет iostream работать быстрее. </p>

<h3>Манипуляторы потока</h3>

<p>В поток можно помещать управляющие символы которые будут форматировать вывод текста, вот список:</p>

<ul>
	<li><strong><em>\ </em></strong><strong><em>a </em></strong>-кратковременная подача звукового сигнала;</li>
	<li><strong><em>\</em></strong><strong><em>b </em></strong>- перевод курсора влево на одну позицию;</li>
	<li><strong><em>\</em></strong><strong><em>n </em></strong>- переход на новую строку;</li>
	<li><strong><em>\</em></strong><strong><em>r </em></strong>- перевод курсора в начало текущей строки;</li>
	<li><strong><em>\</em></strong><strong><em>t </em></strong>- горизонтальная табуляция;</li>
	<li><strong><em>\</em></strong><strong><em>v </em></strong>- вертикальная табуляция.</li>
</ul>

<p>Размер управляющего символа равен стандартному размеру char в таблице ASCII, т.е. 1 байт. Управляющие символы не выводятся на экран.</p>

<p>Также существуют функции манипуляторы. Функцию - манипулятор потока также как и управляющие символы можно включать в операции помещения в поток и извлечения из потока (&lt;&lt;, &gt;&gt;). Чтобы подключить некоторые функции необходимо использовать библиотеку <code>&lt;iomanip&gt;</code>.</p>

<p><br>
В С++ имеется ряд манипуляторов. Рассмотрим основные:</p>

<ul>
	<li>endl - Помещение в выходной поток символа конца строки '\n'</li>
	<li>dec - Установка основания 10-ой системы счисления</li>
	<li>oct - Установка основания 8-ой системы счисления</li>
	<li>hex - Установка основания 16-ой системы счисления</li>
	<li>setbase - Вывод базовой системы счисления</li>
	<li>width - Устанавливает ширину поля вывода</li>
	<li>fill - Заполняет пустые знакоместа значением символа</li>
	<li>precision - Устанавливает количество значащих цифр в числе (или после запятой) в зависимости от использования fixed</li>
	<li>fixed - Показывает, что установленная точность относится к количеству знаков после запятой</li>
	<li>showpos - Показывает знак + для положительных чисел</li>
	<li>scientific - Выводит число в экспоненциальной форме</li>
	<li>get() - Ожидает ввода символа</li>
	<li>getline - Ожидает ввода строки символов. Максимальное количество символов ограничено полем количество</li>
</ul>

<p>Ещё на производительность iostream негативно влияет частое использование <code>endl</code>, поскольку <code>endl</code> не только выводит символ новой строки, но и сбрасывает буфер потока. Вместо <code>endl</code> можно просто выводить <code>'\n'</code> или <code>"\n"</code>в качестве окончания строки .</p>

<h3>Ввод-вывод с помощью функций языка С</h3>

<p>Ввод и вывод информации осуществляется через функции стандартной библиотеки. Прототипы рассматриваемых функций находятся в файле stdio.h. Эта библиотека содержит функции</p>

<ul>
	<li>printf() — для вывода информации</li>
	<li>scanf() — для ввода информации.</li>
</ul>

<h4>Вывод информации</h4>

<p>Функция printf() предназначена для форматированного вывода. Она переводит данные в символьное представление и выводит полученные изображения символов на экран. При этом у программиста имеется возможность форматировать данные, то есть влиять на их представление<br>
на экране.<br>
<br>
Общая форма записи функции printf():</p>

<pre><code class="language-cpp">printf("СтрокаФорматов", объект1, объект2, ..., объектn);</code></pre>

<p>СтрокаФорматов состоит из следующих элементов:</p>

<ul>
	<li>управляющих символов;</li>
	<li>текста, представленного для непосредственного вывода;</li>
	<li>форматов, предназначенных для вывода значений переменных различных типов.</li>
</ul>

<p>Объекты могут отсутствовать.</p>

<p>Форматы нужны для того, чтобы указывать вид, в котором информация будет выведена на экран. Отличительной чертой формата является наличие символа процент ‘%’ перед ним:</p>

<ul>
	<li>%d — целое число типа int со знаком в десятичной системе счисления;</li>
	<li>%u — целое число типа unsigned int;</li>
	<li>%x — целое число типа int со знаком в шестнадцатеричной системе счисления;</li>
	<li>%o — целое число типа int со знаком в восьмеричной системе счисления;</li>
	<li>%hd — целое число типа short со знаком в десятичной системе счисления;</li>
	<li>%hu — целое число типа unsigned short;</li>
	<li>%hx — целое число типа short со знаком в шестнадцатеричной системе счисления;</li>
	<li>%ld — целое число типа long int со знаком в десятичной системе счисления;</li>
	<li>%lu — целое число типа unsigned long int;</li>
	<li>%lx — целое число типа long int со знаком в шестнадцатеричной системе счисления;</li>
	<li>%f — вещественный формат (числа с плавающей точкой типа float);</li>
	<li>%lf — вещественный формат двойной точности (числа с плавающей точкой типа double);</li>
	<li>%e — вещественный формат в экспоненциальной форме (числа с плавающей точкой типа float в экспоненциальной форме);</li>
	<li>%c — символьный формат;</li>
	<li>%s — строковый формат.</li>
</ul>

<p>Строка форматов содержит форматы для вывода значений. Каждый формат вывода начинается с символа %. После строки форматов через запятую указываются имена переменных, которые необходимо вывести.<br>
Количество символов % в строке формата должно совпадать с количеством переменных для вывода. Тип каждого формата должен совпадать с типом переменной, которая будет выводиться на это место. Замещение форматов вывода значениями переменных происходит в порядке их следования.</p>

<h2>Ввод информации</h2>

<p>Функция форматированного ввода данных с клавиатуры scanf() выполняет чтение данных, вводимых с клавиатуры, преобразует их во внутренний формат и передает вызывающей функции. При этом программист задает правила интерпретации входных данных с помощью спецификаций форматной строки.<br>
Общая форма записи функции scanf( ):</p>

<pre><code class="language-cpp">scanf ("CтрокаФорматов", адрес1, адрес2,...);</code></pre>

<p>Строка форматов аналогична функции printf().<br>
Для формирования адреса переменной используется символ амперсанд <code>&amp;</code>:<br>
<code>адрес = &amp;объект</code><br>
<br>
Строка форматов и список аргументов для функции обязательны.</p>

<p>Функция scanf( ) является функцией незащищенного ввода, т.к. появилась она в ранних версиях языка Си. Поэтому чтобы разрешить работу данной функции в современных компиляторах необходимо в начало программы добавить следующую строчку.</p>

<pre><code class="language-cpp">#define _CRT_SECURE_NO_WARNINGS </code></pre>

<p>Однако, такой подход категорически запрещён в большинстве современных проектов, поэтому необходимо воспользоваться функцией защищенного ввода scanf_s( ), которая появилась несколько позже, но содержит тот же самый список параметров.</p>

<p><em><strong>*</strong></em>По умолчанию включена синхронизация iostream с stdio, то есть iostream и stdio можно использовать вместе на одном и том же потоке, перемежая их вызовы. После отключения синхронизации так делать больше нельзя, однако за счёт этого iostream может работать быстрее. Отключение производится следующей строчкой:</p>

<pre><code class="language-cpp">ios_base::sync_with_stdio(false);</code></pre>
