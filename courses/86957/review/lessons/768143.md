<h3>Первый запуск: от исходного файла до результата</h3>
<p><strong>Цель шага:</strong> проследить превращение исходного файла в программу с предсказуемым выводом. В примере файл <code>main.cpp</code>:</p>
<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {
    std::cout &lt;&lt; "Hello, C++!\n";
}</code></pre>
<p><code>#include &lt;iostream&gt;</code> подключает объявления потоков. <code>main</code> — главная функция обычной программы. <code>std::cout</code> выводит текст, а <code>\n</code> обозначает перевод строки. Достижение конца <code>main</code> эквивалентно <code>return 0;</code> — успешному завершению.</p>
<h4>GCC или Clang: Linux и macOS</h4>
<p>Команды выполняются из каталога с <code>main.cpp</code>. Если установлен GCC:</p>
<pre><code class="language-bash">g++ -std=c++20 -Wall -Wextra -Wpedantic -g main.cpp -o hello
./hello</code></pre>
<p>Для Clang замените <code>g++</code> на <code>clang++</code>. Первая команда собирает программу, вторая запускает результат. Запускайте вторую команду после успешной сборки: при ошибке на диске может остаться исполняемый файл от предыдущего запуска.</p>
<h4>MSVC: Windows</h4>
<p>В окружении установленного MSVC используется <em>Developer PowerShell for Visual Studio</em> в каталоге проекта:</p>
<pre><code class="language-powershell">cl /std:c++20 /EHsc /W4 /Zi main.cpp /Fe:hello.exe
.\hello.exe</code></pre>
<p>Если работаете в IDE, создайте консольный C++-проект, добавьте этот исходный файл, выберите C++20 и выполните сборку и запуск. На Windows с GCC можно собрать <code>hello.exe</code> командой <code>g++ -std=c++20 -Wall -Wextra -Wpedantic -g main.cpp -o hello.exe</code> и запустить <code>.\hello.exe</code> в PowerShell.</p>
<p>Ожидаемый вывод во всех вариантах:</p>
<pre><code class="language-text">Hello, C++!</code></pre>
<p>Флаги <code>-Wall -Wextra -Wpedantic</code> включают полезные диагностики GCC/Clang; <code>/W4</code> — высокий уровень предупреждений MSVC. <code>-g</code> и <code>/Zi</code> добавляют отладочную информацию. Наличие предупреждений проверяйте даже тогда, когда сборка завершилась.</p>
<h3>Разбор результата</h3><p>После успешной сборки вывод равен <code>Hello, C++!</code> и переводу строки. Редактирование приветствия меняет только исходный файл; новый текст появится после новой успешной сборки. Точка останова перед выводом показывает, что программа уже запущена, но операция вывода ещё не выполнена.</p><p>Справка: <a href="https://clang.llvm.org/docs/UsersManual.html" rel="noopener noreferrer nofollow">Clang Compiler User’s Manual</a>; <a href="https://learn.microsoft.com/en-us/cpp/build/reference/std-specify-language-standard-version" rel="noopener noreferrer nofollow">стандарт языка в MSVC</a>.</p>

<h3>Как читать первые ошибки</h3>
<p><strong>Цель шага:</strong> найти причину диагностики и проверить исправление. Следующая программа <strong>намеренно ошибочна</strong> и не должна успешно компилироваться:</p>
<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {
    cout &lt;&lt; "Hello, C++!\n";
}</code></pre>
<p>Компилятор сообщает, что имя <code>cout</code> не объявлено или не найдено. Точная формулировка зависит от GCC, Clang или MSVC и их версии. Имя объекта потока — <code>std::cout</code>: замена <code>cout</code> на <code>std::cout</code> устраняет именно эту ошибку. Заголовок подключён, но неквалифицированное имя <code>cout</code> в этой области не находится.</p>
<table><thead><tr><th>Когда обнаружена проблема</th><th>Пример</th><th>Что проверять</th></tr></thead><tbody>
<tr><td>Компиляция</td><td>Неизвестное имя или пропущенный <code>;</code>.</td><td>Файл и строку из первой существенной диагностики, объявления и типы.</td></tr>
<tr><td>Компоновка</td><td>Функция объявлена и вызвана, но её определение не передано компоновщику.</td><td>Состав исходных файлов, библиотеки и соответствие объявлений определениям.</td></tr>
<tr><td>Выполнение</td><td>Программа падает либо выдаёт неверный ответ.</td><td>Входные данные, логику, значения в отладчике и тесты.</td></tr>
</tbody></table>
<p>Текст диагностики создаёт выбранный компилятор, а IDE помогает его показать. Разные IDE могут запускать один и тот же компилятор.</p>
<h3>Два разных дефекта</h3><p>В приведённом исходнике неизвестное имя <code>cout</code> препятствует сборке. После замены на <code>std::cout</code> программа выводит ожидаемое приветствие. Если вместо <code>Hello</code> в строковом литерале записано <code>Helo</code>, синтаксис остаётся правильным и сборка проходит, но вывод отличается от требуемого. Это ошибка результата, которую компилятор не обязан обнаружить.</p><p>При обращении за помощью приложите небольшой полный пример, точную команду сборки, версию компилятора, первую диагностику и ожидаемый результат. Скриншот без исходного кода обычно затрудняет воспроизведение.</p>

[Открыть на Stepik](https://stepik.org/lesson/768143/step/3?unit=770498) · [Исходник step-source](../../raw/step-sources/3215075.json) · [Объект step](../../raw/steps/3215075.json)

<h3>Основы организации ввода-вывода</h3>

<p>По умолчанию язык C++ не содержит встроенных средств для ввода с консоли и вывода на консоль, эти средства предоставляются стандартной библиотекой через заголовок &lt;iostream&gt;. В ней определены два типа: istream и ostream. istream представляет поток ввода, а ostream - поток вывода.</p>

<p>Термин "поток" в данном случае представляет последовательность символов, которая записывается на устройство ввода-вывода или считывается с него. И в данном случае под устройством ввода-вывода рассматривается консоль.</p>

<p>Для записи или вывода символов на консоль применяется объект cout, который представляет тип ostream. А для чтения с консоли используется объект cin</p>

<p>Для использования этих объектов в начало исходного файла необходимо подключить заголовок &lt;iostream&gt;:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;</code></pre>

<p>Среди стандартных потоков, объявленных в &lt;iostream&gt;, рассмотрим три:</p>

<ul>
	<li>cin  стандартный входной поток (stdin в С)</li>
	<li>cout  стандартный выходной поток (stdout в С)</li>
	<li>cerr  стандартный поток вывода сообщений об ошибках (stderr в С)</li>
</ul>

<h3>Вывод на консоль</h3>

<p>Для вывода на консоль применяется оператор &lt;&lt;. Этот оператор получает два операнда. Левый операнд представляет объект типа ostream, в данном случае объект cout. А правый операнд - значение, которое надо вывести на консоль.</p>

<p>Так как оператор &lt;&lt; возвращает левый операнд - cout, то с помощью цепочки операторов мы можем передать на консоль несколько значений. Например, определим простейшую программу вывода на консоль:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {   
    int age = 33;
    double weight = 81.23;
    std::cout &lt;&lt; "Name: " &lt;&lt; "Tom" &lt;&lt; "\n";
    std::cout &lt;&lt; "Age: " &lt;&lt; age &lt;&lt; std::endl;
    std::cout &lt;&lt; "Weight: " &lt;&lt; weight &lt;&lt; std::endl;
    return 0;
}</code></pre>

<p>Оператору &lt;&lt; передаются различные значения - строки, значения переменных, которые выводятся на консоль.</p>

<p>Строки могут содержать управляющие последовательности, которые интерпретируются определенным образом. Например, последовательность "\n" интерпретируется как перевод на новую строку. Из других управляющих последовательностей также нередко употребляется "\t", которая интерпретируется как табуляция.</p>

<p>Также в цепочке вывода можно использовать манипулятор std::endl: он вставляет перевод строки и вызывает сброс буфера потока. Вывод может буферизоваться, поэтому сброс запрашивает передачу накопленных данных дальше; он не является универсальной гарантией мгновенного отображения на физическом устройстве.</p>

<h3>Ввод с консоли</h3>

<p>Для считывания с консоли данных применяется оператор ввода &gt;&gt;, который принимает два операнда. Левый операнд представляет объект типа istream (в данном случае объект cin), с которого производится считывание, а правый операнд - объект, в который считываются данные.</p>

<p>Например, считаем данные с консоли:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {   
    int age{};
    double weight{};
    std::cout &lt;&lt; "Input age: ";
    if (!(std::cin &gt;&gt; age)) return 1;
    std::cout &lt;&lt; "Input weight: ";
    if (!(std::cin &gt;&gt; weight)) return 1;
    std::cout &lt;&lt; "Your age: " &lt;&lt; age &lt;&lt; "\t your weight: " &lt;&lt; weight &lt;&lt; std::endl;
    return 0;
}</code></pre>

<p>Здесь после приглашений к вводу программа ожидает ввода значений для переменных age и weight.</p>

<p>При чтении age ожидается целое число, а при чтении weight — число с плавающей точкой. В используемой здесь стандартной локали разделителем целой и дробной части служит точка. Если ввод не соответствует ожидаемому формату, поток переходит в состояние ошибки. Поэтому примеры проверяют результат чтения и завершаются с кодом 1 при ошибке.</p>

<p>Оператор ввода &gt;&gt; возвращает левый операнд - объект cin, поэтому мы можем по цепочке считывать данные в различные переменные:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
 
int main() {   
    int age{};
    double weight{};
    std::cout &lt;&lt; "Input age: ";
    if (!(std::cin &gt;&gt; age &gt;&gt; weight)) return 1;
    std::cout &lt;&lt; "Your age: " &lt;&lt; age &lt;&lt; "\t your weight: " &lt;&lt; weight &lt;&lt; std::endl;
    return 0;
}</code></pre>

<p>Между значениями можно ввести пробельный разделитель, например пробел или перевод строки.</p>

<p>По умолчанию cin привязан к cout: это позволяет автоматически сбрасывать буфер cout перед чтением из cin. Отключить привязку можно следующей строкой:</p>

<pre><code class="language-cpp">std::cin.tie(nullptr);</code></pre>

<p>Отключение привязки может уменьшить накладные расходы. При интерактивном вводе после этого иногда нужно явно сбрасывать поток вывода, например с помощью std::flush, чтобы приглашение появилось до ожидания ввода. </p>

<h3>Манипуляторы потока</h3>

<p>В поток можно помещать управляющие символы, которые будут форматировать вывод текста, вот список:</p>

<ul>
	<li><code>\a</code> — кратковременная подача звукового сигнала;</li>
	<li><strong><em>\</em></strong><strong><em>b </em></strong>- перевод курсора влево на одну позицию;</li>
	<li><strong><em>\</em></strong><strong><em>n </em></strong>- переход на новую строку;</li>
	<li><strong><em>\</em></strong><strong><em>r </em></strong>- перевод курсора в начало текущей строки;</li>
	<li><strong><em>\</em></strong><strong><em>t </em></strong>- горизонтальная табуляция;</li>
	<li><strong><em>\</em></strong><strong><em>v </em></strong>- вертикальная табуляция.</li>
</ul>

<p>В обычном узком строковом литерале escape-последовательность, например <code>\n</code>, обозначает один символ типа char. Само написание последовательности занимает два знака исходного текста. Действие управляющего символа при выводе зависит от устройства или терминала.</p>

<p>Также существуют функции-манипуляторы. Манипулятор потока, так же как и управляющие символы, можно включать в операции помещения в поток и извлечения из потока (&lt;&lt;, &gt;&gt;). Чтобы подключить некоторые функции необходимо использовать библиотеку <code>&lt;iomanip&gt;</code>.</p>

<p><br>
В С++ имеется ряд манипуляторов. Рассмотрим основные:</p>

<ul>
	<li>endl — помещение в выходной поток символа конца строки и сброс буфера; символ перевода строки — '\n'</li>
	<li>dec - Установка основания 10-ой системы счисления</li>
	<li>oct - Установка основания 8-ой системы счисления</li>
	<li>hex - Установка основания 16-ой системы счисления</li>
	<li>setbase — установка основания 8, 10 или 16 для целочисленного ввода-вывода</li>
	<li>setw — устанавливает ширину поля для следующей операции, использующей эту настройку</li>
	<li>setfill — задаёт символ заполнения свободных позиций поля вывода</li>
	<li>setprecision — задаёт точность: число значащих цифр в defaultfloat или число цифр после точки в fixed/scientific</li>
	<li>fixed - Показывает, что установленная точность относится к количеству знаков после запятой</li>
	<li>showpos - Показывает знак + для положительных чисел</li>
	<li>scientific - Выводит число в экспоненциальной форме</li>
</ul>

<p>Функции get и getline не являются манипуляторами: они читают данные из потока. Например, std::cin.get() читает символ, а std::getline(std::cin, строка) читает строку в std::string. У перегрузки std::cin.get(буфер, размер) и метода std::cin.getline(буфер, размер) размер буфера задаётся отдельно.</p>

<p>Ещё на производительность iostream негативно влияет частое использование <code>endl</code>, поскольку <code>endl</code> не только выводит символ новой строки, но и сбрасывает буфер потока. Вместо <code>endl</code> можно просто выводить <code>'\n'</code> или <code>"\n"</code> в качестве окончания строки.</p>

<h3>Ввод-вывод с помощью функций языка С</h3>

<p>Стандартные функции ввода-вывода C доступны и в C++. В C++ можно включить заголовок <code>&lt;cstdio&gt;</code> и использовать имена <code>std::printf</code>, <code>std::scanf</code>. Совместимый заголовок <code>&lt;stdio.h&gt;</code> также допустим. Рассмотрим две функции:</p>

<ul>
	<li>printf() — для вывода информации</li>
	<li>scanf() — для ввода информации.</li>
</ul>

<h4>Вывод информации</h4>

<p>Функция printf() предназначена для форматированного вывода. Она переводит данные в символьное представление и выводит полученные изображения символов на экран. При этом у программиста имеется возможность форматировать данные, то есть влиять на их представление<br>
на экране.<br>
<br>
Общая форма записи функции printf():</p>

<pre><code class="language-cpp">printf("СтрокаФорматов", объект1, объект2, ..., объектn);</code></pre>

<p>СтрокаФорматов состоит из следующих элементов:</p>

<ul>
	<li>управляющих символов;</li>
	<li>текста, представленного для непосредственного вывода;</li>
	<li>форматов, предназначенных для вывода значений переменных различных типов.</li>
</ul>

<p>Объекты могут отсутствовать.</p>

<p>Форматы нужны для того, чтобы указывать вид, в котором информация будет выведена на экран. Отличительной чертой формата является наличие символа процент ‘%’ перед ним:</p>

<table border="1" cellpadding="4" cellspacing="0">
<caption>Форматированный вывод: printf</caption>
<thead><tr><th>Формат printf</th><th>Ожидаемый аргумент и представление</th></tr></thead>
<tbody>
<tr><td><code>%d</code></td><td><code>int</code>, десятичная запись со знаком</td></tr>
<tr><td><code>%u</code></td><td><code>unsigned int</code>, десятичная запись</td></tr>
<tr><td><code>%x</code>, <code>%o</code></td><td><code>unsigned int</code>, шестнадцатеричная или восьмеричная запись</td></tr>
<tr><td><code>%hd</code>, <code>%hu</code>, <code>%hx</code></td><td><code>short</code> или <code>unsigned short</code> с учётом целочисленных продвижений; x — беззнаковая шестнадцатеричная запись</td></tr>
<tr><td><code>%ld</code></td><td><code>long int</code></td></tr>
<tr><td><code>%lu</code>, <code>%lx</code></td><td><code>unsigned long int</code></td></tr>
<tr><td><code>%f</code>, <code>%e</code>, <code>%g</code></td><td><code>double</code>; аргумент float автоматически продвигается до double</td></tr>
<tr><td><code>%lf</code></td><td>В printf эквивалентно %f; это не способ отличить float от double</td></tr>
<tr><td><code>%Lf</code>, <code>%Le</code>, <code>%Lg</code></td><td><code>long double</code></td></tr>
<tr><td><code>%c</code></td><td><code>int</code>, преобразуемый в символ; char при передаче продвигается до int</td></tr>
<tr><td><code>%s</code></td><td>Указатель на последовательность char, заканчивающуюся нулевым символом</td></tr>
</tbody>
</table>

<p>Каждой спецификации преобразования в строке формата должен соответствовать аргумент нужного типа, с учётом продвижений аргументов. <code>%%</code> печатает знак процента и не потребляет аргумент; звёздочка <code>*</code> для ширины или точности потребляет отдельный аргумент <code>int</code>. Несоответствие формата и аргумента может привести к неопределённому поведению.</p>

<h2>Ввод информации</h2>

<p>Функция форматированного ввода данных с клавиатуры scanf() выполняет чтение данных, вводимых с клавиатуры, преобразует их во внутренний формат и передает вызывающей функции. При этом программист задает правила интерпретации входных данных с помощью спецификаций форматной строки.<br>
Общая форма записи функции scanf( ):</p>

<pre><code class="language-cpp">scanf ("CтрокаФорматов", адрес1, адрес2,...);</code></pre>

<p>У <code>scanf</code> форматы задают тип <strong>указателя</strong> на объект, в который записывается значение. Для получения адреса обычной переменной используется <code>&amp;</code>. В отличие от printf, <code>%f</code> требует <code>float*</code>, <code>%lf</code> — <code>double*</code>, <code>%Lf</code> — <code>long double*</code>.</p>

<table border="1" cellpadding="4" cellspacing="0">
<thead><tr><th>Формат scanf</th><th>Тип аргумента</th></tr></thead>
<tbody>
<tr><td><code>%d</code></td><td><code>int*</code></td></tr>
<tr><td><code>%u</code>, <code>%x</code>, <code>%o</code></td><td><code>unsigned int*</code></td></tr>
<tr><td><code>%hd</code>, <code>%hu</code></td><td><code>short*</code>, <code>unsigned short*</code> соответственно</td></tr>
<tr><td><code>%ld</code>, <code>%lu</code></td><td><code>long*</code>, <code>unsigned long*</code> соответственно</td></tr>
<tr><td><code>%f</code>, <code>%lf</code>, <code>%Lf</code></td><td><code>float*</code>, <code>double*</code>, <code>long double*</code> соответственно</td></tr>
<tr><td><code>%c</code>, <code>%s</code></td><td><code>char*</code>; для %s ограничивайте ширину по размеру буфера</td></tr>
</tbody>
</table><p>Например: <code>double value{}; if (std::scanf("%lf", &amp;value) == 1) { /* значение считано */ }</code>. Возвращаемое число показывает количество успешно считанных и присвоенных значений.</p>

<p><code>scanf</code> входит в стандартную библиотеку C++ через совместимые средства C. В MSVC её использование может вызывать предупреждение C4996. Макрос <code>_CRT_SECURE_NO_WARNINGS</code>, определённый до подключения заголовков, подавляет эти предупреждения Microsoft CRT; для других компиляторов он не является обязательным условием работы <code>scanf</code> и сам по себе не делает ввод безопасным.</p>

<pre><code class="language-cpp">#define _CRT_SECURE_NO_WARNINGS </code></pre>

<p><code>scanf_s</code> — интерфейс, предоставляемый, в частности, Microsoft CRT, но не обязательная переносимая функция C++. При чтении строк и символов её аргументы отличаются от <code>scanf</code>: после буфера для форматов <code>%s</code>, <code>%c</code> и <code>%[...]</code> требуется дополнительный размер буфера типа <code>unsigned</code>. Например, для <code>char name[20]</code> в MSVC можно написать <code>scanf_s("%19s", name, static_cast&lt;unsigned&gt;(sizeof name))</code>. Ширина 19 оставляет место для завершающего нуля. Простая замена имени функции без проверки аргументов неверна. Переносимый вариант для этого буфера — <code>std::scanf("%19s", name)</code>; результат чтения также нужно проверить. Для строк в C++ обычно удобнее <code>std::string</code> и <code>std::getline</code>.</p>

<p>По умолчанию стандартные потоки C++ синхронизированы с потоками C. Вызов <code>std::ios_base::sync_with_stdio(false)</code> до начала ввода-вывода разрешает независимую буферизацию. После него лучше последовательно использовать одну систему ввода-вывода: произвольное смешивание printf и cout может менять порядок видимого вывода.</p>

<pre><code class="language-cpp">std::ios_base::sync_with_stdio(false);</code></pre>
