<h3>IDE</h3>

<p><strong>Интегрированная Среда Разработки </strong>(IDE)<strong> </strong>является составной частью системы программирования. Под системой программирования понимают совокупность языка программирования и программных средств, обеспечивающих подготовку исходных текстов программ, их перевод на машинный язык, и последующую их отладку. Иными словами, системы программирования создаются для удобства работы пользователя с выбранным языком программирования.</p>

<p>Как правило, системы программирования включают в свой состав:</p>

<ul>
	<li>
	<p>интегрированную среду разработки или программирования (Integrated Development Environment - IDE);</p>
	</li>
	<li>
	<p>компилятор;</p>
	</li>
	<li>
	<p>редактор связей или компоновщик;</p>
	</li>
	<li>
	<p>библиотеки заголовочных файлов;</p>
	</li>
	<li>
	<p>библиотеки классов и функций;</p>
	</li>
	<li>
	<p>программы-утилиты.</p>
	</li>
</ul>

<p>Также Интегрированную Среду Разработки можно трактовать как среду, в которой есть все необходимое для проектирования, запуска и тестирования приложений и где все нацелено на облегчение процесса создания программ. IDE интегрирует в себе редактор кодов, отладчик, инструментальные панели, редактор изображений, инструментарий баз данных т.е. всё, с чем приходится работать. Результатом является быстрая разработка сложных прикладных программ. Таким образом, IDE позволяет запустить сборку из одного интерфейса, вызывая нужные инструменты — компилятор, компоновщик и систему сборки. Они могут поставляться вместе с IDE или устанавливаться отдельно; результат не обязательно имеет формат .exe.</p>

<h3>Как IDE выбрать?</h3>

<p>Что требуется от IDE:</p>

<ul>
	<li>Способность IDE корректно «понимать» C++ код. IDE должна уметь индексировать все файлы проекта, а также все сторонние и системные заголовочные файлы и определения (defines, macro).</li>
	<li>IDE должна предоставлять возможность кастомизации команд для построения проекта, а также настройки путей поиска заголовочных файлов и определений макросов.</li>
	<li>Должна эффективно помогать в наборе кода, т.е. предлагать наиболее подходящие варианты завершения, предупреждать об ошибках синтаксиса и т.д.</li>
	<li>Навигация по большому проекту должна быть удобной, а поиск мест использования — быстрым и простым.</li>
	<li>Предоставлять широкие возможности для рефакторинга: переименование и т.д.</li>
	<li>Также необходима способность к генерации шаблонного кода — создание каркаса нового класса, заголовочного файла и файла с реализацией. Генерация геттеров/сеттеров, определения методов, переопределение виртуальных методов, шаблоны реализации абстрактных классов (интерфейсов) и т.д.</li>
	<li>Подсветка и поддержка тегов документирования кода.</li>
</ul>

<h3>Microsoft Visual Studio</h3>

<p>Visual Studio — интегрированная среда разработки с поддержкой C++ и других языков. Она позволяет создавать консольные приложения, приложения с графическим интерфейсом и другие виды проектов. Для обычной разработки C++ под Windows устанавливают рабочую нагрузку «Разработка классических приложений на C++». Поддерживаемые платформы и дополнительные средства зависят от версии IDE и выбранных компонентов; их актуальный список приведён в документации Microsoft.</p>

<ul>

	<li>API для подключения дополнительных инструментов отладки.</li>
	<li>Полный набор инструментов разработчика для создания и клонирования Git-репозиториев, управления ветвями и разрешения конфликтов слияния прямо в интегрированной среде разработки C++.</li>

<h3>Так что же выбрать?</h3>

<p>Все перечисленные IDE заточены под разработку на языке С++ (Ну кроме Visual Studio и Xcode, здесь есть поддержка на одном качественном уровне различных ЯП), поэтому закончу урок цитатой из интервью с <a href="https://en.wikipedia.org/wiki/Bjarne_Stroustrup" rel="noopener noreferrer nofollow">Бьёрне Страуструпом</a>, где он ответил на следующий крайне занимательный вопрос:</p>

<p><strong>C++ всё ещё изучают в школах и вузах, используют в различных отраслях. Зачем в 202Х году нужно учить C++?</strong></p>

<p>- "C++ — один из самых полезных языков, этого уже должно быть достаточно. Человеку, который хочет стать профессионалом, стоит знать несколько языков, а C++ хорош там, где нужна производительность и надёжность. Кроме того, этот язык широко используется в экономике, играх, телекоммуникациях, электронике и производстве. Взгляните на <a href="https://blog.jetbrains.com/clion/2015/07/infographics-cpp-facts-before-clion/" rel="noopener noreferrer nofollow" target="_blank">пост</a> в блоге JetBrains и мою страницу <a href="http://www.stroustrup.com/applications.html" rel="noopener noreferrer nofollow" target="_blank">«C++ Applications»</a> и попытайтесь понять, почему язык без маркетинга настолько популярен.</p>

<p>По-моему, главная причина для изучения C++ — он помогает понять различные подходы к программированию и методологии разработки, которые можно применять и в других языках".</p>

<p>Мой личный набор - Visual Studio и CLion.</p>
