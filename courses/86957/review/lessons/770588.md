<h3>Понятие символьной строки в С++</h3>

<p>Символьные литералы записываются в одинарных кавычках. В C++ обычный литерал из одного символа, например <code>'a'</code>, имеет тип <code>char</code>. В языке C соответствующая символьная константа имеет тип <code>int</code>. Для литералов с префиксами и многосимвольных литералов действуют отдельные правила. Таблица ASCII связывает соответствующие символы с их числовыми кодами.</p>

<p>Один из способов представить строку в C++ — массив элементов char, где последовательность символов заканчивается нулевым символом <code>'\0'</code>. Такое представление называют C-строкой, или строкой в стиле C.</p>

<p>Обычный строковый литерал записывают в двойных кавычках. Для хранения C-строки в массиве нужно предусмотреть отдельный элемент char под завершающий нулевой символ.</p>

<pre><code class="language-cpp">char str[10]{}; // буфер из 10 char; сейчас содержит пустую C-строку
// В нём можно хранить до 9 ненулевых элементов char и завершающий '\0'.</code></pre>

<p>Строка при объявлении  может быть инициализирована начальным значением, например, так:</p>

<pre><code class="language-cpp">char str[] = "abcdefghf";</code></pre>

<p>В литерале "abcdefghf" девять символов. Инициализированный им массив содержит десять элементов char: компилятор добавляет завершающий нулевой символ.</p>

<p>Такие строки называются <strong>С-строками</strong>.</p>

### Шаг 2 — text (ID 3214845)

<h3>Функции для работы со строками и символами</h3>

<p>strlen(имя_строки) - определяет длину указанной строки, без учёта нуль-символа</p>

<h4><strong>Копирование строк</strong></h4>

<p><code>strcpy(s1, s2)</code> копирует C-строку s2 вместе с нулевым терминатором в s1. Целевой буфер должен быть достаточно велик, а области памяти не должны перекрываться.</p>

<p><code>strncpy(s1, s2, n)</code> записывает в s1 ровно n элементов: копирует до n символов источника, а если строка короче n, дополняет остаток нулями. Если первые n символов источника не содержат нуля, терминатор не добавляется. Целевой буфер должен вмещать n элементов; перекрытие областей недопустимо. Возвращает s1.</p>

<h4><strong>Конкатенация строк</strong></h4>

<p>strcat(s1,s2) - объединяет строку s2 со строкой s1. Результат сохраняется в s1</p>

<p><code>strncat(s1, s2, n)</code> добавляет к строке s1 не более n символов из s2 и завершающий нулевой символ. Параметр n ограничивает число добавленных символов, а не полный размер буфера s1. Для результата должно хватать места; области не должны перекрываться.</p>

<h4><strong>Сравнение строк</strong></h4>

<p><code>std::strcmp(s1, s2)</code> из <code>&lt;cstring&gt;</code> сравнивает две C-строки с учётом регистра. Результат типа <code>int</code>: ноль — строки равны, отрицательное число — первая строка лексикографически меньше второй, положительное — больше. Значение не обязано быть ровно −1 или 1.</p>

<p><code>std::strncmp(s1, s2, n)</code> сравнивает не более <code>n</code> символов двух C-строк, останавливаясь на терминаторе. Знаки результата те же: отрицательный — первая последовательность меньше, ноль — сравниваемые части равны, положительный — первая больше.</p>

<p><code>stricmp</code> — встречающееся в некоторых реализациях расширение для сравнения без учёта регистра; в MSVC документирован вариант <code>_stricmp</code>. Эта функция не входит в ISO C++. Отрицательный результат означает, что первая строка меньше второй, ноль — эквивалентна, положительный — больше; правила регистра зависят от локали.</p>

<p><code>strnicmp</code> и MSVC-вариант <code>_strnicmp</code> аналогично сравнивают не более <code>n</code> символов без учёта регистра. Это расширения реализации, а не стандартные функции C++. Знаки результата соответствуют порядку первой строки относительно второй.</p>

<h4><strong>Обработка символов</strong></h4>

<p>Функции классификации символов из &lt;cctype&gt; принимают EOF либо значение, представимое как unsigned char. Для обычной переменной char безопасная форма — <code>std::isalnum(static_cast&lt;unsigned char&gt;(c))</code>; аналогично для остальных функций. Классификация букв зависит от локали.</p><p><code>isalnum(c)</code> возвращает ненулевое значение int, если c является буквой или цифрой, и 0 иначе.</p>

<p><code>isalpha(c)</code> возвращает ненулевое значение int, если c является буквой, и 0 иначе.</p>

<p><code>isdigit(c)</code> возвращает ненулевое значение int, если c является десятичной цифрой, и 0 иначе.</p>

<p><code>islower(c)</code> возвращает ненулевое значение int, если c является буквой нижнего регистра, и 0 иначе.</p>

<p><code>isupper(c)</code> возвращает ненулевое значение int, если c является буквой верхнего регистра, и 0 иначе.</p>

<p><code>isspace(c)</code> возвращает ненулевое значение int, если c является пробельным символом, например пробелом, табуляцией или переводом строки, и 0 иначе.</p>

<p><code>toupper(c)</code> возвращает как int код соответствующей буквы верхнего регистра, если такое преобразование определено текущей локалью; иначе возвращает c без изменений. К аргументу применяется то же ограничение EOF или unsigned char.</p>

<h4><strong>Функции поиска</strong></h4>

<p>strchr(s,c) -  поиск первого вхождения символа с<strong> </strong>в строке s<strong>. </strong>В случае удачного поиска возвращает указатель на место первого вхождения символа с<strong>. </strong>Если символ не найден, то возвращается ноль.</p>

<p>strcspn(s1,s2) - определяет длину начального сегмента строки s1, содержащего те символы, которые не входят в строку s2</p>

<p>strspn(s1,s2) - возвращает длину начального сегмента строки s1, содержащего только те символы, которые входят в строку s2</p>

<p><code>strpbrk(s1, s2)</code> возвращает указатель на первое вхождение в s1 любого символа из s2. Если совпадения нет, возвращается нулевой указатель.</p>

<h4><strong>Функции преобразования</strong></h4>

<p>atof(s1) - преобразует строку s1 в тип double</p>

<p>atoi(s1) - преобразует строку s1 в тип int</p>

<p>atol(s1) - преобразует строку s1 в тип long int</p>

<h4><strong>Функции стандартной библиотеки ввода/вывода &lt;cstdio&gt; (в C — &lt;stdio.h&gt;)</strong></h4>

<p><code>std::getchar()</code> вызывается без аргументов. Она читает один символ из стандартного ввода и возвращает его код в виде <code>int</code> либо <code>EOF</code> при конце ввода/ошибке. Сохраняйте результат в <code>int</code>, чтобы не потерять возможность проверки <code>EOF</code>.</p>

<p>Для чтения строки в ограниченный буфер используйте <code>std::fgets(buffer, capacity, stdin)</code>: она читает не более <code>capacity - 1</code> символов и при успехе добавляет нулевой терминатор. Перенос строки, если прочитан, остаётся в буфере. Проверяйте возвращённый указатель. Функция <code>gets</code> не ограничивала длину ввода и удалена из C11 и C++14. Для <code>std::string</code> используется <code>std::getline</code>.</p>

<h3>Указатель на символы строки: char* и const char*</h3>

<p><code>char s[] = "text";</code> объявляет массив s типа char[5] и инициализирует его строковым литералом. Он содержит элементы t, e, x, t и завершающий нулевой символ.</p>

<p>Элементы массива можно изменять: </p>

<pre><code class="language-cpp">s[0] = 'n'; /* s: "next" */</code></pre>

<p>Но не можете переприсвоить сам массив <code>s</code> (это же массив):</p>

<pre><code class="language-cpp">char s[] = "text";  /* OK */
s = "another text"; /* Это ошибка. */</code></pre>

<p> Если вы используете указатель:</p>

<pre><code class="language-cpp">// До C++11 допускалось устаревшее объявление:
// char* s = "text";
// В современном C++:
const char* s = "text";</code></pre>

<p>Здесь s — указатель типа const char* на первый элемент строкового литерала. Изменять сам литерал нельзя. Даже если принудительно получить неконстантный указатель и записать через него символ, поведение будет неопределённым.</p>

<p>И уже сам указатель переприсваивать можно:</p>

<pre><code class="language-cpp">const char *p = "text"; /* OK */
p = "another text"; /* OK */</code></pre>

<p>В таком объявлении обычный строковый литерал преобразуется в const char*. Неявно получить char* из литерала в современном C++ нельзя. Указатель на константный char не следует путать с константным указателем.</p>

<p>Для обычной работы со строковыми значениями удобно использовать std::string. Массивы char и C-строки остаются полезны, например, при взаимодействии с C API. Далее рассмотрим std::string.</p>
