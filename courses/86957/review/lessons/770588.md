<h3>Понятие символьной строки в С++</h3>

<p>Символ – элементарная единица, некоторый набор которых несет определенный смысл. В языке программирования С++ предусмотрено использование символьных констант. Символьная константа – это целочисленное значение (типа <code>int</code>) представленное в виде символа, заключённого в одинарные кавычки, например <code>'a'</code>. В таблице ASCII представлены символы и их целочисленные значения.</p>

<p>Строки в С++ представляются как массивы элементов типа <code>char</code>, заканчивающиеся нуль-терминатором <code>\0</code> называются С строками или строками в стиле С.</p>

<p>Символьные строки состоят из набора символьных констант заключённых в двойные кавычки. При объявлении строкового массива необходимо учитывать наличие в конце строки нуль-терминатора, и отводить дополнительный байт под него.</p>

<pre><code class="language-cpp">char str[10]; //строка представленная в виде массива символов         
//10 – размер массива, то есть в данной строке может поместиться 9 символов,
//последнее место отводится под нуль-терминатор \0.
</code></pre>

<p>Строка при объявлении  может быть инициализирована начальным значением, например, так:</p>

<pre><code class="language-cpp">char str[] = "abcdefghf";</code></pre>

<p>Если подсчитать кол-во символов в двойных кавычках после символа равно их окажется 9, а размер строки 10 символов,  последнее  место отводится под нуль–терминатор, причём компилятор сам добавит его в конец строки.</p>

<p>Такие строки называются <strong>С-строками</strong>.</p>

<h3>Функции для работы со строками и символами</h3>

<p>strlen(имя_строки) - определяет длину указанной строки, без учёта нуль-символа</p>

<h4><strong>Копирование строк</strong></h4>

<p>strcpy(s1,s2) - выполняет побайтное копирование символов из строки  s2 в строку s1</p>

<p>strncpy(s1,s2, n) - выполняет побайтное копирование n символов из строки  s2 в строку s1. возвращает значения s1</p>

<h4><strong>Конкатенация строк</strong></h4>

<p>strcat(s1,s2) - объединяет строку s2 со строкой s1. Результат сохраняется в s1</p>

<p>strncat(s1,s2,n) - объединяет n символов строки s2 со строкой s1. Результат сохраняется в s1</p>

<h4><strong>Сравнение строк</strong></h4>

<p>strcmp(s1,s2) - сравнивает строку s1 со строкой s2 и возвращает результат типа int: 0 –если строки эквивалентны, &gt;0 – если s1&lt;s2,  &lt;0  — если s1&gt;s2 С учётом регистра</p>

<p>strncmp(s1,s2,n) - сравнивает n символов строки s1 со строкой s2 и возвращает результат типа int: 0 –если строки эквивалентны, &gt;0 – если s1&lt;s2,  &lt;0  — если s1&gt;s2 С учётом регистра</p>

<p>stricmp(s1,s2) - сравнивает строку s1 со строкой s2 и возвращает результат типа <strong>int</strong>: 0 –если строки эквивалентны, &gt;0 – если s1&lt;s2,  &lt;0  — если s1&gt;s2 Без учёта регистра</p>

<p>strnicmp(s1,s2,n)<strong> - </strong>сравнивает n символов строки s1 со строкой s2 и возвращает результат типа int: 0 –если строки эквивалентны, &gt;0 – если s1&lt;s2,  &lt;0 — если s1&gt;s2 Без учёта регистра</p>

<h4><strong>Обработка символов</strong></h4>

<p>isalnum(c) - возвращает значение true, если с является буквой или цифрой, и false в других случаях</p>

<p>isalpha(c) - возвращает значение true, если с является буквой,  и false в других случаях</p>

<p>isdigit(c) - возвращает значение true, если с является цифрой, и false в других случаях</p>

<p>islower(c) - возвращает значение true, если с является буквой нижнего регистра, и false в других случаях</p>

<p>isupper(c) - возвращает значение true, если с является буквой верхнего регистра, и false в других случаях</p>

<p>isspace(c) - возвращает значение true, если с является пробелом, и false в других случаях</p>

<p>toupper(c) - если символ с, является символом нижнего регистра, то функция возвращает преобразованный символ с в верхнем регистре, иначе символ возвращается без изменений.</p>

<h4><strong>Функции поиска</strong></h4>

<p>strchr(s,c) -  поиск первого вхождения символа с<strong> </strong>в строке s<strong>. </strong>В случае удачного поиска возвращает указатель на место первого вхождения символа с<strong>. </strong>Если символ не найден, то возвращается ноль.</p>

<p>strcspn(s1,s2) - определяет длину начального сегмента строки s1, содержащего те символы, которые не входят в строку s2</p>

<p>strspn(s1,s2) - возвращает длину начального сегмента строки s1, содержащего только те символы, которые входят в строку s2</p>

<p>strprbk(s1,s2) - Возвращает указатель  первого вхождения любого символа строки s2 в строке s1</p>

<h4><strong>Функции преобразования</strong></h4>

<p>atof(s1) - преобразует строку s1 в тип double</p>

<p>atoi(s1) - преобразует строку s1 в тип int</p>

<p>atol(s1) - преобразует строку s1 в тип long int</p>

<h4><strong>Функции стандартной библиотеки ввода/вывода &lt;stdio&gt;</strong></h4>

<p>getchar(с) - считывает символ с<strong> </strong>со стандартного потока ввода, возвращает символ в формате int</p>

<p>gets(s) - считывает поток символов со стандартного устройства ввода в строку s<strong> </strong>до тех пор, пока не будет нажата клавиша ENTER</p>

<h3>Указатель на массив символов Char*</h3>

<p>Если <code>char s[] = "text";</code>это объявление массива <code>s</code> типа <code>char []</code> и инициализация этого массива строковым литералом <code>"text"</code>. Т. е. <code>s</code> — это просто массив из <strong>пяти</strong> символов: <code>t</code>, <code>e</code>, <code>x</code>, <code>t</code>, <code>\0</code>.</p>

<p>То вы можете менять его: </p>

<pre><code class="language-cpp">s[0] = 'n'; /* s: "next" */</code></pre>

<p>Но не можете переприсвоить сам массив <code>s</code> (это же массив):</p>

<pre><code class="language-cpp">char s[] = "text";  /* OK */
s = "another text"; /* Это ошибка. */</code></pre>

<p> Если вы используете указатель:</p>

<pre><code class="language-cpp">char *s = "text"; /* до C++11 */
const char *s = "text"; /* начиная C++11 */</code></pre>

<p>Объявление указателя <code>s</code> типа <code>char *</code> и присваивание ему указателя на первый элемент строкового литерала <code>"text"</code>. Попытка изменить этот строковой литерал (<code>s[0] = 'a'</code>, например), — это неопределенное поведение.</p>

<p>И уже сам указатель переприсваивать можно:</p>

<pre><code class="language-cpp">const char *p = "text"; /* OK */
p = "another text"; /* OK */</code></pre>

<p>Начиная с C++11 строковые литералы могут быть прямо присвоены только <code>const char *</code> (только указателям на <em>константный</em> <code>char</code>, <strong>не путать с константным указателем</strong>).</p>

<p>При разработке ПО массив char рекомендуется использовать исключительно как набор одиночных символов. Для всего остального есть библиотека string, к ней мы сейчас и перейдём.</p>
