<h3><strong>АВЛ-дерево</strong></h3>
<p>Предпосылка — <a href="https://stepik.org/lesson/853539/step/2" rel="noopener noreferrer nofollow">инвариант BST</a>. AVL добавляет к нему ограничение высот; поворот обязан сохранить <em>оба</em> свойства. Как и ранее, h(пусто) = 0, h(лист) = 1.</p>

<p>Наиболее простое, но наглядное сбалансированное дерево поиска – это АВЛ-дерево.</p>

<p><strong>АВЛ-дерево</strong> – это сбалансированное дерево поиска, в котором для каждой вершины модуль разности высот её двух поддеревьев не превышает 1.</p>

<p>В реализации ниже баланс узла b(v) = h(left) − h(right). После вставки или удаления в ранее сбалансированном дереве он может стать +2 или −2. Тогда выбирают подходящее вращение по направлению перекоса узла и его ребёнка, чтобы восстановить |b(v)| ≤ 1.</p>

<p>В АВЛ-дереве используются 4 типа вращений, которые позволяют сохранять свойства дерева при изменении его структуры.</p>

<p>1. <strong>Малое левое вращение</strong>. b(v) = −2 и b(v-&gt;right) ≤ 0: правое поддерево тяжелее, а его внешний правый путь не короче внутреннего.</p>

<p><img alt="" height="182" name="Frame 38.png" src="https://ucarecdn.stepik.net/002639dc-ebd5-400f-b3a5-98e55ce44722/-/crop/11139x4011/0,312/-/preview/" width="505"></p>

<p>2. <strong>Большое левое вращение</strong>. b(v) = −2 и b(v-&gt;right) &gt; 0: сначала правое вращение правого ребёнка, затем левое вращение самого v.</p>

<p><img alt="" height="211" name="Frame 39.png" src="https://ucarecdn.stepik.net/eb035d28-a18d-4266-bdd4-efdf05dde59e/-/crop/5669x1909/0,838/-/preview/" width="627"></p>

<p>3. <strong>Малое правое вращение</strong>. b(v) = +2 и b(v-&gt;left) ≥ 0: левое поддерево тяжелее, а его внешний левый путь не короче внутреннего.</p>

<p><img alt="" height="206" name="Frame 40.png" src="https://ucarecdn.stepik.net/32ab76c6-3929-4745-8fa1-9197a338a048/-/crop/11139x4209/0,1295/-/preview/" width="545"></p>

<p>4. <strong>Большое правое вращение</strong>. b(v) = +2 и b(v-&gt;left) &lt; 0: сначала левое вращение левого ребёнка, затем правое вращение самого v.</p>

<p><img alt="" height="245" name="Frame 41.png" src="https://ucarecdn.stepik.net/b5822f44-c2fe-488a-a955-068687786f23/-/crop/5669x2091/0,593/-/preview/" width="664"></p>

<p>Само вращение сохраняет порядок ключей двоичного дерева поиска при наличии нужного дочернего узла. Однако произвольное вращение не обязательно восстанавливает AVL-баланс. Для описанных случаев предполагается, что дочерние поддеревья уже сбалансированы; именно выбор малого или большого вращения по указанным условиям восстанавливает баланс текущего поддерева.</p>

<p>После выбранного по этим условиям вращения высота исправляемого поддерева не превосходит его высоты непосредственно перед вращением. Это не означает, что вставка вообще не может увеличить высоту дерева: высота могла вырасти при добавлении узла до балансировки. После удаления высота поддерева может уменьшиться, поэтому балансировку при необходимости продолжают вверх к корню.</p>

<p>Большое вращение — композиция двух малых. Условие баланса и высоту проверяют для результата всей композиции; промежуточное малое вращение не обязано само по себе восстанавливать AVL-баланс.</p>

<p>Благодаря свойству балансированности высот, время добавления элемента в АВЛ-дерево составляет O(log(N)), где N - количество вершин в дереве.</p><h3>Что сохраняет поворот</h3><p>При левом повороте узла x его правый ребёнок y становится корнем поддерева. Промежуточное поддерево B — прежний левый ребёнок y — становится правым ребёнком x. Все его ключи удовлетворяют x.key &lt; B &lt; y.key, поэтому симметричный порядок не меняется. Правый поворот симметричен. После перепривязки сначала обновляют высоту бывшего корня, затем нового: новая высота зависит от уже исправленных детей.</p><p>Для вставки 30, 10, 20 получается внутренний перекос: у 30 баланс +2, у 10 баланс −1. Сначала левый поворот вокруг 10, затем правый вокруг 30 дают корень 20 с листьями 10 и 30. Это разобранный случай LR; случаи LL, RR и RL выбираются той же таблицей знаков.</p><p>Минимальное число узлов AVL высоты h удовлетворяет N(h) = 1 + N(h − 1) + N(h − 2), N(0) = 0, N(1) = 1. Эта последовательность растёт экспоненциально по h, поэтому h = O(log n). Именно инвариант, а не удачный порядок входных ключей, обеспечивает логарифмическое число сравнений.</p><p>Следующий шаг связывает эти операции с <code>unique_ptr</code>: поворот передаёт владение связями, но не копирует сами узлы.</p>

### Шаг 2 — text (ID 3570281)

[Открыть на Stepik](https://stepik.org/lesson/853540/step/2?unit=857459) · [Исходник step-source](../../raw/step-sources/3570281.json) · [Объект step](../../raw/steps/3570281.json)

<h2>AVL: согласованная реализация и разобранная трассировка</h2>
<p>Ниже полный заголовок <code>avl.hpp</code> и программа, которая его использует. У дерева уникальные целочисленные ключи, значения — строки. <code>insert</code> возвращает <code>false</code> для дубликата без изменения значения; <code>erase</code> возвращает <code>false</code> для отсутствующего ключа; <code>find</code> выдаёт невладеющий указатель или <code>nullptr</code>.</p>
<ol><li>Спуск выбирает ветвь по BST-инварианту.</li><li>После изменения дочернего поддерева пересчитывается высота.</li><li>Если модуль баланса равен 2, выполняется одно или два нужных вращения.</li><li>При возвращении к родителю он получает уже сбалансированное поддерево с актуальной высотой.</li></ol>
<p>Ссылки <code>Tree&amp;</code> позволяют менять владеющую связь без копирования узлов. Вращения используют <code>std::move</code> для передачи <code>unique_ptr</code>. В удалении узла с одним ребёнком старый владелец сначала выносится в локальный объект: так мы не используем член уже уничтоженного узла.</p>
<h3>Заголовок avl.hpp</h3><pre><code class="language-cpp">#pragma once
#include &lt;algorithm&gt;
#include &lt;memory&gt;
#include &lt;string&gt;
#include &lt;utility&gt;

namespace avl_example {
struct Node {
    int key;
    std::string value;
    std::unique_ptr&lt;Node&gt; left, right;
    int height = 1;
    Node(int k, std::string v) : key(k), value(std::move(v)) {}
};
using Tree = std::unique_ptr&lt;Node&gt;;

inline int height(const Tree&amp; tree) {
    return tree ? tree-&gt;height : 0;
}
inline void update(Node&amp; node) {
    node.height = 1 + std::max(height(node.left), height(node.right));
}
inline int balance(const Tree&amp; tree) {
    return tree ? height(tree-&gt;left) - height(tree-&gt;right) : 0;
}

// Preconditions: tree and tree-&gt;right exist.
inline void rotate_left(Tree&amp; tree) {
    Tree new_root = std::move(tree-&gt;right);
    tree-&gt;right = std::move(new_root-&gt;left);
    update(*tree);
    new_root-&gt;left = std::move(tree);
    update(*new_root);
    tree = std::move(new_root);
}
// Preconditions: tree and tree-&gt;left exist.
inline void rotate_right(Tree&amp; tree) {
    Tree new_root = std::move(tree-&gt;left);
    tree-&gt;left = std::move(new_root-&gt;right);
    update(*tree);
    new_root-&gt;right = std::move(tree);
    update(*new_root);
    tree = std::move(new_root);
}

// The children are AVL trees, and the height changed by at most one.
inline void rebalance(Tree&amp; tree) {
    if (!tree) return;
    update(*tree);
    if (balance(tree) &gt; 1) {
        if (balance(tree-&gt;left) &lt; 0) rotate_left(tree-&gt;left);
        rotate_right(tree);
    } else if (balance(tree) &lt; -1) {
        if (balance(tree-&gt;right) &gt; 0) rotate_right(tree-&gt;right);
        rotate_left(tree);
    }
}

// A duplicate key preserves the existing value and returns false.
inline bool insert(Tree&amp; tree, int key, const std::string&amp; value) {
    if (!tree) {
        tree = std::make_unique&lt;Node&gt;(key, value);
        return true;
    }
    bool inserted = false;
    if (key &lt; tree-&gt;key) inserted = insert(tree-&gt;left, key, value);
    else if (key &gt; tree-&gt;key) inserted = insert(tree-&gt;right, key, value);
    else return false;
    rebalance(tree);
    return inserted;
}

inline const Node* find(const Tree&amp; tree, int key) {
    const Node* node = tree.get(); // Non-owning observer.
    while (node) {
        if (key &lt; node-&gt;key) node = node-&gt;left.get();
        else if (key &gt; node-&gt;key) node = node-&gt;right.get();
        else return node;
    }
    return nullptr;
}

inline bool erase(Tree&amp; tree, int key) {
    if (!tree) return false;
    bool removed = false;
    if (key &lt; tree-&gt;key) removed = erase(tree-&gt;left, key);
    else if (key &gt; tree-&gt;key) removed = erase(tree-&gt;right, key);
    else {
        removed = true;
        if (!tree-&gt;left) {
            Tree old_root = std::move(tree);
            tree = std::move(old_root-&gt;right);
        } else if (!tree-&gt;right) {
            Tree old_root = std::move(tree);
            tree = std::move(old_root-&gt;left);
        } else {
            const Node* successor = tree-&gt;right.get();
            while (successor-&gt;left) successor = successor-&gt;left.get();
            // Copy the potentially throwing value before changing the key.
            std::string replacement = successor-&gt;value;
            tree-&gt;key = successor-&gt;key;
            tree-&gt;value = std::move(replacement);
            erase(tree-&gt;right, tree-&gt;key);
        }
    }
    rebalance(tree);
    return removed;
}
} // namespace avl_example</code></pre>
<p>При двух потомках берётся минимальный ключ правого поддерева. Замещается <em>пара</em> ключ–значение, затем удаляется прежний узел этой пары. Потенциально бросающее копирование строки выполнено до изменения ключа. Это сохраняет соответствие данных при отказе копирования в данной конкретной реализации с <code>int</code> и обычным <code>std::string</code>.</p>
<h3>Программа avl_demo.cpp</h3><pre><code class="language-cpp">#include "avl.hpp"
#include &lt;iostream&gt;

int main() {
    avl_example::Tree tree;
    for (int key : {30, 10, 20, 40}) {
        avl_example::insert(tree, key, std::to_string(key));
    }
    avl_example::insert(tree, 20, "replacement");
    std::cout &lt;&lt; tree-&gt;key &lt;&lt; ' ' &lt;&lt; tree-&gt;height &lt;&lt; '\n';
    avl_example::erase(tree, 20);
    for (int key : {10, 20, 30, 40}) {
        if (const auto* node = avl_example::find(tree, key)) {
            std::cout &lt;&lt; node-&gt;key &lt;&lt; ':' &lt;&lt; node-&gt;value &lt;&lt; ' ';
        }
    }
    std::cout &lt;&lt; '\n';
}</code></pre>
<p>После 30, 10, 20 двойной поворот даёт корень 20. Вставка 40 увеличивает высоту дерева до 3; повтор 20 оставляет его строку прежней. Первая строка вывода — <code>20 3</code>. После удаления 20 выводятся <code>10:10 30:30 40:40</code>: данные преемника перенесены вместе с ключом.</p>
<p>Это объясняющая реализация, а не замена <code>std::map</code>: открытые узлы позволяют внешнему коду нарушить инвариант, нет библиотечного интерфейса итераторов. После удаления не следует сохранять наблюдатели на узлы; удаление с заменой пары также меняет содержимое существующего узла. Поиск, вставка и удаление требуют O(log n) сравнений; рекурсивные операции используют O(log n) памяти стека. Стоимость копирования строки рассматривается отдельно от числа сравнений ключей.</p>
