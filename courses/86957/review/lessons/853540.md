<h3><strong>АВЛ-дерево</strong></h3>

<p>Наиболее простое, но наглядное сбалансированное дерево поиска – это АВЛ-дерево.</p>

<p><strong>АВЛ-дерево</strong> – это сбалансированное дерево поиска, в котором для каждой вершины модуль разности высот её двух поддеревьев не превышает 1.</p>

<p>В реализации ниже баланс узла b(v) = h(left) − h(right). После вставки или удаления в ранее сбалансированном дереве он может стать +2 или −2. Тогда выбирают подходящее вращение по направлению перекоса узла и его ребёнка, чтобы восстановить |b(v)| ≤ 1.</p>

<p>В АВЛ-дереве используются 4 типа вращений, которые позволяют сохранять свойства дерева при изменении его структуры.</p>

<p>1. <strong>Малое левое вращение</strong>. b(v) = −2 и b(v-&gt;right) ≤ 0: правое поддерево тяжелее, а его внешний правый путь не короче внутреннего.</p>

<p><img alt="" height="182" name="Frame 38.png" src="https://ucarecdn.stepik.net/002639dc-ebd5-400f-b3a5-98e55ce44722/-/crop/11139x4011/0,312/-/preview/" width="505"></p>

<p>2. <strong>Большое левое вращение</strong>. b(v) = −2 и b(v-&gt;right) &gt; 0: сначала правое вращение правого ребёнка, затем левое вращение самого v.</p>

<p><img alt="" height="211" name="Frame 39.png" src="https://ucarecdn.stepik.net/eb035d28-a18d-4266-bdd4-efdf05dde59e/-/crop/5669x1909/0,838/-/preview/" width="627"></p>

<p>3. <strong>Малое правое вращение</strong>. b(v) = +2 и b(v-&gt;left) ≥ 0: левое поддерево тяжелее, а его внешний левый путь не короче внутреннего.</p>

<p><img alt="" height="206" name="Frame 40.png" src="https://ucarecdn.stepik.net/32ab76c6-3929-4745-8fa1-9197a338a048/-/crop/11139x4209/0,1295/-/preview/" width="545"></p>

<p>4. <strong>Большое правое вращение</strong>. b(v) = +2 и b(v-&gt;left) &lt; 0: сначала левое вращение левого ребёнка, затем правое вращение самого v.</p>

<p><img alt="" height="245" name="Frame 41.png" src="https://ucarecdn.stepik.net/b5822f44-c2fe-488a-a955-068687786f23/-/crop/5669x2091/0,593/-/preview/" width="664"></p>

<p>Само вращение сохраняет порядок ключей двоичного дерева поиска при наличии нужного дочернего узла. Однако произвольное вращение не обязательно восстанавливает AVL-баланс. Для описанных случаев предполагается, что дочерние поддеревья уже сбалансированы; именно выбор малого или большого вращения по указанным условиям восстанавливает баланс текущего поддерева.</p>

<p>После выбранного по этим условиям вращения высота исправляемого поддерева не превосходит его высоты непосредственно перед вращением. Это не означает, что вставка вообще не может увеличить высоту дерева: высота могла вырасти при добавлении узла до балансировки. После удаления высота поддерева может уменьшиться, поэтому балансировку при необходимости продолжают вверх к корню.</p>

<p>Большое вращение — композиция двух малых. Условие баланса и высоту проверяют для результата всей композиции; промежуточное малое вращение не обязано само по себе восстанавливать AVL-баланс.</p>

<p>Благодаря свойству балансированности высот, время добавления элемента в АВЛ-дерево составляет O(log(N)), где N - количество вершин в дереве.</p>

### Шаг 2 — text (ID 3570281)

[Открыть на Stepik](https://stepik.org/lesson/853540/step/2?unit=857459) · [Исходник step-source](../../raw/step-sources/3570281.json) · [Объект step](../../raw/steps/3570281.json)

<h3>Реализация</h3>

<p>Ниже самостоятельная реализация AVL-дерева с уникальными ключами: определение узла, создание узла, вставка, повороты и удаление. Поле height нового листа равно 1; высота пустого поддерева равна 0. При удалении узла с двумя потомками копируется вся пара ключ–значение.</p>

<pre><code class="language-cpp">#include &lt;memory&gt;
#include &lt;string&gt;
#include &lt;utility&gt;

struct Node {
    int key;
    std::string value;
    std::shared_ptr&lt;Node&gt; left, right;
    int height = 1; // используется в AVL-дереве

    Node(int nKey, std::string nValue)
        : key(nKey), value(std::move(nValue)) {}
};

std::shared_ptr&lt;Node&gt; newNode(int key, std::string value) {
    return std::make_shared&lt;Node&gt;(key, std::move(value));
}

// Высота дерева
int getHeight(std::shared_ptr&lt;Node&gt; node) {
    if (!node)
        return 0;
    return node-&gt;height;
}

int max(int a, int b) {
    return (a &gt; b) ? a : b;
}

// Правый поворот
std::shared_ptr&lt;Node&gt; rightRotate(std::shared_ptr&lt;Node&gt; node) {
    std::shared_ptr&lt;Node&gt; x = node-&gt;left;
    std::shared_ptr&lt;Node&gt; T2 = x-&gt;right;

    // Выполняем поворот
    x-&gt;right = node;
    node-&gt;left = T2;

    // Обновляем высоту 
    node-&gt;height = max(getHeight(node-&gt;left), getHeight(node-&gt;right)) + 1;
    x-&gt;height = max(getHeight(x-&gt;left), getHeight(x-&gt;right)) + 1;

    // Возвращаем новый корень 
    return x;
}

// Левый поворот
std::shared_ptr&lt;Node&gt; leftRotate(std::shared_ptr&lt;Node&gt; node) {
    std::shared_ptr&lt;Node&gt; y = node-&gt;right;
    std::shared_ptr&lt;Node&gt; T2 = y-&gt;left;

    // Выполняем поворот 
    y-&gt;left = node;
    node-&gt;right = T2;

    // Обновляем высоту
    node-&gt;height = max(getHeight(node-&gt;left), getHeight(node-&gt;right)) + 1;
    y-&gt;height = max(getHeight(y-&gt;left), getHeight(y-&gt;right)) + 1;

    // Возвращаем новый корень
    return y;
}

// Разность высот поддеревьев
int getBalance(std::shared_ptr&lt;Node&gt; node) {
    if (!node)
        return 0;
    return getHeight(node-&gt;left) - getHeight(node-&gt;right);
}

// Вставка
std::shared_ptr&lt; Node&gt; insert(std::shared_ptr&lt;Node&gt; node, int key, std::string value) {
    // 1: Выполняем обычную вставку BST 
    if (!node)
        return(newNode(key, value));

    if (key &lt; node-&gt;key) {
        node-&gt;left = insert(node-&gt;left, key, value);
    }
    else if (key &gt; node-&gt;key) {
        node-&gt;right = insert(node-&gt;right, key, value);
    }
    // Одинаковые ключи не допускаются 
    else {
        return node;
    }

    // 2: Обновляем высоту этого родительского узла 
    node-&gt;height = 1 + max(getHeight(node-&gt;left), getHeight(node-&gt;right));

    // 3: Получаем коэффициент баланса этого
    //    родительского узла, чтобы проверить,
    //    является ли этот узел сбалансированным 
    int balance = getBalance(node);

    // Если этот узел не сбалансирован,
    // то есть 4 случая:

    // Left Left Case 
    if (balance &gt; 1 &amp;&amp; key &lt; node-&gt;left-&gt;key)
        return rightRotate(node);

    // Right Right Case 
    if (balance &lt; -1 &amp;&amp; key &gt; node-&gt;right-&gt;key)
        return leftRotate(node);

    // Left Right Case 
    if (balance &gt; 1 &amp;&amp; key &gt; node-&gt;left-&gt;key) {
        node-&gt;left = leftRotate(node-&gt;left);
        return rightRotate(node);
    }

    // Right Left Case 
    if (balance &lt; -1 &amp;&amp; key &lt; node-&gt;right-&gt;key) {
        node-&gt;right = rightRotate(node-&gt;right);
        return leftRotate(node);
    }

    // возвращаем (неизменный) указатель узла
    return node;
}

// Минимальное значение в поддереве с корнем node.
std::shared_ptr&lt; Node&gt; minValueNode(std::shared_ptr&lt;Node&gt; node) {
    std::shared_ptr&lt;Node&gt; current = node;

    // Получаем самый левый узел
    while (current-&gt;left)
        current = current-&gt;left;

    return current;
}

// Удаление узла
std::shared_ptr&lt; Node&gt; deleteNode(std::shared_ptr&lt;Node&gt; root, int key) {
    // 1: Выполняем стандартное удаление
    if (!root)
        return root;

    // Если ключ удаляемого элемента меньше
    // ключа корня, тогда он лежит
    // в левом поддереве 
    if (key &lt; root-&gt;key) {
        root-&gt;left = deleteNode(root-&gt;left, key);
    }

    // Если ключ удаляемого элемента больше
    // ключа корня, тогда он лежит
    // в правом поддереве 
    else if (key &gt; root-&gt;key) {
        root-&gt;right = deleteNode(root-&gt;right, key);
    }

    // Если ключ совпадает с ключом корня
    // то это удаляемый элемент 
    else {
        // Узел имеет только одного потомка
        // Или не имеет ни одного 
        if ((!root-&gt;left) || (!root-&gt;right)) {
            std::shared_ptr&lt;Node&gt; temp = root-&gt;left ?
                root-&gt;left :
                root-&gt;right;

            // Нет потомка
            if (!temp) {
                temp = root;
                root = std::shared_ptr&lt;Node&gt;();
            }
            // Один потомок
            else {
                *root = *temp; // Копируем содержимое
                               // непустого потомка
            }
        }
        else {
            // Узел с двумя потомками: Получим преемника 
            // (минимальный в правом поддереве) 
            std::shared_ptr&lt;Node&gt; temp = minValueNode(root-&gt;right);

            // Копируем данные преемника в этот узел
            root-&gt;key = temp-&gt;key;
            root-&gt;value = temp-&gt;value;

            // Удаляем преемника
            root-&gt;right = deleteNode(root-&gt;right, temp-&gt;key);
        }
    }

    // Если дерево имеет только один узел
    if (!root)
        return root;

    // 2: Обновляем высоту текущего узла 
    root-&gt;height = 1 + max(getHeight(root-&gt;left),
        getHeight(root-&gt;right));

    // 3: Получаем баланс-фактор этого узла
    // (чтобы проверить, стал ли этот узел несбалансированным)
    int balance = getBalance(root);

    // Если этот узел стал несбалансированным
    // То есть 4 случая

    // Left Left Case 
    if (balance &gt; 1 &amp;&amp; getBalance(root-&gt;left) &gt;= 0)
        return rightRotate(root);

    // Left Right Case 
    if (balance &gt; 1 &amp;&amp; getBalance(root-&gt;left) &lt; 0) {
        root-&gt;left = leftRotate(root-&gt;left);
        return rightRotate(root);
    }

    // Right Right Case 
    if (balance &lt; -1 &amp;&amp; getBalance(root-&gt;right) &lt;= 0)
        return leftRotate(root);

    // Right Left Case 
    if (balance &lt; -1 &amp;&amp; getBalance(root-&gt;right) &gt; 0) {
        root-&gt;right = rightRotate(root-&gt;right);
        return leftRotate(root);
    }

    return root;
}
