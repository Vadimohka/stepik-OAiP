<h2>Учебный словарь предметов: договор до реализации</h2>
<p>Разобранная модель — соответствие числового ID названию предмета: 1 → pencil, 5 → notebook. Предметная запись и организация корзин разделены. Это продолжение <a href="https://stepik.org/lesson/877082/step/1" rel="noopener noreferrer nofollow">интерфейса класса</a> и <a href="https://stepik.org/lesson/853536/step/1" rel="noopener noreferrer nofollow">владения ресурсами</a>.</p>
<p>В следующем шаге приведён полный класс <code>ItemTable</code>. Владелец хранения — <code>std::vector&lt;std::list&lt;Entry&gt;&gt;</code>: вектор владеет корзинами, список — записями, строка — текстом. Для списка нужны только заголовок <code>&lt;list&gt;</code>, обход, добавление в конец и удаление по итератору; самостоятельную реализацию узлов здесь не требуем.</p>
<table><thead><tr><th>Операция</th><th>Договор</th></tr></thead><tbody><tr><td>Конструктор</td><td>Создаёт положительное число пустых корзин; нулевой размер отклоняется исключением.</td></tr><tr><td><code>insert_or_assign(id, name)</code></td><td>Добавляет новый ID либо заменяет имя прежнего; возвращает true только для нового ID.</td></tr><tr><td><code>find(id)</code></td><td>Возвращает независимую копию строки в <code>std::optional</code> или отсутствие значения.</td></tr><tr><td><code>erase(id)</code></td><td>Удаляет одну запись; сообщает, существовал ли ID.</td></tr><tr><td><code>rehash(m)</code></td><td>Переносит все записи в m положительных корзин с пересчётом индекса.</td></tr></tbody></table>
<p><code>std::optional&lt;std::string&gt;</code> (C++17, <code>&lt;optional&gt;</code>) — объект, который содержит строку или не содержит значения. В <code>if (auto name = table.find(id))</code> условие проверяет наличие значения; внутри ветви <code>*name</code> обозначает строку. Отсутствие ключа не маскируется пустой строкой, которая может быть нормальным значением.</p>
<p><strong>Инварианты</strong>: каждый ID встречается не более одного раза; запись находится в корзине <code>id % m</code>; число элементов отличается от числа корзин и от числа непустых корзин. Внутренние записи наружу не выдаются, поэтому внешний код не может изменить ключ, не переместив запись.</p>
<p>Копирование контейнеров создаёт независимые записи; специальный деструктор и ручной <code>delete</code> не нужны — это <strong>правило нуля</strong>. После перемещения объект может иметь ноль корзин; методы следующего шага учитывают это и позволяют повторное использование. Учебная таблица не увеличивается автоматически: rehash вызывается явно, поэтому поддержание низкого α — часть условия её ожидаемой эффективности.</p>

<h2>Цепочки: полная реализация и разбор</h2>
<p>Здесь весь заголовок <code>hash_table.hpp</code> и использующая его программа C++17/20. Все объявленные операции определены; скрытых методов списка и отдельного ручного освобождения памяти нет.</p>
<h3>hash_table.hpp</h3><pre><code class="language-cpp">#pragma once
#include &lt;cstddef&gt;
#include &lt;list&gt;
#include &lt;optional&gt;
#include &lt;stdexcept&gt;
#include &lt;string&gt;
#include &lt;utility&gt;
#include &lt;vector&gt;

class ItemTable {
    struct Entry {
        std::size_t id;
        std::string name;
    };
    std::vector&lt;std::list&lt;Entry&gt;&gt; buckets_;

public:
    explicit ItemTable(std::size_t bucket_count = 8) : buckets_(bucket_count) {
        if (bucket_count == 0) throw std::invalid_argument("zero buckets");
    }
    // Copying and moving are provided by the owning standard containers.
    std::size_t bucket_count() const { return buckets_.size(); }
    std::size_t size() const {
        std::size_t result = 0;
        for (const auto&amp; bucket : buckets_) result += bucket.size();
        return result;
    }
    double load_factor() const {
        return buckets_.empty() ? 0.0
            : static_cast&lt;double&gt;(size()) / static_cast&lt;double&gt;(buckets_.size());
    }
    // true: a new ID; false: replacement of an existing name.
    bool insert_or_assign(std::size_t id, std::string name) {
        // A moved-from table can have no buckets; reuse remains valid.
        if (buckets_.empty()) buckets_.resize(8);
        auto&amp; bucket = buckets_[id % buckets_.size()];
        for (auto&amp; entry : bucket) {
            if (entry.id == id) {
                entry.name = std::move(name);
                return false;
            }
        }
        bucket.push_back(Entry{id, std::move(name)});
        return true;
    }
    std::optional&lt;std::string&gt; find(std::size_t id) const {
        if (buckets_.empty()) return std::nullopt;
        const auto&amp; bucket = buckets_[id % buckets_.size()];
        for (const auto&amp; entry : bucket) {
            if (entry.id == id) return entry.name;
        }
        return std::nullopt;
    }
    bool erase(std::size_t id) {
        if (buckets_.empty()) return false;
        auto&amp; bucket = buckets_[id % buckets_.size()];
        for (auto it = bucket.begin(); it != bucket.end(); ++it) {
            if (it-&gt;id == id) {
                bucket.erase(it);
                return true;
            }
        }
        return false;
    }
    void rehash(std::size_t bucket_count) {
        if (bucket_count == 0) throw std::invalid_argument("zero buckets");
        std::vector&lt;std::list&lt;Entry&gt;&gt; replacement(bucket_count);
        for (const auto&amp; bucket : buckets_) {
            for (const auto&amp; entry : bucket) {
                replacement[entry.id % bucket_count].push_back(entry);
            }
        }
        buckets_.swap(replacement);
    }
};</code></pre>
<h3>Что происходит при операциях</h3>
<p><code>insert_or_assign</code> сначала ищет равный ID в выбранной цепочке. Совпавшая корзина не означает совпадения ключей. Для нового ID запись добавляется в конец списка; для прежнего меняется только имя. <code>find</code> возвращает копию строки: последующий rehash или удаление не сделают найденное значение висячей ссылкой.</p>
<p><code>rehash</code> строит временный набор корзин и копирует в него записи по новому индексу. Если выделение памяти или копирование строки не удалось, старый набор ещё не изменён. Обмен контейнеров выполняется после успешного заполнения. Это простая гарантия для данного варианта с обычными стандартными аллокаторами, ценой временного хранения второй копии.</p>
<p>Число элементов вычисляется суммой размеров списков. Поэтому <code>size()</code> и <code>load_factor()</code> стоят O(m) по числу корзин; у <code>std::unordered_map::size()</code> другая, константная гарантия. Кэширование счётчика ускорило бы запрос, но потребовало бы поддерживать ещё один инвариант при каждой мутации и перемещении. Здесь этот выбор сделан явно ради простоты.</p>
<h3>hash_demo.cpp</h3><pre><code class="language-cpp">#include "hash_table.hpp"
#include &lt;iostream&gt;

int main() {
    ItemTable items(4);
    items.insert_or_assign(1, "pencil");
    items.insert_or_assign(5, "notebook");
    items.insert_or_assign(9, "ruler");
    items.insert_or_assign(5, "book");
    std::cout &lt;&lt; items.size() &lt;&lt; ' ' &lt;&lt; items.load_factor() &lt;&lt; '\n';
    if (const auto name = items.find(5)) std::cout &lt;&lt; *name &lt;&lt; '\n';
    items.rehash(8);
    items.erase(1);
    std::cout &lt;&lt; items.size() &lt;&lt; ' ' &lt;&lt; items.bucket_count() &lt;&lt; '\n';
    std::cout &lt;&lt; std::boolalpha &lt;&lt; items.find(1).has_value() &lt;&lt; '\n';
}</code></pre>
<p>При m = 4 ключи 1, 5, 9 находятся в одной корзине. Обновление 5 оставляет три элемента, поэтому первые строки вывода — <code>3 0.75</code> и <code>book</code>. После rehash(8) ключи 1 и 9 находятся в корзине 1, а 5 — в корзине 5. Удаление 1 оставляет две записи: далее выводятся <code>2 8</code> и <code>false</code>.</p>
<p>Поиск нужной записи и её обнаружение для удаления просматривают одну цепочку: число сравнений ID ожидаемо <code>O(1 + α)</code> при подходящем распределении, в худшем <code>O(n)</code>. Это оценка поиска записи, а не всей обработки строки. При успешном <code>find</code> дополнительно создаётся независимая копия имени: для длины <code>L</code> учитывается ещё <code>O(L)</code> работы с символами. Полученная строка живёт независимо от таблицы; эта гарантия объясняет и цену копирования. Вставка включает поиск и создание либо замену строки, удаление — уничтожение записи. Стоимость выделения памяти и операций над строками рассматривается отдельно от сравнений ID.</p>
<p>Rehash в этой реализации требует O(m<sub>старое</sub> + m<sub>новое</sub> + n) операций над контейнерами плюс копирование текста. Простое <code>id % m</code> и отсутствие автоматического роста не дают универсальной гарантии <code>O(1)</code>. Модель стоимости продолжает <a href="https://stepik.org/lesson/770594/step/1" rel="noopener noreferrer nofollow">разбор базовой операции</a>; в <a href="https://stepik.org/lesson/973825/step/2" rel="noopener noreferrer nofollow"><code>std::map::find</code></a> результатом будет итератор на существующую запись, поэтому договор времени жизни и затраты отличаются от копии в нашем <code>ItemTable</code>.</p>
<p>Этот класс иллюстрирует алгоритм, а не заменяет библиотечный контейнер: нет настраиваемого хеша, компаратора равенства и итераторов. В <a href="https://stepik.org/lesson/973826/step/1" rel="noopener noreferrer nofollow">следующем модуле</a> <code>std::unordered_map</code> предоставляет готовый интерфейс, управление нагрузкой и собственные гарантии инвалидирования. Их следует читать как контракт стандарта, не выводить из устройства нашего примера.</p>
