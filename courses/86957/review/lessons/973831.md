<p>В этом разделе будут приведены примеры кода для реализации вышеописанной теории. Будет реализована хеш-таблица, методом борьбы с коллизиями будет метод цепочек</p>

<p style="text-align: center;"><strong>Подопытный класс “Пароль”</strong></p>

<pre><code>class Password {
    int ID;
    std::string description;
    std::string password;

public:
    std::shared_ptr&lt;Password&gt; nextElement;

    Password(int IDInput, std::string descriptionInput,
             std::string passwordInput);

    int GetID();
    std::string GetDescription();
    std::string GetPassword();
    void SetDescription(std::string description);
    void SetPassword(std::string password);
};</code></pre>

<p>Данный класс содержит в себе поля, а именно:</p>

<ul>
	<li>ID - представляет собой табельный номер пароля, это поле будет использоваться для вычисления хеш-функции;</li>
	<li>description - представляет собой описание пароля, например от какого аккаунта этот пароль;</li>
	<li>password - собственно сам пароль;</li>
	<li>nextElement - так как этот класс будет использоваться как элемент односвязного списка, ему необходима ссылка на следующий элемент. ( Вообще, более правильно для списка будет создать класс Node, который будет содержать в себе ссылку на следующий элемент и сам объект класса Password. ).</li>
</ul>

<p style="text-align: center;"><strong>Подопытный класс “Список”</strong></p>

<pre><code>class PasswordList {
protected:
    int count;
    std::shared_ptr&lt;Password&gt; head;
    std::shared_ptr&lt;Password&gt; tail;

public:
    PasswordList();
    std::shared_ptr&lt;Password&gt; GetHead();
    void AddElement(std::shared_ptr&lt;Password&gt; newElement);
    std::shared_ptr&lt;Password&gt; SearchElementByID(int IDToSearch);
    int GetCount();
};</code></pre>

<p>Данный класс описывает список паролей (PasswordList). А также данный список содержит в себе количество записанных в него элементов, указатели на начало и конец списка, тут ничего необычного.</p>

<p style="text-align: center;"><strong>Хеш-таблица</strong></p>

<pre><code class="language-cpp">class HashTable {
    int tableSize;
    int tableCount;
    PasswordList** items;
    
public:
    HashTable(int tableSize);
    int CalculateHash(int ID);
    void InsertElement(int IDToAdd, std::string 
    descriptionToAdd, std::string passwordToAdd); 
    float CalculateNumberOfElements();
    float CalculateSumOfKeys();
    ~HashTable();
};</code></pre>

<p>В данном классе есть такие поля как:</p>

<ul>
	<li>tableSize - размер таблицы, задается при ее создании;</li>
	<li>tableCount - количество непустых списков в таблице; оно не ограничивает общее число элементов, поскольку один список может содержать много элементов;</li>
	<li>items - массив списков, необходимый для борьбы с коллизиями методом цепочек.</li>
</ul>

### Шаг 2 — text (ID 4035481)

[Открыть на Stepik](https://stepik.org/lesson/973831/step/2?unit=980692) · [Исходник step-source](../../raw/step-sources/4035481.json) · [Объект step](../../raw/steps/4035481.json)

<p style="text-align: center;"><strong>Реализация некоторых функций хеш-таблицы</strong></p>

<pre><code>HashTable::HashTable(int tableSize) {
    this-&gt;tableSize = tableSize;
    this-&gt;tableCount = 0;

    items = new PasswordList*[tableSize]{};

    try {
        for (int i = 0; i &lt; tableSize; i++) {
            items[i] = new PasswordList;
        }
    } catch (...) {
        for (int i = 0; i &lt; tableSize; i++) {
            delete items[i]; // ещё не заполненные позиции равны nullptr
        }
        delete[] items;
        throw;
    }
}</code></pre>

<p>Для этого упрощённого примера размер tableSize должен быть положительным, а ID — неотрицательным. Конструктор создаёт tableSize пустых списков; tableCount увеличивается только при первой вставке в ранее пустой список. Даже когда все списки непусты, в цепочки можно добавлять элементы и обновлять прежние записи.</p>

<pre><code>int HashTable::CalculateHash(int ID) {
    return ID % tableSize;
}</code></pre>

<p>Функция CalculateHash содержит в себе хеш-функцию, которая берет остаток от деления входного параметра, в нашем случае табельный номер пароля, на размер таблицы.</p>

<pre><code>void HashTable::InsertElement(int IDToAdd, std::string descriptionToAdd, std::string passwordToAdd) {
    int indexToInsert = CalculateHash(IDToAdd);

    PasswordList* passwordList = items[indexToInsert];
    
    std::shared_ptr&lt;Password&gt; existingPassword(passwordList-&gt;SearchElementByID(IDToAdd));
    if (existingPassword) {
        existingPassword-&gt;SetDescription(descriptionToAdd);
        existingPassword-&gt;SetPassword(passwordToAdd);
    } else {
        const bool wasEmpty = passwordList-&gt;GetCount() == 0;
        std::shared_ptr&lt;Password&gt; newPassword(new Password(IDToAdd, descriptionToAdd, passwordToAdd));
        passwordList-&gt;AddElement(newPassword);
        if (wasEmpty) {
            this-&gt;tableCount++;
        }
    }
}</code></pre>

<p> </p>

<p>Функция InsertElement вычисляет индекс по ID входящего элемента и выбирает соответствующий список. Если в нём уже есть запись с таким же ID, функция обновляет её поля. Иначе новый элемент добавляется в список. Совпадение одного индекса ещё не означает дубликат ключа: разные ID могут попасть в одну цепочку.</p>
<p>Если создание одного из списков выбросит исключение, конструктор освобождает уже созданные списки и массив указателей, затем передаёт исключение дальше. Деструктор самого HashTable при неудачном конструировании не вызывается. В InsertElement счётчик непустых списков меняется после успешного добавления: отказ при создании нового Password не должен увеличивать tableCount.</p>
