<p>В этом разделе будут приведены примеры кода для реализации выше описанной теории. Будет реализована хеш-таблица, методом борьбы с коллизиями будет метод цепочек</p>

<p style="text-align: center;"><strong>Подопытный класс “Пароль”</strong></p>

<pre><code>class Password {
    int ID;
    std::string description;
    std::string password;

public:
    std::shared_ptr&lt;Password&gt; nextElement;

    Password(int IDInput, std::string descriptionInput,
             std::string passwordInput);

    int GetID();
    std::string GetDescription();
    std::string GetPassword();
    void SetDescription(std::string description);
    void SetPassword(std::string password);
};</code></pre>

<p>Данный класс содержит в себе поля, а именно:</p>

<ul>
	<li>ID - представляет из себя табельный номер пароля, это поле будет использоваться для вычисления хеш-функции;</li>
	<li>description - представляет из себя описание пароля, например от какого аккаунта этот пароль;</li>
	<li>password - собственно сам пароль;</li>
	<li>nextElement - так как этот класс будет использоваться как элемент односвязного списка, ему необходима ссылка на следующий элемент. ( Вообще, более правильно для списка будет создать класс Node, который будет содержать в себе ссылку на следующий элемент и сам объекта класса Password. ).</li>
</ul>

<p style="text-align: center;"><strong>Подопытный класс “Список”</strong></p>

<pre><code>class PasswordList {
protected:
    int count;
    std::shared_ptr&lt;Password&gt; head;
    std::shared_ptr&lt;Password&gt; tail;

public:

<p>Данный класс описывает список паролей (PasswordList). А так же данный список содержит в себе количество записанных в него элементов, указатели на начало и конец списка, тут ничего необычного.</p>

<p style="text-align: center;"><strong>Хеш-таблица</strong></p>

<pre><code class="language-cpp">class HashTable {
    int tableSize;
    int tableCount;

<p>В данном классе есть такие поля как:</p>

<ul>
	<li>tableSize - размер таблицы, задается при ее создании;</li>
	<li>tableCount - количество созданных списков в таблице;</li>
	<li>items - массив списков, необходимый для борьбы с коллизиями методом цепочек.</li>
</ul>

### Шаг 2 — text (ID 4035481)

[Открыть на Stepik](https://stepik.org/lesson/973831/step/2?unit=980692) · [Исходник step-source](../../raw/step-sources/4035481.json) · [Объект step](../../raw/steps/4035481.json)

<p style="text-align: center;"><strong>Реализация некоторых функций хеш-таблицы</strong></p>

<pre><code>HashTable::HashTable(int tableSize) {
    this-&gt;tableSize = tableSize;
    this-&gt;tableCount = 0;

    items = new PasswordList*[tableSize];

    for (int i = 0; i &lt; tableSize; i++) {
        items[i] = new PasswordList;
    }
}</code></pre>

<p>В конструктор приходит tableSize, в зависимости от его значения создается то или иное количество списков.</p>

<pre><code>int HashTable::CalculateHash(int ID) {
    return ID % tableSize;
}</code></pre>

<p>Функция calculateHash содержит в себе хеш-функцию, которая берет остаток от деления входного параметра, в нашем случае табельный номер пароля, на размер таблицы.</p>

<pre><code>void HashTable::InsertElement(int IDToAdd, std::string descriptionToAdd, std::string passwordToAdd) {
    if (tableCount == tableSize) {
        return;
    }

    int indexToInsert = CalculateHash(IDToAdd);

    PasswordList* passwordList = items[indexToInsert];
    
    std::shared_ptr&lt;Password&gt; existingPassword(passwordList-&gt;SearchElementByID(IDToAdd));
    if (existingPassword) {
        existingPassword-&gt;SetDescription(descriptionToAdd);
        existingPassword-&gt;SetPassword(passwordToAdd);
    } else {
        if (passwordList-&gt;GetCount() == 0) {
            this-&gt;tableCount++;
        }
        std::shared_ptr&lt;Password&gt; newPassword(new Password(IDToAdd, descriptionToAdd, passwordToAdd));
        passwordList-&gt;AddElement(newPassword);
    }
}</code></pre>

<p> </p>

<p>Функция insertElement получает хеш входящего элемента определяет список, в который подойдет этот элемент, проверяет, нет ли уже точно такого же элемента, если вдруг находит, то изменяет ему значения полей, если же дубликата не нашлось, элемент добавляется в список.</p>
