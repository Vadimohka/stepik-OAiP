<p>Для поддержки семантики перемещения в C++11 ввели <strong>3 новые категории значений</strong>:</p>

<ul>
	<li>
	<p>x-values (eXpiring values) - это категория значений, которая была введена в C++11 для представления объектов, которые находятся в конце своего жизненного цикла и могут быть перемещены в другой объект. Они представляют собой изменяемые r-values, но не имеют адреса в памяти. Примерами x-values могут быть объекты, которые были созданы с помощью функции std::move() или которые являются результатом выражения std::move();</p>
	</li>
	<li>
	<p>pr-values (pure r-values) - это r-values, которые не являются x-values. Они имеют только значение, но не обладают адресом в памяти и не могут быть изменены. Примерами pr-values являются литералы и временные значения;</p>
	</li>
	<li>
	<p>gl-values (generalized l-values) - это категория значений, которая включает в себя l-values и x-values. Они обладают адресом в памяти и могут быть модифицированы. Примерами gl-values являются переменные и объекты.</p>
	</li>
</ul>

<p>Их понимание не столь важно в изучении или эффективном использовании семантики перемещения.</p>

<p>До версии C++11 существовал только один тип ссылок, его называли просто — <em>«ссылка»</em>. В <em>C++11</em> этот тип ссылки еще называют «ссылкой l-value». <strong>Ссылки <em>l-value</em></strong> могут быть инициализированы только изменяемыми <em>l-values</em>.</p>

### Шаг 2 — text (ID 3569919)

[Открыть на Stepik](https://stepik.org/lesson/853534/step/2?unit=857453) · [Исходник step-source](../../raw/step-sources/3569919.json) · [Объект step](../../raw/steps/3569919.json)

<p><strong><em>Ссылки r-value</em></strong></p>

<p>В C++11 был добавлен новый тип ссылок - <strong>ссылки r-value</strong>, которые позволяют получать доступ к r-values и x-values. Они используются для реализации семантики перемещения и эффективной передачи аргументов функций. Хотя <em>ссылка l-value</em> создается с использованием одного амперсанда, <em>ссылка r-value</em> создается с использованием двойного амперсанда:</p>

<pre><code class="language-cpp">int x = 7;
int&amp; lref = x; // инициализация ссылки l-value переменной x (значение l-value)
int&amp;&amp; rref = 7; // инициализация ссылки r-value литералом 7 (значение r-value)
</code></pre>

<p><em>Ссылки r-value</em> имеют <strong>два полезных свойства</strong><strong>:</strong></p>

<ul>
	<li>
	<p>Увеличение продолжительности жизни объекта: когда r-value инициализирует ссылку r-value, то продолжительность жизни объекта, на который ссылается r-value, продлевается до конца жизни ссылки r-value. Это особенно полезно, когда мы хотим передать r-value в функцию, которая требует l-value.</p>
	</li>
	<li>
	<p>Возможность изменения значений r-values: неконстантные ссылки r-value позволяют изменять значения r-values, на которые они указывают.</p>
	</li>
</ul>

<p>Ссылки r-value часто используются в качестве параметров функции. Это особенно полезно при перегрузке функций, когда мы хотим, чтобы выполнение функции отличалось в зависимости от типа аргумента (l-value или r-value). Например:</p>

<pre><code class="language-cpp">// перегрузка функции для работы с аргументами l-values
fun(const int&amp; lref) {
    std::cout &lt;&lt; "L-value reference to const\n";
}

// перегрузка функции для работы с аргументами r-values
void fun(int&amp;&amp; rref) {
    std::cout &lt;&lt; "r-value reference\n";
}

int main() {
    int x=7;
    fun(x); // аргумент l-value вызывает функцию с ссылкой l-value
    fun(7); // аргумент r-value вызывает функцию с ссылкой r-value
    return 0;
}</code></pre>

<p>Output: </p>

<pre><code class="language-1c">l-value reference to const
r-value reference</code></pre>
