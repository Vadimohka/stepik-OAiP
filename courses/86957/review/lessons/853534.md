### Шаг 1 — text (ID 3569323)

[Открыть на Stepik](https://stepik.org/lesson/853534/step/1?unit=857453) · [Исходник step-source](../../raw/step-sources/3569323.json) · [Объект step](../../raw/steps/3569323.json)

<p>Для поддержки семантики перемещения в C++11 ввели <strong>3 новые категории значений</strong>:</p>

<ul>
<li><p><strong>xvalue</strong> обозначает объект, ресурсы которого могут быть использованы повторно, например при перемещении. Для обычного объекта x выражение <code>std::move(x)</code> — xvalue; это тот же x, а не новый объект. Его время жизни от вызова std::move не меняется.</p></li>
<li><p><strong>prvalue</strong> вычисляет значение или инициализирует объект. Примеры: <code>42</code>, сумма двух int, вызов функции, возвращающей int по значению. Prvalue класса может участвовать в создании временного объекта.</p></li>
<li><p><strong>glvalue</strong> объединяет lvalue и xvalue. Эти выражения определяют идентичность объекта или функции. Они не обязательно допускают изменение: например, имя константного объекта — glvalue.</p></li>
</ul>

<p>Для перемещения особенно важно различать выражение с именем объекта (lvalue) и std::move от него (обычно xvalue). Rvalue объединяет prvalue и xvalue.</p>

<p>До C++11 существовали ссылки, которые теперь называют lvalue-ссылками и записывают <code>T&amp;</code>. Неконстантная lvalue-ссылка на объект обычно привязывается к подходящему неконстантному lvalue. Ссылка <code>const T&amp;</code> может привязываться также к const-lvalue и к временному объекту подходящего типа. Например: <code>int x = 1; int&amp; a = x; const int&amp; b = 2;</code>. При прямой привязке локальной b к временному int его время жизни продлевается до конца жизни b.</p>

### Шаг 2 — text (ID 3569919)

[Открыть на Stepik](https://stepik.org/lesson/853534/step/2?unit=857453) · [Исходник step-source](../../raw/step-sources/3569919.json) · [Объект step](../../raw/steps/3569919.json)

<p><strong><em>Ссылки r-value</em></strong></p>

<p>В C++11 был добавлен новый тип ссылок - <strong>ссылки r-value</strong>, которые позволяют получать доступ к rvalue-выражениям (prvalue и xvalue). Они используются для реализации семантики перемещения и эффективной передачи аргументов функций. Хотя <em>ссылка l-value</em> создается с использованием одного амперсанда, <em>ссылка r-value</em> создается с использованием двойного амперсанда:</p>

<pre><code class="language-cpp">int x = 7;
int&amp; lref = x; // инициализация ссылки l-value переменной x (значение l-value)
int&amp;&amp; rref = 7; // инициализация ссылки r-value литералом 7 (значение r-value)
</code></pre>

<p><em>Ссылки r-value</em> имеют <strong>два полезных свойства</strong><strong>:</strong></p>

<ul>
	<li>
	<p>Прямая привязка локальной rvalue-ссылки к подходящему временному объекту может продлить его жизнь: в <code>std::string&amp;&amp; s = std::string{"abc"};</code> объект живёт до конца жизни s. Однако временный объект, привязанный к ссылочному параметру функции, живёт только до конца полного выражения с вызовом. Возврат или сохранение такой ссылки не продлевает его жизнь. Вызов <code>std::move</code> тоже сам по себе не продлевает жизнь временного объекта.</p>
	</li>
	<li>
	<p>Через неконстантную rvalue-ссылку можно изменять объект, на который она ссылается. При этом выражение с именем самой ссылки — lvalue; чтобы снова получить xvalue, обычно используют std::move.</p>
	</li>
</ul>

<p>Ссылки r-value часто используются в качестве параметров функции. Это особенно полезно при перегрузке функций, когда мы хотим, чтобы выполнение функции отличалось в зависимости от категории выражения аргумента (lvalue или rvalue). Например:</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

// перегрузка функции для работы с аргументами l-values
void fun(const int&amp; lref) {
    std::cout &lt;&lt; "l-value reference to const\n";
}

// перегрузка функции для работы с аргументами r-values
void fun(int&amp;&amp; rref) {
    std::cout &lt;&lt; "r-value reference\n";
}

int main() {
    int x=7;
    fun(x); // аргумент l-value вызывает функцию с ссылкой l-value
    fun(7); // аргумент r-value вызывает функцию с ссылкой r-value
    return 0;
}</code></pre>

<p>Output: </p>

<pre><code class="language-1c">l-value reference to const
r-value reference</code></pre>
