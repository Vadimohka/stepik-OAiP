### Шаг 1 — text (ID 3569321)

[Открыть на Stepik](https://stepik.org/lesson/853532/step/1?unit=857451) · [Исходник step-source](../../raw/step-sources/3569321.json) · [Объект step](../../raw/steps/3569321.json)

<p><strong>l-value и r-value</strong></p>

<p>Категория значения — свойство выражения. Выражение, состоящее из имени обычной переменной, является <strong>lvalue</strong>: оно обозначает конкретный объект. Например, в <code>int x = 7;</code> выражение <code>x</code> — lvalue, даже если оно стоит справа от знака присваивания. Имя константного объекта также является lvalue, но изменять этот объект нельзя.</p>

<p>Для встроенного присваивания левая часть должна быть изменяемым lvalue. Поэтому <code>9 = 10;</code> не компилируется: целочисленный литерал <code>9</code> — prvalue. Это правило нельзя превращать в определение всех категорий через левую и правую стороны присваивания.</p>

<p><img alt="" height="310" name="image.png" src="https://ucarecdn.stepik.net/ff2336ab-7e2f-46f4-b459-917fe2482d01/" width="772"></p>

<p>В C++17/20 к <strong>rvalue</strong> относятся две категории: <strong>prvalue</strong> и <strong>xvalue</strong>. Выражения <code>7</code> и <code>3 + x</code> для целого x — prvalue: они вычисляют значение. Выражение <code>std::move(x)</code> — xvalue: оно обозначает тот же существующий объект x и позволяет выбрать операции перемещения. Rvalue не обязательно обозначает временный объект; у объекта, обозначенного xvalue, может быть обычное имя и продолжающееся время жизни. Наличие адреса и возможность изменения сами по себе не определяют категорию выражения.</p>

### Шаг 2 — text (ID 3569891)

[Открыть на Stepik](https://stepik.org/lesson/853532/step/2?unit=857451) · [Исходник step-source](../../raw/step-sources/3569891.json) · [Объект step](../../raw/steps/3569891.json)

<p>Рассмотрим выражения разных категорий в операциях присваивания:</p>

<pre><code class="language-cpp">int a; // объявляем целочисленную переменную a
a = 5; // 5 имеет значение 5, которое затем присваивается переменной a
a = 4 + 6; // 4 + 6 имеет значение 10, которое затем присваивается переменной a

int b; // объявляем целочисленную переменную b
b = a; // a имеет значение 10 (исходя из предыдущих операций), которое затем присваивается переменной b
b = b; // b имеет значение 10, которое затем присваивается переменной b (ничего не происходит)
b = b + 2; // b + 2 имеет значение 12, которое затем присваивается переменной b
</code></pre>

<p>Давайте детально рассмотрим последнюю операцию присваивания:</p>

<pre><code class="language-cpp">b = b + 2;
</code></pre>

<p>Оба выражения <em>b</em> — lvalue. Для вычисления правой части из правого b читается хранимое значение 10: выполняется lvalue-to-rvalue-преобразование. Выражение <code>b + 2</code> целиком — prvalue со значением 12. Затем это значение записывается в объект, обозначенный левым b. Схематично вычисление правой части можно представить так:</p>

<pre><code class="language-cpp">b = 10 + 2;
</code></pre>

### Шаг 3 — text (ID 3569896)

[Открыть на Stepik](https://stepik.org/lesson/853532/step/3?unit=857451) · [Исходник step-source](../../raw/step-sources/3569896.json) · [Объект step](../../raw/steps/3569896.json)

<p>Категория значения принадлежит выражению, а не типу переменной. Она влияет на привязку ссылок, выбор перегрузки и возможность перемещения.</p>

<p>В C++17/20 каждое выражение относится ровно к одной основной категории: <strong>lvalue</strong>, <strong>xvalue</strong> или <strong>prvalue</strong>. Две объединяющие категории устроены так: <strong>glvalue = lvalue или xvalue</strong>, <strong>rvalue = prvalue или xvalue</strong>.</p>

<p>Lvalue обозначает объект или функцию. Изменяемое lvalue объекта может стоять слева во встроенном присваивании. Константное lvalue, массив или функция не допускают такого присваивания. Например, имя переменной <code>x</code> — lvalue, а имя <code>const int n</code> — немодифицируемое lvalue.</p>

<p>Prvalue используется для вычисления значения или инициализации объекта. Например, целочисленный литерал <code>5</code> и сумма двух int — prvalue. Но не все литералы являются rvalue: строковый литерал <code>"abc"</code> — lvalue массива const char.</p>

<p>Xvalue обозначает объект, ресурсы которого разрешается использовать для перемещения. Например, <code>std::move(x)</code> обозначает тот же x и не создаёт нового объекта. Xvalue может обозначать и const-объект; само наличие этой категории не гарантирует, что перемещение возможно.</p>

<p>Для rvalue класса может быть допустим вызов изменяющего метода, включая подходящий operator=. Например, <code>std::string{} = "abc";</code> — допустимое выражение. Поэтому правило «rvalue нельзя изменять» неверно. Время жизни временных объектов определяется отдельными правилами: обычно до конца полного выражения, а в некоторых случаях привязка ссылки его продлевает. Категория xvalue сама по себе время жизни не сокращает.</p>
