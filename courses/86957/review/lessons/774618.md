<h3>Что такое CMake?</h3>

<p><strong>CMake</strong> — кроссплатформенный инструмент настройки и организации сборки. Он читает <code>CMakeLists.txt</code> и генерирует файлы для выбранной системы сборки. Это могут быть Makefiles, файлы Ninja или проекты Visual Studio. Непосредственную компиляцию выполняют выбранный компилятор и система сборки; команда <code>cmake --build</code> запускает соответствующий инструмент сборки.</p>

<table border="1" cellpadding="4" cellspacing="0">
<caption>Примеры цепочек сборки</caption>
<thead><tr><th>Описание проекта</th><th>Генератор CMake</th><th>Дальнейшая сборка</th></tr></thead>
<tbody>
<tr><td><code>CMakeLists.txt</code></td><td><code>Unix Makefiles</code></td><td>make и выбранный компилятор</td></tr>
<tr><td><code>CMakeLists.txt</code></td><td><code>Ninja</code></td><td>ninja и выбранный компилятор</td></tr>
<tr><td><code>CMakeLists.txt</code></td><td>Visual Studio</td><td>MSBuild и выбранный компилятор</td></tr>
</tbody>
</table>

<p>CMake может искать необходимые библиотеки и настраивать сборку под разные компиляторы и операционные системы. Для переноса проекта нужны его исходники, описание сборки, подходящий набор инструментов и зависимости. Затем выполняют настройку и генерацию файлов сборки, после чего запускают саму сборку.</p>

<h3>Установка и запуск CMake из консоли</h3>

<p>CMake можно установить с <a href="https://cmake.org/download/" rel="noopener noreferrer nofollow">официального сайта</a> или через пакетный менеджер ОС. Например, в Debian/Ubuntu используется команда <code>sudo apt install cmake</code>. Для сборки также нужен установленный компилятор C++ и инструмент выбранного генератора.</p>

<p>Создайте в одной директории файлы <code>test.cpp</code> и <code>CMakeLists.txt</code>.</p>
<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {
    std::cout &lt;&lt; "Hello World\n";
}</code></pre>

<pre><code>cmake_minimum_required(VERSION 3.22)
project(test LANGUAGES CXX)
add_executable(test test.cpp)
set_target_properties(test PROPERTIES
    CXX_STANDARD 20
    CXX_STANDARD_REQUIRED YES
    CXX_EXTENSIONS NO
)</code></pre>

<p>Из директории с <code>CMakeLists.txt</code> выполните:</p>
<pre><code>cmake -S . -B build
cmake --build build --config Release</code></pre>

<p>Первая команда настраивает проект и создаёт файлы сборки в отдельной директории <code>build</code>. Вторая запускает выбранную систему сборки; <code>--config Release</code> выбирает конфигурацию у многоконфигурационных генераторов, например Visual Studio. Генераторы с одной конфигурацией используют конфигурацию, заданную при настройке.</p>

<p>При генераторе Unix Makefiles или Ninja в Linux полученную программу обычно запускают так:</p>
<pre><code>./build/test</code></pre>
<p>Для Visual Studio исполняемый файл обычно находится в <code>build/Release/test.exe</code>. Точное расположение зависит от генератора и настроек проекта. В обоих случаях программа выводит:</p>
<pre><code>Hello World</code></pre>

<p>Дополнительные параметры описаны в <a href="https://cmake.org/cmake/help/latest/manual/cmake.1.html" rel="noopener noreferrer nofollow">официальной документации cmake</a>.</p>
