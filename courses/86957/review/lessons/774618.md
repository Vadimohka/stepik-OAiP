<h3>Что такое CMake?</h3>

<p><strong>CMake</strong> — кроссплатформенная автоматизированная система сборки проектов. Непосредственно сборкой она не занимается, а только генерирует <em>Makefile</em>, который потом будет выполнен утилитой make.</p>

<p><img alt="" height="5369" name="Frame 7.png" src="https://ucarecdn.stepik.net/1bb92134-94f9-4e34-bd08-ffb43f2ccc5a/-/preview/" width="7930"></p>

<p>CMake может проверять наличие необходимых библиотек и подключать их, собирать проекты под разными компиляторами и операционными системами. Т.е. у вас есть куча кода и файлик, содержащий информацию для cmake, и чтобы скомпилить это дело где-нибудь еще, вам нужно просто запустить там cmake, который сделает всё сам. Удобно, полезно, просто.</p>

<h3><strong>Установка и запуск Cmake из консоли</strong></h3>

<p>Установить Cmake можно с официального сайта <a href="https://cmake.org/" rel="noopener noreferrer nofollow">https://cmake.org/</a> или на linux ввести команду:</p>

<p><code>sudo apt install cmake</code></p>

<p>Создадим простейший test.cpp, в котором выведем Hello, World! В этой же директории создадим CMakeLists.txt, в который добавим:</p>

<p><code>cmake_minimum_required(VERSION 3.22.1) # объявляем минимальную версию cmake</code><br>
<code>project(test) # устанавливаем имя проекта</code><br>
<code>set(SOURCES test.cpp) # переменной SOURCES присваиваем значение test.cpp</code><br>
<code>add_executable(test ${SOURCES}) # добавляем переменную SOURCES к исполняемым файлам</code></p>

<p>Запускаем в консоли следующую команду: </p>

<p><code>cmake CMakeLists.txt</code></p>

<p>Затем:</p>

<p><code>make</code></p>

<p>И после выполнения данной программы появится исполняемый файл. На linux его можно запустить с помощью:</p>

<p><code>./test</code></p>

<p>Полученный вывод:</p>

<p><code>Hello World</code></p>

<p>Таким образом, можно быстро запускать C++ проект из консоли.</p>

<p>Подробнее о синтаксисе Cmake: <a href="https://www.pvsm.ru/kompilyatsiya/300549" rel="noopener noreferrer nofollow">https://www.pvsm.ru/kompilyatsiya/300549</a>"</p>

<p>CMake выглядит следующим образом: В корневой директории находятся файлы: CMakeLists.txt (файл с командами, указаниями исполняемых файлов и тд), и файлы исходного кода, например, main.cpp.</p>

<p>Файл CMakeLists.txt может выглядеть примерно так:</p>
