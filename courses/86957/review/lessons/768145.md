<h3><strong>Функция</strong></h3>

<p>Функция — это мини-программа внутри вашей основной программы, которая выполняет какой-то один понятный алгоритм. Вы однажды описываете, что это за алгоритм, а потом ссылаетесь на это описание.</p>

<p>Например, вы пишете игру. Каждый раз, когда игрок попадает в цель, убивает врага, делает комбо, заканчивает уровень или падает в лаву, вам нужно добавить или убавить ему очков. Это делается двумя действиями: к старым очкам добавляются новые, на экран выводится новая сумма очков. Если в игре предусмотрено 100 действий, при которых количество очков увеличивается или уменьшается, то обработку очков нужно предусмотреть для каждого из этих действий. Если каждый раз копировать и вставлять код в нужное место, то программа раздуется до огромных объёмов, поэтому повторяющийся код обязательно необходимо оформлять как отдельные функции.</p>

<p>Далее вы ознакомитесь с базовыми терминами и примерами, т.к. во всех программах, которые вы будете писать в рамках курса, вы будете использовать функции. Самописные функции будут рассмотрены в самом конце курса.</p>

<h3>Зачем нужны функции?</h3>

<p>Функции нужны, чтобы заметно упрощать и сокращать код, адаптировать его для разных платформ, делать более отказоустойчивым, легко отлаживать. И вообще порядок в функциях — порядок в голове.</p>

<p>Возьмём тот же пример с подсчётом очков. Что если при добавлении очков нужно не только выводить их на экран, но и записывать в файл? Просто добавляете в определении функции дополнительные команды, связанные с файлами, и они теперь будут исполняться каждый раз, когда функцию снова вызовут в основной программе. Не нужно ползать по всему коду, искать места с добавлением очков и дописывать там про файлы. Меньше ручного труда, меньше опечаток, меньше незакрытых скобок.</p>

<h3>Прикладное применение функций</h3>

<p>У всех в школе был базовый HTML/CSS, поэтому пример на всем понятных кнопках.</p>

<p>Например, у вас на сайте есть форма, и при клике на кнопку «Отправить» вы хотите проверять, что данные в форме правильно введены. Вы спокойно описываете где-то в коде функцию validateForm () и вешаете её на нажатие кнопки. Кнопку нажали — функция вызвалась. Не нужно вписывать в кнопку полный текст программы.</p>

<p>А без функции пришлось бы писать огромную программу-валидатор прямо внутри кнопки. Это исполнимо, но код выглядел бы страшно громоздким. Что если у вас на странице три формы, и каждую нужно валидировать?</p>

<p><strong>Одна из главных задач функций — улучшение читаемости кода.</strong></p>

<p>Хорошо написанные функции резко повышают читаемость кода. Мы можем читать чужую программу, увидеть там функцию getExamScore (username) и знать, что последняя каким-то образом выясняет результаты экзамена по такому-то юзернейму. Как она там устроена внутри, куда обращается и что использует — вам неважно. Для нас это как бы одна простая понятная команда.</p>

<p>Можно написать кучу вспомогательных функций, держать их в отдельном файле и подключать к проекту как библиотеку. Например, вы написали один раз все функции для обработки физики игры и потом подключаете эти функции во все свои игры. В одной — роботы, в другой — пираты, но в обеих одна и та же физика.</p>

<h3>Примеры кода с использованием функций</h3>

<pre><code>#include &lt;iostream&gt;
int main() {
    std::cout &lt;&lt; "Hello world!";
}</code></pre>

<p>В этом примере определена функция <code>main()</code> и использован объект стандартного потока вывода <code>std::cout</code>.</p>

<p><code>main()</code> — точка входа в обычную программу C++. <code>std::cout</code> — объект потока, связанного со стандартным выводом, а <code>&lt;&lt;</code> — оператор вставки данных в поток. Выражение <code>std::cout &lt;&lt; "Hello world!"</code> выводит текст. Префикс <code>std::</code> указывает пространство имён стандартной библиотеки; подробнее мы разберём его в следующем модуле.</p>

<p>Более сложный пример кода на C++ с использованием функций. Здесь используются точные коэффициенты: 1 дюйм = 0,0254 м, 1 фут = 0,3048 м.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;

double InchesToMeters(double inches) {
    return 0.0254 * inches;
}

double FootsToMeters(double foots) {
    return 0.3048 * foots;
}

double MetersToInches(double meters) {
    return meters / 0.0254;
}

double MetersToFoots(double meters) {
    return meters / 0.3048;
}

int main() {
    std::cout &lt;&lt; "Enter length: ";
    double length = 0.0;
    std::cin &gt;&gt; length;
    std::cout &lt;&lt; "Inches to meters = " &lt;&lt; InchesToMeters(length) &lt;&lt; std::endl;
    std::cout &lt;&lt; "Foots to meters = " &lt;&lt; FootsToMeters(length) &lt;&lt; std::endl;
    std::cout &lt;&lt; "Meters to inches = " &lt;&lt; MetersToInches(length) &lt;&lt; std::endl;
    std::cout &lt;&lt; "Meters to foots = " &lt;&lt; MetersToFoots(length) &lt;&lt; std::endl;
    std::cout &lt;&lt; "Inches to foots = " &lt;&lt; MetersToFoots(InchesToMeters(length)) &lt;&lt; std::endl;
    std::cout &lt;&lt; "Foots to inches = " &lt;&lt; MetersToInches(FootsToMeters(length)) &lt;&lt; std::endl;
    return 0;
}</code></pre>

<p>Можете скопировать к себе и покопаться в его устройстве. Чем больше ошибок вам откроется на данном этапе, тем интереснее вам будет читать следующие модули :)</p>
