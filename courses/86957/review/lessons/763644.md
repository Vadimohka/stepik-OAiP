<h3>Массив: несколько значений одного типа</h3>
<p>Пусть нужно хранить баллы четырёх учеников. Вместо четырёх отдельных переменных удобно использовать последовательность элементов одного типа. У каждого элемента есть <strong>индекс</strong>: для четырёх элементов это 0, 1, 2 и 3. Элементы массива расположены подряд; размер встроенного массива из четырёх <code>int</code> равен <code>4 * sizeof(int)</code>. Размер самого <code>int</code> зависит от реализации.</p>
<p>В C++ есть встроенные массивы и стандартные контейнеры. В этом уроке познакомимся с обоими способами хранения фиксированного числа элементов:</p>
<table><thead><tr><th>Запись</th><th>Что означает</th></tr></thead><tbody>
<tr><td><code>int values[4]{};</code></td><td>Встроенный массив из четырёх нулей. Его размер не меняется.</td></tr>
<tr><td><code>std::array&lt;int, 4&gt; values{};</code></td><td>Стандартный контейнер фиксированного размера. Он знает свой размер, поддерживает копирование и тоже содержит четыре нуля.</td></tr>
</tbody></table>
<p>Для обычного C++ кода с заранее известным числом элементов удобно начинать со <code>std::array</code>. Подключается заголовок <code>&lt;array&gt;</code>; запись <code>&lt;int, 4&gt;</code> задаёт тип и количество элементов. Если количество выясняется во время работы программы, позже используем <code>std::vector</code>.</p>
<p><strong>Полная программа.</strong> Цикл по диапазону перебирает значения по очереди, поэтому для суммы нам не нужен индекс.</p>
<pre><code class="language-cpp">#include &lt;array&gt;
#include &lt;iostream&gt;

int main() {
    const std::array&lt;int, 4&gt; scores{10, 20, 15, 5};
    int total{};
    for (int score : scores) {
        total += score;
    }
    std::cout &lt;&lt; scores.size() &lt;&lt; ' ' &lt;&lt; total &lt;&lt; '\n';
}
</code></pre>
<p>Результат: <code>4 50</code>. Метод <code>size()</code> возвращает число элементов. <code>const</code> означает, что эту последовательность программа не изменяет.</p>
<p><strong>Проверьте себя.</strong> Замените последний балл 5 на 0. Размер останется равен 4, а сумма станет 45. Значение элемента и количество элементов — разные характеристики.</p>
<p>Встроенные массивы нужны для понимания модели памяти и низкоуровневых интерфейсов; их правила разберём в следующих шагах. Они отличаются от правил <code>std::array</code>, поэтому далее будем явно указывать, о каком типе идёт речь.</p>

<h3>Массивы в программировании</h3>
<p><strong>Терминология этого шага.</strong> Здесь рассматривается именно <em>встроенный массив</em> вида <code>T a[N]</code>. Контейнер <code>std::array&lt;T, N&gt;</code> имеет другой тип: он не преобразуется неявно в указатель и поддерживает копирование как целое значение.</p>


<p>Массив — это структура данных, представленная в виде группы ячеек одного типа, объединенных под одним единым именем. Массивы используются для обработки большого количества <strong>однотипных</strong> данных. Массив имеет собственный тип <code>T[N]</code>. Во многих выражениях он неявно преобразуется в указатель <code>T*</code> на первый элемент; например, в <code>sizeof(a)</code> и <code>&amp;a</code> этого преобразования нет. Подробнее указатели рассмотрим в следующих модулях. Отдельная ячейка данных массива называется элементом массива. Элементами массива могут быть данные подходящего объектного типа; например, числа, указатели или объекты классов. Ограничения на тип элементов рассмотрены далее. Массивы могут иметь одно или несколько измерений. В зависимости от количества измерений массивы делятся на одномерные массивы, двумерные массивы, трёхмерные массивы и так далее до n-мерного массива. Чаще всего в программировании используются одномерные и двумерные массивы, поэтому мы рассмотрим только эти  массивы.</p>

<p> </p>

<p>Массив является простейшим агрегатным типом. Он моделирует набор однотипных элементов, расположенных подряд в <strong>непрерывном</strong> отрезке памяти. Массивы в той или иной форме поддерживаются практически всеми языками программирования и неудивительно, что они появились в первых версиях C и затем стали частью C++.</p>

<h3>Создание одномерного массива</h3>
<p>Одномерный массив — последовательность элементов, к которым обращаются по одному индексу. У массива из 16 элементов допустимы индексы от 0 до 15.</p>
<p><strong>Встроенный массив.</strong> В объявлении размер записывают после имени в квадратных скобках. Для обычного определения массива он должен быть положительной целочисленной константой времени компиляции.</p>
<pre><code class="language-cpp">int values[4]{};                   // четыре нуля
int scores[4]{10, 20, 15, 5};       // четыре заданных значения
int inferred[]{10, 20, 15, 5};      // размер 4 выведен из инициализатора
int partial[4]{1, 2};              // 1, 2, 0, 0
</code></pre>
<p>Это отдельные объявления, которые можно написать внутри функции. У локального массива <code>int values[4];</code> без инициализатора элементы не инициализированы. Поэтому в новых примерах сразу задаём значения или используем пустые фигурные скобки.</p>
<p>Если <code>n</code> прочитано через <code>std::cin</code>, запись <code>int values[n];</code> не является стандартным C++17/C++20. Даже <code>const int count = n;</code> не превращает введённое значение в константу времени компиляции. Некоторые компиляторы принимают такие массивы как расширение; для переносимой программы используйте <code>std::vector</code>.</p>
<p><strong>std::array.</strong> Число элементов тоже задаётся при компиляции, но контейнер можно копировать и присваивать целиком. Полная программа показывает частичную инициализацию и независимую копию:</p>
<pre><code class="language-cpp">#include &lt;array&gt;
#include &lt;iostream&gt;

int main() {
    int raw[4]{1, 2};
    const std::array&lt;int, 4&gt; original{1, 2};
    std::array&lt;int, 4&gt; copy = original;
    copy[0] = 9;

    std::cout &lt;&lt; raw[0] &lt;&lt; ' ' &lt;&lt; raw[3] &lt;&lt; '\n';
    std::cout &lt;&lt; copy[0] &lt;&lt; ' ' &lt;&lt; copy[3] &lt;&lt; '\n';
}
</code></pre>
<p>Вывод:</p><pre><code>1 0
9 0</code></pre>
<p>Встроенные массивы нельзя присваивать друг другу оператором <code>=</code>; их элементы можно копировать циклом или подходящим стандартным алгоритмом. Для <code>std::array</code> обычное копирование контейнера выполняет копирование элементов.</p>
<p><strong>Проверьте себя.</strong> Почему последнее значение равно 0? Потому что незаданные элементы <code>int</code> в инициализации списком получают нулевые значения. При пяти инициализаторах и размере 4 программа не скомпилируется.</p>

<h3>Ещё немного про инициализацию массива*</h3>

<p>В С++11 появилась универсальная инициализация (uniform initialization) и теперь можно инициализировать так:</p>

<pre><code class="language-cpp">int a[4]{ 1, 2, 3, 4 };</code></pre>

<p>Для универсальной инициализации также можно использовать =, и различать эти два типа инициализации не всегда просто, а, скорее всего, не очень нужно.</p>

<p>Размер массива можно не указывать, тогда он определится по числу инициализаторов.</p>

<pre><code class="language-cpp">int a[] { 1, 2, 3, 4 };</code></pre>

<p>Если размер массива указан, число инициализаторов не должно превышать его размер. Незаданные элементы агрегата инициализируются из пустого списка. Для встроенного типа <code>int</code> это даёт нули; конструктора у <code>int</code> нет. Для элементов классов применяются правила инициализации соответствующего класса. Поэтому следующий массив целиком заполнен нулями:</p>

<pre><code class="language-cpp">int a[4]{};</code></pre>

<p>При определении массива констант типа int нужно задать инициализатор.</p>

<pre><code class="language-cpp">const int a[4] = { 3, 2, 1 };</code></pre>

<p>Число инициализаторов может быть меньше размера массива: в приведённом выше <code>const int a[4] = {3, 2, 1};</code> последний элемент равен нулю.</p>

<p>Символьные массивы можно инициализировать строковым литералом.</p>

<pre><code class="language-cpp">const char str[] = "meow";
const wchar_t wstr[] = L"meow";</code></pre>

<p>В этих примерах массив содержит пять элементов: четыре символа слова meow и завершающий нулевой символ.</p>

<p> </p>

<h4>Использование псевдонимов при инициализации</h4>

<p>В языке С++ для типов массивов можно вводить псевдонимы. Можно использовать традиционный вариант с ключевым словом <code>typedef</code>:</p>

<pre><code class="language-cpp">typedef int I4[4];</code></pre>

<p>или более современный (C++11) с ключевым словом <code>using</code>:</p>

<pre><code class="language-cpp">using I4 = int[4];</code></pre>

<p>После этого массивы объявляются как простые переменные:</p>

<pre><code class="language-cpp">I4 a, b;</code></pre>

<p>Это будет то же самое, что</p>

<pre><code class="language-cpp">int a[4], b[4];</code></pre>

<h3>Границы и обход массива</h3>
<p>Если элементов <code>N</code>, индексы существующих элементов лежат в диапазоне <code>0 &lt;= index &amp;&amp; index &lt; N</code>. Последний индекс равен <code>N - 1</code>, а не <code>N</code>.</p>
<p>В C++17/C++20 выход за границы встроенного массива или <code>std::array</code> через <code>[]</code> имеет неопределённое поведение. Программа не обязана вывести сообщение или завершиться с ошибкой. Поэтому сначала проверяем индекс и только затем обращаемся к элементу.</p>
<p><strong>Полная программа.</strong> Ввод — один целый индекс. Для допустимого индекса выводится элемент, для неверного ввода или индекса — <code>INVALID</code>. <code>constexpr</code> обозначает здесь константу времени компиляции.</p>
<pre><code class="language-cpp">#include &lt;array&gt;
#include &lt;iostream&gt;

int main() {
    constexpr int count = 4;
    const std::array&lt;int, count&gt; values{10, 20, 30, 40};
    int index{};
    if (!(std::cin &gt;&gt; index) || index &lt; 0 || index &gt;= count) {
        std::cout &lt;&lt; "INVALID\n";
        return 0;
    }
    std::cout &lt;&lt; values[index] &lt;&lt; '\n';
}
</code></pre>
<p>Для ввода <code>0</code> получится <code>10</code>, для <code>3</code> — <code>40</code>, для <code>-1</code> и <code>4</code> — <code>INVALID</code>. Проверка <code>index &lt; count</code> не заменяет проверку <code>index &gt;= 0</code>, когда индекс имеет знаковый тип.</p>
<p>Если индекс не нужен, проще использовать цикл по диапазону. Следующий фрагмент расположен внутри функции; заголовки <code>&lt;array&gt;</code> и <code>&lt;iostream&gt;</code> должны быть подключены:</p>
<pre><code class="language-cpp">std::array&lt;int, 4&gt; values{4, 3, 2, 1};
for (int value : values) {
    std::cout &lt;&lt; value &lt;&lt; ' ';
}
</code></pre>
<p>Так же можно обойти встроенный массив. Для встроенного массива стандартные функции <code>std::begin(a)</code> и <code>std::end(a)</code> из <code>&lt;iterator&gt;</code> обозначают начало и позицию <em>после</em> последнего элемента. Разыменовывать <code>std::end(a)</code> нельзя. Сам цикл по диапазону для массива не требует этих вызовов в исходном тексте.</p>
<p>У <code>std::array</code> есть метод <code>at(index)</code>, который проверяет границу и при неверном индексе выбрасывает <code>std::out_of_range</code>. Обработку исключений изучим отдельно. Встроенный массив метода <code>at</code> не имеет.</p>
<p><strong>Самопроверка.</strong> Проверьте первый индекс, последний, -1 и ровно число элементов. Эти четыре случая помогают обнаружить типичную ошибку <code>&lt;=</code> вместо <code>&lt;</code>.</p>
