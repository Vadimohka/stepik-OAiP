[Открыть на Stepik](https://stepik.org/lesson/763644/step/2?unit=765811) · [Исходник step-source](../../raw/step-sources/3177296.json) · [Объект step](../../raw/steps/3177296.json)

<h3>Массив: несколько значений одного типа</h3>
<p>Пусть нужно хранить баллы четырёх учеников. Вместо четырёх отдельных переменных удобно использовать последовательность элементов одного типа. У каждого элемента есть <strong>индекс</strong>: для четырёх элементов это 0, 1, 2 и 3. Элементы массива расположены подряд; размер встроенного массива из четырёх <code>int</code> равен <code>4 * sizeof(int)</code>. Размер самого <code>int</code> зависит от реализации.</p>
<p>В C++ есть встроенные массивы и стандартные контейнеры. В этом уроке познакомимся с обоими способами хранения фиксированного числа элементов:</p>
<table><thead><tr><th>Запись</th><th>Что означает</th></tr></thead><tbody>
<tr><td><code>int values[4]{};</code></td><td>Встроенный массив из четырёх нулей. Его размер не меняется.</td></tr>
<tr><td><code>std::array&lt;int, 4&gt; values{};</code></td><td>Стандартный контейнер фиксированного размера. Он знает свой размер, поддерживает копирование и тоже содержит четыре нуля.</td></tr>
</tbody></table>
<p>Для обычного C++ кода с заранее известным числом элементов удобно начинать со <code>std::array</code>. Подключается заголовок <code>&lt;array&gt;</code>; запись <code>&lt;int, 4&gt;</code> задаёт тип и количество элементов. Если количество выясняется во время работы программы, позже используем <code>std::vector</code>.</p>
<p><strong>Полная программа.</strong> Цикл по диапазону перебирает значения по очереди, поэтому для суммы нам не нужен индекс.</p>
<pre><code class="language-cpp">#include &lt;array&gt;
#include &lt;iostream&gt;

int main() {
    const std::array&lt;int, 4&gt; scores{10, 20, 15, 5};
    int total{};
    for (int score : scores) {
        total += score;
    }
    std::cout &lt;&lt; scores.size() &lt;&lt; ' ' &lt;&lt; total &lt;&lt; '\n';
}
</code></pre>
<p>Результат: <code>4 50</code>. Метод <code>size()</code> возвращает число элементов. <code>const</code> означает, что эту последовательность программа не изменяет.</p>
<p><strong>Разбор изменения данных.</strong> У последовательности <code>{10, 20, 15, 0}</code> также четыре элемента, но сумма равна 45. Нулевой элемент продолжает занимать свою позицию; значение элемента и число элементов — разные характеристики.</p>

<p>Встроенные массивы нужны для понимания модели памяти и низкоуровневых интерфейсов; их правила разберём в следующих шагах. Они отличаются от правил <code>std::array</code>, поэтому далее будем явно указывать, о каком типе идёт речь.</p>
<p>Запись <code>for (int score : scores)</code> означает: для каждого элемента создать локальную копию его значения <code>score</code> и выполнить тело. Запись <code>scores.size()</code> вызывает операцию самого контейнера; круглые скобки означают вызов.</p>

<h2>Встроенный массив и его элементы</h2>
<p>Встроенный массив <code>T a[N]</code> содержит <code>N</code> последовательно размещённых объектов одного типа <code>T</code>. Сам массив тоже объект, его тип — <code>T[N]</code>. Например, у <code>int values[3]{2, 4, 6};</code> тип <code>int[3]</code>; элементы <code>values[0]</code>, <code>values[1]</code>, <code>values[2]</code> имеют тип <code>int</code>.</p>
<p><strong>Фрагмент внутри функции; это не отдельная программа.</strong></p>
<pre><code class="language-cpp">int values[3]{2, 4, 6};
int copy = values[1]; // copy = 4
values[1] = 9;       // массив теперь {2, 9, 6}; copy остаётся 4
</code></pre>
<p>Индекс выбирает элемент, а не новое хранилище. Поэтому присваивание в <code>values[1]</code> меняет элемент исходного массива. Определение <code>copy</code>, наоборот, создаёт отдельный объект. Размер массива фиксирован, изменение значения не добавляет и не удаляет элементы.</p>
<p>Массив из <code>N</code> элементов занимает <code>N * sizeof(T)</code> байтов. Для отдельных переменных <code>a</code>, <code>b</code>, <code>c</code> последовательное размещение не гарантируется; объявление массива как раз задаёт такую связь его элементов.</p>
<p>Многомерный массив — массив, элементы которого сами массивы. <code>int table[2][3]</code> содержит две строки по три <code>int</code>. <a href="https://stepik.org/lesson/763646/step/1" rel="noopener noreferrer nofollow">Следующий урок</a> объясняет индексы каждого уровня.</p>
<p><code>std::array&lt;T, N&gt;</code> — другой тип: стандартный контейнер с операциями <code>size()</code>, копированием и проверяемым доступом <code>at()</code>. Встроенный массив во многих выражениях преобразуется в указатель на первый элемент, но не становится объектом-указателем. Пока для обращения достаточно индекса; точная модель преобразования появится в <a href="https://stepik.org/lesson/770586/step/2" rel="noopener noreferrer nofollow">уроке «Указатели и массивы»</a>.</p>

<h3>Создание одномерного массива</h3>
<p>Одномерный массив — последовательность элементов, к которым обращаются по одному индексу. У массива из 16 элементов допустимы индексы от 0 до 15.</p>
<p><strong>Встроенный массив.</strong> В объявлении размер записывают после имени в квадратных скобках. Для обычного определения массива он должен быть положительной целочисленной константой времени компиляции.</p>
<pre><code class="language-cpp">int values[4]{};                   // четыре нуля
int scores[4]{10, 20, 15, 5};       // четыре заданных значения
int inferred[]{10, 20, 15, 5};      // размер 4 выведен из инициализатора
int partial[4]{1, 2};              // 1, 2, 0, 0
</code></pre>
<p>Это отдельные объявления, которые можно написать внутри функции. У локального массива <code>int values[4];</code> без инициализатора элементы не инициализированы. Поэтому в новых примерах сразу задаём значения или используем пустые фигурные скобки.</p>
<p>Если <code>n</code> прочитано через <code>std::cin</code>, запись <code>int values[n];</code> не является стандартным C++17/C++20. Даже <code>const int count = n;</code> не превращает введённое значение в константу времени компиляции. Некоторые компиляторы принимают такие массивы как расширение; для переносимой программы используйте <code>std::vector</code>.</p>
<p><strong>std::array.</strong> Число элементов тоже задаётся при компиляции, но контейнер можно копировать и присваивать целиком. Полная программа показывает частичную инициализацию и независимую копию:</p>
<pre><code class="language-cpp">#include &lt;array&gt;
#include &lt;iostream&gt;

int main() {
    int raw[4]{1, 2};
    const std::array&lt;int, 4&gt; original{1, 2};
    std::array&lt;int, 4&gt; copy = original;
    copy[0] = 9;

    std::cout &lt;&lt; raw[0] &lt;&lt; ' ' &lt;&lt; raw[3] &lt;&lt; '\n';
    std::cout &lt;&lt; copy[0] &lt;&lt; ' ' &lt;&lt; copy[3] &lt;&lt; '\n';
}
</code></pre>
<p>Вывод:</p><pre><code>1 0
9 0</code></pre>
<p>Встроенные массивы нельзя присваивать друг другу оператором <code>=</code>; их элементы можно копировать циклом или подходящим стандартным алгоритмом. Для <code>std::array</code> обычное копирование контейнера выполняет копирование элементов.</p>
<p><strong>Разбор границы инициализации.</strong> Последнее значение равно 0: для незаданных элементов <code>int</code> инициализация списком даёт нули. Если размер равен 4, а значений в списке пять, компилятор отвергает определение — лишнего пятого элемента у объекта нет.</p>

<h2>Список инициализации массива</h2>
<p>У встроенного массива список в фигурных скобках задаёт начальные значения по порядку. Следующие независимые объявления можно расположить внутри функции:</p>
<p><strong>Фрагмент внутри функции; это не отдельная программа.</strong></p>
<pre><code class="language-cpp">int complete[4]{1, 2, 3, 4};
int inferred[]{1, 2, 3, 4};  // размер выведен: 4
int partial[4]{1, 2};        // 1, 2, 0, 0
int zeros[4]{};              // 0, 0, 0, 0
const int fixed[4]{3, 2, 1}; // 3, 2, 1, 0
</code></pre>
<p>В этих примерах пустой список для оставшихся элементов <code>int</code> даёт нули. У <code>int</code> нет конструктора; позднее для элементов пользовательского типа будут действовать правила инициализации этого типа. У локального <code>int a[4];</code> без инициализатора нулевые значения не гарантируются, и читать такие элементы до записи нельзя.</p>
<p>Формы <code>int a[4]{1, 2};</code> и <code>int a[4] = {1, 2};</code> в данном случае дают одинаковые элементы. Однако для произвольных классов и контейнеров круглые и фигурные скобки могут выбирать разные операции. Это разобрано на <a href="https://stepik.org/lesson/770587/step/2" rel="noopener noreferrer nofollow">создании <code>vector</code></a> и <a href="https://stepik.org/lesson/770589/step/3" rel="noopener noreferrer nofollow">создании <code>string</code></a>; не нужно механически заменять один вид скобок другим.</p>
<p>Инициализация списком не допускает сужения: <code>int a[]{1, 2.5};</code> — ошибка компиляции. Большее число инициализаторов, чем элементов, также ошибка. Для массива нулевой длины встроенная форма <code>int a[0];</code> не является стандартным C++; <code>std::array&lt;int, 0&gt;</code> допускается, но обращаться к его элементам нельзя.</p>
<h3>Псевдоним типа и строковый литерал</h3>
<p><strong>Фрагмент внутри функции; это не отдельная программа.</strong></p>
<pre><code class="language-cpp">using FourInts = int[4];
FourInts first{};
FourInts second{1, 2, 3, 4};
const char word[] = "meow";
</code></pre>
<p><code>using</code> вводит другое имя того же типа: здесь два массива <code>int[4]</code>. В старом коде тот же псевдоним записывается <code>typedef int FourInts[4];</code>. Массив <code>word</code> содержит пять элементов: четыре буквы и завершающий <code>'\0'</code>. Этот дополнительный элемент понадобится для <a href="https://stepik.org/lesson/770588/step/1" rel="noopener noreferrer nofollow">C-строк</a>.</p>

[Открыть на Stepik](https://stepik.org/lesson/763644/step/6?unit=765811) · [Исходник step-source](../../raw/step-sources/3212920.json) · [Объект step](../../raw/steps/3212920.json)

<h3>Границы и обход массива</h3>
<p>Если элементов <code>N</code>, индексы существующих элементов лежат в диапазоне <code>0 &lt;= index &amp;&amp; index &lt; N</code>. Последний индекс равен <code>N - 1</code>, а не <code>N</code>.</p>
<p>В C++17/C++20 выход за границы встроенного массива или <code>std::array</code> через <code>[]</code> имеет неопределённое поведение. Программа не обязана вывести сообщение или завершиться с ошибкой. Поэтому сначала проверяем индекс и только затем обращаемся к элементу.</p>
<p><strong>Полная программа.</strong> Ввод — один целый индекс. Для допустимого индекса выводится элемент, для неверного ввода или индекса — <code>INVALID</code> и код завершения 1. Успешный доступ завершается с кодом 0. <code>constexpr</code> обозначает здесь константу времени компиляции.</p>
<pre><code class="language-cpp">#include &lt;array&gt;
#include &lt;iostream&gt;

int main() {
    constexpr int count = 4;
    const std::array&lt;int, count&gt; values{10, 20, 30, 40};
    int index{};
    if (!(std::cin &gt;&gt; index) || index &lt; 0 || index &gt;= count) {
        std::cout &lt;&lt; "INVALID\n";
        return 1;
    }
    std::cout &lt;&lt; values[index] &lt;&lt; '\n';
}
</code></pre>
<p>Для ввода <code>0</code> получится <code>10</code>, для <code>3</code> — <code>40</code>, для <code>-1</code> и <code>4</code> — <code>INVALID</code>. Проверка <code>index &lt; count</code> не заменяет проверку <code>index &gt;= 0</code>, когда индекс имеет знаковый тип. Программа извлекает только первое целое и не проверяет остаток потока: как <code>1x</code>, так и <code>1 2</code> дают индекс 1 и вывод <code>20</code>. Проверка синтаксиса всей строки — другой контракт; <a href="https://stepik.org/lesson/770589/step/5" rel="noopener noreferrer nofollow">разбор <code>from_chars</code></a> проверяет и место остановки.</p>
<p>Если индекс не нужен, проще использовать цикл по диапазону. Следующий фрагмент расположен внутри функции; заголовки <code>&lt;array&gt;</code> и <code>&lt;iostream&gt;</code> должны быть подключены:</p>
<pre><code class="language-cpp">std::array&lt;int, 4&gt; values{4, 3, 2, 1};
for (int value : values) {
    std::cout &lt;&lt; value &lt;&lt; ' ';
}
</code></pre>
<p>Так же можно обойти встроенный массив. Для встроенного массива стандартные функции <code>std::begin(a)</code> и <code>std::end(a)</code> из <code>&lt;iterator&gt;</code> обозначают начало и позицию <em>после</em> последнего элемента. Разыменовывать <code>std::end(a)</code> нельзя. Сам цикл по диапазону для массива не требует этих вызовов в исходном тексте.</p>
<p>У <code>std::array</code> есть метод <code>at(index)</code>, который проверяет границу и при неверном индексе выбрасывает <code>std::out_of_range</code>. Сам механизм объясняет <a href="https://stepik.org/lesson/778425/step/3" rel="noopener noreferrer nofollow">шаг об исключениях</a>, а <a href="https://stepik.org/lesson/778425/step/4" rel="noopener noreferrer nofollow">разобранный <code>try</code>/<code>catch</code></a> показывает такой же проверяемый доступ через <code>vector::at</code>. Встроенный массив метода <code>at</code> не имеет.</p>
<p><strong>Разбор границ.</strong> Индекс 0 обозначает первый элемент 10; индекс 3 — последний элемент 40. Значения −1 и 4 отклоняются до обращения к массиву. Условие <code>index &lt;= count</code> ошибочно пропустило бы 4, хотя элемент с этим индексом отсутствует. Пустой или нечисловой ввод также приводит к <code>INVALID</code>.</p>

<h2>Какие элементы может содержать массив</h2>
<p>Каждому элементу нужен конкретный объектный тип с определённым размером. Подходят, например, <code>int</code>, <code>double</code>, другой массив фиксированной длины и многие пользовательские типы. <code>void</code> обозначает отсутствие значения, поэтому элементов типа <code>void</code> быть не может.</p>
<p>Массив ссылок также запрещён. Ссылка — имя для обращения к существующему объекту, а не отдельный объект-элемент. Здесь достаточно увидеть ограничение; ссылки подробно вводятся в <a href="https://stepik.org/lesson/770591/step/4" rel="noopener noreferrer nofollow">модуле о функциях</a>.</p>
<p><strong>Фрагмент внутри функции; это не отдельная программа.</strong></p>
<pre><code class="language-cpp">int first{1}, second{2};
// int&amp; aliases[2]{first, second}; // ошибка: массив ссылок запрещён
int values[2]{first, second};     // допустимо: две независимые копии
</code></pre>
<p>Если далее изменить <code>first</code>, значение <code>values[0]</code> не изменится: массив хранит скопированные числа. Если нужно хранить способы обращения к исходным объектам, можно использовать элементы-указатели. Их смысл и время жизни рассматриваются в <a href="https://stepik.org/lesson/770585/step/1" rel="noopener noreferrer nofollow">следующем модуле</a>; они не снимают ответственности за существование исходных объектов.</p>
<p>У стандартного встроенного массива размер в определении положителен и известен при компиляции. Размер во время выполнения — другая потребность, для которой в C++ подходит <a href="https://stepik.org/lesson/770587/step/1" rel="noopener noreferrer nofollow">std::vector</a>.</p>
