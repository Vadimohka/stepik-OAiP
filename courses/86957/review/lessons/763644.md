<h3>Базовое представление массива</h3>

<p>Массив — это определённое число ячеек памяти, расположенных подряд. Они позволяют эффективно хранить однотипные данные: зарплаты сотрудников, координаты персонажей, баллы учеников и так далее.</p>

<p><img alt="" height="400" name="image.png" src="https://ucarecdn.stepik.net/f2fe60cf-bef7-4223-9098-06af37a42924/" width="1500"></p>

<p>На картинке выше показано объявление массива из четырёх элементов целочисленного типа. Несмотря на то что значения элементам не присваивались, массив всё равно будет занимать такой объём памяти, который занимали бы четыре переменные. Если <code>sizeof(int) == 4</code>, как в показанном примере, массив занимает 16 байт.</p>

<p>Массивы очень удобные и быстрые: расположение ячеек <strong>друг за другом</strong> позволяет увеличить скорость работы с данными в них.</p>

<h3>Массивы в программировании</h3>

<p>Массив — это структура данных, представленная в виде группы ячеек одного типа, объединенных под одним единым именем. Массивы используются для обработки большого количества <strong>однотипных</strong> данных. Массив имеет собственный тип <code>T[N]</code>. Во многих выражениях он неявно преобразуется в указатель <code>T*</code> на первый элемент; например, в <code>sizeof(a)</code> и <code>&amp;a</code> этого преобразования нет. Подробнее указатели рассмотрим в следующих модулях. Отдельная ячейка данных массива называется элементом массива. Элементами массива могут быть данные подходящего объектного типа; например, числа, указатели или объекты классов. Ограничения на тип элементов рассмотрены далее. Массивы могут иметь одно или несколько измерений. В зависимости от количества измерений массивы делятся на одномерные массивы, двумерные массивы, трёхмерные массивы и так далее до n-мерного массива. Чаще всего в программировании используются одномерные и двумерные массивы, поэтому мы рассмотрим только эти  массивы.</p>

<p> </p>

<p>Массив является простейшим агрегатным типом. Он моделирует набор однотипных элементов, расположенных подряд в <strong>непрерывном</strong> отрезке памяти. Массивы в той или иной форме поддерживаются практически всеми языками программирования и неудивительно, что они появились в первых версиях C и затем стали частью C++.</p>

<h3>Одномерные массивы в С++</h3>

<p>Одномерный массив — последовательность элементов, к которым обращаются по одному индексу. Его можно изобразить как строку из N ячеек. Ниже показана структура целочисленного одномерного массива <strong>a</strong>. Размер этого массива — 16 ячеек.</p>

<p><img alt="" height="228" name="Frame 9.png" src="https://ucarecdn.stepik.net/04a8f90a-ba9e-407b-9a54-9d55c5808695/-/crop/2256x228/0,113/-/preview/" width="2256"></p>

<p>Максимальный индекс одномерного массива <strong>a</strong> равен 15, но размер массива 16 ячеек, потому что нумерация ячеек массива всегда начинается с 0. Индекс ячейки – это целое неотрицательное число, по которому можно обращаться к каждой ячейке массива и выполнять какие-либо действия над ней (ячейкой).</p>

<pre><code class="language-cpp">/*тип данных*/  /*имя одномерного массива*/[/*размерность одномерного массива*/];
int a[16];</code></pre>

<p>Всегда сразу после имени массива идут квадратные скобочки, в которых задаётся размер одномерного массива, этим массив и отличается от всех остальных переменных.</p>

<pre><code class="language-cpp">//ещё один способ объявления одномерных массивов
int array[10], a[16];</code></pre>

<p>Объявлены два одномерных массива  <span style="color: #000000;">array</span><strong> </strong>и <code>а</code> размерами 10 и 16 ячеек соответственно. Причём в таком способе объявления элементы обоих массивов имеют одинаковый тип, в нашем случае — <code>int</code>.</p>

<pre><code class="language-cpp">// инициализация одномерного массива
int array[5] = { 0, -9, 23, 61, -15 };</code></pre>

<p>Инициализация одномерного массива выполняется в фигурных скобках после знака <strong>равно</strong>, каждый элемент массива отделяется от предыдущего запятой.</p>

<pre><code class="language-cpp">// Ещё вариант инициализации одномерного массива
int array[] = { 0, -9, 23, 61, -15 };</code></pre>

<p>В данном случае компилятор сам определит размер одномерного массива. В таком определении размер вычисляется по числу инициализаторов. В показанном выше определении без инициализатора размер нужно указать явно.</p>

<h3>Ещё немного про инициализацию массива*</h3>

<p>В С++11 появилась универсальная инициализация (uniform initialization) и теперь можно инициализировать так:</p>

<pre><code class="language-cpp">int a[4]{ 1, 2, 3, 4 };</code></pre>

<p>Для универсальной инициализации также можно использовать =, и различать эти два типа инициализации не всегда просто, а, скорее всего, не очень нужно.</p>

<p>Размер массива можно не указывать, тогда он определится по числу инициализаторов.</p>

<pre><code class="language-cpp">int a[] { 1, 2, 3, 4 };</code></pre>

<p>Если размер массива указан, число инициализаторов не должно превышать его размер. Незаданные элементы агрегата инициализируются из пустого списка. Для встроенного типа <code>int</code> это даёт нули; конструктора у <code>int</code> нет. Для элементов классов применяются правила инициализации соответствующего класса. Поэтому следующий массив целиком заполнен нулями:</p>

<pre><code class="language-cpp">int a[4]{};</code></pre>

<p>При определении массива констант типа int нужно задать инициализатор.</p>

<pre><code class="language-cpp">const int a[4] = { 3, 2, 1 };</code></pre>

<p>Число инициализаторов может быть меньше размера массива: в приведённом выше <code>const int a[4] = {3, 2, 1};</code> последний элемент равен нулю.</p>

<p>Символьные массивы можно инициализировать строковым литералом.</p>

<pre><code class="language-cpp">const char str[] = "meow";
const wchar_t wstr[] = L"meow";</code></pre>

<p>В этих примерах массив содержит пять элементов: четыре символа слова meow и завершающий нулевой символ.</p>

<p> </p>

<h4>Использование псевдонимов при инициализации</h4>

<p>В языке С++ для типов массивов можно вводить псевдонимы. Можно использовать традиционный вариант с ключевым словом <code>typedef</code>:</p>

<pre><code class="language-cpp">typedef int I4[4];</code></pre>

<p>или более современный (C++11) с ключевым словом <code>using</code>:</p>

<pre><code class="language-cpp">using I4 = int[4];</code></pre>

<p>После этого массивы объявляются как простые переменные:</p>

<pre><code class="language-cpp">I4 a, b;</code></pre>

<p>Это будет то же самое, что</p>

<pre><code class="language-cpp">int a[4], b[4];</code></pre>

<h3>Доступ к элементам массива</h3>

<p>Доступ к элементам массива осуществляется через индексатор, значения индекса от <code>0</code> до <code>N-1</code>. Вот пример:</p>

<pre><code class="language-cpp">int a[4]{};
a[0] = 42;
int t = a[3]; // 0: остальные элементы были инициализированы нулями</code></pre>

<p>Выход за границы массива <strong>не контролируется</strong>, ошибка может привести к неопределенному поведению.</p>

<p>В C++11 в стандартной библиотеке появились свободные (<em>не члены</em>) шаблоны функций <code>std::begin()</code> и <code>std::end()</code>. Вызванная для массива <code>std::begin()</code> возвращает указатель на первый элемент массива, <code>std::end()</code> указывает за последний элемент. Такой указатель нельзя разыменовывать. (Начиная с C++14 есть также константные версии: <code>std::cbegin()</code>, <code>std::cend()</code>.) Это позволяет использовать массивы в диапазонном <code>for</code>.</p>

<pre><code class="language-cpp">int a[4]{ 4, 3, 2, 1 };

for (auto t : a) {
    std::cout &lt;&lt; t &lt;&lt; ' ';
}</code></pre>
