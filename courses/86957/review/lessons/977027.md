<p style="text-align: center;"><strong>Приведение типов в C++</strong></p>

<p><strong>Приведение типов в C++ </strong>- это процесс изменения типа данных одного значения на другой тип данных. В некоторых случаях операции могут быть выполнены только с определенными типами данных, поэтому необходимо привести данные к необходимому типу. Приведение типов может быть необходимо, например, при выполнении арифметических операций, при передаче аргументов в функции, при работе с указателями и т.д.</p>

<p>Приведение типов в C++ можно разделить на две категории: <strong>явное</strong> и <strong>неявное</strong>.</p>

<p><strong>     1. Неявное приведение типов.</strong></p>

<p>Неявное преобразование выбирается компилятором по правилам языка и может вычисляться во время выполнения либо при вычислении константного выражения. Оно происходит, когда значения одного типа данных автоматически преобразуются в другой тип данных. Например, если вы пытаетесь сложить целое число с числом с плавающей запятой, то целое число автоматически преобразуется в число с плавающей запятой. Этот тип приведения типов осуществляется в соответствии с правилами, которые определяются стандартом языка C++. Неявное приведение типов может происходить при следующих операциях:</p>

<ul>
	<li>Арифметические операции между значениями разных типов;</li>
	<li>Присваивание значения одного типа переменной другого типа;</li>
	<li>Использование значения переменной в выражении с другими переменными разных типов;</li>
	<li>Передача аргументов функции, которые имеют типы, отличные от типов параметров функции.</li>
</ul>

<p>Пример неявного приведения типов:</p>

<pre><code>int x = 5;
float y = 2.5;
float z = x + y; // целочисленное значение x неявно преобразуется в значение с плавающей запятой, чтобы выполнить операцию сложения</code></pre>

<p><strong>     2. Явное приведение типов.</strong></p>

<p>Явное приведение типов <strong>выполняется программистом</strong> явно в коде программы. Оно используется, когда вам нужно явно указать компилятору, какой тип данных вы хотите использовать для конкретной операции. Ниже перечислены основные формы явного приведения типов.</p>

<p>Существует несколько видов явного приведения типов в c++: </p>

<ul>
	<li>static_cast;</li>
	<li>dynamic_cast;</li>
	<li>const_cast;</li>
	<li>reinterpret_cast;</li>
	<li>C-style cast;</li>
</ul>

<p>Также есть специальные функции преобразования в Qt(<code>qobject_cast</code>, <code>qvariant_cast</code> и <code>qSharedPointerCast)</code>  но рассматриваться они в данном курсе не будут :)</p>

<p>Далее рассмотрим подробнее каждый из них.</p>

<p style="text-align: center;"><strong>static_cast</strong></p>

<p><strong>static_cast</strong> - это оператор приведения типов в C++, который позволяет явно преобразовать значение одного типа в другой. Он может быть использован для преобразования между разными числовыми типами, указателями, ссылками и указателями на члены класса.</p>

<p>Синтаксис static_cast:</p>

<pre><code>static_cast&lt;new_type&gt;(expression)</code></pre>

<p>new_type - новый тип данных, в который нужно преобразовать выражение.</p>

<p>expression - выражение, которое нужно преобразовать.</p>

<p>Примеры:</p>

<p>     1. Преобразование между числовыми типами:</p>

<pre><code>int x = 5;
double y = static_cast&lt;double&gt;(x); // преобразование целочисленного значения в вещественное число
</code></pre>

<p>     2. Преобразование указателей:</p>

<pre><code>int* p = new int(10);
void* q = static_cast&lt;void*&gt;(p); // преобразование указателя int* в указатель void*
</code></pre>

<p>     3. Преобразование ссылок:</p>

<pre><code>struct Base { int value = 5; };
struct Derived : Base {};

Derived object;
Base&amp; base = object;
Derived&amp; derived = static_cast&lt;Derived&amp;&gt;(base); // корректно: base обозначает базовую часть object
// int x = 5; static_cast&lt;double&amp;&gt;(x); // недопустимо: int-объект не является double</code></pre>

<p>     4. Преобразование указателя на базовый класс в указатель на производный класс:</p>

<pre><code>#include &lt;iostream&gt;

class Base {
public:
    virtual ~Base() {}
};

class Derived : public Base {
public:
    void foo() {
    std::cout &lt;&lt; "Derived::foo()" &lt;&lt; std::endl; 
    }
};

int main() {
    Derived object;
    Base* p = &amp;object;
    Derived* q = static_cast&lt;Derived*&gt;(p); // преобразование указателя на базовый класс в указатель на производный класс
    q-&gt;foo(); // вызов функции foo() из класса Derived
}
</code></pre>

<p>static_cast проверяет допустимость категории преобразования при компиляции, но не выполняет динамическую проверку фактического типа объекта при приведении к производному классу. В приведённых примерах известно, что базовая ссылка или указатель относятся к объекту Derived. Если это не так, использование такого приведения может иметь неопределённое поведение. Числовое преобразование int в double создаёт значение double, а не превращает существующий int в объект double.</p>

<p style="text-align: center;"><strong>dynamic_cast</strong></p>

<p><strong>dynamic_cast</strong> - это оператор приведения типов в C++, который позволяет выполнить преобразование между типами во время выполнения программы. Он используется для преобразования указателей и ссылок на базовые классы в указатели и ссылки на их производные классы.</p>

<p>Синтаксис dynamic_cast:</p>

<pre><code>dynamic_cast&lt;new_type&gt;(expression)</code></pre>

<p>new_type - новый тип данных, в который нужно преобразовать выражение.</p>

<p>expression - выражение, которое нужно преобразовать.</p>

<p>Примеры:</p>

<p>     1. Преобразование указателя на базовый класс в указатель на производный класс:</p>

<pre><code>#include &lt;iostream&gt;

class Base {
public:
    virtual ~Base() {}
};

class Derived : public Base {
public:
    void foo() {
    std::cout &lt;&lt; "Derived::foo()" &lt;&lt; std::endl; 
    }
};

int main() {
    Base* p = new Derived();
    Derived* q = dynamic_cast&lt;Derived*&gt;(p); // преобразование указателя на базовый класс в указатель на производный класс
    if (q != nullptr) {
        q-&gt;foo(); // вызов функции foo() из класса Derived
    } else {
        std::cout &lt;&lt; "Invalid cast" &lt;&lt; std::endl;
    }
    delete p;
}
</code></pre>

<p>     2. Проверка корректности преобразования:</p>

<pre><code>#include &lt;iostream&gt;

class Base {
public:
    virtual ~Base() {}
};

class Derived : public Base {
public:
    void foo() {
    std::cout &lt;&lt; "Derived::foo()" &lt;&lt; std::endl;
    }
};

int main() {
    Base* p = new Base();
    Derived* q = dynamic_cast&lt;Derived*&gt;(p); // попытка преобразования указателя на базовый класс в указатель на производный класс
    if (q != nullptr) {
        q-&gt;foo(); // вызов функции foo() из класса Derived
    } else {
        std::cout &lt;&lt; "Invalid cast" &lt;&lt; std::endl; // вывод сообщения об ошибке преобразования
    }
    delete p;
}
</code></pre>

<p>При неудачной проверке приведение к указателю, например <code>dynamic_cast&lt;Derived*&gt;(p)</code>, возвращает nullptr. Приведение к ссылке <code>dynamic_cast&lt;Derived&amp;&gt;(base)</code> вместо этого выбрасывает <code>std::bad_cast</code> (заголовок &lt;typeinfo&gt;). Для проверяемого приведения вниз или поперёк иерархии исходный тип должен быть полиморфным, то есть иметь виртуальную функцию. Преобразование вверх к доступной однозначной базе допустимо и без виртуальных функций. nullptr можно преобразовать в соответствующий нулевой указатель.</p>

<p style="text-align: center;"><strong>const_cast</strong></p>

<p><strong>const_cast</strong> - это оператор приведения типов в C++, который позволяет удалить или добавить константность к выражению. Он используется для преобразования указателей и ссылок на константные объекты в указатели и ссылки на не константные объекты и наоборот.</p>

<p>Синтаксис const_cast:</p>

<pre><code>const_cast&lt;new_type&gt;(expression)</code></pre>

<p>new_type - новый тип данных, в который нужно преобразовать выражение.</p>

<p>expression - выражение, которое нужно преобразовать.</p>

<p>Примеры:</p>

<p>     1. Удаление константности:</p>

<pre><code>#include &lt;iostream&gt;

void print_string(char* str) {
    std::cout &lt;&lt; str &lt;&lt; std::endl;
}

int main() {
    const char* const_str = "Hello, world!";
    char* str = const_cast&lt;char*&gt;(const_str); // удаление константности
    print_string(str); // вызов функции, которая принимает указатель на не константный char
    return 0;
}
</code></pre>

<p>     2. Добавление константности:</p>

<pre><code>#include &lt;iostream&gt;

void print_string(const char* str) {
    std::cout &lt;&lt; str &lt;&lt; std::endl;
}

int main() {
    char str[] = "Hello, world!";
    const char* const_str = const_cast&lt;const char*&gt;(str); // добавление константности
    print_string(const_str); // вызов функции, которая принимает указатель на константный char
    return 0;
}
</code></pre>

<p>Сам const_cast не изменяет объект и не вызывает неопределённого поведения только из-за снятия const. Неопределённое поведение возникает при попытке изменить объект, который изначально является константным, например строковый литерал. В первом примере print_string только читает строку; если бы она записывала в неё, пример был бы некорректным. Для такой читающей функции лучше сразу принимать const char*. Добавление const во втором примере можно выполнить и обычным неявным преобразованием.</p>

<p style="text-align: center;"><strong>reinterpret_cast</strong></p>

<p><strong>reinterpret_cast</strong> - это оператор приведения типов в C++, который позволяет приводить один тип к другому, даже если они не связаны между собой. Он применяется для преобразования указателей и ссылок на один тип в указатели и ссылки на другой тип без изменения значения, которое содержится в памяти.</p>

<p>Синтаксис reinterpret_cast:</p>

<pre><code>reinterpret_cast&lt;new_type&gt;(expression)
</code></pre>

<p>new_type - новый тип данных, в который нужно преобразовать выражение.</p>

<p>expression - выражение, которое нужно преобразовать.</p>

<p>Примеры:</p>

<p>     1. Преобразование указателей:</p>

<pre><code>int x = 10;
int* ptr = &amp;x;
char* char_ptr = reinterpret_cast&lt;char*&gt;(ptr); // приведение указателя на int к указателю на char
</code></pre>

<p>     2. Граница применения: числовое преобразование выполняется через static_cast, а не reinterpret_cast:</p>

<pre><code>double d = 3.14159;
unsigned long long ull = static_cast&lt;unsigned long long&gt;(d); // значение 3
// reinterpret_cast&lt;unsigned long long&gt;(d) не допускается языком.</code></pre>

<p>Если требуется не числовое преобразование, а исследование байтов представления, в C++17 можно скопировать их через std::memcpy в массив unsigned char. В C++20 std::bit_cast переносит представление между тривиально копируемыми типами одинакового размера; он не является числовым преобразованием.</p>

<p>reinterpret_cast допускает только перечисленные стандартом низкоуровневые преобразования. Само преобразование указателя не создаёт объект другого типа и не разрешает произвольно читать память через полученный указатель: должны соблюдаться требования к типу доступа, выравниванию и времени жизни объекта. Некоторые результаты зависят от реализации, но зависимость от платформы сама по себе не означает неопределённое поведение.</p>

<p style="text-align: center;"><strong>C-style cast</strong></p>

<p>C-style cast — унаследованная от C запись явного приведения (T)expression. В C++ она интерпретируется по установленным правилам как const_cast, static_cast, reinterpret_cast либо одна из допустимых комбинаций static_cast/ reinterpret_cast с const_cast. Это не разрешение преобразовать любые два типа: если подходящего разрешённого преобразования нет, программа не компилируется.</p>

<p>Синтаксис C-style cast:</p>

<pre><code>(new_type) expression
</code></pre>

<p>new_type - новый тип данных, в который нужно преобразовать выражение.</p>

<p>expression - выражение, которое нужно преобразовать.</p>

<p>Примеры:</p>

<p>     1. Приведение указателей:</p>

<pre><code>int x = 10;
int* ptr = &amp;x;
char* char_ptr = (char*) ptr; // приведение указателя на int к указателю на char
</code></pre>

<p>     2. Приведение числовых типов:</p>

<pre><code>double d = 3.14159;
unsigned long long ull = (unsigned long long) d; // приведение double к unsigned long long
</code></pre>

<p>В новом C++-коде обычно предпочитают именованные операторы: static_cast, const_cast, reinterpret_cast и dynamic_cast явно показывают намерение и ограничивают набор допустимых преобразований. Это облегчает чтение и проверку кода, но не отменяет требований каждой операции. Например, ни C-style cast, ни reinterpret_cast сами по себе не разрешают доступ к объекту через произвольный несовместимый тип.</p>
