<p style="text-align: center;"><strong>Приведение типов в C++</strong></p>

<p><strong>Приведение типов в C++ </strong>- это процесс изменения типа данных одного значения на другой тип данных. В некоторых случаях операции могут быть выполнены только с определенными типами данных, поэтому необходимо привести данные к необходимому типу. Приведение типов может быть необходимо, например, при выполнении арифметических операций, при передаче аргументов в функции, при работе с указателями и т.д.</p>

<p>Приведение типов в C++ можно разделить на две категории: <strong>явное</strong> и <strong>неявное</strong>.</p>

<p><strong>     1. Неявное приведение типов.</strong></p>

<p>Неявное приведение типов <strong>выполняется автоматически</strong> компилятором во время выполнения программы. Он происходит, когда значения одного типа данных автоматически преобразуются в другой тип данных. Например, если вы пытаетесь сложить целое число с числом с плавающей запятой, то целое число автоматически преобразуется в число с плавающей запятой. Этот тип приведения типов осуществляется в соответствии с правилами, которые определяются стандартом языка C++. Неявное приведение типов может происходить при следующих операциях:</p>

<ul>
	<li>Арифметические операции между значениями разных типов;</li>
	<li>Присваивание значения переменной разных типов;</li>
	<li>Использование значения переменной в выражении с другими переменными разных типов;</li>
	<li>Передача аргументов функции, которые имеют типы, отличные от типов параметров функции.</li>
</ul>

<p>Пример неявного приведения типов:</p>

<pre><code>int x = 5;
float y = 2.5;
float z = x + y; // целочисленное значение x неявно преобразуется в значение с плавающей запятой, чтобы выполнить операцию сложения</code></pre>

<p><strong>     2. Явное приведение типов.</strong></p>

<p>Явное приведение типов <strong>выполняется программистом</strong> явно в коде программы. Он используется, когда вам нужно явно указать компилятору, какой тип данных вы хотите использовать для конкретной операции. Существует два вида явного приведения типов: static_cast и dynamic_cast.</p>

<p>Существует несколько видов явного приведения типов в c++: </p>

<ul>
	<li>static_cast;</li>
	<li>dynamic_cast;</li>
	<li>const_cast;</li>
	<li>reinterpret_cast;</li>
	<li>C-style cast;</li>
</ul>

<p>Так же есть некоторые специальные приведения типов для qt(<code>qobject_cast</code>, <code>qvariant_cast</code> и <code>qSharedPointerCast)</code>  но рассматриваться они в данном курсе не будут :)</p>

<p>Далее рассмотрим подробнее каждый из них.</p>

<p style="text-align: center;"><strong>static_cast</strong></p>

<p><strong>static_cast</strong> - это оператор приведения типов в C++, который позволяет явно преобразовать значение одного типа в другой. Он может быть использован для преобразования между разными числовыми типами, указателями, ссылками и указателями на члены класса.</p>

<p>Синтаксис static_cast:</p>

<pre><code>static_cast&lt;new_type&gt;(expression)</code></pre>

<p>new_type - новый тип данных, в который нужно преобразовать выражение.</p>

<p>expression - выражение, которое нужно преобразовать.</p>

<p>Примеры:</p>

<p>     1. Преобразование между числовыми типами:</p>

<pre><code>int x = 5;
double y = static_cast&lt;double&gt;(x); // преобразование целочисленного значения в вещественное число
</code></pre>

<p>     2. Преобразование указателей:</p>

<pre><code>int* p = new int(10);
void* q = static_cast&lt;void*&gt;(p); // преобразование указателя int* в указатель void*
</code></pre>

<p>     3. Преобразование ссылок:</p>

<pre><code>int x = 5;
double&amp; y = static_cast&lt;double&amp;&gt;(x); // преобразование ссылки на целочисленное значение в ссылку на вещественное число
</code></pre>

<p>     4. Преобразование указателей на члены класса:</p>

<pre><code>class Base {
public:
    virtual ~Base() {}
};

class Derived : public Base {
public:
    void foo() {
    cout &lt;&lt; "Derived::foo()" &lt;&lt; endl; 
    }
};

int main() {
    Base* p = new Derived();
    Derived* q = static_cast&lt;Derived*&gt;(p); // преобразование указателя на базовый класс в указатель на производный класс
    q-&gt;foo(); // вызов функции foo() из класса Derived
}
</code></pre>

<p>Важно отметить, что <strong>static_cast не выполняет проверку корректности преобразования</strong> и может привести к ошибкам во время выполнения программы, если преобразование некорректно. Поэтому при использовании <strong>static_cast </strong>необходимо быть <strong>осторожным</strong> и убедиться в корректности преобразования перед его использованием.</p>

<p style="text-align: center;"><strong>dynamic_cast</strong></p>

<p><strong>dynamic_cast</strong> - это оператор приведения типов в C++, который позволяет выполнить преобразование между типами во время выполнения программы. Он используется для преобразования указателей и ссылок на базовые классы в указатели и ссылки на их производные классы.</p>

<p>Синтаксис dynamic_cast:</p>

<pre><code>dynamic_cast&lt;new_type&gt;(expression)</code></pre>

<p>new_type - новый тип данных, в который нужно преобразовать выражение.</p>

<p>expression - выражение, которое нужно преобразовать.</p>

<p>Примеры:</p>

<p>     1. Преобразование указателя на базовый класс в указатель на производный класс:</p>

<pre><code>class Base {
public:
    virtual ~Base() {}
};

class Derived : public Base {
public:
    void foo() {
    cout &lt;&lt; "Derived::foo()" &lt;&lt; endl; 
    }
};

int main() {
    Base* p = new Derived();
    Derived* q = dynamic_cast&lt;Derived*&gt;(p); // преобразование указателя на базовый класс в указатель на производный класс
    if (q != nullptr) {
        q-&gt;foo(); // вызов функции foo() из класса Derived
    } else {
        cout &lt;&lt; "Invalid cast" &lt;&lt; endl;
    }
}
</code></pre>

<p>     2. Проверка корректности преобразования:</p>

<pre><code>class Base {
public:
    virtual ~Base() {}
};

class Derived : public Base {
public:
    void foo() {
    cout &lt;&lt; "Derived::foo()" &lt;&lt; endl;
    }
};

int main() {
    Base* p = new Base();
    Derived* q = dynamic_cast&lt;Derived*&gt;(p); // попытка преобразования указателя на базовый класс в указатель на производный класс
    if (q != nullptr) {
        q-&gt;foo(); // вызов функции foo() из класса Derived
    } else {
        cout &lt;&lt; "Invalid cast" &lt;&lt; endl; // вывод сообщения об ошибке преобразования
    }
}
</code></pre>

<p>Важно отметить, что <strong>dynamic_cast выполняет проверку корректности преобразования во время выполнения программы</strong> и возвращает нулевой указатель (nullptr), если преобразование некорректно. Поэтому при использовании<strong> dynamic_cast</strong> необходимо быть осторожным и проверять корректность преобразования перед его использованием. Кроме того, для использования <strong>dynamic_cast</strong> класс должен содержать <strong>хотя бы один виртуальный метод.</strong></p>

<p style="text-align: center;"><strong>const_cast</strong></p>

<p><strong>const_cast</strong> - это оператор приведения типов в C++, который позволяет удалить или добавить константность к выражению. Он используется для преобразования указателей и ссылок на константные объекты в указатели и ссылки на не константные объекты и наоборот.</p>

<p>Синтаксис const_cast:</p>

<pre><code>const_cast&lt;new_type&gt;(expression)</code></pre>

<p>new_type - новый тип данных, в который нужно преобразовать выражение.</p>

<p>expression - выражение, которое нужно преобразовать.</p>

<p>Примеры:</p>

<p>     1. Удаление константности:</p>

<pre><code>void print_string(char* str) {
    cout &lt;&lt; str &lt;&lt; endl;
}

int main() {
    const char* const_str = "Hello, world!";
    char* str = const_cast&lt;char*&gt;(const_str); // удаление константности
    print_string(str); // вызов функции, которая принимает указатель на не константный char
    return 0;
}
</code></pre>

<p>     2. Добавление константности:</p>

<pre><code>void print_string(const char* str) {
    cout &lt;&lt; str &lt;&lt; endl;
}

int main() {
    char str[] = "Hello, world!";
    const char* const_str = const_cast&lt;const char*&gt;(str); // добавление константности
    print_string(const_str); // вызов функции, которая принимает указатель на константный char
    return 0;
}
</code></pre>

<p>Важно отметить, чт<strong>о const_cast может привести к неопределенному поведению программы</strong>, если константность удалена из выражения, которое в действительности является константным. Поэтому при использовании<strong> const_cas</strong>t необходимо быть осторожным и убедиться, что удаление или добавление константности безопасно для программы.</p>

<p style="text-align: center;"><strong>reinterpret_cast</strong></p>

<p><strong>reinterpret_cast</strong> - это оператор приведения типов в C++, который позволяет приводить один тип к другому, даже если они не связаны между собой. Он применяется для преобразования указателей и ссылок на один тип в указатели и ссылки на другой тип без изменения значения, которое содержится в памяти.</p>

<p>Синтаксис reinterpret_cast:</p>

<pre><code>reinterpret_cast&lt;new_type&gt;(expression)
</code></pre>

<p>new_type - новый тип данных, в который нужно преобразовать выражение.</p>

<p>expression - выражение, которое нужно преобразовать.</p>

<p>Примеры:</p>

<p>     1. Преобразование указателей:</p>

<pre><code>int x = 10;
int* ptr = &amp;x;
char* char_ptr = reinterpret_cast&lt;char*&gt;(ptr); // приведение указателя на int к указателю на char
</code></pre>

<p>     2. Преобразование числовых типов:</p>

<pre><code>double d = 3.14159;
unsigned long long ull = reinterpret_cast&lt;unsigned long long&gt;(d); // приведение double к unsigned long long
</code></pre>

<p>Однако <strong>следует быть осторожным </strong>при использовании<strong> reinterpret_cast</strong>, так как он может привести к неопределенному поведению программы, если производится приведение типов, которые несовместимы между собой или если результаты приведения зависят от аппаратной платформы. Поэтому использование <strong>reinterpret_cast</strong> должно быть ограничено только к тем случаям, когда это <strong>абсолютно необходимо</strong> и когда разработчик <strong>полностью понимает риски</strong> такого приведения типов.</p>

<p style="text-align: center;"><strong>C-style cast</strong></p>

<p><strong>C-style cast</strong> (или старый стиль приведения типов) - это устаревший способ приведения типов в C++. Он является эквивалентом использования нескольких операторов приведения типов вместе (static_cast, reinterpret_cast, const_cast), и позволяет производить приведение между любыми типами, даже если они несовместимы между собой.</p>

<p>Синтаксис C-style cast:</p>

<pre><code>(new_type) expression
</code></pre>

<p>new_type - новый тип данных, в который нужно преобразовать выражение.</p>

<p>expression - выражение, которое нужно преобразовать.</p>

<p>Примеры:</p>

<p>     1. Приведение указателей:</p>

<pre><code>int x = 10;
int* ptr = &amp;x;
char* char_ptr = (char*) ptr; // приведение указателя на int к указателю на char
</code></pre>

<p>     2. Приведение числовых типов:</p>

<pre><code>double d = 3.14159;
unsigned long long ull = (unsigned long long) d; // приведение double к unsigned long long
</code></pre>

<p>Однако, <strong>C-style cast</strong> является не рекомендуемым способом приведения типов, так как он <strong>не является безопасным</strong>. Он может привести к неопределенному поведению программы, если приведение типов несовместимо, а также может затруднить чтение и понимание кода. Вместо использования <strong>C-style cast</strong> лучше использовать более безопасные и понятные операторы приведения типов в C++, такие как <strong>static_cast</strong>, <strong>const_cast</strong> и <strong>reinterpret_cast</strong>.</p>
