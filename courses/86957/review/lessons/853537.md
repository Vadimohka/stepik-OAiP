<h3><strong>Shared_ptr и weak_ptr</strong></h3>

<p><code>std::unique_ptr</code> хорош, но он не подходит для ситуаций, когда несколько объектов должны работать с общим ресурсом и когда этот ресурс должен быть автоматически выгружен из памяти, когда все объекты освобождают его.</p>

<p>В таких случаях используется <code>std::shared_ptr</code>: несколько владельцев разделяют один блок управления. В нём учитываются сильные ссылки (shared_ptr) и слабые ссылки (weak_ptr). Копирование shared_ptr увеличивает число сильных владельцев, уничтожение или reset уменьшает его. Когда сильных владельцев не осталось, управляемый объект уничтожается. Сам блок управления продолжает жить, пока на него ссылаются weak_ptr: им необходимо безопасно определять, что объект уже уничтожен.</p>

<pre><code class="language-cpp">#include &lt;iostream&gt;
#include &lt;memory&gt;

struct X {};

int main() {
    auto ptr = std::make_shared&lt;X&gt;();
    {
        auto ptr2 = ptr;
        std::cout &lt;&lt; ptr.use_count() &lt;&lt; '\n'; // 2
    }
    std::cout &lt;&lt; ptr.use_count() &lt;&lt; '\n'; // 1
} // последний shared_ptr уничтожается, затем уничтожается X</code></pre>

<p>В некоторых ситуациях объект A может ссылаться на объект B, и наоборот, создавая таким образом циклическую ссылку (cyclic reference/circular dependency). Это может привести к тому, что оба объекта никогда не будут выгружены из памяти.</p>

<p>Чтобы разорвать цикл владения, одну из связей можно сделать <code>std::weak_ptr</code>. Он не увеличивает число сильных владельцев и не продлевает жизнь объекта, но удерживает блок управления. Метод <code>lock()</code> пытается получить shared_ptr: если сильный владелец ещё существует, результат удерживает объект; если объект уже уничтожен, результат пуст. У std::weak_ptr эта проверка и получение сильной ссылки выполняются атомарно. Отдельная проверка expired() не заменяет lock(), когда другой поток может освободить последнего владельца.</p>

<p>Таким образом, shared_ptr владеет объектом, а weak_ptr лишь наблюдает за ним. Чтобы использовать объект через слабую ссылку, сначала получите локальный shared_ptr с помощью lock() и проверьте его. После обнуления числа сильных владельцев воскресить объект через weak_ptr нельзя.</p>

<h3>Учебная реализация общего и слабого владения</h3>

<p>Объект T и блок управления имеют разные времена жизни. Ниже используется простая <strong>однопоточная</strong> схема с двумя счётчиками: strong — число shared_ptr; weak — число weak_ptr плюс одна служебная слабая ссылка, пока сохраняется сильное владение или выполняется уничтожение T. Поэтому новый блок получает счётчики strong = 1, weak = 1. При переходе strong к нулю сначала уничтожается T, затем освобождается служебная слабая ссылка. Блок удаляется только при переходе weak к нулю. Эта служебная ссылка нужна, в частности, если у T есть weak_ptr на самого себя: уничтожение этого поля не должно удалить блок посреди деструктора T. В стандартной библиотеке внутреннее представление может отличаться, но слабые ссылки также должны безопасно переживать объект.</p>

<p>При копировании shared_ptr увеличивается strong, при копировании weak_ptr — weak. Перемещение передаёт ссылку на блок, не меняя счётчик. Присваивание сначала получает новое владение, затем освобождает прежнее; в примере это обеспечивается передачей параметра по значению и swap. Уничтожение weak_ptr не удаляет T, но может удалить уже ненужный блок управления.</p>

<p>lock() при strong == 0 возвращает пустой shared_ptr. Пока strong больше нуля, он увеличивает счётчик и возвращает нового владельца. В однопоточной версии между этими действиями нет другого потока. Для настоящей многопоточной реализации нужна атомарная операция получения сильной ссылки; простая замена двух счётчиков на atomic сама по себе не делает весь алгоритм правильным. В прикладном коде используйте std::shared_ptr и std::weak_ptr.</p>

<pre><code class="language-cpp">#include &lt;cstddef&gt;
#include &lt;utility&gt;

namespace teaching {

template&lt;class T&gt;
struct control_block {
    T* value;
    std::size_t strong;
    std::size_t weak;
};

template&lt;class T&gt; class weak_ptr;

template&lt;class T&gt;
class shared_ptr {
    control_block&lt;T&gt;* control_ = nullptr;
    struct counted_t {};
    shared_ptr(control_block&lt;T&gt;* p, counted_t) noexcept : control_(p) {}
    friend class weak_ptr&lt;T&gt;;

    void release() noexcept {
        if (control_ &amp;&amp; --control_-&gt;strong == 0) {
            T* value = std::exchange(control_-&gt;value, nullptr);
            delete value; // служебная слабая ссылка удерживает блок
            if (--control_-&gt;weak == 0) delete control_;
        }
        control_ = nullptr;
    }

public:
    shared_ptr() noexcept = default;

    explicit shared_ptr(T* p) {
        if (!p) return;
        try {
            control_ = new control_block&lt;T&gt;{p, 1, 1};
        } catch (...) {
            delete p;
            throw;
        }
    }

    shared_ptr(const shared_ptr&amp; other) noexcept : control_(other.control_) {
        if (control_) ++control_-&gt;strong;
    }
    shared_ptr(shared_ptr&amp;&amp; other) noexcept
        : control_(std::exchange(other.control_, nullptr)) {}
    shared_ptr&amp; operator=(shared_ptr other) noexcept {
        swap(other);
        return *this;
    }
    ~shared_ptr() { release(); }

    void swap(shared_ptr&amp; other) noexcept { std::swap(control_, other.control_); }
    void reset() noexcept { shared_ptr{}.swap(*this); }
    std::size_t use_count() const noexcept { return control_ ? control_-&gt;strong : 0; }
    T* get() const noexcept { return control_ ? control_-&gt;value : nullptr; }
    explicit operator bool() const noexcept { return get() != nullptr; }
    T&amp; operator*() const { return *get(); } // только для непустого указателя
    T* operator-&gt;() const noexcept { return get(); }
};

template&lt;class T&gt;
class weak_ptr {
    control_block&lt;T&gt;* control_ = nullptr;

    void release() noexcept {
        if (control_ &amp;&amp; --control_-&gt;weak == 0) {
            delete control_;
        }
        control_ = nullptr;
    }

public:
    weak_ptr() noexcept = default;
    weak_ptr(const shared_ptr&lt;T&gt;&amp; owner) noexcept : control_(owner.control_) {
        if (control_) ++control_-&gt;weak;
    }
    weak_ptr(const weak_ptr&amp; other) noexcept : control_(other.control_) {
        if (control_) ++control_-&gt;weak;
    }
    weak_ptr(weak_ptr&amp;&amp; other) noexcept
        : control_(std::exchange(other.control_, nullptr)) {}
    weak_ptr&amp; operator=(weak_ptr other) noexcept {
        swap(other);
        return *this;
    }
    ~weak_ptr() { release(); }

    void swap(weak_ptr&amp; other) noexcept { std::swap(control_, other.control_); }
    void reset() noexcept { weak_ptr{}.swap(*this); }
    std::size_t use_count() const noexcept { return control_ ? control_-&gt;strong : 0; }
    bool expired() const noexcept { return use_count() == 0; }

    shared_ptr&lt;T&gt; lock() const noexcept {
        if (!control_ || control_-&gt;strong == 0) return {};
        ++control_-&gt;strong;
        return shared_ptr&lt;T&gt;(control_, typename shared_ptr&lt;T&gt;::counted_t{});
    }

    bool same_owner(const weak_ptr&amp; other) const noexcept {
        return control_ == other.control_;
    }
};

} // namespace teaching</code></pre>

<p>Это учебный вариант для одиночного объекта, переданного из new T: в нём нет пользовательских deleter, массивов, aliasing-конструкторов и межтиповых преобразований стандартной библиотеки. Один сырой указатель нельзя передавать в два независимых shared_ptr. Функция same_owner сравнивает принадлежность к блоку управления; сравнение адресов объектов и сравнение владения — разные операции.</p>

<p>Пример после определений классов выше:</p>
<pre><code class="language-cpp">#include &lt;iostream&gt;

int main() {
    teaching::weak_ptr&lt;int&gt; observer;
    {
        teaching::shared_ptr&lt;int&gt; owner(new int(42));
        observer = owner;
        auto second_owner = observer.lock();
        std::cout &lt;&lt; owner.use_count() &lt;&lt; '\n'; // 2
    } // int уничтожен; observer ещё удерживает блок управления
    auto result = observer.lock();
    std::cout &lt;&lt; std::boolalpha &lt;&lt; observer.expired() &lt;&lt; '\n'; // true
    std::cout &lt;&lt; static_cast&lt;bool&gt;(result) &lt;&lt; '\n'; // false
} // последний weak_ptr освобождает блок управления</code></pre>
