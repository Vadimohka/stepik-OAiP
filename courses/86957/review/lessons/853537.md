<h3><strong>Shared_ptr и weak_ptr</strong></h3>

<p><code>std::unique_ptr</code> хорош, но он не подходит для ситуаций, когда несколько объектов должны работать с общим ресурсом и когда этот ресурс должен быть автоматически выгружен из памяти, когда все объекты освобождают его.</p>

<p>В таких случаях следует использовать <code>std::shared_ptr.</code>Этот умный указатель разрешает объекту иметь несколько владельцев, а когда все владельцы уничтожаются, уничтожается и объект. Такое поведение достигается за счёт наличия специального счётчика ссылок внутри <code>std::shared_ptr.</code> Каждый раз, когда такой указатель копируется, счётчик инкрементируется, а когда один из указателей уничтожается – декрементируется. В момент, когда счётчик достигает нуля, объект уничтожается. Посмотрим на код:</p>

<pre><code class="language-cpp">{
    std::shared_ptr&lt;x&gt; ptr =  std::make_shared&lt;x&gt;(); // Создаётся объект
    {
        std::shared_ptr&lt;x&gt; ptr2 = ptr; // Тепеpь у объекта два владельца,
                                       // Выраженных в виде ptr и ptr2
    } // ptr2 выходит из области видимости, но объект не освобождается
      // потому что есть ptr, который по-прежнему ссылается на него
} // ptr выходит из области видимости, и объект уничтожается</code></pre>

<p>В некоторых ситуациях объект A может ссылаться на объект B, и наоборот, создавая таким образом циклическую ссылку (cyclic reference/circular dependency). Это может привести к тому, что оба объекта никогда не будут выгружены из памяти.</p>

<p>Чтобы избежать этой проблемы, можно использовать<code> std::weak_ptr</code>. Этот умный указатель не владеет объектом и предназначен для использования вместе с <code>std::shared_ptr.</code> Копирование <code>std::weak_ptr</code> не увеличивает счётчик ссылок в<code>std::shared_ptr</code>, поэтому не защищает объект от уничтожения. Однако всегда можно проверить, существует ли объект, на который ссылается<code>std::weak_ptr.</code></p>

<p>В целом, использование<code>std::weak_ptr</code> необходимо, когда нужно ссылаться на управляемый объект <code>std::shared_ptr</code>, но при этом не нужно защищать его от уничтожения.</p>

<h3>Реализация</h3>

<p>Для реализации аналога <code>weak_ptr</code>, за основу можно взять класс <code>shared_ptr</code>.</p>

<p>1.     Необходимо добавить блок управления, а именно счетчик ссылок на выделенную память. К примеру: int* m_references_count; Этот указатель далее можно передавать при копировании, инкрементируя его.</p>

<p>2.     Можно снова разрешить конструкторы копирования, которые будут выполнять поверхностное копирование, а после инкрементировать счетчик.</p>

<p>3.     При вызове деструктора, или при копировании поверх уже имеющихся данных, вызывается функция удаления, которая декрементирует счетчик, и удаляет значения и сам счетчик, если количество ссылок нулевое.</p>

<p>4.     Теперь надо реализовать класс weak_ptr и подружить наши классы. Для этого надо перед определением классов, добавить определение другого без реализации.</p>

<pre><code class="language-cpp">template&lt;class T&gt;
class shared_ptr;

template&lt;class T&gt;
class weak_ptr {
    T* m_ptr;
    int* m_references_count;

    friend class shared_ptr&lt;T&gt;;
...</code></pre>

<pre><code class="language-cpp">template&lt;class T&gt;
class weak_ptr;

template&lt;class T&gt;
class shared_ptr {
    T* mptr;
    int* m_ references_count;

    friend class weak_ptr&lt;T&gt;;
...</code></pre>

<p>5.     Класс <code>weak_ptr </code>не имеет переопределенных операторов разыменовывания, а так же в нем не вызывается функция удаления, т.к он является не владеющим.</p>

<p>6.     В обоих классах необходимо реализовать конструкторы копирования, и операторы присваивания копированием, принимающими в качестве аргумента своего друга.</p>

<pre><code class="language-cpp">shared_ptr(weak_ptr&lt;T&gt;&amp; x);

shared_ptr&amp; operator=(weak_ptr&lt;T&gt;&amp; x)

weak_ptr(shared_ptr&lt;T&gt;&amp; x)

weak_ptr&amp; operator=(shared_ptr&lt;T&gt;&amp; x)</code></pre>

<p>7.     Осталось реализовать метод <code>lock()</code> для <code>weak_ptr</code>, который будет возвращать <code>shared_ptr</code>, из которого уже можно обращаться к данным.</p>

<pre><code class="language-cpp">shared_ptr&lt;T&gt; lock() {
    return shared_ptr&lt;T&gt;(*this);
}</code></pre>

<p>8.     Для удобства можно сделать метод сравнивающий два объекта, к примеру:</p>

<pre><code class="language-cpp">bool equals(weak_ptr ptr) {
    return m_ptr == ptr.m_ptr;
}</code></pre>
